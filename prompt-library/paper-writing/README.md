# 论文写作 AI 提示词资料集（Paper-Writing Prompt Library）

> 这是 `research-skillbox` 仓库里的**提示词资料**，不是技能（没有 `SKILL.md`，不会被注册）。
> 存放目的只有一个：把网络流传的论文写作提示词原文集中成可复制的包，供粘贴到
> ChatGPT / DeepSeek 等网页端使用。

## 一句话定位

不教你怎么写论文，直接给你**能用的提示词**。所有模板原文保留（含 `【XX】`、`[ ]` 等
变量占位符），复制、填空、执行即可。

> 方法论层面的内容不在本目录。写论文、文献综述、去 AI 味、文献精读分别由
> `skills/research-paper-writing/`、`skills/academic-deai-writing/`、
> `skills/critical-paper-reading/` 承担，那些是技能，会主动介入任务。

## 使用原则

1. **选模板 → 替换变量 → 分步执行**。不要一次把全文扔给 AI，按环节选用模板，替换占位符后逐节推进。
2. **迭代优于一次生成**。润色、降 AIGC 类任务多轮迭代（每轮针对一个维度），效果好于单轮。
3. **事实核验**。文献综述、引用类产出必须逐条核实文献真实性与原文内容，AI 幻觉在此环节最常见。
4. **区分查重与降 AIGC**。查重（重复率）与 AIGC 率是两套检测、两套对策，提示词里常被混为一谈，使用时留意方案的实际目标。
5. **学术诚信**。降 AIGC / 降重技巧只用于改进表达质量，不得用于掩盖实质性 AI 代写；使用须遵守所在机构与期刊的披露要求。
