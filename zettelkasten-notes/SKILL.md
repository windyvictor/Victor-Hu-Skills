# zettelkasten-notes（卡片盒笔记法）

## 核心思想

卡片盒不是仓库，是**生产线**。三个关键词构成闭环：**写**（用自己的话写独立可复用的卡片）→ **连**（新旧卡片连接，知识成网络）→ **长**（主题卡片足够多、连接足够密时，文章自然"长"出来）。卢曼 30 年写约 9 万张卡片，出版 58 本专著+数百篇论文，成本为零——不靠意志力硬撑，靠系统。

三条铁律（违反任意一条，系统即失效）：
1. **用自己的话复述**，不摘抄。摘抄 = 去语境化的信息搬运；复述 = 强制理解 + 可被检索调用。
2. **一卡一想法**（原子化）。每张卡只含一个互斥概念，自足可读，脱离原文也看得懂。
3. **每张新卡都写进已有卡片网络的语境里**——先找相关旧卡，再决定新卡怎么写、连到哪。不预设主题文件夹（按主题分类会导致"往哪放"的两难，连接比分类更重要）。

## 标准工作流（一次完整的"阅读→卡片→输出"）

1. **捕获**：阅读/闪念出现 → 随手记闪念笔记（卡片/手机，形式不限），当天或隔天处理。
2. **文献笔记**：精读时用自己的话写复述（完整句子）+ 标注出处页码；只记真正触动且与自身问题相关的内容。
3. **永久笔记**：每日固定时段翻闪念与文献笔记 → 把有长期价值的想法写成自足的永久卡 → 找相关旧卡建立双向链接 → 打标签（场景标签优先于主题文件夹）。
4. **生长**：永久卡积累形成主题集群；为成型的集群建索引页（不是分类目录，是入口/综述）。
5. **回顾**：每周迁移一次（子弹笔记机制强制反思）+ 随机/定期回顾三问。
6. **输出**：写作时按集群调卡 → 排序 → 补缺（缺什么再去定向读什么）→ 初稿。产出素材不足不是缺陷，是系统在告诉你该读什么。

## 写一张合格永久卡的判据

- 一句话能概括（标题化，"以后我会在什么情况下偶然遇到它"的措辞）
- ≤300 字、自足可读、可直接引用进文章
- 有 ≥1 条到既有卡片的链接，或说明"与哪张卡矛盾"
- 标注来源（读到的书/文章）或标记"原创想法"

## 完成前自检

- [ ] 每张卡都是用户自己的话复述，没有大段摘抄
- [ ] 一卡一想法；卡片自足可读（不看原文也能懂）
- [ ] 每张新卡都有与已有卡片网络的显式连接（链接/提及）
- [ ] 没有为新卡预设主题文件夹；用标签+链接组织
- [ ] 闪念笔记有明确的处理时限，没有无限堆积
- [ ] 有回顾安排（至少周度迁移或回顾三问）
- [ ] 最终指向输出（文章/项目/决策），不是"收藏"
