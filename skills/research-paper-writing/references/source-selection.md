# 文献来源选择与选题策略

来源：《论文成长笔记》（2025 版）、《论文白皮书》、《硕博论文写作与研究方法全攻略 3.0》。适用于国内学术语境（示例以法学/社科为主，原则可平移到理工科）。

---

## 一、综述文献不必穷尽，但要"有目的地挑"

核心期刊分层（人文社科，按认可度从高到低）：

| 层级 | 说明 | 综述价值 |
|------|------|---------|
| 学科顶刊（如法学《中国社会科学》《中国法学》《法学研究》） | 前沿性与权威性兼备 | 必综述，选材最可信 |
| CLSCI（22 本专业核心） | 学科领先期刊 | 必综述，代表学科核心方向 |
| CSSCI 来源期刊（C 刊） | 人文社科"硬通货" | 必综述，把握主流观点 |
| C 扩 / CSSCI 集刊 | 认可度略低于 C 刊，各校认定不一 | 补充参考 |
| 非对口学科的专业 C 刊 | 学科交叉（如"税制改革"涉法学+经济学） | 交叉选题应跨学科综述，拓宽视野 |
| 高校学报 / 综合社科 C 刊 | 人文社科共通话题 | 补充不同学科的研究思路与方法 |

理工科对应思路：CCF/中科院分区、领域顶会（CVPR、NeurIPS 等）+ 顶刊，逻辑相同——先顶刊顶会，再扩展。

**如何判断是否权威期刊**（人文社科）：参考中国人文社会科学期刊 AMI 综合评价报告（2022）；报告中标注"顶级""权威"字样的即为国内认可；知网期刊介绍页右上角也会标注"AMI 顶级""AMI 权威"。

**紧跟代表性作者**：领域内发表量大、引用率居高不下的学者即代表性作者，沿其论文脉络探索可迅速掌握研究现状与前沿方向；利用知网"作者"检索项定期查看这些作者的新文章，跟进前沿动态。同领域其他高价值检索项：基金（以基金名检索可获高度相关文献）、文献来源、通讯作者等——不要只用"主题"一项。

## 一·补：选题类型决定文献策略的三种划分维度

| 维度 | 类型 | 应对 |
|------|------|------|
| **创新程度** | 开拓性选题（前人未写过） | 资料少、发挥余地大但风险高；资料收集至关重要——收集到他人未掌握的资料才可动笔 |
|  | 推进性选题（前人研究充分） | 资料多、基础好，但创新困难甚至论题枯竭；必须调整思路、另辟蹊径 |
| **题目大小** | 小题大作（**推荐**） | 题目越小越能反映研究的深入程度；博士论文选题的演变趋势即"由章标题→四级/五级标题" |
| **性质** | 理论性选题 vs 实践性选题 | 学术型学位论文宜理论性题目；专业学位/应用型学位宜实践性题目 |

中外选题差异须注意：某题目在甲国"太大不可作"，在乙国可能恰是前沿（与学术成熟度相关），取决于该国对问题的研究深度。

**选题的五条检验标准**（"不可自嗨"）：①导师是否认可；②自己是否胜任；③操作是否可行（数据可得性、实验跨度、结果可靠性、资料可查性）；④是否符合自己的研究领域；⑤是否有创新性（视角创新／理论创新／研究方法或模式创新）。

## 二、重要图书（人文学科尤其重要）

1. **知名学者专著与译著**：系统了解领域理论体系与研究脉络。
2. **权威版本著作**：经典作家的著作须用最新、最权威版本，确保引用准确。
3. **法律解释书**（法学）：新法律出台后的立法释义，理解法条含义与适用方法的重要依据。

## 三、各来源的使用边界

| 来源 | 是否综述 | 要点 |
|------|---------|------|
| 权威专业报纸（《光明日报》《人民日报》《中国社会科学报》《法治日报》等） | 部分学科可用 | 马理论、新闻传播等学科有价值；优先权威性、专业性 |
| 普刊、"水刊" | **坚决不用** | 审稿不严、质量参差，浪费精力且误导方向 |
| 硕博论文 | 毕业论文可适度引用；期刊论文尽量避免 | 数量不宜多；可借其学习研究思路、方法与写作技巧 |
| 网站资料 / 微信公众号 | 尽量不用 | 多为发散观点，缺乏学理性；刊物较忌讳；仅权威官网的政策解读、研究报告可少用 |
| 法律法规政策 | **全面收集，而非"综述"** | 研究某法条须收集齐全立法历程、修订情况、司法解释与规范性文件——是研究前提，不是可综述可不综述的材料 |

## 四、选题类型 → 文献策略匹配

| 选题类型 | 文献与资料策略 |
|---------|---------------|
| **基本原理 / 基础理论类**（宏观、中观） | 尽可能广泛搜集，文献越多越好；对知识储备与综合能力要求高，不适合初学者 |
| **具体制度规则 / 政策类** | 国内外文献 + 典型案例资料（提供实践依据） |
| **热点问题、新兴论题类**（"双碳""共同富裕"式选题） | 兼顾国内外动态，密切关注最新成果 + 案例资料 |

问题来源二元架构：**基本问题**（学科发展中的理论沉淀，多见于基础理论研究）与**具体问题**（社会实践中的现实映照，对策性强）。综述前先判断自己的研究问题属于哪一维。

## 五、新旧选题的综述方式差异

- **旧选题**（已被大量研究）：综述必须详尽全面，系统梳理并客观评价现有成果的优缺点，在此基础上写出新意——新观点、新视角、新理论，"新瓶装旧酒"。只有综述体现创新性，选题才有写作与发表意义。
- **新选题**（新兴或几乎无人涉足）：综述重在**论证选题的必要性、重要性与可行性**，让读者认识研究价值。

## 六、质量自查（综述合格线）

学位论文综述合格的基本要求：全面涵盖相关领域的研究现状，并分析前人研究的不足之处。仅"涵盖了"不分析不足，仍属"文献综述不足"的高频退修原因。
