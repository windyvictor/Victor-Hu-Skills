# 好论文的结构与方法论：核心知识笔记

> 来源：Turabian《A Manual for Writers》(9th ed.)、Mensh & Kording《Ten Simple Rules for Structuring Papers》(2017)、《How to Write a Research Paper》、《Handbook for Writing Research Paper》

## 一、好论文的判断标准与核心原则

### Ten Simple Rules 的十条规则（Mensh & Kording）

**总体原则（Rules 1–4，适用于论文所有尺度：句子、段落、章节、全文）：**

1. **聚焦单一核心贡献，用标题传达它**。读者一年后仍能向同事复述你论文的主要贡献，才算成功。同时主打多个贡献的论文对每个都不够有说服力。标题是论文最重要的元素（读标题数 >> 读全文数），尽早拟标题并反复打磨，它还能反过来帮你聚焦研究与写作。
2. **为不了解你工作的真实人类写作**。你是自己工作最了解的人，也就最没资格从"天真读者"视角判断自己的文章。定义术语、少用缩写、尊重工作记忆限制（减少读者需同时记住的"悬空线索"）。
3. **坚持 C-C-C 结构（Context–Content–Conclusion）**。开头设语境、中段推进内容、结尾给出结论，避免读者问"为什么告诉我这个？"（缺 context）或"所以呢？"（缺 conclusion）。C-C-C 应贯穿全文（引言设语境、结果是内容、讨论收结论）、也贯穿段落（首句立主题、尾句给结论）。
4. **优化逻辑流：避免来回跳转（zig-zag），善用平行结构**。除中心思想外，每个话题只在一个地方讲完；相似的观点连续陈述；平行的信息用平行的句式表达。同一个概念坚持用同一个词，不要为了"换着说"而引起歧义。

**组件规则（Rules 5–8）：**

5. **摘要是完整的故事**——多数读者只读摘要，它必须独立传达全文信息（见下文摘要写法）。
6. **引言回答"这篇论文为什么重要"**——逐段收窄，落在文献空白（gap）上。
7. **结果是一条逻辑陈述链，配图支撑中心主张**——图标题应传达结论，图例说明方法。
8. **讨论说明空白如何被填补、解释的局限、以及对领域的意义**。

**过程规则（Rules 9–10）：**

9. **把时间花在刀刃上：标题、摘要、图、提纲**。看标题、摘要、图的人数远多于读正文的人，读方法部分的人最少，时间投入要按比例分配。
10. **通过反馈反复迭代故事（reduce, reuse, recycle）**。写作是同时优化"故事—提纲—句子"的迭代过程；整段推翻重写常常比逐句修补更快。如果你几分钟内向同事讲不清论文大纲，读者更讲不清。

**各规则被违反的信号：** 读者给不出一句话总结（违 1）；读者没"get"到论文（违 2）；读者问"这有什么意义"（违 3）；读者在局部卡壳（违 4）；读完摘要说不出 elevator pitch（违 5）；读者毫无兴趣（违 6）；读者不认同你的结论（违 7）；读者留下未解答的质疑（违 8）。

### 其他三本书对"好论文"的标准

- 论文是**论证**而非资料汇编："a research paper analyzes a perspective or argues a point"——必须有可论证的 thesis，而非事实陈述（"爱因斯坦发明相对论"不可论证，不是好 thesis）。
- 写作前先回答三问（Handbook）：**我为什么要写这篇？我的论文想说什么？说给谁听？** 聚焦的论文优于面面俱到的论文。
- 论文的价值判据：是否是新信息？是否值得说？结论是否已被证据坐实（而非猜想）？

## 二、论文整体架构：漏斗/沙漏模型

**沙漏模型（Handbook，hourglass model）**：引言从宽泛领域收窄到具体研究问题 → 主体（方法与结果）保持最窄的主题范围 → 讨论再从具体结果扩展到一般性结论。**论证应是环形的**：结论要回到开篇，用研究呈现的证据重新审视最初提出的目的（Berry）。

**King 模型（扩展沙漏）**把标题、摘要、参考文献纳入结构。论文各部分的职责分工：

| 部分 | 职责 | 一句话判据 |
|---|---|---|
| 标题 | 宣布主题 + 传达概念框架 | 描述性、信息性、含关键词 |
| 摘要 | 独立完整的全文缩影 | 动机—问题—方法—结果—结论 |
| 引言 | 从领域收窄到研究问题，说明意义 | 领域→空白→本文 |
| 主体/结果 | 证据、事实、细节 | 每段回答一个小问题 |
| 讨论/结论 | 解释结果意味着什么、为什么 | 从具体到一般，呼应引言但不重复 |

**IMRaD 组织**（Turabian：实验科学读者期待 Introduction—Methods and Materials—Results—Discussion—Conclusion）：遵循领域惯例即可，非实验领域则需用"故事板/大纲"自建读者能理解的计划。

**组织论文的方法（Turabian 第 6 章）：**
- 提纲以完整句子为佳：I. 主张 → II/III. 各条 reason → A/B. 每条 reason 的证据摘要 → 1/2. 证据本身。
- **关键术语贯穿全文**：在引言中圈出 4–5 个表达核心概念的词，全文反复出现（不必每次），读者才会觉得论文连贯；若找不到这样的词，说明主题太泛。
- 排序方式应服务读者（时间序、质量序、重要性序），而不是你阅读文献的顺序。

## 三、引言的经典写法（漏斗模型，逐段拆解）

### Handbook/Climb's 三阶段（Create Research Space 模式）

1. **Establish a territory（建立领域）**：指出主题重要性 / 概述该主题的一般陈述 / 综述当前研究。
2. **Establish a niche（建立空位）**：反驳既有假设 / **揭示研究空白** / 提出研究问题 / 延续某一传统。
3. **Occupy the niche（占领空位）**：说明本文意图 / 列出本文工作的关键特征 / 概述主要结果 / 简述论文结构。

### Turabian 引言四步（最可操作的逐句模板）

1. **开篇语境（context）**：综述论文将要扩展/修正/纠正的先行研究。简短即可——忙碌读者只想看与你直接相关的文献，不要为了显示读书多而堆砌综述。公正呈现前人研究，"像做这些研究的人自己会表述的那样去描述"。
2. **研究问题/问题条件**：用 But/However 引出——前人没做什么？哪里不完整甚至错了？
3. **问题意义（回答 So what?）**：把后果表述为"若不知道答案，我们将无法理解什么"；或反向表述为"若能理解 X，我们将获得什么"。
4. **主张（claim）或其承诺**：在引言末给出答案，或用含关键术语的句子预告答案。

Turabian 示例（每句可扩为一段）：
> 数世纪以来，风险分析师把风险当作概率统计问题研究【语境】。但风险传播者发现，普通人思考风险的方式与统计概率无关【问题】。不理解外行如何思考风险，人类认知的一个重要方面就仍是谜团【意义】。外行似乎是通过想象最坏情境并评估其可怕程度来判断风险的【主张】。

**引言末段（Ten Rules Rule 6）**：紧凑总结填补空白的结果；与摘要的区别是不再给语境、结果更具体、几乎不提前给结论。

**首句禁忌（Turabian 10.1.5）**：不要复读作业题面、不要引用词典定义（"Webster defines..."）、不要开口太大（"For centuries, philosophers have debated..."）；引言常拖到写作最后才定稿，但应尽早写一个"工作引言"来定方向。

### 摘要写法

- **五要素 checklist（Handbook）**：①Motivation 为什么关心这个问题；②Problem statement 论文要解决什么、范围多大；③Approach 用了什么方法；④Results 答案是什么；⑤Conclusions 答案蕴含什么。≤250 词。
- **Ten Rules 的摘要结构**：Context（大领域收窄到具体空白 + 空白为何重要）→ Content（"Here we" + 方法 + 结果概要）→ Conclusion（回应开头问题 + 更广意义）。宽—窄—宽，"结果要像钥匙插进锁孔一样恰好填住空白"。
- 摘要最常见的错误：**在读者准备好之前就抛出结果**。
- 风格：单段、过去时、自足（不引用图表和文献）、只报告正文出现过的内容；不放正文没有的信息和结论；关键词要具体、可被检索。

### 标题写法

- 标题应"宣布主题 + 传达概念框架"，**由引言的关键术语构成**（Turabian：标题最后写）。
- 两段式（主标题：副标题）给关键术语更多空间。对比：`Risk`（太泛）< `Thinking about Risk`（仍泛）< `Irrational but Systematic Risk Assessment: The Role of Visual Imagination in Calculating Relative Risk`（好）。
- 要求（Handbook）：描述性、信息性、准确、无歧义、具体、完整；不用缩写（除非众所周知）；避免含糊、不准确或搞笑的标题；简短描述结果的标题被引更高。
- 标题还是**写作路上的聚焦器**：反复回访标题，能帮你在写作和实验设计时始终围绕单一贡献。

### 结论/讨论的写法

- **结论 = 引言的镜像**：早而完整地重述主张（比引言版更具体）→ 提出新的意义、实际应用或后续研究 → "让对话继续"。
- Turabian 的"十四步讨论法"核心：从**具体到一般**组织（你的发现 → 文献 → 理论 → 实践）；用与引言相同的关键术语、时态（现在时）和视角；先重述假设并直接回答引言的问题，再用结果支持答案，然后对比已有文献；讨论相互冲突的解释（好讨论的标志）；报告意外发现（段首给出发现再解释）；指出局限但**不用道歉语气**；建议不超过两条后续研究——别建议本可在本研究内轻松解决的问题（那暴露你解释不足）。
- 讨论不是结果的复述（"no significance ≠ no difference"）；把发现放进文献综述引用过的前人语境中：与已有研究一致还是矛盾？

## 四、论证构建：主张—理由—证据—承认回应—理据（Turabian 第 5 章）

研究论证不是争胜，而是**与一群"接受但持怀疑态度的同事"对话**。五个元素对应读者必然要问的五个问题：

| 元素 | 读者的问题 | 说明 |
|---|---|---|
| **Claim 主张** | 你要我相信什么？ | 由工作假设升级而来；要具体，避免 important/interesting/significant 等空洞价值词；好主张让读者说"真的吗？说说看"，坏主张让读者说"这我知道" |
| **Reason 理由** | 为什么该同意？ | 常用 because 与主张相连；复杂论证中理由本身也是主张，需再被支持 |
| **Evidence 证据** | 你怎么知道？ | 基于 reasons 之上，"到外部世界去寻找"；怀疑型读者会追问证据的类型、质量（准确/精确/新近/代表性/权威性）、数量（"单一数据点/引文/轶事不足"）；高级研究需要一手来源或自己的观察，不能只靠二手转述 |
| **Acknowledgment & Response 承认与回应** | 可是……怎么办？ | 两类挑战：内在的（证据性质/质量/数量问题，理由不一致/太少/太弱）与外在的（不同视角下的替代解释、例外情况）。对异见不要反驳"你们错了"，而是承认差异、比较解释，展示你理解并尊重对方观点 |
| **Warrant 理据** | 这怎么推得出来？ | 连接理由与主张的一般原则（"天冷→该穿暖"）。当读者可能质疑理由的**相关性**（而非真实性）时给出 |

**关键原则：宁可依赖证据，不依赖纯理据推理。** 纯原理推出的主张被视为"必然真"，证据支撑的主张被视为"可能真"——当代读者更信任后者。事实性主张几乎不能只靠原理推理，必须拿证据来。

**论证组装范例（Turabian 5.6）**：主张（暴力游戏抵消了游戏对智力的益处）→ 理据（榜样影响儿童发展）→ 理由（儿童每天接触大量暴力画面）→ 证据（每天玩 3 小时、见 20+ 次暴力行为）→ 承认（有研究显示儿童能区分游戏与现实暴力）→ 回应（但交互性使其仍可能造成影响）→ 主张重述并强化。

**写作过程要点（How to Write a Research Paper）**：选题从学科（subject）收窄为话题（topic，会提问题/因果/比较），再凝练为 thesis——一句话、一个需证明的主张、能引发"再说点什么"。提纲围绕 thesis 展开：写出 3–4 个支持 thesis 的理由，每个理由配 2–3 个支持陈述，陈述下挂证据点；提纲同时暴露证据缺口，反向指导资料搜集。一稿之后必须留出"冷却期"再修改，请中立者审读，朗读检查通顺度。

## 五、图表设计原则（Turabian 第 8 章 + Ten Rules Rule 7）

**何时用图**：一句话装得下 4–5 个以内的数字就用文字；超过则用图形。三种基本形式各有修辞效果：
- **表格**：强调精确的具体数值，显得客观，但要求读者自己推断关系；
- **柱状图**：强调离散项目间的比较，一眼可见；
- **折线图**：强调（通常是随时间的）趋势。

**设计原则**：
1. 图表很少"自己会说话"，必须**加框**：用正文一句话引出它、说明数据如何支撑观点，句中点出的关键数字必须出现在图/表中；
2. 标题/图注**具体可区分**：不写"户主类型"而写"单亲和双亲户主类型的变化，1970–2010"；用名词短语、避免关系从句；不在标题里预下结论（不写"Weaker effects... "而写"Effect of... , 1995–2014"）；
3. 在图表内加辅助信息帮读者看懂（趋势列、图中文字标注关键事件）；
4. 保持尽可能简单；用视觉高亮聚焦读者该看的地方；
5. **数据伦理**：不歪曲数据、不夸大视觉效果。
6. 图标题应传达**结论**，图例说明方法（Ten Rules：很多人只看摘要+图就跳过全文）。

## 六、可直接执行的 Checklist

**写作前**
- [ ] 能用一句话说出论文的单一核心贡献吗？标题是否已传达它？
- [ ] 三个问题已回答：为什么写？想说什么？说给谁？
- [ ] Topic 是否可论证（能被证据支持或反驳），而非事实陈述？
- [ ] 提纲：主张 → 每条理由 → 每条理由的证据，缺口已识别？
- [ ] 每个计划中的段落在提纲里都有一句话的角色定义（1 段 = 1 句话）？
- [ ] 全文贯穿的 4–5 个关键术语已圈定？

**引言**
- [ ] 四步齐全：语境 → But/However 引出空白 → So what 的意义 → 主张（或承诺）？
- [ ] 无"For centuries..."式开头、无词典定义、无题面复述？
- [ ] 文献综述只覆盖你要扩展/修正/纠正的研究？

**摘要**
- [ ] 动机—问题—方法—结果—结论五要素齐全？宽—窄—宽？
- [ ] ≤250 词、单段、过去时、自足、与正文完全一致、不含引用与图表？

**结果**
- [ ] 逻辑链明确：每段以问题开头、以答案收尾，后段依赖前段结论？
- [ ] 图标题=结论、图例=方法？每个图表在正文有一句引出？

**讨论/结论**
- [ ] 回答了引言的全部问题（含不显著的结果）？
- [ ] 与前人研究对比？讨论了冲突解释与意外发现？
- [ ] 局限被坦承但无道歉语气？后续建议 ≤2 条且非本研究可轻易完成？
- [ ] 结论回到开篇目的（环形论证）？

**修改**
- [ ] 时间分配向标题、摘要、图倾斜？
- [ ] 已请"天真读者"测试：他们能一句话复述贡献、复述大纲吗？
- [ ] 同一概念同一用词、平行信息平行句式、无话题来回跳？
- [ ] 引用规范、无抄袭；放置几天后冷读一遍；朗读检查？
