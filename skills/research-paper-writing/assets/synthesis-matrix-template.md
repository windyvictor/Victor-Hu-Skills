# 综合矩阵模板（Synthesis Matrix）

用途：整理已读文献、识别趋势/共识/矛盾/空白、并直接导出批判性综述段落。行按发表时间排序。

## 模板

| 作者(年份) | 研究目的 | 方法 | 样本 | 时长 | 关键发现 | 我的评注（优点/局限/与本课题关系） |
|-----------|---------|------|------|------|---------|----------------------------------|
| （示例）Inman (2007) | 探究学术领导者如何习得领导力 | 半结构化传记访谈 | 18 名学术领导者 | 6 | 关键事件/重要他人影响/自我学习 | 质性深描充分，但样本限于英国情境 |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

使用要点：
- 列可按学科调整（如工程类可加"数据集/评价指标/性能"列；算法类可加"状态空间/动作空间/奖励设计"列）。
- "我的评注"列是批判性的落点，务必填写——对照研究问题评估相关性与证据质量。
- 填完后横向扫描：①研究情境分布（哪些情境被忽视→空白）；②范式与方法倾向；③发现的共识与分歧；④反复出现的批判点。

## 50 字文献归纳卡（快速筛读用）

```
作者/年份：
一句话目的：
方法/表征手段：
主要结论（take-home message）：
与我的研究问题关系：□核心 □相近 □背景   优先级：001/002/003…
```
