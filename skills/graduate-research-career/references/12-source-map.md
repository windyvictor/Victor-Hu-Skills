# 12 原书索引（20 部文档速览）

用途：回答"哪本书讲了什么""这个问题该看哪本""这本书值不值得读"。各书原文请自行获取（详见本目录 `09-quotes.md` 与各条目所列书目信息）。

## 一、思想源头（先读这三篇，一小时可读完）

**Hamming《You and Your Research》（1986 演讲）**
- 定位：贝尔实验室数学家基于 40 年观察回答"为什么少数人做出重大贡献"。全清单的思想源头。
- 结构：破"全靠运气"论 → 勇气与头脑 → 年龄效应与诺贝尔效应 → 工作条件论 → 复利论 → 模糊容忍 → 重要问题论 → 开门定律 → 推销论 → 教育老板 → 值不值得。
- 命名概念：**重要问题的 attack 判据**、**Great Thoughts Time**（周五午餐只谈大问题）、**10–20 个重要问题清单**、**复利论**、**开门/关门定律**、**诺贝尔效应**、**IAS 诅咒**、**种橡子**、**sound absorbers vs 临界质量**、**back room scientists**、**表象顺从**、**七年换域**、**"重要的不是做什么而是怎么做"**、**类而非个案**。
- 检索关键词：Luck favors the prepared mind / attack / open door / compound interest / Nobel effect / seven-year shift。

**Weinberg《Four Golden Lessons》（Nature 2003）**
- 四条：①没人什么都懂，你也不必 ②往湍流里去——go for the messes ③原谅自己浪费的时间 ④学一点科学史。
- 案例：Lorentz 与 Abraham 追电子理论（做了错误的问题）；1960s 学生选广义相对论而避开"一团乱"的粒子物理（恰好选错方向）；1903 年英国首相 vs Rutherford 与 Soddy。

**MIT AI Lab《How to do Research at the MIT AI Lab》（1988）**
- 定位：历届研究生集体撰写，操作性最强的"研究生生存手册"。12 节：Reading / Getting connected / Learning other fields / Notebooks / Writing / Talks / Programming / Advisors / The thesis / Research methodology / Emotional factors。
- 命名概念：**Secret Paper Passing Network**、**thesis avoidance（论文回避症）**、**3 倍法则**、**telescoping（望远镜式课题结构）**、**flakey ↔ cut-and-dried 谱系**、**neat vs scruffy**、**backlash effect**、**taste**、**论文 machismo**。
- 金句："If your project can't fail, it's development, not research."

## 二、方法论主干

**Booth 等《The Craft of Research》（第 4 版）**
- 定位：**论证工程学**。回答"论证如何成立"。最擅长：把兴趣变成读者认可的研究问题。
- 核心工具：**三步公式**（I am studying X because I want to find out Y in order to help my reader understand Z）、**practical vs conceptual problem**、**论证五要素**（claim/reason/evidence/acknowledgment+warrant）、**warrant 六类**（经验/权威/知识体系/文化常识/方法论/信仰）、**创造性同意 3 类 vs 创造性分歧 5 类**、**引言 Context+Problem+Response**、**修订五层级**、**三种坏计划**、**清晰写作四原则**（主语=角色、动作=动词、旧信息在前、复杂信息在后）、**伦理六条"不可为"**。
- 注意：全书无独立 fallacies 清单；笔记法是"关键词/摘要/评注/索书号"卡片式，无"三栏笔记"。

**Bundy 等《The Researcher's Bible》（爱丁堡 DAI）**
- 定位：**研究生生存工程学**。回答"人如何活下来并把论文写出来"。
- 核心工具：**11 种标准陷阱**（Solving the World / Manna from Heaven / Computer Bum / Yet Another Language / Micawberism / Ivory Tower / Misunderstood Genius / Lost in Abstraction / Ambitious Paralysis / 方法论越位 / 发现路径≠辩护）、**6 种心理障碍**（心态 / 研究阳痿 / 面对批评 / 冷启动 / 定理嫉妒 / 暴露恐惧）、**七阶段研究方法论**、**选题四标准**、**thesis message 八要求**、**论文四段框架**、**三同心圆阅读法**、**viva 六种判决**。
- 注意：本 PDF 字体损坏需 OCR；无 Fleck 评估标准（用爱丁堡 Calendar reg. 3.2.6/3.3.7 + viva 判决表）。

**贝弗里奇《科学之路》（The Art of Scientific Investigation）**
- 定位：科学发现的思维艺术（机遇、假设、想象力、直觉、推理、观察、战略）。
- 最适合：理解"直觉从哪来""如何处理意外""如何设计关键实验"。对应对照实验、逐步排除法、直觉产生四条件、"推测型 vs 条理型"科学家分类。

**徐光宪《科研创新的 16 条方法》**
- 定位：可复用的创新方法工具箱。16 条含：知识框架法 / 创新链与创新树 / 分类研究法 / 学科交叉法 / 移花接木法 / 四两拨千斤法 / 逆向思维法 / 柳暗花明法 / 天上人间法 / 傻瓜提问法 / 大胆假设小心求证 / 意外机遇法 / 灵感培养法（王国维三境界）/ 虚拟实验法 / 综合集成法 / 原始大创新五步。

**周志华《做研究与写论文》**
- 定位：计算机领域"从入门到发表"全流程讲稿。
- 核心：**TPIC 流程**（Topic→Problem→Idea→Concrete work）、**选题三考虑**、**idea 自检四问**、**实验五要求**、**论文逐节写法**、**审稿人五指标**（Relevance/Originality/Significance/Soundness/Presentation）、**四个误区**、**写作技巧清单**。
- 金句："问题是科学研究的心脏""论文是做出来的而不是写出来的"。

## 三、中文生涯指南（研究生最该先读）

**冯长根《研究生如何夯实成功科研生涯的基础》（《科技导报》主编心语）**
- 定位：国内最系统的科研生活操作手册。**24 个正式章名分置于 34 个连载段**（不是 32 篇独立文章）。
- 24 章名：开场白 / 选择导师 / 与导师的交往 / 注意克服时间陷阱 / 管理时间 / 文献搜索与阅读 / 撰写进展报告 / 口头报告 / 写论文 / 出论文 / 对论文的反馈 / 学术论文的发表 / 写摘要 / 学术会议 / 壁报交流 / 博士论文的撰写 / 博士论文答辩 / 处理好紧张与压力 / 成为一个博士后 / 研究合作 / 在实验室指导学生 / 写科研经费申请书 / 走进科学共同体 / 努力寻找成功之门。
- 命名清单：**师生交往六规则**、**拖延毕业四大原因**、**文献三分类**（基本的 / 有时间可读的 / 天知道我为什么打印的）、**口头报告三步曲**、**幻灯规范**（5 行×7 词、A4 纸可视测试）、**壁报规范**（边缘 40mm、单元 15mm）、**答辩 5 点计划**、**压力应对清单**、**科学共同体成员五素质**、**10 年计划**。

**《研究生学习生活手册》（多作者文集）**
- 定位：论坛经验帖汇编，鲜活具体、含大量反面案例。10 章（Life / Research / Your Boss / Approach / Object / Reference / Reading Notes / Affection / Personage / Others）。
- 最重要一篇：**王汎森《如果让我重做一次研究生》**——研究生与大学生之别、老师如何训练研究生、研究生如何训练自己（学习取舍 / 知识树 / 掌握工具 / 突破学科界线 / **论文题目要有延展性** / 遵守学术格式 / 善用图书馆 / 留下时间精致思考 / 找到学习楷模）、两条腿走路（研究+兴趣）。
- 实用清单：五学期规划、文献管理 5 条、引用 5 种小聪明、造假 5 类型、外文文献阅读法、开题报告写法、优秀科技论文五要素。
- 警示案例：廉价技术员 / 昼眠夜醒 / 温水里的青蛙 / "SCI 是个陷阱"。

**徐芳《走好学术路：科研萌新的自我修养》（2024）**
- 定位：唯一含**生成式 AI 使用规范**的新书；含"研0"到答辩全流程。六大模块：开启学术之路 / 方法与工具 / 论文写作 / 论文发表 / 研究生生活 / 经验分享。
- 命名方法：**文献三遍法**、**文献数量标准**（本科 20–30 / 硕士 50 / 博士 100）、**帕累托关键节点**、**定标比超法**、**时间管理五法**（甘特图/清单/番茄/时间矩阵/时间块）、**导师两类型**、**迷茫 11 原因**、**讨论五步法**（Hartley）、**AI 能做 8 条 / 不能做 4 条**。

**Petre & Rugg《给研究生的学术建议》（第 2 版）**
- 定位：博士"潜规则"手册，专讲没人明说的隐性知识。18 章。
- 命名概念：**橱柜比喻**、**工具性行为 vs 表现性行为**、**表现性行为陷阱**、**习得性无助**、**第二年忧郁**、**图表测试**、**"然后呢？"**、**带说明的文献目录**、**叙述线索/红线**、**非正式委员会**、**有效争论**、**自我陈述技巧**、**实耗时间 vs 任务时间**、**替代活动 vs 生产活动**、**三类学术生涯**（研究帝国 / 巡游学者 / 隐士学者）、**简历五特征**、**导师见面会九步**。
- 金句："与其说读博像拿砍刀在丛林开路，不如说像拿放大镜在平地匍匐前行。"

**《我的研究生五年》（南大数学系博士生自述）**
- 定位：真实心路 + 时间线，适合"导师放养、自选题目"情境对照。
- 要点：中科院随冯琦学习 → 新加坡随杨跃访问 → 游戏/灌水/网恋导致停滞 → 转向国际合作（Downey、Slaman、Nies）完成博士 → 新西兰博后。
- 可复用动作：做题前先发邮件问原作者；结果单薄时先 announce 按住不发；同一本经典读四遍；主动申请外单位访问；会议主动做报告。

## 四、职业与道德（博士后期与青年 PI）

**BWF/HHMI《博士后与科研新手指南》（Making the Right Moves）**
- 定位：美国科研管理实操手册，13 章，从求职到带实验室全流程。研究生可提前了解规则。
- 13 章：求职与协商 / 了解大学结构与终身职位 / 实验室领导能力 / 人员配备 / 导师与你 / 时间管理 / 计划管理 / 数据管理与实验笔记 / 申请经费 / 发表论文与影响力 / 技术转移 / 建立合作 / 教学与课程设计。
- 命名工具：**领导=远见+关系+任务**、**Blanchard-Hershey 四种领导风格**、**Thomas-Kilmann 五种冲突模型**、**时间四象限**、**KISS**、**WBS 工作分解结构**、**实验记录五重目的 + 证人制度**、**R01 两级审查**、**pre-submission inquiry**、**MTA 三类**、**Bloom 六层级**、**教学文件夹**。

**何毓琦《科学人生纵横》**
- 定位：哈佛终身教授的博文摘编（黄金法则 / 经历 / 建议三部分）。
- 命名法则：**做任何事三准则**（懂规则 / 按规则玩 / 玩得更好）、**科研两条黄金法则**、**三件同等重要的工作**、**选题三问**（有人真关心 / 我不完全了解 / 我感兴趣）、**跳下水学游泳**、**六七年换方向**、**建立联系四步法**、**赋予-索取关系**、**50% 准则**、**人生伴侣法则**。

**邹承鲁《我的科学之路》**
- 定位：院士五十年生涯总结，8 部分（经历 / 选题来源 / 选题原则 / 计划实验与小结 / 论文 / 与学生共同工作 / 成果评价 / 科学道德）。学术道德与署名部分权威性最高。
- 原文级要点：**选题三原则**（重要性 / 可能性 / 现实性）、**课题三来源**、**可重复性 3:0 标准**、**署名两条件**（负责+贡献缺一不可）、**违反科学道德四形式**（伪造数据 / 剽窃 / 一稿两投 / 强行署名）、**错误更正流程**、**成果评价三条**（时间考验 / 教科书与引文 / 拒绝新闻发布会）。
- 金句："先进仪器用钱都可以买到，但先进的创新学术思想是用钱买不到的。""科学上是没有银牌的位置的。"

**饶毅《If I Were a First Year Graduate Student Now》**
- 定位：借 10 余个真实发现故事重建科研观。最适合入学第一课。
- 故事清单：Fire & Mello/RNAi（含 Guo & Kemphues 诚实发表 sense/antisense 都有效应）、Tom Cech 多余条带、Brenner、Nüsslein-Volhard、Capecchi、Prasher 与 GFP、David Page 与 Y 染色体、David Julius 与 TRP 通道、外激素、Gehring 与 PAX-6、Benzer。
- 主张：**你为自己工作（work with 而非 work for）**、诚实是不可逾越底线、不可解释的结果里可能藏重要发现、贡献不保证社会认可、**做你自己的 I 与 T**、成功与幸福无一定关系。

## 五、单篇法则与经验帖（可作学生手册附录印发）

**Herman《The Laws of Herman》（研究生从事学术研究的 20 条法则）**
- 定位：哥伦比亚大学应用物理学教授 Irving P. Herman 基于指导研究生的经历，从**导师视角**提出的 20 条劝告，幽默但字字有实指。
- 五组结构：①导师关系（3–5、12–13：多数情况下导师错的时候不多；确信自己对就去说服他）②正确与产出（1–2、6–10：产出 ∝ 有效时间^1000，∝ 拖延分析数据时间的倒数^1000；今天能拿数据别等明天；数据到手 5 分钟内永久备份）③学位论文（11、14–16：成为比导师更大的专家；写进论文的每部分结果都达到可发表要求；论文是你自己的，必须亲力亲为）④师生相互成就（17–20）。
- 特别提醒：原文献强调**选导师是攻读学位过程中最最重要的环节**；法则 3–4 执行时不得凌驾学术道德（见 07）。
- 完整中英对照见 `06-advisor-collaboration.md`。

**《硕博研究生期间应该明确的 50 件事》（网络经验帖）**
- 定位：面向硕博生的全谱系自我管理清单，50 条分六类：学术（1–15）/ 成长（16–20）/ 心态（21–35）/ 社交（36–40）/ 身体（41–45）/ 生活（46–50）。
- 特色：唯一覆盖**身体与生活习惯**的文献（锻炼习惯、每天吃早餐、少咖啡依赖、培养游戏外爱好）；心态类条目直白实用（不攀比、不抱怨课程、先爱自己的专业）。
- 与主流共识同源的条目：第 1 条（一半时间读文献）、第 8 条（先读最早专著教材，勿网上乱搜——与手册同源）、第 12 条（不要期待导师给太多指导，全世界都一样——与 MIT/冯长根共识一致）、第 15 条（写下想法以调整思路——与"写作即思考"一致）。
- 学术类要点：口头+书面说清观点（4）、读写作高手的书思考句法（5）、学好英语不学二外（6）、能直接写专业英语论文（7）、做科研笔记（14）。
- 已按主题拆入 01（心态/成长/身体/生活）、03（文献）、04（计划与笔记）、05（写作）、08（职业准备）、11（攀比焦虑、基础差不敢开始）。
