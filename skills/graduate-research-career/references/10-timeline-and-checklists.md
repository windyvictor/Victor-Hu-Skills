# 10 阶段路线图与自检清单

本文件的清单条目标注出处。回答用户时可直接挑相关清单交付，或把清单改写成用户自己的任务表。

## 一、阶段路线图

### 硕士三年（六学期）

| 阶段 | 核心任务 | 要点 |
|---|---|---|
| 研0（入学前） | 打基础 | 提前读方向文献、联系导师、学工具软件、学方法与统计、练外语与写作（徐芳研0 九条）；联系导师邮件讲清资格+兴趣+研究基础 |
| 第 1 学期 | 学习学期 | 修课、博览群书形成"T 字形"结构；读文献 20–30 篇；**尽量多与每位老师交谈**（MIT）；建立固定工作日程（Bible） |
| 第 2 学期 | 知识补充学期 | 补短板、定方向；**开题前旁听学长学姐的开题与答辩**（徐芳）；建立文献管理目录（Petre：100–150 部带说明文献） |
| 第 3 学期 | 资料收集 + 开题 + 投小论文 | 文献约 50 篇（徐芳）；开题报告；写第一篇小论文 |
| 第 4 学期 | 论文完稿 + 择业思考 | 数据成文；同步看招聘信息 |
| 第 5 学期 | 答辩 + 择业冲刺 | 送盲审 → 答辩；求职提前一年（10 月底启动） |
| 第 6 学期 | 收尾 | 答辩、修改、毕业；考博者关键在英语与提前联系导师 |

### 博士 4–5 年

| 阶段 | 核心任务 | 要点 |
|---|---|---|
| 第 1 年 | 读 + 选导师 | 头两年读教材与期刊（MIT）；**第一年结束前、至迟第二年年初定论文导师**——"选论文导师是研究生涯最重要的决定，比选课题更重要"（MIT） |
| 第 2 年 | 定题 + 开题 | 文献约 100 篇（徐芳）；准备一句话/一段话/五分钟三版本 thesis 陈述（MIT）；与导师明确"什么算完成" |
| 第 3 年 | 主攻 | 按七阶段方法论推进（Bible）；每几个月写一篇 DRAFT 工作论文（MIT）；投会议/期刊 |
| 第 4 年 | 章节化 + 求职 | 学位论文双向写作（Bible）；**毕业前一年申请自己的 fellowship**（Ten Simple Rules） |
| 第 5 年 | 整合 + 答辩 + 转岗 | 学位论文质量标准："写进论文的每部分结果都达到能够发表的要求"（Herman 法则 14） |
| 时间上限 | — | PhD 全职 33 月、上限 5 年；MPhil 21 月、上限 4 年（Bible） |

### 博后（建议不超过 3 年，Ten Simple Rules）

- 年 1：定主攻项目 + 保底项目，申请自有经费；年 2：产出 + 求职准备；年 3：收尾 + 转岗。

### 关键节点（帕累托法则，徐芳）

开题 / 中期 / 盲审 / 答辩 / 小论文是决定成败的"少数关键因素"，重点投入；其余放手自我成长。

## 二、自检清单

### A. 选导师前（10 条）

- [ ] 问清导师风格参数：想要多少指导（现成课题 vs hands-off）、多少接触、多大压力、多少情感支持（MIT）
- [ ] 与其**至少两名在读学生**谈过，**一年级和七年级的都谈**（MIT）
- [ ] 列席过其组会（多数开放）；读过其近期论文与实验室研究摘要（MIT）
- [ ] 确认导师对课题真有热情（Ten Simple Rules）
- [ ] 确认导师愿在会议上推广你的工作、肯替你对抗体制（MIT）
- [ ] 明确沟通你想要的指导方式，别让"跟你做"被听成"给我个窄题目"（MIT）
- [ ] 商量好见面频率与"什么算完成"（MIT）
- [ ] 判断导师类型：生气型 还是 解决问题型（徐芳）——影响你如何接收批评
- [ ] 若课题与导师主业无关，确认 junior faculty 的 tenure 风险是否影响指导（MIT）
- [ ] 若遭遇骚扰（种族/性别/性向），知道求助渠道（MIT）

### B. 开题前（12 条）

- [ ] 三步句写清 Topic / Question / Significance，并答出 So what?（Craft）
- [ ] 区分并确认这是 conceptual 问题（而非误当 practical）（Craft）
- [ ] 通过"图表测试"：列出所有可能结果并解释每种含义，通不过就重新设计（Petre）
- [ ] 用何毓琦三问自检（有人真关心 / 我不完全了解 / 我感兴趣），两条为"是"即可做
- [ ] 用邹承鲁三原则自检：重要性 / 可能性 / 现实性
- [ ] 已做检索确认**世界范围内无重复报道**（邹承鲁）
- [ ] 选题满足 Bible 四标准：热情 / 配得上学位 / 三年可做 / 有人愿指导
- [ ] 宜小题大做，忌大题小做；用四五个词的宽题加"动作名词"收窄（周志华 / Craft）
- [ ] 建成"望远镜式"风险结构：核心必成 + 一圈圈风险扩展（MIT）
- [ ] 已看过同一领域一篇通过答辩的学位论文找"尺寸感"（Petre / MIT）
- [ ] 已完成文献综述：按主题而非年份、有评论性、指向你的问题（徐芳）
- [ ] 预判最苛刻读者的三个必然分歧：另有成因 / 反例 / 定义之争（Craft）

### C. 投稿前（16 条）

- [ ] 有想法那天就开始写；稿件放一段时间后再改、并请他人读（周志华 Revise×3）
- [ ] 标题≤20 字、清楚、有吸引力；缩写好发音（STARE 优于 SBRE）（周志华）
- [ ] 摘要说清"观点是什么"而非"论文关于什么"（MIT）
- [ ] Introduction 含：X 重要 / A、B、C 已做 / 其不足 / 我们的 D / 优势 / 结果 / 组织（周志华）
- [ ] 未过度批评前人工作（周志华）
- [ ] 论证含齐五要素：claim / reason / evidence / 承认与回应 / warrant（Craft）
- [ ] 已想象最挑剔读者逐条列 objections 并回应（Craft）
- [ ] 证据检查：accurate / precise / sufficient / representative / authoritative / relevant（Craft）
- [ ] 图表在正文中被讨论（不能只写"结果在表 2 中"）（Petre）
- [ ] 严格区分 reasons 与 evidence——证据必须能"拿给所有人看"（Craft）
- [ ] 避开四误区：点子越多越好 / 越复杂越好 / 越推销越好 / 越权威越好（周志华）
- [ ] 已按目标发表源的要求排版；已读过其 author guide（周志华 / MIT）
- [ ] 请无利害关系的同事读过初稿（Ten Simple Rules）
- [ ] 引用必读原文；无虚假文献（邹承鲁 / Petre）
- [ ] "领先""首次"审慎；未夸大结论（邹承鲁 / 冯长根）
- [ ] 投稿前考虑 pre-submission inquiry；绝不一稿多投（BWF / 周志华）

### D. 答辩前（12 条）

- [ ] 准备好"用自己的话概括关键贡献"的简洁答案（Bible）
- [ ] 按"5 点计划"准备：信心 / 彻底了解论文 / 学者味 / 坚守已知 / 向委员提问（冯长根）
- [ ] 答辩姿态是"告诉专家我的研究值得授予学位"，而非"不答辩不给学位"（冯长根）
- [ ] 演练过简洁作答、不跑题（Bible：Do not ramble）
- [ ] 前一晚睡好——胜过押题（Bible）
- [ ] 照"最后实验清单"排序：只保留安全的、按重要性排序（冯长根）
- [ ] 已请非正式委员会成员预审（Petre）
- [ ] 熟悉考官想让你通过这一前提："答辩是合作过程，给他们所需的全部帮助"（Bible）
- [ ] 准备了 3 个可以反问考官的问题（冯长根）
- [ ] 论文各章已被整理为可发表成果（Herman 法则 14）
- [ ] 已完成开题十大注意事项、答辩缓焦虑清单（徐芳）
- [ ] 盲审提醒：盲审不过多是"临时突击写论文"的恶果（徐芳）

### E. 每周 / 每月例行（10 条）

- [ ] 每周给导师发一次进展消息（含"本周没有新结果"）（冯长根）
- [ ] 每周留 1 小时去图书馆 skim 新文献与摘要（Bible 外圈）
- [ ] 每周固定时间与人交谈、参与社群活动，避免孤立（Petre）
- [ ] 每周记录读过的论文与短评（Bible）
- [ ] 每月做一次笔记摘要回读（MIT Notebooks）
- [ ] 每几个月写一篇 2 天内完成的 DRAFT 工作论文散发（MIT）
- [ ] 每天结束时记下"次日第一件事"（冯长根）
- [ ] 每天开门办公、接受打断（Hamming）
- [ ] 每月自问："本领域重要问题是什么？我现在做的是其中之一吗？"（Hamming）
- [ ] 每季度/每学期校准：用三步句重述项目意义（Craft）

### F. 实验与数据（8 条）

- [ ] 实验方案周全、含基准测试与他人可用的数据、含不可缺少的比较（周志华）
- [ ] 结果可重复性达 3:0（满意）或至少 2:0；3:2 只能算失败（邹承鲁）
- [ ] 记录详细到"同行能看懂"；写明目的、条件、结果、小结（邹承鲁）
- [ ] 严格区分"观察到的现象"与"自己的解释"（贝弗里奇）
- [ ] 错误划线不擦除；重要电子结果打印签字存档；记录至少保存 5 年（BWF）
- [ ] 数据到手 5 分钟内做永久备份（Herman 法则 9）
- [ ] 用仪器前读说明书与原始文献方法，不靠口头传授（邹承鲁）
- [ ] 只记成功不记失败 → 会丢掉宝贵发现（手册）

### G. 学术道德红线（8 条）

- [ ] 未伪造数据、未按主观需要取舍数据（邹承鲁 / Craft）
- [ ] 未剽窃（含段落、图表、他人思路与方法未引注）（邹承鲁 / Craft）
- [ ] 未一稿两投或变相一稿两投（改头换面、图表重复、数据不同组合）（邹承鲁）
- [ ] 未在自己无贡献的论文上"搭车"署名（邹承鲁）
- [ ] 每位署名者都对全过程有了解、能对某重要部分负责（负责+贡献缺一不可）（邹承鲁）
- [ ] 已征得每位署名者同意；单位署名反映实际完成时的单位（邹承鲁）
- [ ] 不隐瞒无法反驳的反驳、不漫画化对立观点、不销毁数据（Craft 伦理六条）
- [ ] 拒绝用新闻发布会宣传未经验证的成果（邹承鲁）

### H. 警示信号（出现即自省，来自反面案例）

- [ ] 我在做"廉价而勤奋的技术员"的工作，不做自己的思考（手册）
- [ ] 我突然觉得修一个废弃系统的冷僻 bug 无比迷人——论文回避症（MIT）
- [ ] 我在表演勤奋（图书馆坐一天无进展）——表现性行为陷阱（Petre）
- [ ] 我在无限重磨"已够好的论文"——半故意的逃避（MIT）
- [ ] 我昼眠夜醒 / 通宵游戏或刷帖（手册 / 《我的研究生五年》）
- [ ] 我用"读研"当缓解就业压力的遮眼罩——温水里的青蛙（手册）
- [ ] 我在读别人而不是在想问题——"读太多别人的东西就会像别人一样想"（Hamming）
- [ ] 我的引文有"知而不引、断章取义、引而不确、来源不实、盲目自引"（手册：引用 5 种小聪明）
- [ ] 我总在等灵感而不动手——Manna from Heaven（Bible）
- [ ] 我硬套旧方法论（Theorem Envy）或另造轮子（Yet Another Language）（Bible）
- [ ] 我闭门造车、不参加讨论（Ivory Tower）（Bible）
- [ ] 我用"如果我能做到，那就是 trivial 的"贬低自己的工作（Bible / MIT）
