# 投稿前自检清单（模板）

> 用法：定稿后逐项打勾再投。出处见《10 阶段路线图与自检清单》C 组。

## 一、论证（Craft 五要素）

- [ ] Claim 明确、具体、已加限定（qualifying）
- [ ] 每条 Reason 都配了可展示的 Evidence（不是 reasons 冒充 evidence）
- [ ] 已逐条预判并回应最苛刻读者的异议
- [ ] 需要时陈述并支撑了 warrant（读者在领域外 / 原则新且有争议 / 主张被抗拒）
- [ ] 三种必然分歧已预判：另有成因 / 反例 / 定义之争

## 二、结构

- [ ] Title ≤20 字、含主旨关键词、有吸引力
- [ ] Abstract 说清"观点是什么"，而非"论文关于什么"
- [ ] Introduction：Context → Problem → Response；末尾给出 point
- [ ] 全文贯穿 4–5 个关键术语并保持一致
- [ ] 每节都能回答"它对应五要素中的哪一问"
- [ ] Previous work 分类综述、未过度批评前人
- [ ] 图表都在正文被讨论（不能只写"结果在表 2 中"）
- [ ] Conclusion：重述 main point（更具体）+ 新的意义 + 呼吁后续研究

## 三、数据与可重复性

- [ ] 实验方案周全、有基准、有不可缺少的比较
- [ ] 数据他人可获取，实验可被同行按描述重复
- [ ] 结果可重复性达 3:0（或至少 2:0）
- [ ] 已分析 strength/weakness 与 how/why strong/weak
- [ ] 图片处理规范，无不当修饰

## 四、文献与引用

- [ ] 关键引用都亲自核对过原文
- [ ] 无虚假文献；无"知而不引 / 断章取义 / 引而不确 / 来源不实 / 盲目自引"
- [ ] 引用格式统一（顺目标期刊要求：Chicago / APA / MLA 等）

## 五、语言与形式

- [ ] 标题/摘要最后写并反复打磨
- [ ] 删掉了引言第一段（多半是空洞套话）
- [ ] 缩写易读好发音（如 STARE 优于 SBRE）
- [ ] 未犯四误区：点子越多越好 / 越复杂越好 / 越推销越好 / 自引越多越权威
- [ ] 按目标期刊 author guide 排版

## 六、流程

- [ ] 已请无利害关系的同事通读一遍
- [ ] 拼写检查已过；冷置数日后重读一遍
- [ ] 若投高影响期刊，考虑先发 pre-submission inquiry
- [ ] 通讯作者、作者顺序、署名均经全体署名者同意
- [ ] 确认未一稿多投

---

**投稿后**
- [ ] 记录投稿日期与预计审稿期；超期后礼貌致信主编（不自行联系审稿人）
- [ ] 收到意见先冷静几天再逐条回应；major revision 写进 cover letter
- [ ] 被拒 → 按意见修改再投，绝不原样转投；对审稿人保持礼貌
