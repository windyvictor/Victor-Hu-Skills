# 周进展报告（给导师的邮件模板）

> 用法：每周固定时间发送（如周一早上），**没有新结果也要发**——"用不着害怕承认从上次以来我还没有得到新的结果"（冯长根）。四段式，控制在 300 字内。

主题：【周报】<你的名字> · <年月日> · <课题名>

X 老师：

**1. 本周做了什么**
- 实验/推导/阅读：
- 关键数据或现象（一两句，附图/表编号）：

**2. 结果与判断**
- 我的解读：
- 与预期的差异（若有"不方便"的结果，重点说明——那可能藏着重要发现）：

**3. 遇到的问题 / 需要您的意见**
- 问题一：（我先想的两个方案是 A / B）
- 问题二：
- 请重点看：<文件/编号>

**4. 下周计划**
- 计划做：
- 预计产出：
- 想和您确认的一点：

顺祝安好
<你的名字>

---

**发送前自检**
- [ ] 是否讲了结论，而不只是过程
- [ ] 是否只提了 2–3 个最需要他判断的问题（别给一堆琐碎）
- [ ] 是否明确了下周可交付物
- [ ] 是否把"没有进展"如实写出——不隐瞒、不修饰
- [ ] 附件命名是否清楚（课题_日期_内容）
