# 答辩准备清单（模板）

> 用法：送审后立即开始。核心心态——"答辩是合作过程，考官想让你通过，给他们所需的全部帮助"（Researcher's Bible）。

## 一、内容准备

- [ ] 用**自己的话**写一段"我的关键贡献是什么"（30 秒版）+ 一段（2 分钟版）
- [ ] 按"5 点计划"准备：①树立信心 ②彻底了解自己的论文 ③要有学者的味儿 ④坚守自己知道的事 ⑤不妨问一些问题（冯长根）
- [ ] 每章回答三个问题：①问题是什么 ②用什么手段攻 ③得到什么结果（Bible 四段框架）
- [ ] 准备"我的论文新在哪、好在哪"以及与近缘工作的**显式比较**
- [ ] 列出 5–8 个最可能被问的问题与简短答案（不跑题、简洁）
- [ ] 前 10 分钟讲清全局图景，不扎进细节

## 二、边界与诚实

- [ ] 明确"我知道什么、不知道什么"——不知道就说不知道，不要慌
- [ ] 三条黄金法则：不要说谎；不要故作幽默；不要惊慌失措而在压力下吐露真相（Petre）
- [ ] 审慎使用"领先""首次"——每条都要能当场给出文献依据

## 三、形式与演练

- [ ] 试讲至少一次（最好在组会），请人挑刺
- [ ] 计时：不超过规定时长的 90%
- [ ] 核对格式：学校规定的装订、页数、图表编号、参考文献
- [ ] 着装：正常办公装，可略正式
- [ ] 前一晚睡好——**胜过押题**（Bible）

## 四、材料

- [ ] 论文打印本（自己一份，标注关键页）
- [ ] 答辩 PPT / 讲稿
- [ ] 笔记本与笔（记录考官意见）
- [ ] 需要补充的图、代码、数据放在手边

## 五、答辩中

- [ ] 听清问题再答，必要时请考官确认（"您问的是不是……？"）
- [ ] 承认不确定 + 说出你会怎么去查
- [ ] 记录每一条意见——它们是修改的依据
- [ ] 保持冷静：把 viva 当作 debug——论文是程序，你是程序员，考官是解读者；错误信息不可忽视但不必照单全收（Bible）

## 六、答辩后

- [ ] 按意见修改并提交最终稿
- [ ] 总结哪些问题答得不好，写进自己的经验清单
- [ ] 把可发表章节整理投稿（Herman 法则 14：写进论文的部分都应达到可发表水平）
- [ ] 若准备求职：提前一年启动，简历突出"处理和解决新问题的能力"（Petre）
