# 导师见面会议程（模板）

> 用法：见面会**由学生主动组织**（Petre & Rugg）。提前一周送材料、会末定下次日期、会后立即邮件总结。

## 会前（提前 1 周）

- [ ] 邮件发出议程与讨论材料（附文件或链接）
- [ ] 明确本次会议的 3 个目标
- [ ] 准备好想请教的 3 个**具体**问题（不要泛问"我该怎么办"）
- [ ] 带上数据、图、代码或稿件打印本
- [ ] 上次会后行动项复核：哪些完成、哪些未完成、为什么

## 会议议程（30–60 分钟）

| 时段 | 内容 |
|---|---|
| 0–5 min | 复核上次行动项 |
| 5–15 min | 进展汇报（**先讲结论再讲过程**） |
| 15–35 min | 提出 3 个具体问题，逐一讨论 |
| 35–45 min | 下一步计划与时间节点确认 |
| 45–50 min | 其他事项（投稿计划、会议、合作、资源需求） |
| 50–55 min | 明确"什么算完成"与截止日期 |
| 55–60 min | 定下次会面时间 |

## 会后（当天内）

- [ ] 立即发邮件总结：决定事项 / 行动项 / 负责人 / 日期
- [ ] 更新自己的任务清单
- [ ] 若对某条意见有异议：带证据、用提问方式下次再谈（"为什么这种方法行得通？"而非"这行不通"）

## 需主动汇报的五类事项（不要等他问）

- [ ] 进展（含停滞）
- [ ] 困难
- [ ] 偏离原计划的变动
- [ ] 想改方向
- [ ] 想投稿 / 收到审稿意见
