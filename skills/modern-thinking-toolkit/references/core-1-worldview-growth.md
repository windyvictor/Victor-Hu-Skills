## 一、基本世界观（6）

### 1.1 叙事（Narrative）

**何时调用**：事实很多却没有方向；同一组数据引出相反行动；个人或组织不知道“我们在做什么”；情绪被某个故事牢牢占据。叙事不是装饰，而是从事实中选择主角、目标、时间顺序和因果线索，使人能够预测、赋予意义并协调行动的接口。

**核心模型**：任何叙事都做了选择。它突出一些事实、忽略另一些事实，把先后写成因果，把一个价值方向设为目标。叙事可以承载真实或虚构内容，但有用叙事必须含有可检验的因果关系，并能在新事实出现时修改。叙事有三种主要功能：压缩世界以便预测；指定“什么值得关心”以产生意义；让多人围绕共同对象协调。

**Agent 程序**：

1. 先列不依赖叙事的事实、数据、约束和未知，把评价词暂时拿掉。
2. 写出当前叙事：谁是主角，想要什么，谁或什么构成阻力，哪条因果链把现在连到未来。
3. 至少生成两个能解释同样事实的替代叙事，尤其加入一个会导向不同决定的版本。
4. 为每个叙事写出可观察预测、遗漏事实、受益者和行动倾向；用证据与后果比较，而不是按感染力选择。
5. 选一个暂时最好用的叙事，同时保留修订条件。若任务是协调，确保参与者知道目的、边界和自己的行动接口。

**诊断问题**：这是事实，还是对事实的命名？谁获得了叙事权？如果换主角、时间起点或目标函数，结论会不会改变？这个故事预测了什么？

**边界与输出**：故事不能替代证据，能动性不能变成给别人洗脑的许可证。不要把复杂冲突压成善恶剧，也不要因“一切叙事都主观”而滑向事实虚无。输出应包含“事实底板—当前叙事—替代叙事—可检验预测—行动选择”。

### 1.2 重尾分布（Heavy-Tailed Distribution）

**何时调用**：少数人、产品、事件或时段贡献大部分结果；平均数与多数人的体验明显不符；一次极端事件能改写长期成绩；用户在选择赛道、组合或曝光策略。

**核心模型**：薄尾世界的个体差异有自然上限，平均值稳定；重尾世界的尾部很长，极端值支配总量。重尾常由乘法增长、复利、优先连接、可复制信息、网络效应和“越大越容易变大”的正反馈生成。这里最重要的不是记住某个 80/20 比例，而是承认极少数结果可能比其余结果之和更重要，常规样本对尾部估计又很不可靠。

**Agent 程序**：

1. 明确结果变量，查看中位数、分位数、最大值占比和尾部，而不只报平均值。
2. 问变量是否有物理上限、是否可复制、增长是相加还是相乘，是否存在网络效应或累积优势。
3. 若是重尾，区分两类任务：防守上避免单个负尾事件毁灭；进攻上增加低成本、多样化的上行暴露。
4. 把资源配置成“保底层 + 探索层”：底层保证不出局，探索层允许多次小失败以等待少数大成功。
5. 评估路径依赖：早期微小优势是否会被反馈放大；若会，重视进入时间、分发和持续积累。

**诊断问题**：平均值代表谁？最大几个样本拿走多少总量？删掉最大值后结论是否改变？成功来自能力差异，还是可放大结构？

**边界与输出**：不能看到不平等就宣称幂律，也不能从统计分布推出道德正当性。重尾赛道可能回报巨大，也可能让多数参与者颗粒无收。输出应说明分布判断、形成机制、防毁灭措施和获取上行的方式。

### 1.3 稳态生存逻辑与文化滞后（Steady-State Survival Logic / Cultural Lag）

**何时调用**：旧观念在新环境中限制行动；人们把节俭、听话、忙碌、从众或达标本身当成美德；组织环境已经高波动，制度和心智仍按低波动时代运行。

**核心模型**：稳态生存逻辑是匮乏、弱规则和简单模型共同塑造的局部理性。匮乏带来零和、风险厌恶和“省比创造重要”；弱规则让安全依赖关系与权威，于是从众、面子和态度压过个性；简单模型把努力、指标和回报想成线性关系。物质环境变化快，文化更新慢，便形成文化滞后。旧规范曾保护生存，不等于仍适合增长。

**Agent 程序**：

1. 找出被当作天经地义的规则，并追问它最初解决的是匮乏、风险、弱规则还是协调问题。
2. 检查环境是否已改变：资源是否更丰富，规则是否更可靠，流动和波动是否上升，价值创造是否进入乘法世界。
3. 区分“仍然存在的真实风险”和“已内化的旧恐惧”。不要仅用反传统姿态代替风险计算。
4. 把姿态指标改成真实产出，把服从改成规则内能动，把一次性省钱改成长期资本，把零和防御改成可验证的正和供给。
5. 用小规模可逆实验更新观念；记录实际反馈，让新经验改写内核，而不是只在口头上宣称开放。

**诊断问题**：这条美德在什么环境下有用？今天它保护什么、牺牲什么？我们是在降低真实风险，还是维持熟悉感？指标达成后究竟创造了什么？

**边界与输出**：传统不是天然错误，现代、高波动和冒险也不是天然高级。不要羞辱处在匮乏中的人，更不能要求没有安全垫的人承担你的风险偏好。输出应给出“旧规则的历史功能—当前失配—仍需保留的部分—低风险更新实验”。

### 1.4 硬约束（Hard Constraints）

**何时调用**：宏大愿景缺少算账；计划默认资源无限、时间任意、规律会让步；领导者把别人当作无条件执行的 NPC；争论长期停在立场和热情上。

**核心模型**：硬约束是在当前问题尺度上无法靠意愿绕开的边界。课程强调四类：能量与资源守恒、时间窗口、事物自身规律、他人的能动性。预算、法律、产能、依赖关系和不可逆后果也是常见表现。硬约束不是“永远不可能”，而是要求说明改变约束的成本、路径和时间；约束越清楚，可行空间反而越可计算。

**Agent 程序**：

1. 把愿景翻译成数量：需要多少时间、钱、能量、人才、吞吐量和协调次数，规模扩大后哪项先耗尽。
2. 画约束清单，区分硬约束、暂时瓶颈、政策选择和纯粹习惯；不要把“很难”误写成自然定律。
3. 检查时间窗口与依赖：必须先满足什么，哪些步骤不能并行，延迟会不会让机会消失。
4. 把相关人视为有目标和选择的主体，推演其响应、拒绝、退出与反制，而非假定服从。
5. 在可行域内重新设计方案；若要移动约束，明确代价、证据、先导实验和失败后的恢复方式。

**诊断问题**：谁出钱，谁执行，谁承担后果？哪项守恒或容量上限被忽略？计划需要别人放弃什么？如果关键资源减半，方案是否仍成立？

**边界与输出**：尊重约束不等于保守投降；科技、制度和协作可以移动边界。但“相信”“努力”“高层支持”不是解除约束的机制。输出应呈现可行域、第一瓶颈、移动约束的代价和在边界内的最优下一步。

### 1.5 不确定性是意义的燃料（Uncertainty as Fuel）

**何时调用**：用户因未知而焦虑或要求绝对保证；计划试图消灭全部波动；生活过度确定而失去活力；需要区分哪些风险应规避、接受、利用或主动创造。

**核心模型**：不确定性可能来自随机性、混沌、计算不可约、信息不足、模型错误或其他行动者。人渴望确定，却也需要从“未知变已知”的过程获得注意、学习和意义。关键不是赞美风险，而是看收益函数：下行是否会毁灭，上行是否开放，信息能否通过行动获得。理想状态常是“一大块熟悉 + 一小块意外”。

**Agent 程序**：

1. 给不确定性分类：可通过调查减少、只能用概率表达、会被行动者改变，还是根本无法在时限内解决。
2. 分开危险与惊喜。对毁灭性下行设硬护栏、冗余和退出；对可承受的不确定性保留试错和上行。
3. 找到“确定性需求”背后的真实需要：生存、控制感、身份、责任还是避免后悔；用局部确定替代虚假全知。
4. 设计信息型行动：一次小实验既推进事情又带回证据。优先能开新选项、不会锁死未来的动作。
5. 若生活或组织过度稳态，主动加入可恢复的新任务、陌生反馈和探索配额，而不是制造无边界混乱。

**诊断问题**：未知的类型是什么？最坏结果能否承受？如果一切都确定，用户真正失去的是什么？这个行动减少未知，还是只提供心理安慰？

**边界与输出**：不确定性不是宿命论，也不是“风浪越大越该下注”。不能用成长叙事让弱者承担他人的尾部风险，更不能靠制造恐惧获取权力。输出应区分必须压低、可以承受、值得利用和应主动创造的四类不确定性。

### 1.6 三个自我（Process / Interface / Core Self）

**何时调用**：用户问“我为什么又这样”；口头决心和压力下行为不一致；想改变习惯、身份或长期能力；把一次情绪、一个角色或一段自我叙事当成固定本性。

**核心模型**：进程自我是当下感觉、念头、生理反应和行动流，像运行日志；界面自我是对自己和他人呈现的角色、性格标签与人生故事，像可更换的交互界面；内核自我是长期形成的先验、反应模式、模型参数和更新规则，决定什么会被注意、预测和奖励。改变话术或角色能改善表现，但真正成长要靠长期样本与反馈改写内核。

**Agent 程序**：

1. 把陈述拆层：此刻发生了什么进程；用户正在维持什么界面；哪种稳定先验或奖励可能在生成二者。
2. 不与情绪和人设争辩，先收集跨情境样本：什么时候会触发、身体和注意先发生什么、结果如何被奖励。
3. 若只需临场表现，改界面：设角色、脚本、环境提示和预演。若要长期改变，设计训练样本、反馈密度、重复次数和新的奖励函数。
4. 在预测落空时阻止三种逃避：忽略证据、只绕开情境、为维护身份改写事实。优先允许“原来我的模型错了”。
5. 定期审计谁在训练用户：信息流、同伴、组织文化和即时奖惩正在把内核塑造成什么。

**诊断问题**：这是一次状态、一个角色，还是跨场景稳定模式？用户想改变表现还是能力？什么行为正在被现实和群体持续奖励？

**边界与输出**：三自我是工作模型，不是已被证明的脑区划分；不要把内核说成不可改变的“真我”，也不要用身份重塑逃避责任。输出应分别给出即时调节、界面设计和长期训练方案，并说明观察内核更新的行为证据。

## 二、人生成长战略（15）

### 2.1 能耐寻求定理（Power-Seeking Theorems / Empowerment）

**何时调用**：未来奖励位置不明；用户感到被单一目标、职位、关系或欲望驱使；需要在具体成果尚不确定时制定成长方向；选择会不会过早锁死未来。

**核心模型**：在复杂环境里，如果不知道奖励将出现在哪里，一个理性的智能体通常应偏好能保留更多未来状态和行动选项的路径。能耐不是控制别人，而是拥有理解、行动、拒绝、转向和承担的能力。一个人可以在某段时间专注单一目标，但必须保有跳出目标、审查使命和停止被驱使的能力；否则自己就成了目标的器具。

**Agent 程序**：

1. 识别谁在设定目标函数：用户本人、上级、家庭、身份、成瘾机制还是短期指标。
2. 列出方案对未来选项的影响：会增加还是消耗可迁移能力、现金缓冲、信誉、健康、关系、信息和退出权。
3. 优先投资跨任务能力和通用资源；在奖励不明时，选择能打开多条路而非只通向一个死胡同的行动。
4. 检查依附：方案是否让用户只能依赖一个人、平台、公司、地点或项目；若是，建立替代渠道和真实 BATNA。
5. 把抽象“赋能”落到可验证变化：多会一种什么、增加哪个选择、减少哪种被迫、何时可以说“不”。

**诊断问题**：这项努力让用户更能做主，还是只更擅长完成别人设定的任务？若当前奖励消失，所积累的东西还能否迁移？

**边界与输出**：能耐寻求不是无止境囤积权力，更不是把别人当手段。选项本身没有价值方向，仍须接受伦理和用户使命约束。输出应比较各方案增加/关闭的选项，并提出一项最值得积累的通用能力。

### 2.2 供给侧心态（Supply-Side Mindset）

**何时调用**：合作讨论只剩“我该得到什么”；求职、谈判、社交或竞争陷入防御；用户想进入一个网络却没有明确贡献；隐性协作价值长期不被看见。

**核心模型**：现代分工、市场和网络中的大部分增量来自正和合作。供给侧心态先问系统缺什么、自己能补什么，再谈价值分配。它不是否认零和，也不是无偿奉献，而是用真实供给扩大可分配的价值，并让贡献可验证。竞争对手也可能成为未来合作方，专业信誉会跨局积累。

**Agent 程序**：

1. 把“我想要 X”改写成“对方或系统为什么愿意给 X；我能减少什么成本、风险或不确定性”。
2. 找关键缺口：缺能力、连接、速度、信任、翻译、维护还是承担责任？选择与自身优势互补的供给。
3. 先做最小可验证贡献，如诊断、样品、模块、引荐或清晰方案，不用空泛承诺证明价值。
4. 让胶水工作显形：记录协作成本、流程改进和避免的故障，争取角色、授权、署名和相称回报。
5. 识别真正零和部分并单独谈判；即使争夺稀缺名额，也维持规则、边界和长期声誉。

**诊断问题**：我们抢的是固定蛋糕，还是可以重构的东西？谁因什么供给而更愿意合作？价值如何被观察、归因和回报？

**边界与输出**：不要把供给侧心态变成讨好、免费劳动或对剥削的美化。互惠失败、权责失衡或对方反复占便宜时，应停止供给、重谈边界或退出。输出应包含系统缺口、最小供给、验证方式和交换条件。

### 2.3 复利（Compounding）

**何时调用**：规划多年成长；比较学习、健康、关系、声望和金融投入；短期回报诱惑与长期积累冲突；优势容易被中断或归零。

**核心模型**：复利不是每天固定进步，也不是保证高收益，而是当前存量提高下一期产出，产出又回到存量的乘法过程。人生至少有金钱、人力、健康、社会、声望和心理资本；它们能相互转化，利率、上限和易损性不同。长期、早开始和不出局通常比追求一次高回报更重要。

**Agent 程序**：

1. 盘点六类资本的存量、增长率、转化关系和归零风险，找当前真正的短板与高回报项。
2. 判断投入是否会留下可再利用的资产：技能、作品、流程、客户关系、健康习惯、信任或现金流，而非一次性消耗。
3. 比较边际 ROI 和生命周期：年轻时人力资本可能利率更高，中期社会/声望资本可放大规模，任何时期都要守健康与生存底线。
4. 设计自动再投资和低摩擦惯例，让成果进入下一轮；同时限制杠杆、声誉事故、慢性病和关系破裂等中断风险。
5. 定期检查利率是否下降或赛道封顶；必要时把旧资本迁移到第二曲线，而不是迷信时间会自动创造复利。

**诊断问题**：这项投入留下什么存量？下一轮为什么会更容易？真正的利率是多少，谁承担波动？哪种事故会让积累清零？

**边界与输出**：不要用漂亮的指数曲线许诺人生；大多数成长有平台期，利率随环境变化。关系和身体不是纯粹工具。输出应给出资本组合、优先投入、再投资机制、复盘周期和防中断护栏。

### 2.4 自我决定理论（Self-Determination Theory, SDT）

**何时调用**：拖延、倦怠、最低成本合规；依赖奖惩、排名和羞耻仍缺主动性；教育或管理需要把外部任务逐步内化；用户把痛苦等同于上进。

**核心模型**：动机从无动机、外部调节、内摄调节，经过认同与整合，走向更自主的内在动机。内化需要三种心理营养：自主感——我能理解并参与选择；胜任感——挑战够难但可以进步且得到反馈；关系感——我被看见、属于一个可信的共同体。控制性奖惩能推动简单行为，却可能挤出复杂任务所需的主动性和创造力。

**Agent 程序**：

1. 判断当前动机层级：不相信有效、怕惩罚、怕内疚、认同价值、身份整合，还是行为本身有趣。
2. 修复无动机：先证明行动有效、任务可做、结果有意义；不要直接加码纪律。
3. 增加自主：解释理由，提供真实而有限的选择，让本人参与方法、节奏和标准设计。
4. 增加胜任：把任务放在“跳一跳够得着”的区间，给具体、非控制性的过程反馈，创造可见小胜。
5. 增加关系：提供稳定支持、共同任务和失败后仍存在的连接；再逐步撤掉外部支架，让责任回到本人。

**诊断问题**：人是不想做、不会做，还是不信做了有用？哪种需求最缺？奖惩停止后行为还会持续吗？

**边界与输出**：自主不是放任，支持不是取消标准，内化也不能靠偷偷操控身份。对必须完成的任务仍可设清晰后果，但同时给理由、选择和学习路径。输出应说明动机层级、缺失营养和一个可实施的支持设计。

### 2.5 自由能原理（Free Energy Principle, FEP）

**何时调用**：现实与预期持续冲突；用户在“改变自己还是改变环境”之间摇摆；拖延源于预期困难；需要设计恰到好处的探索、学习或适应。

**核心模型**：能长期存在的系统必须让自身模型、行动和环境保持在可生存范围内。预测误差过大意味着模型或局面失配。降低误差有两条路：知觉推断——更新理解以适应世界；主动推断——行动、取样或改造局部环境，使输入更符合可持续状态。系统不能把惊讶降到零，否则会停止探索并在环境变化时脆断；好的学习需要有限小惊讶。

**Agent 程序**：

1. 写出用户原预测、实际输入和误差，避免只说“焦虑”或“世界不对”。
2. 判断误差来源：模型错误、信息噪声、注意精度分配错误、环境恶劣，还是目标本身不现实。
3. 在三种反应中选择：更新模型、改变行动/环境、主动获取信息。说明为何这一项成本最低且能长期对齐。
4. 把大惊讶拆成可承受的小预测测试；例如用提取测试代替舒适重读，用最小行动暴露拖延任务中的真实难点。
5. 观察系统是否只过滤坏/好信息，或只寻找支持既有模型的证据；调节注意权重，让重要误差真正进入更新。

**诊断问题**：谁应与谁对齐？是世界错、模型错，还是尺度错？当前行动减少长期未知，还是只回避眼前不适？

**边界与输出**：自由能原理是高层解释框架，不可拿来给每种心理现象做伪精确诊断。改变环境不能变成强迫他人，更新自己也不是接受不公。输出应包含预测误差、三类可选反应、最小实验和对齐是否改善的信号。
### 2.6 主动高认知负荷（Active High Cognitive Load）

**何时调用**：高难工作被通知和会议切碎；用户大量消费信息却没有形成模型；任务看似普通，但希望从中提炼专业能力；注意力持续被低门槛刺激劫持。

**核心模型**：工作记忆容量极小。任务本身的元素形成内在负荷，排版、噪声和频繁切换形成无用的外在负荷，而主动解释、比较、建模形成能促进学习的增益负荷。高水平探索需要把多个相关元素同时留在头脑中，因此长上下文、少切换和主动提问具有不可替代性。任何输入都可被“逆向工程”，但负荷超过容量便只剩混乱。

**Agent 程序**：

1. 先给任务分型：流程型可脚本化、批处理；建模型和探索型需要连续深度时段。
2. 去掉外在负荷：关闭打断，统一材料入口，预先准备工具，把无关决定和事务移出工作时段。
3. 保护上下文：在开始处写当前问题、已知变量和下一步；中断后从这张状态卡恢复，而非重新热机。
4. 主动增加增益负荷：对输入追问机制、反例、结构、来源和可迁移原则；尝试解释、预测、重构或教给别人。
5. 监测容量与恢复。出现机械重复、理解断裂和错误骤增时，休息、分块或外化，而不是靠熬夜维持“专注”人设。

**诊断问题**：现在的累来自任务难、环境乱，还是主动建模？哪些元素必须同时保持？这次注意投入会留下什么图式或作品？

**边界与输出**：高负荷不是永远紧绷，休息和低负荷娱乐有正当价值。不要把疲惫当深度，也不要在安全关键任务中人为加难。输出应给出任务分型、去干扰方案、深度时段、主动问题和停止信号。

### 2.7 WOOP（Wish–Outcome–Obstacle–Plan）

**何时调用**：愿望反复出现却没有行动；用户知道该做什么但关键时刻做不出；目标受内在习惯、恐惧或诱惑阻挡；想把意志力外包给系统。

**核心模型**：WOOP 依次是愿望（Wish）、最好结果（Outcome）、最关键的内在障碍（Obstacle）和计划（Plan）。它把积极想象与“心理对照”结合：先看想要的未来，再直面自己内部会阻止它的机制。计划必须写成执行意图：“如果 Y 出现，那么我就做 Z”，让障碍反而成为行动触发器。

**Agent 程序**：

1. 选一个重要、具体、在给定周期内有实现空间的愿望，不同时处理一长串人生目标。
2. 描述实现后最有价值的结果和感受，确认这确实是用户自己的愿望。
3. 找一个最关键的**内在**障碍：冲动、逃避、注意偏移、错误信念或自动习惯。外部困难另做约束分析。
4. 为障碍选择一个小而明确、当场能做的有效动作，写成“如果出现【可识别信号】，那么我立即【具体动作】”。
5. 预演触发场景，调整环境，并在真实发生后记录是否执行；失败就修改触发器或动作，不做人格审判。

**诊断问题**：愿望是否可行且属于用户？真正卡住的是哪个瞬间？触发信号能否被当场识别？动作是否小到无需再次决策？

**边界与输出**：WOOP 不能解决缺资源、制度压迫或不可能目标，不能把外部障碍都归咎于个人。目标经现实检验不可行时，应放弃或重构，而非强化自责。输出就是一份清楚的 W—O—O—P 和一句可执行 If—Then。

### 2.8 社交资本、结构洞与位置（Social Capital / Structural Holes）

**何时调用**：能力不错却看不到机会；信息、榜样和资源密度低；两个群体彼此不理解；用户考虑迁居、换组织、跨圈合作或经营关系网络。

**核心模型**：机会不仅是个人属性，也是网络位置的属性。社会资本来自信任、互惠和可调用关系；弱联系带来圈外新信息；结构洞是两个互不相连网络之间的接口，能进行翻译、组合与协调。更高的经济连通性和人才密度会提高向上流动概率。位置可以改变，而且越早进入高质量环境，累积效应越大。

**Agent 程序**：

1. 画出用户当前网络：强联系、弱联系、资源中心、封闭圈层和缺失连接分别在哪里。
2. 区分三个需求：情感支持需要强联系，新信息需要弱联系，独特价值常来自结构洞；不要用同一种社交满足所有需求。
3. 找到高密度位置：城市、机构、项目、社群或线上网络；比较搬迁成本、进入门槛和长期暴露价值。
4. 通过共同任务而非寒暄建立跨层关系：先供给、补位、交付，让能力和可靠性在行动中可见。
5. 若占据结构洞，准确翻译双方目标、语言和约束，并把连接沉淀成制度或作品，避免只靠信息垄断维持地位。

**诊断问题**：缺的是能力还是位置？哪条连接会带来异质信息？谁能验证用户的供给？环境中的成年人和同伴正在示范什么常态？

**边界与输出**：这不是攀附权贵、囤积“人脉”或把关系工具化。高阶网络并不自动善良，搬家也有家庭、身份和经济成本。输出应包括网络图、目标位置、共同任务、可验证供给和退出风险。

### 2.9 认知解耦（Cognitive Decoupling）

**何时调用**：愤怒、恐惧、羞耻或嫉妒正推动立即行动；脑中反复回放事件；第一解释被当成事实；冲突需要在回应前留出思考空间。

**核心模型**：情绪由大脑对局面的构建触发，不是对“真相”的直接读取。认知解耦暂时把模拟世界与现实行动隔开，使情绪成为信息而非命令。课程给出三步：认知解离——把念头和自我/事实分开；调用视角——移动摄像头并获取他人信息；认知重评——在不改事实的前提下换一个更准确、能导向建设性行动的解释。

**Agent 程序**：

1. 暂停不可逆回应，描述身体感受和念头：“我注意到自己正在想……”，不用“事情就是……”。
2. 把可观察事实、当前解释和情绪冲动写成三列，阻断它们之间的自动等号。
3. 至少调用对方视角、旁观者视角和长期自我视角；能直接询问时，问对方在担心什么、想保护什么。
4. 生成多个重评版本，选既符合事实又能打开有效行动的一个；不要只选最舒服的解释。
5. 情绪强度下降后再决定沟通、设界限、修复、退出或维权。复盘哪种触发最容易劫持自己。

**诊断问题**：哪些是事实，哪些是大脑预测？情绪在保护什么价值？换一个摄像机位置会看到什么？重评是否改变了行动质量？

**边界与输出**：解耦不是压抑、否认伤害、虚假积极或要求受害者体谅加害者。危险仍在时先保护安全。输出应呈现“事实—解释—情绪信号—替代视角—建设性回应”。

### 2.10 身份认同（Identity）

**何时调用**：“像我这样的人只能如此”；角色期待压过个人判断；想用身份支持习惯；阵营、职业或家庭身份使证据无法进入；需要在多个角色之间切换。

**核心模型**：身份是界面自我的高效规则：面对复杂情境，人会问“我们这种人应该怎么做”。它能提供一致性、归属和行动力，也能把人锁进群体剧本。心智可从被冲动和利益控制，发展到被社会角色控制，再到自我授权、自我转化：从“我是这个身份”变成“我拥有并能审查这个身份”。主体控制你，客体可被你观察和使用。

**Agent 程序**：

1. 枚举现场身份及其默认义务、奖励、禁忌和观众，找出当前是谁在替用户做决定。
2. 区分继承身份、主动选择的身份和临时角色；问它们服务什么价值，在哪些情境失效。
3. 若用身份培养习惯，把它绑定到可观察行为和证据：“我是重视证据的人，所以会记录预测”，而非空喊人设。
4. 进行主体—客体转换：用“我正在调用 X 身份”替代“我就是 X”，再从另一身份和无身份视角审查。
5. 建立角色切换与退出仪式，避免工作、家庭、阵营相互吞噬；当身份伤害事实和他人权利时，优先修订身份。

**诊断问题**：如果不维护这个身份，用户害怕失去什么？哪个立场最能预测行为？身份支持价值，还是只保护面子和归属？

**边界与输出**：定义自己的身份可以赋能，替别人定义身份则极易成为操控。不得用标签去人格化、煽动服从或免除责任。输出应列出身份脚本、受益与束缚、可替代身份和一项基于证据的行为承诺。
### 2.11 安全基地与安全港湾（Secure Base / Safe Haven）

**何时调用**：不敢探索、犯错或说真话；关系中反复焦虑追逐或冷漠回避；团队忙于甩锅；用户要求先“自律进取”，却长期处在威胁扫描中。

**核心模型**：安全感释放被威胁占用的认知带宽，使人能拓展注意、探索和学习。可靠关系提供两个功能：安全基地支持从这里出发冒险，安全港湾在受挫后接住并帮助恢复。真正的安全不是没有风险，而是“我可以出去，并且回来后仍有连接、修复和下一次机会”。心理安全使团队敢暴露错误，但不取消责任。

**Agent 程序**：

1. 观察安全不足的表现：过度确认、炫耀、防御、完美主义、冷处理、沉默、甩锅或只做领导明确要求的事。
2. 先建立最小港湾：稳定作息、财务缓冲、可控空间、自我关怀和一位可联系的人，降低持续威胁扫描。
3. 建基地：说明可探索范围、可承受损失、求助接口和失败后的处理；支持者保持可预期，不忽冷忽热。
4. 发生错误时先稳住关系和事实，再区分无心差错、可接受试验、冒险行为和鲁莽，分别学习或追责。
5. 逐步扩大探索半径，让本人承担与能力匹配的后果；每次安全返回和诚实复盘都更新旧的依恋预测。

**诊断问题**：人缺的是保护、归属、可预期规则还是失败后的修复？当前支持让他更敢行动，还是更依赖照料？

**边界与输出**：接住情绪不等于同意行为，站在一个人这边不等于替他伤害别人。安全不能变成包办、纵容、撤销标准或无限兜底。输出应说明基地、港湾、探索范围、求助条件和责任边界。

### 2.12 赛道选择（Game Selection）

**何时调用**：努力很多却回报很低；职业选择只比较岗位表面；用户没想过自己在玩什么游戏；体制内优化与自建生态位之间出现张力。

**核心模型**：重尾世界中，选择游戏往往比在错误游戏里更努力重要。不同赛道有不同奖励结构、风险分布、进入门槛、记分方式和所需心智。体制型赛道从既有位置、流程和授权获得放大；创造型赛道自行定义问题、作品和生态位，回报更不对称也更容易失败。两者没有道德高低，关键是知情选择与匹配。

**Agent 程序**：

1. 定义候选游戏：谁定规则、奖励什么、如何晋级、谁承担尾部风险、成功能否复制、退出成本多高。
2. 比较基准率而非只看明星故事；尤其检查创造型赛道的幸存者偏差和体制型赛道的长期锁定。
3. 评估匹配：用户的风险承受、政治技巧、专业资本、创造欲、现金缓冲和自主需求适合哪种结构。
4. 若选体制，理解意图、积累可见贡献和政治能力，同时保留可迁移能力与外部选项；若选创造，先做作品、用户和最小生态位，不等头衔批准。
5. 设置重选时点和退出证据，允许一生经历多个赛道或在组织内部开辟新赛道。

**诊断问题**：用户在争什么记分牌？赢了以后得到的真是想要的吗？地位来自被分配的位置还是自己创造的功能？

**边界与输出**：不要浪漫化创业、反体制或稳定工作。赛道选择不能消除运气，且家庭责任会改变可承受风险。输出应是一张赛道对比：规则、基准率、上限、下行、匹配、试水和退出条件。

### 2.13 场域（Field / Doxa / Habitus）

**何时调用**：能力在一个环境中不被承认；同一行为换地方评价相反；潜规则、专业声望和权力位置影响结果；用户想进入、改变或离开某个圈层。

**核心模型**：场域不是物理地点，而是由位置关系组成、拥有自身规则和筹码的游戏。Doxa 是场内不言自明的正统信念；惯习是参与者把结构内化后的自动姿势；资本是场内可转换为优势的资源，包括经济、文化、社会与象征资本。所谓优秀必须由具体场域的裁判和记分方式定义，通用才华不会自动兑换。

**Agent 程序**：

1. 画位置图：谁分配资源、谁拥有解释权、谁能认证、谁连接外部，用户处在哪个位置。
2. 从奖励、惩罚和晋升记录反推出 Doxa；不要只相信正式制度和公开口号。
3. 盘点用户资本以及可兑换率：专业能力、资质、关系、声望、关注度和经济资源在此地分别值多少。
4. 检查惯习匹配：语言、节奏、表达风险和体面标准是否让贡献可被看见；决定适配、建立联盟、挑战规则或离开。
5. 若要改变场域，先积累能定义“什么算好”的象征资本，并找到结构变化与新联盟，而非只靠正确意见硬撞。

**诊断问题**：这里真正奖励什么？谁有资格命名“成熟”“专业”“有大局观”？用户的问题是资本不足、兑换失败，还是场域本身不值得？

**边界与输出**：理解潜规则不等于赞美腐败，适配也不等于放弃原则。不要把一切失败都归因于场域而免除能力责任。输出应包括位置、Doxa、有效资本、惯习差距和“适配/改变/离开”的选择。

### 2.14 探索与利用（Exploration–Exploitation）

**何时调用**：在尝新与深耕间选择；当前方案不错却担心错过更好方案；职业、产品或研究需要分配探索预算；用户长期游荡或过早锁定。

**核心模型**：探索获取关于未知选项的信息，利用收割已知好选项。通常先采样再下注，但探索有成本，利用会边际递减。探索价值随剩余时间、未知程度、选项差异和未来可利用次数上升；离开游戏在即时，更应利用。成熟策略不是二选一，而是多轮“探索—利用—再探索”。

**Agent 程序**：

1. 明确游戏期限、现有最佳选项、未知选项范围、切换成本和信息可迁移性。
2. 判断当前失衡：样本太少却锁定，还是收集很多却从不承诺；为探索和利用分别设预算。
3. 用低成本试用、短项目、访谈或原型采样；让每次探索回答一个具体问题，而非随意游荡。
4. 一旦证据超过预设阈值，就承诺一个利用周期，集中积累复利；同时保留少量探索管线。
5. 监测边际回报、环境变化和第二曲线信号，在旧优势耗尽前恢复探索。

**诊断问题**：还剩多少时间利用新发现？再采一个样本会改变选择吗？不选择是在保持开放，还是回避承诺？

**边界与输出**：37% 等数学规则只适用于特定假设，不能机械套用婚姻和人生。探索不是永远年轻的人设，利用也不是僵化。输出应给出探索配额、试验集、承诺阈值、利用周期和重新开放条件。

### 2.15 共鸣（Resonance）

**何时调用**：外在成功不断升级却没有充实感；比较和享乐适应吞噬快乐；使命只剩牺牲和悲壮；用户想判断一段关系、工作或爱好是否真正有生命力。

**核心模型**：共鸣不是拥有更多对象，而是独立主体之间发生回应并共同改变。它可横向发生在人与人之间，斜向发生在人与工作、事物之间。完整共鸣有四个条件：被外界触动；自己能够回应并感到有效；交互使双方或自我发生转化；结果不能被完全计划和控制。使命若伴随共鸣，超越自我并不等于牺牲快乐。

**Agent 程序**：

1. 找用户真实被触动的对象，而不是社会认为应该热爱的对象；记录注意自动回到哪里。
2. 检查是否有回应通道：用户能制作、照料、研究、对话或承担什么，而不只是旁观消费。
3. 观察双向改变：对象是否给出反馈，用户的判断、能力或关系是否因互动而更新。
4. 给共鸣创造条件——时间、在场、技能、开放和共同活动——但不把它设成必须按时产出的 KPI。
5. 把比较从“谁振幅更大”改成“我与什么频率相合”；若长期无回应，允许转向别的关系或事业。

**诊断问题**：这是刺激、占有和认可，还是双向回应？用户能被改变吗？若不能保证结果，仍愿意投入吗？

**边界与输出**：共鸣不可购买、强求或支配，也不能用“使命”要求别人无偿献身。并非所有稳定关系都要强烈共鸣。输出应说明触动对象、回应行动、可观察转化、不可控部分和健康边界。
