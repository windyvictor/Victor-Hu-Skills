## 三、决策与判断（16）

### 3.1 无免费午餐定理（No Free Lunch Theorem）

**何时调用**：寻找适用于一切情境的最佳方法；方案“既要、又要、还要”；用户想等信息完备后得到唯一客观答案；价值选择被伪装成技术结论。

**核心模型**：没有算法能在所有可能问题上都优于其他算法。一个方法之所以在某类问题上强，是因为它植入了关于该类问题的归纳偏置，也必然在别处付出代价。决策因此包含不可消除的主观起点：先选择什么问题值得解决、什么结果算好，再做客观搜索。偏置是可修订的起始立场；偏执是在反馈反对后仍拒绝更新。

**Agent 程序**：

1. 把方案宣称的“普适最优”拆成具体任务分布、目标函数和环境假设。
2. 迫使用户排序：哪些维度必须牺牲，哪些价值不能交换；把隐含偏置写明。
3. 在选定的问题类内比较算法、证据和工程约束，不用“价值主观”逃避技术严谨。
4. 采用系统化冒险：小注起步、收集反馈、预设改判条件和退出机制；允许强先验但不允许不可证伪。
5. 记录方法的适用域和失败域。若换了对象、尺度或分布，重新选工具，不把一次成功扩张为宇宙规律。

**诊断问题**：这个方法靠什么假设获得优势？它牺牲了什么？所谓客观答案中藏着谁的价值排序？什么反馈会让我们换算法？

**边界与输出**：定理不意味着“所有方法一样好”或“随便选”。一旦任务分布被限定，方法可以有稳定优劣。输出应给出目标偏置、适用问题类、主要代价、搜索方案和更新条件。

### 3.2 概率分布（Probability Distribution）

**何时调用**：只报成功率或平均收益；用一次成败评价策略；选择涉及低概率重损、高方差或不对称回报；用户问“最可能怎样”却真正关心能否承受。

**核心模型**：决策选择的不是一个结果，而是一整个未来分布。至少检查均值、中位数、方差、偏度、上下限、尾部、相关性和重复次数。同样期望值可能对应完全不同的生活体验；个体的财富、年龄、责任和恢复能力决定其能承受哪个分布。好的过程可能输一次，坏的过程也可能侥幸赢。

**Agent 程序**：

1. 列出主要结果区间及概率；数据不足时给情景和范围，不伪造精确小数。
2. 计算或定性比较期望，同时单独标注最坏可置信结果、毁灭尾部、上行空间和结果偏斜。
3. 把分布与用户效用匹配：同一笔损失对有无安全垫的人意义不同，生命阶段也改变风险承受。
4. 判断决策能否重复。可重复的小赌可依赖长期统计；一次性、相关或会出局的赌局必须提高安全权重。
5. 事后分开评价过程与结果：按当时信息评审策略，再用结果更新参数，避免结果偏差。

**诊断问题**：平均值掩盖了什么？最坏能有多坏，用户能否恢复？这是一次赌局还是可重复系统？赢和输的幅度是否对称？

**边界与输出**：概率分布仍依赖模型和数据，不能把数字外观当确定性。极端风险常被样本低估。输出应是一张简化分布表、承受性判断、尾部护栏及事后评价规则。

### 3.3 颗粒度与因果中介（Granularity / Causal Mediator / MDL）

**何时调用**：解释只有口号或标签；模型细节多到无法行动；相关关系被当成因果；干预总盯最终结果，找不到可撬动环节。

**核心模型**：有效控制需要足够复杂的内部模型，但复杂并非越多越好。最小描述长度（MDL）追求用尽量短的模型解释尽量多的有效数据。因果不是“同时发生”，而是干预 X 会改变 Y。许多粗糙关系通过中介变量发生；找到中介，才知道在哪里动手。颗粒度应由当前决策需要决定。

**Agent 程序**：

1. 明确模型服务的决定：要预测、解释还是干预；无关细节即使真实也先拿掉。
2. 列关键变量，画带方向的因果图；区分原因、结果、共同原因、中介和可能的反馈。
3. 对每条箭头问：如果单独干预前项，后项会变化吗？有什么实验、自然对照或机制证据？
4. 若关系太粗，寻找可操作中介；若图太繁，合并不会改变决定的节点，以最小模型保留最大解释力。
5. 指定要观测和干预的一两个关键中介，并写出预测：中介改变后，终点指标应在何时、以何方向变化。

**诊断问题**：模型缺少哪种复杂度才会犯错？哪项只是相关？真正改变概率结构的是哪一步？删掉哪个变量结论仍不变？

**边界与输出**：简化不是武断，复杂也不等于真实。因果图是可修订假说，不能用漂亮箭头掩盖无证据。输出应包含最小因果链、关键中介、干预点、观测指标和替代机制。

### 3.4 贝叶斯先验（Bayesian Prior）

**何时调用**：新证据需要改变信念；罕见事件检测；判断人、消息或风险是否可信；用户在“毫无立场”和“绝不动摇”之间摆动。

**核心模型**：后验判断来自先验与新证据的似然共同作用。先验不是可耻偏见，而是压缩历史频率、环境知识和已有经验的起点；新证据的力量取决于它在不同假设下出现的相对可能性。罕见事物即使测试很准，也可能有大量假阳性。科学气度是先有合理强度的信念，又为“我可能错”保留概率。

**Agent 程序**：

1. 定义互斥或可比较的假设，并找最接近的基准率作为外部先验。
2. 加入对象特征，说明它为何应使先验上调或下调；不要重复计算同一信息。
3. 评价证据似然：若假设真/假，看到该证据各有多常见；生动、权威和转发量不等于高似然比。
4. 更新到一个范围或等级，并记录前后变化。证据弱就小改，独立且诊断性强的证据才大改。
5. 预先规定下一条什么证据会继续更新，并用行动获取；持续校准预测而非只发表观点。

**诊断问题**：基准率是多少？这个证据在假设为假时也很常见吗？先验来自数据、环境，还是身份忠诚？

**边界与输出**：不把概率设为绝对 0 或 1，但也不必对荒谬说法假装五五开。证据相关、选择性呈现时不能连乘。输出应列先验、证据诊断性、更新后判断和下一更新条件。

### 3.5 信息价值（Value of Information, VOI）

**何时调用**：是否继续调研、测试或购买报告；信息焦虑和 FOMO；团队收集很多数据却不改变动作；需要选择最值得问的问题。

**核心模型**：信息的决策价值等于“获得信息后能做得多好”减去“没有信息时能做得多好”，再扣获取、延迟和注意成本。真实、精彩或稀缺的信息未必有 VOI；只有可能让行动跨过决策边界的信息才值钱。与决定无关但令人愉快的信息属于消费价值，应另账处理。

**Agent 程序**：

1. 先写当前选项、默认行动和切换阈值；没有具体决定，就暂不谈决策信息价值。
2. 枚举可能得到的答案，以及每种答案会不会改变行动；若无论如何都不变，VOI 接近零。
3. 估计完美信息价值上限，再比较现实测试的准确度、样本偏差、价格、时间和错过窗口的成本。
4. 优先寻找本地、痛感强、诊断性高的信息：瓶颈数据、失败反馈、真实产能、用户行为，而非人人可见的宏观热搜。
5. 选择最便宜的充分信息行动，如小样本、A/B 测试、原型或专家复核；达到决策阈值就停止搜集。

**诊断问题**：知道答案后具体会做什么不同？当前离切换边界多远？这条信息减少不确定，还是确认“我是懂行的人”？

**边界与输出**：低 VOI 不等于信息无真理或审美价值，只是对当前决定帮助小。研究可能产生未来选项，但需说明。输出应给出决策边界、候选信息、价值上限、获取成本和停止规则。
### 3.6 凯利公式（Kelly Criterion）

**何时调用**：已经判断有优势，却不知道投入多少；乘法式、可重复赌局；职业转向、项目、投资或信任需要决定仓位；用户在小利上冒命、在大机会前惜身。

**核心模型**：凯利准则把认知优势转换成下注比例，以最大化长期对数增长率。简化形式中，最优仓位随主观胜率相对市场赔率形成的 edge 增大；没有正 edge 就不下注。它不是让单次收益最大，而是在连续复利游戏中避免过量下注导致清零，也避免仓位太小浪费可靠优势。

**Agent 程序**：

1. 确认这是可重复、乘法结算且损益相对当前资本计算的场景；一次性人生决定只能借其精神，不能机械套公式。
2. 估计胜率、赢时收益、输时损失和市场隐含判断，说明自己的 edge 来自何种独立信息或能力。
3. 若 edge 不清楚或没有可验证来源，仓位设为零或信息型小注；绝不因高赔率本身兴奋。
4. 计算理论上限后，考虑估计误差、相关风险和人性承受，采用半凯利或更低的分数凯利。
5. 保留不能被一把清零的资本，按新证据逐步加减仓；评价长期过程，不随一次输赢改变纪律。

**诊断问题**：凭什么认为自己比市场高明？胜率误差若扩大一倍，仓位是否仍安全？这项资本损失后能否补回？

**边界与输出**：凯利依赖准确概率和稳定赔率，现实常不满足；财务和高风险应用需专业审查。道德承诺也不能由收益公式决定。输出应给 edge 来源、理论仓位、折扣理由、清零护栏和更新规则。

### 3.7 非遍历性（Non-Ergodicity）

**何时调用**：总体期望很好但个人可能出局；用群体平均替个体长期命运；连续乘法风险、杠杆、债务、创业或健康选择；需要设计保险和共担机制。

**核心模型**：遍历系统中，许多个体同一时刻的集合平均可以代表一个个体跨时间的平均；非遍历系统中不能。少数极端赢家能抬高群体期望，但一个真实的人沿单一路径生活，破产、死亡或失去资格后无法跳到赢家路径。数学期望是上帝视角，时间平均才是凡人命运。

**Agent 程序**：

1. 判断结果是相加还是相乘，失败是否改变下一轮本金、资格、健康或行动空间。
2. 同时报集合平均与典型个体路径；模拟连续多轮，而非只算一轮期望。
3. 找吸收状态和不可恢复损失：破产、重伤、声誉清零、职业断裂。先降低进入这些状态的概率。
4. 用小仓位、少交易、杠铃配置、分散独立风险和冗余降低时间路径方差。
5. 能合法公平共担时，通过保险、家庭互助、投资组合或组织规模把个体风险汇总；明确谁付费、谁兜底。

**诊断问题**：平均增长由多少幸存者贡献？同一个人连续经历会怎样？失败后还在游戏里吗？风险是否真的独立？

**边界与输出**：非遍历性不是拒绝一切风险，而是反对把可出局个体当成可替换样本。风险共担会带来道德风险和治理成本。输出应比较集合平均、时间路径、吸收状态和结构性保护。

### 3.8 脆弱与反脆弱（Fragility / Antifragility）

**何时调用**：系统面对波动；需要判断安全、韧性和成长方式；小压力是否有益；收益与损失落在不同主体；想同时做防守和捕捉重尾上行。

**核心模型**：脆弱性由收益曲线的非线性决定：波动增大时，损失加速；鲁棒是冲击后基本不变，韧性是能恢复；反脆弱是在一定范围内从波动、试错或随机性中获益。性质是局部的：小压力有益不代表大压力也有益。最危险的脆弱不是普通亏损，而是毁灭。

**Agent 程序**：

1. 画冲击大小与结果的关系，找出曲线拐点、不可恢复区和收益上行；不要只问“有无风险”。
2. 对脆弱部分做否定法：去杠杆、减复杂、删依赖、增加安全边际，而非不断叠加补丁。
3. 做毁灭隔离：分块、限权、沙箱、备份，让一处失败不能传遍全局。
4. 对反脆弱机会采用小成本、多次、独立试错；主动注入可恢复微压力，以暴露弱点并训练响应。
5. 审计风险归属：上行归谁、下行归谁；禁止让决策者获得收益却把破产风险转嫁给无选择者。

**诊断问题**：波动翻倍，损失是线性还是加速？哪个局部会清零全局？所谓反脆弱的收益是否由别人承担代价？

**边界与输出**：不能用“反脆弱”美化创伤、羞辱、过劳或无同意的风险。压力必须小、可恢复、可停止。输出应分脆弱/鲁棒/韧性/反脆弱区域，并给排雷、隔离和小试方案。

### 3.9 期权（Optionality / BATNA / Real Options）

**何时调用**：未来信息会逐步揭晓；承诺昂贵或难逆；谈判缺退路；双方对未来判断不同；项目可以分阶段学习再锁定。

**核心模型**：期权是一项有期限、有成本的权利而非义务。真正期权需要未来存在多条路径，而且持有人对某条路径有受保护的进入权。试用、里程碑投资、优先权、真实 BATNA 和对赌协议都能把单向门部分转为双向门。期权价值来自“先学习、后承诺”，不是永远不选择。

**Agent 程序**：

1. 给决定分型：双向门应快速试，单向门应提高证据门槛；寻找能否拆成一串较小双向门。
2. 列未来会揭晓的信息、可保留路径、独占进入权、期权费、期限和行权条件。
3. 设计最小期权：试用、原型、小额首期、里程碑付款、退出条款或可回归关系；推迟到“最后负责时刻”再锁定。
4. 谈判前建立真实 BATNA 并改善它；只需让对方知道你有选择，不虚构或泄露全部细节。
5. 设置行权/放弃日期。证据成熟或期权成本超过信息价值时，明确承诺，不把开放状态当成身份。

**诊断问题**：我拥有的是人人都有的自由，还是受保护的稀缺进入权？为保留它付了什么？何时必须坍缩选择？

**边界与输出**：期权过多会分散注意、拖延关系和错过复利；有些合作必须通过自我约束砍掉退路才可信。输出应包含门类型、期权结构、成本期限、BATNA、行权与退出条件。

### 3.10 状态杠杆（State Leverage / DSM / TOC）

**何时调用**：人人很忙但吞吐不增；返工和等待反复发生；任务顺序混乱；项目把精力平均撒在所有环节；需要决定“先做哪一步”。

**核心模型**：行动价值不只在本步产出，更在它把系统带到什么下一状态。状态杠杆有三类：前置杠杆在上游设计和准备，减少下游昂贵错误；顺序杠杆根据依赖和耦合重排任务；约束杠杆只优化当前瓶颈，因为系统吞吐由最窄处决定。动态规划要求每一步都让未来路径更宽或成本更低。

**Agent 程序**：

1. 定义系统产出与当前状态，不把待办数量当成果。
2. 画任务依赖；必要时用设计结构矩阵思考谁依赖谁、哪里双向耦合、哪些可并行。
3. 找上游高代价决定，先做需求、架构、材料和接口准备，采用“慢慢谋定，快速行动”。
4. 找当前唯一或主要瓶颈：利用它、保护它、为它减负，再提升它；其他环节不要制造更多在制品。
5. 瓶颈解除后重新测量，因为约束会移动；让本轮输出成为下一轮的输入、工具或知识。

**诊断问题**：这一步做完，下一步更容易吗？谁在等谁？哪里一变就大面积返工？增加非瓶颈产能会不会只制造堆积？

**边界与输出**：不能把所有问题都压成单一瓶颈；多约束和高不确定系统需迭代。前置规划也会过度。输出应给依赖图、瓶颈证据、优先动作、被暂停的非瓶颈工作和重测时点。
### 3.11 选择偏差（Selection Bias）

**何时调用**：从成功者、名校生、现存公司、主动回应者或可见内容推断总体；怀旧；观察到样本内的奇怪相关；评估培训、基金、疗法或选拔效果。

**核心模型**：进入视野的样本常不等概率代表世界。自我选择使愿意来的人不同；幸存者偏差删除失败者；分组选拔使两组起点不同；门槛偏差会在“都跨过总分门槛”的样本中制造变量间的负相关。即使每个人都说真话，样本生成机制仍能让结论系统性失真。

**Agent 程序**：

1. 定义目标总体和实际样本，画出从总体进入数据的选择流程。
2. 连问四句：谁没来？谁来不了？分组随机吗？是否有共同门槛？
3. 追踪退出、失败、未发表、未回复和被算法压低的样本；若找不到，明确缺失方向可能怎样改变结论。
4. 区分选拔效应和处理效应：优秀结果可能来自原本优秀，而非学校、项目或管理措施。
5. 能做时随机化、匹配或使用自然对照；不能做时给敏感性分析，不用幸存者故事证明因果。

**诊断问题**：为何我能看见这些人？未出现者的结果可能更差还是更好？样本中的相关是否由共同门槛制造？

**边界与输出**：指出偏差不等于证明结论必错，只是证据强度下降。输出应写目标总体、选择机制、缺失群体、偏差方向和更可信的取样/对照方案。

### 3.12 回归均值（Regression to the Mean）

**何时调用**：极端表现后立即干预，随后指标改善；“换帅立刻见效”；一次异常被解释成趋势、天才或灾难；奖励与惩罚效果凭相邻两次表现判断。

**核心模型**：观察值通常由稳定成分与随机波动共同生成。一个极端值往往同时包含极端运气；下一次即使能力不变，运气也更可能普通，于是结果自然靠近平均。人类喜欢在极端时采取行动，便容易把自然回弹归功于整改，把好运误认成实力。

**Agent 程序**：

1. 检查是否因指标极端才选择对象和启动干预；若是，先把回归均值列为基准解释。
2. 获取更长时间序列、同类对照和测量误差，估计个人/系统的稳定基线及自然波动范围。
3. 问若完全不干预，下一次预计会怎样；把措施效果定义为超过这条反事实基线的变化。
4. 避免按每次偏差追着调系统；区分共同原因的系统变化与偶然原因的噪声。
5. 用贝叶斯式小更新评估能力与趋势，只有多次一致偏移或机制证据才大幅改判。

**诊断问题**：我们是否只因极端才关注？极端中多少是运气？对照组也回弹了吗？测量是否稳定？

**边界与输出**：回归均值不否认真实趋势、干预效果或结构突变。紧急风险不能因等待更多数据而放任。输出应列自然回弹基线、干预增量、所需追加数据和避免过度调整的规则。

### 3.13 前景理论（Prospect Theory）

**何时调用**：亏损后越赌越大；现状和买入价支配未来决定；拥有后不愿放手；同一结果换种表述就改变选择；谈判中的“本来应该有”引发强烈反应。

**核心模型**：人不是只按最终财富判断，而是相对心理参照点感受收益和损失。价值曲线在收益区边际变平、倾向求稳；在损失区倾向冒险求翻本；同额损失通常比收益更痛。由此产生损失厌恶、现状偏见、禀赋效应和框架效应。参照点是隐形变量，也可被主动重设。

**Agent 程序**：

1. 找当前参照点：现状、买入价、峰值、承诺、同伴水平还是预期身份；把最终结果与相对得失分开。
2. 用中性单位重写所有方案，同时呈现收益和损失框架，检查偏好是否反转。
3. 问“如果今天从零开始，我会不会以当前价格买入/选择它”，削弱禀赋和沉没参照。
4. 把参照点移到长期目标、机会成本或客观基准，并用凯利/概率分布重新决定仓位。
5. 设计沟通时透明说明基准和变化；管理预期但不暗中操纵他人损失感。

**诊断问题**：用户到底在保什么零点？继续加码是因为 edge，还是只想回本？换成另一种等价表述还会选同样方案吗？

**边界与输出**：前景理论描述常见行为，不证明所有人必然如此，也不是操控客户和员工的指南。输出应标出参照点、偏差类型、中性重算结果和新的决策基准。

### 3.14 参考类预测（Reference Class Forecasting）

**何时调用**：工期、成本、成功率过度乐观；内部团队强调“这次不同”；用户按愿望和努力程度预测；高复杂度项目缺少可靠的单点模型。

**核心模型**：内部视角盯个案剧情、计划和诚意；外部视角把自己视为一个统计样本。参考类预测用已完结的相似案例分布确定基准，再仅凭硬证据调整。它是一种反自恋装置：每个人都独特，但预测所需的独特性必须足以把对象移入另一个参考类。

**Agent 程序**：

1. 明确预测变量和结算点：总成本、完成时间、留存、成功或失败必须可判定。
2. 选择数量足够、机制相似、已经结案且包含失败者的参考类；避免只挑榜样。
3. 查看完整分布，至少报告中位数、失败率、上分位数和超支/拖期幅度。
4. 先用基准线做预测，再列对象与参考类不同的可验证因素；按这些因素小幅上调或下调。
5. 若要高置信不超支，按目标分位数给预算和工期上调；保留应急储备而非把中位数当承诺。

**诊断问题**：类似项目实际怎样结束？参考类是否包含没做成的？所谓特殊优势在过去能产生多大效应？

**边界与输出**：参考类太宽会失真，太窄会样本不足；结构性突破可能让历史失效，但需机制证据。输出应给参考类、分布基线、调整项、置信目标和最终区间。

### 3.15 超级预测（Superforecasting）

**何时调用**：重大未来问题边界模糊；预测成了立场表达；团队反复说“很可能”却从不结算；需要融合参考类、细节和新信息。

**核心模型**：预测是一套可训练的工程：费米化问题、外部视角打底、内部视角微调、贝叶斯更新、用评分规则长期校准。概率不是信念强度的修辞，而是相似判断在长期应兑现的频率。高水平预测者把自尊与判断分开，持续小幅更新，既不听而不闻也不听风就是雨。

**Agent 程序**：

1. 把云状问题拆成有对象、阈值、截止日期和可信结算来源的事件；必要时拆为若干条件概率。
2. 找参考类和基准率，给第一版概率区间；记录来源和假设。
3. 识别本次个案的少数关键变量，避免把所有新闻都当独立证据；据此有限微调。
4. 建更新日志：什么消息、为何有诊断性、概率从多少变到多少；预设下一观察节点。
5. 到期结算并计算布里尔分数或至少做校准复盘，比较预测者在 60%、80% 等档位的实际命中率。

**诊断问题**：事件怎样才算发生？概率来自基准率还是情绪？哪条新信息真正改变似然？预测能否被记分？

**边界与输出**：不要为缺数据的罕见事件制造虚假精确，也不要用概率逃避价值选择。AI 可协助搜集和分解，问题边界与参考类仍需判断。输出应给可结算事件、当前概率、推理分解、更新日志和结算方法。

### 3.16 OODA 环（Observe–Orient–Decide–Act）

**何时调用**：信息不全而必须快速行动；对抗、危机、产品迭代或急诊场景；团队反应很快却不断重复旧动作；需要让行动本身带回信息。

**核心模型**：OODA 是观察、定向、决策、行动的循环。速度不是单纯手快，关键是定向：用经验、文化、模型和新信息重新解释“这是什么局”，必要时改叙事和归纳偏置。有效小行动改变环境并产生新观察。优势来自地图更新得更准、更快，而不是在错误地图上跑得更快。

**Agent 程序**：

1. 观察：只收集当前决定需要的信号，标出延迟、来源和噪声；建立前线反馈通道。
2. 定向：给局面定性，选择模型并挑战旧假设；问“如果不是执行不足，而是题目变了呢”。
3. 决策：选一个与当前模型一致、损失可控且能产生信息的动作，说明意图和边界。
4. 行动：快速执行，避免层层审批拖过窗口；让现场在正当意图内调整手段。
5. 立即把结果送回观察，更新地图；当旧动作连续无效时，优先换模型而非加码力度。

**诊断问题**：我们看见的是信号还是旧叙事筛出的材料？定向改变了吗？这次行动会产生什么新信息？反馈多久回来？

**边界与输出**：OODA 不授权鲁莽、欺骗或制造无谓混乱。不可逆和高危行动仍需护栏。输出应是一轮清楚的观察—定向—决定—行动，以及下一轮触发信号。
