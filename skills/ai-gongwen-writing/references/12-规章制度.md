# 规章制度

规章制度采用**章条式**写法：一级标题为"第一章、第二章"，章下设"第一条、第二条"，依次类推。流程分三段：**找依据抓重点 → 定框架明要点 → 写内容查合规**。

---

## 一、用 AI 找依据抓重点

### 1.1 分析问题 ·【分析问题】提示词（先找漏洞）

```
你是国有企业资产管理处处长，非常了解国有企业固定资产管理具体要求，请为我分析一家规模快速扩大的国有企业，在固定资产管理上容易出现的问题和漏洞，请描述问题及其成因。
```

### 1.2 文件检索 ·【文件检索】提示词（找上位依据）

```
请查找关于国有企业固定资产管理的相关文件，列出文件名称和内容要点。
```

检索到的上位依据示例：

```
#文档1 关于加强行政事业单位固定资产管理的通知
#文档2 企业国有资产监督管理暂行条例
#文档3 行政事业性国有资产管理条例
#文档4 国有资产评估管理办法（2020年修订）
```

### 1.3 综合分析 ·【综合分析】提示词（问题 ↔ 依据 结合）

```
你是国有企业资产管理处处长，非常了解国有企业固定资产管理具体要求，熟悉国企固定资产管理存在问题和解决方案。请根据我上传的四份文件，结合【A公司固定资产管理存在问题及成因分析】，提出改进A公司固定资产管理重点问题的具体要求。
#A公司固定资产管理存在问题及成因分析
```

## 三、用 AI 写内容查合规

### 3.1 生成制度全文 ·【制度】提示词

```
你是国有企业资产管理处处长，非常了解国有企业固定资产管理具体要求，擅长撰写规章制度。请依据【A公司固定资产管理规章制度框架】撰写"A公司固定资产管理制度"。要求：1.采用章条式写法，条文排列逻辑清晰、严谨有序；2.内容细化，表达精准，意义明确，有明确具体的可执行要求；3.使用概念、句式、词语符合公文表达要求；4.字数：4000字。（说明：章条式是规章制度特有的一种写法，意思是文件内容一级标题是第一章、第二章这样，章下面分第一条、第二条，以此类推）
#A公司固定资产管理规章制度框架
```

```

```

## 规章制度写作要点

1. **章条式结构**：第一章 总则 → 中间各章（分领域）→ 末章 附则；章下设条，条下设款
2. 第一章总则通常包含：目的依据、适用范围、基本原则、管理职责
3. 每一条都要**可执行**，写清"谁、在什么条件下、做什么、怎么做"，避免宣示性空话
4. 用词精准：多用"应当""不得""须""由××负责"，少用"要""尽量"
5. 全文 4000 字左右时，必须**逐章生成**，每章细化单独下指令
6. 成稿后必须做**上位法合规比对**，检查是否存在冲突抵触条款
7. 涉及金额、比例、时限等数值未确定时用 `××` 占位
