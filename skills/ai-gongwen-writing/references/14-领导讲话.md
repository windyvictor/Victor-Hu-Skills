# 领导讲话

以**工作推进会讲话**为标准范式，结构为：**帽段 → 现状分析部分 → 核心工作部分 → 工作要求部分 → 结尾段**。流程分三段：**工作研究 → 思路分析 → 生成文稿**。

---

## 三、写作公式

### 3.1 帽段 ·【领导讲话帽段】提示词

```
帽段 = 会议召开的宏观背景句 + 当前面临的具体背景句 + 工作要求句 + 过渡句
```

```
你是市科技局办公室主任，擅长公文材料写作，熟悉人工智能产业发展政策。为贯彻落实中央和省委、省政府关于发展新一代人工智能的相关会议精神，加快推进H市人工智能产业发展，H市将召开全市人工智能产业发展推进会，请结合上传的文档，根据【帽段公式】，撰写市领导推进会讲话帽段。
#帽段公式
```

### 3.2 现状分析部分 ·【现状分析部分提纲】提示词

```
现状分析部分 = 一级标题 + 小帽段 + 取得成绩段1 + 取得成绩段2 + …… + 存在问题段

小帽段     = 总体成就概述句
取得成绩段 = 二级标题（成绩概括）+ 支撑句（做法）+ 支撑句（成果，含事例 + 数据）
存在问题段 = 问题概述句 + 解决决心句
```

提纲提示词：

```
你是市科技局办公室主任，擅长公文材料写作，熟悉人工智能产业发展政策。为贯彻落实中央和省委、省政府关于发展新一代人工智能的相关会议精神，加快推进H市人工智能产业发展，H市将召开全市人工智能产业发展推进会，请结合【H市人工智能产业发展现状】，根据【现状分析部分公式】，撰写市领导推进会讲话现状分析部分提纲。要求：1.仅列出一级标题和二级标题，不需要填充具体内容。2.二级标题采用结果导向式标题。
#H市人工智能产业发展现状
#现状分析部分公式
```

### 3.3 核心工作部分 ·【核心工作部分提纲】提示词

```
核心工作部分 = 一级标题 + 小帽段 + 对策措施段1 + 对策措施段2 + 对策措施段3……

小帽段     = 上级要求句 + 工作思路句 + 工作目标句
对策措施段 = 二级标题（措施概括）+ 主题句 + 支撑句（措施）
```

提纲提示词：

```
你是市科技局办公室主任，擅长公文材料写作，熟悉人工智能产业发展政策。为贯彻落实中央和省委、省政府关于发展新一代人工智能的相关会议精神，加快推进H市人工智能产业发展，H市将召开全市人工智能产业发展推进会，请结合【核心工作对策措施】，根据【核心工作部分公式】，撰写市领导推进会讲话核心工作部分提纲。要求：1.仅列出一级标题和二级标题，不需要填充具体内容。2.二级标题采用行动导向式标题。
#核心工作对策措施
#核心工作部分公式
```

### 3.4 工作要求部分 ·【工作要求部分提纲】提示词

```
工作要求部分 = 一级标题 + 小帽段 + 要求段1 + 要求段2 + 要求段3 + ……

小帽段 = 形势分析句 + 总体要求句
要求段 = 二级标题 + 支撑句（具体要求）
```

```

#工作要求部分公式
```

### 3.5 结尾段 ·【结尾段】提示词

```
结尾段 = 归纳点题句 + 号召倡议句
```


## 领导讲话写作要点

1. **先提纲后正文**：正文必须严格按已确认的提纲填充，不得自行增删标题
2. **二级标题导向规则**：成绩段用结果导向，对策段/要求段用行动导向
3. **一级标题是复句**：现状部分"做法+结果"，工作/要求部分"措施+目标"
4. 三部分小帽段功能不同：现状部分"总体成就"、核心工作"上级要求+思路+目标"、工作要求"形势+总体要求"
5. 存在问题段只写"问题概述 + 解决决心"，不展开剖析——推进会讲话重在鼓劲
6. 全文约 4000 字，必须**分部分生成**，每部分确认后再继续
7. 数据、事例用 `××` 占位；"××市""H市"等代称沿用用户给定的写法
