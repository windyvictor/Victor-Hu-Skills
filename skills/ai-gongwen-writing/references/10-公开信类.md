# 公开信类（感谢信 / 慰问信 / 倡议书）

面向社会公众或特定群体的公开文书。与前几类公文不同，**允许并鼓励文学化表达**（诗句、排比、金句）。

| 类型 | 对象 | 情感基调 |
|---|---|---|
| 感谢信 | 游客、客户、支援单位 | 真诚感恩 + 坦诚不足 + 再邀 |
| 慰问信 | 教师、职工、一线人员 | 肯定贡献 + 期望号召 + 承诺支持 |
| 倡议书 | 市民、行业、员工 | 意义动员 + 分条倡议 + 号召 |

---

## 一、感谢信（文旅类）

### 写作公式

```
感谢信（文旅）篇章 = 标题 + 帽段 + 表达感谢段 + 服务与改进段 + 地方特色介绍段
                  + 扩大邀请段 + 未来展望与邀请段 + 结束语段

标题 = 发文单位 + 致×××× + 感谢信
帽段 = 诗句 + 问候句 + 写作目的句

表达感谢段     = 感谢观点句 + 感谢支撑句
服务与改进段   = 坦诚不足句 + 改进努力句 + 服务承诺句
地方特色介绍段 = 历史文化句 + 自然风光句 + 人文景观句 + 地区特产句
扩大邀请段     = 扩大邀请范围句 + 各地核心特色介绍句（×地所在省）
未来展望与邀请段 = 展望未来句 + 再次邀请句
结束语段       = 诗句 + 祝福语
```

### 第一步 ·【文学风格分析】提示词

```
你是省政府办公厅公文材料写作高手，请从文学风格上综合对比分析这两封感谢信的文字表达特点，如修辞手法、语言表达等等。
```

输入示例：

```
#文档1 淄博感谢信
#文档2 黑龙江感谢信
```

### 第二步 ·【搜索信息】提示词（搜索地域信息）

```
请综合分析黄山的历史文化背景、自然风光、人文景观、地区特产等情况。
```

### 第三步 ·【感谢信】提示词

```
你是省文旅厅公文写作专家，擅长公文材料写作，思路清晰、文笔优美。请根据【感谢信写作公式】，结合【黄山地域情况】，按照【感谢信文学风格】和【感谢信示例】撰写一封感谢信，感谢对象是春节假期来黄山旅游的游客。要求：1.严格按照感谢信写作公式进行撰写；2.把黄山地域情况融入其中；3.字数1500字。
#感谢信写作公式
#黄山地域情况
#感谢信文学风格
#感谢信示例
```

###【调整修改】提示词1（服务与改进段）

```
请丰富服务与改进段内容，把黄山搞好旅游服务的具体工作，以精炼的方式总结出来。
```

###【调整修改】提示词2（扩大邀请段，排比）

```
请丰富扩大邀请段内容，增加对安徽其他旅游地区的描述，要有吸引力，以排比形式呈现。
```

## 二、慰问信

### 写作公式

```
慰问信篇章 = 标题 + 帽段 + 背景介绍段 + 表扬感谢段 + 期望号召段 + 承诺与支持段 + 祝福结尾段

标题 = 发文单位 + 致×××× + 慰问信
帽段 = 金句 + 问候句 + 致谢句

背景介绍段   = 良好形势句 + 工作措施句 + 业绩成果句
表扬感谢段   = 慰问对象贡献句
期望号召段   = 当前形势句 + 希望句 + 号召句
承诺与支持段 = 支持举措句 + 承诺目标句
```

### 生成提示词 ·【慰问信】提示词

```
你是市教育局办公室主任，擅长公文写作，熟悉教育系统工作情况。请按照【慰问信写作公式】，结合【B市202×年度教育系统亮点工作的总结】撰写一份市委、市政府致全市广大教师、教育工作者和离退休教职工的教师节慰问信。要求：1.严格按照慰问信写作公式进行撰写；2.把教育系统亮点工作融入其中，总结要精炼，体现核心做法和最显著成绩；3.字数1000字。
#慰问信写作公式
#B市202×年度教育系统亮点工作的总结
```

###【调整修改】提示词（补充政治表述）

```
在期望号召段内，加入"为党育人、为国育才"等类似新的关于教育工作的要求，请修改。
```

## 三、倡议书

### 写作公式

```
倡议书篇章 = 标题 + 帽段 + 倡议段1 + 倡议段2 + 倡议段3 + …… + 结尾段

标题 = 事由 + 倡议书
帽段 = 活动（工作）意义句 + 倡议过渡句

倡议段 = 子标题（倡议点）+ 要求句1 + 要求句2 + ……
结尾段 = 主题句 + 号召句
```

### 第一步 ·【分析问题】提示词（穷举要求）

```
你是市创建全国文明城市工作负责人，非常熟悉创建全国文明城市的标准要求，请问如果要对广大市民提出要求、发出倡议，应该提出哪些要求。
```

### 第二步 ·【压缩内容】提示词（合并成 4 个方面）

```
请将以上内容进行合并处理，综合成4个方面，请按照符合逻辑的方式重新调整结构，让表达更加精炼。
```

### 第三步 ·【倡议书】提示词

```
你是市创建全国文明城市工作负责人，非常熟悉创建全国文明城市的标准要求，擅长撰写公文材料。请按照【倡议书写作公式】，以【对市民的要求与倡议】为核心内容，撰写一份面向广大市民的倡议书。要求：1.严格按照倡议书写作公式撰写；2.子标题符合对仗式标题要求，采用行动导向标题；3.字数1500字。
#倡议书写作公式
#对市民的要求与倡议
```

###【调整修改】提示词（融入地域特色）

```
请在倡议书的开头与结尾，加上与合肥有关的内容，以体现合肥这座城市的特点。
```

## 公开信类写作要点

1. **帽段与结尾用诗句/金句**，形成首尾呼应，这是公开信的标志性特征
2. 感谢信要**坦诚不足**（服务与改进段），不能只唱赞歌，这是赢得共情的关键
3. 倡议段子标题用**行动导向 + 对仗式**，每条倡议下用多个要求句展开
4. 地方特色介绍段按「历史文化 → 自然风光 → 人文景观 → 地区特产」固定顺序
5. 扩大邀请段用**排比**增强气势
6. 慰问信必须同时有「表扬贡献」和「承诺支持」，单向情感不完整
