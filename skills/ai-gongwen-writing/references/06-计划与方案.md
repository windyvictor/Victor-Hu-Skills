# 计划与方案

**计划**回答"要做什么、做到什么程度"（目标导向），**方案**回答"具体怎么组织实施"（执行导向）。

| 类型 | 典型场景 | 关键区别 |
|---|---|---|
| 专项工作计划 | 产业发展、专项整治、年度工作 | 有工作目标段（总体目标+分目标） |
| 会议工作方案 | 大会、论坛、活动 | 有具体活动段、任务分工段、条件保障段 |

---

## 一、专项工作计划

### 写作公式

```
计划篇章 = 标题 + 帽段 + 工作思路段 + 工作目标段 + 重点任务段（N项任务）+ 保障措施段

标题     = 主题 + 计划
帽段     = 目的句 + 依据句 + 过渡句
工作思路段 = 指导思想句 + 形势背景句 + 工作思路句 + 工作目标句
工作目标段 = 【总体目标 + 分目标】
重点任务段 = 任务小标题 + 工作做法句
保障措施段 = 组织领导段 + 资金投入段 + 政策制度段 + 监督管理段 + 宣传引导段
```

### 第一步 ·【分析文件】提示词

```
你是省政府政策研究室主任，请从下级单位贯彻落实文件精神的角度，提炼这份文件的重点内容。要求列出所有工作措施，按照文件的层次顺序，以有序或无序列表呈现。
```

### 第二步 ·【头脑风暴】提示词（含追问1-4）

见 `references/00-通用方法与模块库.md` 六、6.3「头脑风暴 + 追问法」。

```
我是一位【人工智能产业政策制定者】，对人工智能产业发展方向具有浓厚兴趣。你是一位【人工智能领域的资深专家】，精通人工智能领域及其涉及的计算机科学、数学、神经科学、心理学、语言学、哲学和认知科学等多学科。接下来，我会和你不断探索，找到推动人工智能产业发展的可行性措施。现在请列出你认为可能促进人工智能产业发展的措施。
```

追问链：

```
追问1：很好，请问是否还有其他可能的措施？
追问2：很棒，我看到了一些有价值的措施，请问是否还有其他可能的措施，请尽可能发挥你的想象力，对这个问题进行深入分析。
追问3：非常好，我又看到了新的举措，而且更加具有宏观视野，我想知道是否有其他可能的措施？
追问4：非常好，现在请你综合上面所有提出的举措，对发展人工智能产业的措施进行综合分析，需要对主题进行归纳，要有层次区分，重复的内容可以合并，相近内容可以归并于更高层级的主题。以有序或无序列表形式输出。
```

输入材料三件套：

```
#（文档1）上级文件重点
#（文档2）促进人工智能产业发展可行性措施
#（文档3）H市人工智能产业发展现状
```

### 第三步 ·【文件综合分析】提示词

```
你是市政府政策研究室主任，非常熟悉人工智能产业发展，擅长用前瞻性眼光开展工作规划。请根据【上级文件重点】【促进人工智能产业发展可行性措施】和【H市人工智能产业发展现状】三方面材料，分析并确定H市人工智能产业专项工作计划中的重点任务。要求：1.重点任务要包括上级文件提到的主要工作内容；2.在满足第一点的基础上，重点任务还可以从促进人工智能产业发展措施提取；3.重点任务安排符合H市特点，发挥H市优势资源。4.重点任务以有序或无序列表输出。
```

### 第四步 ·【提炼分析】提示词

```
你是市政府政策研究室主任，非常熟悉人工智能的产业发展，擅长用前瞻性眼光开展工作规划。请结合下面的重点任务，高度概括并提出H市人工智能产业发展的总体目标和分目标。要求：分目标标题是以结果为导向的标题；表达简洁清晰。
#重点任务
```

### 第五步 ·【专项工作计划】提示词（4000字，可分段输出）

```
你是市政府政策研究室主任，非常熟悉人工智能产业发展，擅长用前瞻性眼光开展工作规划。请根据【专项工作计划写作公式】，结合【重点任务】，起草H市人工智能产业发展计划。要求：字数4000字，可分段输出。
#专项工作计划写作公式
计划篇章=标题+帽段+工作思路段+工作目标段+重点任务段（N项任务）+保障措施段
标题=主题+计划
帽段=目的句+依据句+过渡句
工作思路段=指导思想句+形势背景句+工作思路句+工作目标句
工作目标段=【总体目标+分目标】
重点任务段=任务小标题+工作做法句
保障措施段=组织领导段+资金投入段+政策制度段+监督管理段+宣传引导段
#重点任务
#总体目标+分目标
```

###【调整修改】提示词（任务量化）

```
对下面的【重点任务段内容】进行补充完善，分点列举，要提出对各级各部门、企业等方面具体的工作落实举措和要求，对于需要量化的工作提出数据性指标，具体数字用××代替。
#重点任务内容
```

###【修改标题】提示词（任务标题行动化）

```
对下列【重点任务的标题】进行修改，要求是行动导向的标题表述，仅输出标题即可。
#重点任务标题
（一）发挥本地优势，加速智算平台建设
（二）数据资源全面开放与深度利用
（三）关键核心技术攻关与创新应用
（四）市场主体培育与产业生态构建
```

## 二、会议工作方案

### 写作公式

```
会议工作方案篇章 = 标题 + 帽段 + 指导思想段 + 总体安排段 + 具体活动段（N项活动）
                + 组织机构段 + 任务分工段 + 条件保障段 + 工作要求段

标题       = 会议名称 + 工作方案
指导思想段  = 指导思想句 + 工作思路句 + 工作目标句
总体安排段  = 活动名称 + 活动主题 + 活动地点 + 主办单位 + 参会嘉宾
具体活动段  = 时间 + 地点 + 参加人员及规模 + 主题 + 内容
组织机构段  = 大会组委会成员 + 成员单位
任务分工段  = 单位名称 + 任务安排（有序列表）
条件保障段  = 场地安排 + 经费安排
工作要求段  = 思想要求 + 工作要求 + 责任要求
```

### 第一步 ·【辅助思考】提示词（创新性）

```
你是举办大型产业会议的专家，擅长组织各类产业大会。我是H市政府科技局工作人员，H市近期要举办第二届全球人工智能产业大会，怎样才能让大会办得更有创新性和吸引力，扩大H市人工智能产业领域影响力？
```

### 第二步 ·【策划活动】提示词

```
很好，这场大会将举办2天，按照你的理解请为我详细规划一下大会的各项活动安排，要求：1.至少列举8项活动；2.每项活动有具体名称；3.每项活动按"时间+地点+参加人员及规模+主题+内容"，以有序列表形式输出。
```

### 第三步 ·【调整修改】提示词（细化活动内容）

```
请对各项活动的"内容"进行细化，"内容"以无序列表呈现，请重新生成各项活动安排。
```

### 第四步 ·【会议工作方案】提示词

```
你是市政府办公室会务工作负责人，擅长统筹安排会务工作，请结合上述活动安排，按照【会议工作方案写作公式】撰写一份人工智能产业大会工作方案。要求：1.方案各部分内容要尽可能详细具体；2.任务分工要到位，具体到市政府各相关部门、高校等单位；3.用清晰的序号及标题区分各部分，表达简洁清晰，明确可执行。
#会议工作方案写作公式
```

## 计划与方案写作要点

1. **计划重目标**：必须有可量化的工作目标段（总体目标 + 分目标），分目标标题用结果导向
2. **方案重执行**：必须有任务分工段（单位名称 + 具体任务）与条件保障段（场地 + 经费）
3. 保障措施五件套固定：组织领导、资金投入、政策制度、监督管理、宣传引导
4. 重点任务标题用**行动导向**，目标标题用**结果导向**，两者不可混用
5. 涉及数量指标一律用 `××` 占位
6. 4000 字以上的计划必须分段输出并逐段确认
