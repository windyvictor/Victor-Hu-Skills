# 工作计划与方案（职场视角）

> 来源：《得到·职场写作训练营》第 09、10 讲。公文体专项工作计划、会议工作方案见 `06-计划与方案.md`；本文件针对**中长期（年度/季度/项目）工作计划**与**要说服人的方案**（提案、可研、竞标、活动策划）。

---

# 甲、工作计划 = 对目标 + 对进度表

口诀：**对标、对表**——对目标（跟组织对齐大方向），对进度表（跟协作者对齐节奏）。

计划的意义：周期越长不确定性越大，计划不是把所有事定死，而是**在不确定性面前先定出自己的确定性**，作为变化来临时讨论的锚点。写计划不要只想着自己眼前的事，要汇入组织大目标——"做事不由东，累死也无功"。

## 一、对目标 = 目标 + 关键结果

### 1. 写目标那句话：三个原则

**① 关联组织目标**（最核心）。写作格式：
> 公司/部门的目标是……，为此，我的目标是……

写公司级计划则用公司愿景"盖帽"。示例：
> 部门目标：第三季度流水较上季度提升50%。
> 为此，我的目标是：重点策划拉新、激活和转化类的社群活动，把私域用户转化率从10%提升到15%。

（只写"策划有吸引力的社群活动" ✗——没有指向性，是吸引热闹还是提升流水？）

**② 聚焦优先目标**。一份计划 3–4 个目标足够。用**子贡三问**排序：五个目标非要去掉一个先去哪个？一轮轮逼问，最后不能放弃的才是真目标。排序时站在组织角度，不是个人偏好。

**③ 有挑战性**：跳一跳够得着。上季度轻易超额5%的目标，这次就该定20%；挑战幅度跟组织文化走，跟着公司目标涨幅走不会错。

（目标尚不清晰时，用 `21-申请.md` 的目标5要素"多快好省爽"填空梳理。）

### 2. 写关键结果：OKR 思路 + SMART 原则

用**目标实现那一刻产生的结果**倒逼目标——问自己"目标实现了会看到哪几个关键特征？"一个目标对应 3–5 条关键结果。

SMART 五性中，**具体、可衡量、有相关性**最易错：

| 要素 | 要求 | 示例 |
|---|---|---|
| 具体 | 确定无歧义 | "降低20%成本" ✗ → "降低产品包装成本20%" ✓ |
| 可衡量 | 量化（数量/进度/百分比/关键指标/第三方评价） | "搭建有实力的团队" → "核心岗位到岗率、成员满意度"；"质量好" → "好评率、NPS" |
| 有相关性 | 关键结果真的支撑目标 | YouTube 选"观看时长"而非点击量衡量"用户喜欢"——选错关键结果会在错误方向努力 |

**事后检查法**：所有关键结果都实现了，加起来是否就等于目标达成？不等，说明拆漏了维度。

**关键结果 ≠ 行动步骤**：
> 目标：盖一所好房子。
> ✗ 关键结果：画设计图 / 打地基 / 盖房子 / 装修（这是待办事项）
> ✓ 关键结果：【设计】设计合理性获至少3位头部设计师认可；【质量】建筑质量与安全性达最高标准。

示例（团队目标拆解）：
> 目标：打造配置完备、运作高效的团队。
> 关键结果1：关键职能员工到岗率100%。
> 关键结果2：核心人员流失率不高于15%。
> 关键结果3：团队平均效能提升10%。

## 二、对进度表 = 关键大事件

跨度长的计划不必事事排期——用**关键大事件**做牵引，各部门自然对齐（脱不花：一年五到十个大事件平均散布，公司士气就不用愁；"大事件就是打仗，士气都是打出来的"）。

关键大事件三特征：
1. **是个事件**：有明确时间、地点、参与人、要发生的事（发布会、直播、大促；"双11"就是电商全体的大事件）。
2. **有价值且参与者认同**。
3. **卷入外部相关人**：用客户倒逼内部协作（客服团队"6月出一本SOP手册提交全公司"→人人有动力总结分享）。

示例：
> 关键结果：【品牌传播】各账号涨粉40%。
> 关键事件1：423读书节，图书品牌线下发布会，联合700家书店办展，线上线下联动。
> 关键事件2：双十一直播大促，联动头部作者一周系列主题直播，全渠道预热。

## 分步提示词（工作计划）

```
【角色】你是<单位/岗位>负责人，擅长制定有确定性的工作计划。
【背景】上级/组织目标：<原文要点>；我的职责范围：<…>；可选目标池：<列举>；可依托的资源与外部节点：<…>。
【任务】请按"对目标（组织目标+我的目标，3-4条，每条配3-5个SMART关键结果）+ 对进度表（2-4个关键大事件）"的清单体结构撰写计划；关键结果用可量化指标（未提供用××），标注每条目标对应组织的哪条目标。
```

调整：`请用子贡三问法帮我给这5个目标排序，说明每轮淘汰理由。` / `请检查关键结果是否为行动步骤，若是请改写为目标实现时的结果性指标。` / `请为关键结果×设计2个关键大事件。`

# 乙、方案 = 需求定义 + 解决方案 + 还原场景

写方案说明你已是主力——谈生意、干项目、竞标、策划，全靠方案推动。方案不是搞创意也不是干执行，是**主动说服用户接受**。最怕熬夜写完被当场全盘推翻。

## 一、需求定义 = 客户 + 目标 + 障碍

**警惕乙方思维**："需求是用户的，我照做就好"——真相是：**提需求的人大概率自己没想清楚**（资深房产经纪人：99%的客户最终买的房子和最初提的需求不一样）。

需求定义三问：
1. **客户是谁**？对接人背后有没有复杂关系？
2. **目标是什么**？既要又要还要时，优先级是哪个？
3. **障碍是什么**？

示例（博世产品经理，老板抛出"年销100万台"，常规只有二三十万）：
> 客户=领导；目标=100万台；障碍=①不靠砸广告，营销成本要合理 ②靠微创新不可能翻五倍，必须找到未被满足的市场空白。
> → 关键问题定义："营销成本固定的前提下，如何定位蓝海市场、研发有竞争力新产品？"（后来在大电动与手动工具之间找到空白，真做成了。）

可研报告示例（硅酸锆扩产）：客户=陶瓷釉料行业；目标=高档陶瓷需求扩大、产量要跟上；障碍=高品质硅酸锆技术门槛高、依赖进口。

## 二、解决方案：扣着障碍搭框架

- **入门级**：摊大饼求全面（"方案背景/宣传目标/节目定位/内容大纲/实施计划"——行活，给任何一家公司都行）。
- **王者级**：列出甲方**特有的障碍**，一一对应写章节：
> 障碍：①公司缺知名度信誉度 ②软件采购成本高 ③只有高管有决策权
> → 框架：一、方案背景 二、宣传目标 **三、如何体现品牌价值？四、如何体现产品效果？五、如何锁定目标用户？** 六、实施计划
- **红线**：已明确的障碍没有体现在方案里，是方案大忌——说明没扣着需求走。

### 填正文：行动 + 观点 + 事实

> ✗ "定价199元，有竞争力，可能抢占价格空白地带。"（只有观点）
> ✓ ①定价199元（行动）②有竞争力，抢占价格区间空白（观点）③手动螺丝刀价格区间19–169元，电动为299–799元（事实）。

三句话框架：我打算怎么做 / 为什么这样做有效 / 论据是什么。

### 进阶1：新旧方案对比
先摆旧方案的劣势（"2020发布会：用户还是老用户没扩圈；以创始人为中心而非用户"），新方案逐条扣着劣势写优势（"节目用户平均35岁、45%为公司高级主管；从用户视角体现产品优势"）。

### 进阶2：打明牌（脱不花）
方案最前面加一部分：**公开你对甲方做的功课与结论**——"我做了这些研究，得出这几点结论，你们看对不对？"对齐认知、换取信任；认知有偏差当场就能纠正。

### 进阶3：逻辑连环刀（创意方案）
创意没有评判标准，说服成本高，越要一环扣一环从需求连到创意（六个核桃"一言不合就动脑"：销量停滞+品牌老化 → 扩大饮用场合 → 场景变多 → 动脑时刻变多 → 鼓励被动动脑变主动动脑 → 传播主题）。每扣一环客户点一次头。

### 难点处理：给选择题
关键问题自己拿不准时，**不要只摆选项**（像甩锅），要给：①主要矛盾与关键变量 ②各方案优点缺点 ③你的倾向及理由 ④把拍板权留给领导：
> 主要矛盾：采购量与供应稳定性。
> 影响变量：①国外疫情，部分食材可能不稳定 ②仓储成本高。
> A方案10吨：成本可控/存在风险；B方案20吨：能扛风险/成本高+仓储费。特殊时期推荐B，先保证供应与品质。
> 风险应对：①提价 ②减利保老客 ③海外食材主题月招新客。

## 三、还原场景（说服力捷径）

用感性体验替代抽象论证：
- **华与华提案猫头鹰logo**：提前布置会议室成猫头鹰空间、现场掏出丝巾——沉浸式攻击。
- **亚马逊"模拟新闻公关稿"**：新品立项必须先写上市当天的新闻稿（记者会问什么、用户会问什么、怎么答），写不出来说明没想清楚。
- 笔头版：方案最后呈现"方案落地后的场景"。写作要素清单：①发布时间 ②产品介绍（与同类有何不同）③用户评价（解决了什么痛点）④媒体评价（前景）⑤政府/监管评价（社会意义）。

## 分步提示词（方案）

```
【角色】你是<行业/岗位>资深方案撰写人，擅长有说服力的提案。
【背景】客户/领导是谁：<…>；其目标与优先级：<…>；已明确的障碍：<1/2/3>；我方调研结论：<…>；历史方案及其不足：<…>。
【任务】请按"需求定义（客户+目标+障碍）→ 解决方案（扣障碍搭框架，每节用行动+观点+事实论证）→ 还原场景（模拟落地效果/新闻稿要素）"的结构撰写方案；开头可加"打明牌"调研结论部分；拿不准的关键点按"选择题"格式给出（变量+AB方案+倾向+风险应对）；数据用××。
```

**检查**：框架是否逐一覆盖已明确的障碍？论证处是否只有观点没有事实？关键分歧是否给了带倾向的选择题？

## 自检

- [ ] 计划：目标关联组织目标、3–4条、有挑战；关键结果 SMART 且非行动步骤
- [ ] 计划：有关键大事件拉齐长周期进度
- [ ] 方案：需求定义三要素齐全；框架逐一对应障碍
- [ ] 方案：观点均有事实支撑；敏感表述过外人视角检查（`19`）
