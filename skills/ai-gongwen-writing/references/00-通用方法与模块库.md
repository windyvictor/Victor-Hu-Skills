## 三、总结类材料通用篇章公式

```
总结类材料篇章 = 帽段 + 主体段（做法）×N + 主体段（问题） + 主体段（计划）

帽段        = 指导思想句 + 情况背景句 + 工作思路句 + 工作成果句
主体段（做法）= 主题句（why）+ 支撑句（how）+ 支撑句（what）
主体段（问题）= 客观形势句 + 问题表现句
主体段（计划）= 形势分析句 + 工作思路句 + 结尾句
```

### 主体段公式释义

- **主题句（why）**：用一句话概括提出本段中心思想
- **支撑句（how）**：说明本段主要做法
- **支撑句（what）**：围绕做法提供实例、理由、细节、数据

### 框定内容结构【帽段公式扩写】提示词

```
你是国家电网A市电力公司办公室主任，具备深厚的公文写作功底，对中央能源政策把握准确到位，对当前电力工作发展形势与现状认识深刻。请按照【帽段公式】撰写一段本公司年终工作总结的帽段，要求融入中央最新的能源政策精神，语言表达符合公文特点。字数300字。
#帽段公式
帽段=指导思想句+情况背景句+工作思路句+工作成果句
```

### 框定内容结构【主体段公式改写】提示词

```
你是市政府办公室主任，善于分析工作做法、总结提炼工作重点。请按照【主体段公式】改写【工作情况】内容。要讲清楚核心做法，列举关键数据，不列举个人案例。段落长度控制在300字。
#主体段公式
主体段公式=主题句（why）+支撑句（how）+支撑句（what）
#工作情况
```

## 四、可复用段落模块库

### 4.1 帽段公式（总结/汇报类）

```
帽段 = 指导思想句 + 情况背景句 + 工作思路句 + 工作成果句
```

变体（领导讲话帽段）：

```
帽段 = 会议召开的宏观背景句 + 当前面临的具体背景句 + 工作要求句 + 过渡句
```

变体（计划类帽段）：

```
帽段 = 目的句 + 依据句 + 过渡句
```

变体（汇报类引言段）：

```
引言段 = 指导思想句 + 情况背景句 + 工作思路句 + 总体成效 + 过渡句
```

## 五、标题改写规则库

| 场景 | 规则 | 提示词 |
|---|---|---|
| 段落标题统一风格 | 公文对仗式标题 | `请按照公文对仗式标题写法，对下面的【标题】进行修改。` |
| 做法/成绩段 | 复句标题：前半句做法 + 后半句结果 | `围绕这些二级标题，提炼一个一级标题，要求为复句标题，前半句为做法，后半句为结果。` |
| 对策/要求段 | 行动导向标题 | `请对标题进行修改，要求是行动导向的标题表述，仅输出标题即可。` |
| 成果/收获段 | 结果导向标题 | `改成结果导向的标题句式，表达出学到了什么的含义；符合公文对仗式标题要求。` |
| 子标题长度统一 | 字数一致 | `请调整修改下面三个子标题，要求按照心得体会的表达风格进行修改，三个子标题保持基本一致的长度。` |
| 引用型标题 | 标题中引用诗句，字数一致 | `请模仿下面的【引用型标题】，对【标题】进行修改。要求：标题中要引用诗句，且保持字数一致。` |

### 引用型标题示例

```
激发"敢为天下先"的青春勇气。
保持"会当凌绝顶"的青春自信。
涵养"滴水能穿石"的青春定力。
```

### 标题改写前后对照示例

改写前：

```
一、优化政务环境，提升服务效能
二、精准定位，构建创新成果转化聚集地
三、深化协同创新与产业协作，推进产业链发展
四、强化项目引进与创新载体建设，扩大创新资源集聚
五、前瞻布局，持续优化创新政策与合作模式
```

改写后（对仗式）：

```
一、公文处理：迅速响应，精准执行，提升效能
二、会议组织：精简高效，强化实效，服务决策
三、信息报送与信息公开：敏锐捕捉，高效传播，提升透明度
四、沟通协调与接待工作：积极服务，强化协作，展现良好形象
```

## 六、内容提炼四法

### 6.1 「理法事果」四分法（工作总结材料归类）

```
你是省政府政策研究室的公文写作专家，熟悉产业政策，擅长课题研究，公文写作水平高。请对下面的【工作材料】，按照"理、法、事、果"四分法进行材料内容分类标注。"理"是"理念"，代表对问题的看法、观点。"法"是"做法"，代表具体开展工作的方法。"事"是"事例"，事例中会出现具体的单位和成效。"果"是"成果"，做法带来的成果，以数据或明确的奖项、成绩展现。
#工作材料
```

提炼要点：

```
接下来，以上面的内容为基础提炼工作要点。要求：1.提炼"理"的内涵，作为主标题；2.对做法进行归类提炼，要求提炼出共性关键词，并将事例和成果放到相应的做法之后。
```

### 6.2 数字概括法（做法提炼）

```
请用数字概括法，对下面三条做法进行概括，提炼出一个核心做法词。
###
融合生产链
融入市场化
融会新科技
```

要点：先让每条做法包含同一个关键字（如"融"），再用"数字概括法"（三融、四化、五抓）提炼核心做法词。

```
请对这三点概括出同样字数的三条做法，并要包含"融"字。
```

### 6.3 头脑风暴 + 追问法 ·【头脑风暴】提示词（措施穷举）

```
我是一位【人工智能产业政策制定者】，对人工智能产业发展方向具有浓厚兴趣。你是一位【人工智能领域的资深专家】，精通人工智能领域及其涉及的计算机科学、数学、神经科学、心理学、语言学、哲学和认知科学等多学科。接下来，我会和你不断探索，找到推动人工智能产业发展的可行性措施。现在请列出你认为可能促进人工智能产业发展的措施。
```

追问链（连续追问 3-4 轮，逐步放开想象力）：

```
追问1：很好，请问是否还有其他可能的措施？
追问2：很棒，我看到了一些有价值的措施，请问是否还有其他可能的措施，请尽可能发挥你的想象力，对这个问题进行深入分析。
追问3：非常好，我又看到了新的举措，而且更加具有宏观视野，我想知道是否有其他可能的措施？
追问4：非常好，现在请你综合上面所有提出的举措，对发展人工智能产业的措施进行综合分析，需要对主题进行归纳，要有层次区分，重复的内容可以合并，相近内容可以归并于更高层级的主题。以有序或无序列表形式输出。
```

### 6.4 综合分析法 ·【文件综合分析】提示词 +【提炼分析】提示词（多文档交叉确定重点任务）

```
你是市政府政策研究室主任，非常熟悉人工智能产业发展，擅长用前瞻性眼光开展工作规划。请根据【上级文件重点】【促进人工智能产业发展可行性措施】和【H市人工智能产业发展现状】三方面材料，分析并确定H市人工智能产业专项工作计划中的重点任务。要求：1.重点任务要包括上级文件提到的主要工作内容；2.在满足第一点的基础上，重点任务还可以从促进人工智能产业发展措施提取；3.重点任务安排符合H市特点，发挥H市优势资源。4.重点任务以有序或无序列表输出。
```

## 七、调整修改指令速查

| 目的 | 提示词 |
|---|---|
| 补充数据指标 | `请补充具体工作和数据增长指标，相关数据用××代替。` |
| 补充细节与时限 | `请对第×段内容进行补充完善，充实相关工作细节要求，明确时间节点。仅输出该部分。` |
| 分点量化 | `对下面的内容补充完善，分点列举，要提出对各级各部门、企业等方面具体的工作落实举措和要求，对于需要量化的工作提出数据性指标，具体数字用××代替。` |
| 增加理论性主题句 | `请为下面的内容在段首增加一句主题句。要求：主题句具有理论性，能概括段落内容。` |
| 压缩成段 | `请将上述内容整合成一段文字，不改变关键内容，字数500字。` |

| 扩充技术细节 | `请拓展下面采访得到的事实性内容，对特点与优势进行补充说明，添加更多技术细节，字数250字。` |

| 加入特定政治表述 | `在××段内，加入"为党育人、为国育才"等类似新的工作要求，请修改。` |
