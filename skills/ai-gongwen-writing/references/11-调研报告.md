# 调研报告

调研报告的完整流程分三段：**调研准备 → 材料分析 → 撰写成文**。前两段决定报告的深度，不能跳过。

---

## 一、调研准备

### 1.1 文件研究 ·【文件研究】提示词

```
请梳理国务院和安徽省关于文旅产业发展的相关文件。
```

### 1.2 确定调研选题 ·【确定调研选题】提示词

```
你是一位文旅经济产业专家，非常熟悉了解文旅行业发展现状。近两年，以"淄博烧烤""贵州村超""哈尔滨冰雪季""天水麻辣烫"等为代表，文旅产业出现"网红城市"现象，我是安徽省文旅厅工作人员，想围绕"网红城市"现象写一篇关于文旅产业的调研报告，请为我提供5个调研选题？
```

### 1.3 设计调研方案 ·【设计调研方案】提示词

```
以第1点作为调研选题，生成一份完整详细的调研方案。要求详细具体，具备可操作性。
```

### 1.4 拟制访谈提纲（外地）·【拟制访谈提纲（外地）】提示词

```
你是一位文旅经济产业专家，非常熟悉了解文旅行业发展现状。"网红城市"调研组将到山东淄博市、黑龙江哈尔滨市、贵州榕江县、甘肃天水市等地进行调研，与当地文旅部门、相关企业进行座谈，探讨分析当地打造"网红城市"的经验做法，请联系上述调研方案替我拟制一份访谈提纲。要求紧扣调研主题，问题列举要精。
```

### 1.5 拟制调研提纲（本地）·【拟制调研提纲（本地）】提示词

```
你是一位文旅经济产业专家，非常熟悉了解文旅行业发展现状。"网红城市"调研组将到安徽黄山市、池州市、六安市、淮南市等地进行调研，与当地文旅部门、相关企业进行座谈，探讨传统文旅产业发展现状、以及对当地对"网红城市"的看法，请联系上述调研方案替我拟制一份访谈提纲。要求紧扣调研主题，问题列举要精。
```

> 外地提纲重在"你们怎么做到的"，本地提纲重在"你们现在怎么样、怎么看"。

## 二、调研材料分析

### 2.1 间接调研 ·【间接调研】提示词1、提示词2（背景知识）

```
请分析安徽省传统文旅产业发展情况。
```

```
请分析"网红城市"的兴起原因、主要特征及对旅游者的吸引力。
```

### 2.2 本地情况分析 ·【本地情况分析】提示词（多文档综合）

```
请结合上述五份文档，分析总结安徽省文旅产业发展的现状优势和存在问题。
```

输入文档：

```
#文档1 安徽省的传统文旅产业发展情况
#文档2 安徽黄山市文旅产业发展方面的情况
#文档3 池州市的文旅产业发展情况
#文档4 淮南市的文旅产业发展情况
#文档5 六安市的文旅产业发展情况
```

### 2.3 先进地区分析 ·【先进地区分析】提示词

```
请结合上述五份文档，分析总结"网红城市"文旅产业发展的基本要素和特点。
```

输入文档：

```
#文档6 网红城市的兴起原因、主要特征及对旅游者的吸引力可以从多个维度进行分析
#文档7 贵州村超的兴起原因、主要特征及对旅游者的吸引力
#文档8 哈尔滨冰雪季的兴起原因、主要特征及对旅游者的吸引力
#文档9 淄博烧烤的兴起原因、主要特征及对旅游者的吸引力
#文档10 天水麻辣烫的兴起原因、主要特征及对旅游者的吸引力
```

### 2.4 对策建议 ·【对策建议】提示词（差距对比法）

```
对比【安徽省文旅产业发展现状优势与存在问题】与【"网红城市"文旅产业发展的基本要素和特点】，总结二者之间的区别，提出安徽省打造"网红城市"、促进文旅产业发展的对策措施。
```

> 核心方法：**本地现状 ↔ 先进要素** 做差距对比，差距即对策。

## 三、调研报告写作公式

```
调研报告篇章 = 标题 + 帽段 + 基本情况部分 + 存在问题及原因分析部分 + 对策建议部分

标题 = 关于 + 主题概括 + 调研报告
帽段 = 理论依据句 + 调研目的句 + 调研过程概况句

基本情况部分 = 情况概括段 + 正面情况段1 + 正面情况段2 + 正面情况段3 + ……
正面情况段   = 子标题 + 工作思路句 + 成效支撑句（成果 + 数据 + 事例 + 对比）

存在问题及原因分析部分 = 问题概括段 + 问题及原因分析段1 + 问题及原因分析段2 + ……
问题及原因分析段       = 子标题 + 问题描述句（表现 + 数据 + 影响）+ 原因分析句（数据 + 对比 + 事例）

对策建议部分 = 对策概括段 + 对策段1 + 对策段2 + 对策段3 + ……
对策段      = 子标题 + 目标句 + 对策措施句
```

## 调研报告写作要点

1. **三段论结构固定**：基本情况 → 问题及原因 → 对策建议，对策必须与问题对应
2. 每个部分都有「概括段 + N 个分析段」，概括段统领，不可省略
3. **三段支撑要素不同**：
   - 正面情况段 = 工作思路 + 成果数据事例对比
   - 问题段 = 表现数据影响 + 原因数据对比事例
   - 对策段 = 目标 + 措施
4. 帽段必须写清"调研过程概况"（何时、谁、去了哪、怎么调研的）
5. 全文约 4000-5000 字，必须**分部分生成并逐部分确认**
6. 对策要"从差距中来"，避免凭空提建议
