# 复盘报告

> 来源：《得到·职场写作训练营》第 08 讲。公文体总结（面向上级汇报成绩）见 `07-总结与汇报.md`；本文件针对**项目复盘、经验复盘、事故/故障复盘**——写给继任者的攻略。

## 定位

- 复盘报告**不是对过去的总结，而是写给继任者的攻略**。真正发挥价值的时刻，不是交领导那一刻，而是下次同类问题出现时，它能像问题解决说明书一样：指出坑在哪、怎么避、给近道。
- 两个极端误区：怕得罪人写成**表彰大会**；犯了错写成**小学生检讨**（按小时流水账——潜台词是"我没有任何判断能力，读者自己评判"）。
- 三原则卡位：导向行动=让后人把经验用起来；用户=下一次干这件事的人；默认公开=让下一个干这件事的人也能理解经验价值。写好复盘 = 为组织沉淀经验 = 把经验复制给他人 = **领导力的最好证明**。
- 心态锚：**给山里小木屋的下一任主人写信**——"森林里啥都有，好好活下去" ✗；"春天有什么食材、觅食注意什么" ✓。

## 写作公式

**复盘报告 = 定义问题 + 操作步骤 + 决策思路（+ 加分项：正反案例）**

每一条经验都是一个小闭环，按此框架逐条说清楚。

### 一、定义问题（这条经验治什么病）

只给行动不够，必须说清行动是**用来解决什么问题的**。类比拿破仑炮兵手册："发射时炮前站一名士兵"的规定流传两百年，没人记得它本来是牵马的——没定义问题，后人就会滥用或误用经验。"抛开剂量谈毒性就是耍流氓"，复盘同理。

定义三问：①这个问题是什么？②在什么情况下出现？③出现了有哪些特征？

**定义要具体——加限制条件**：
> ✗ "学术领域出名的作者，怎么向公众做好宣传？" ✓（限制清晰，继任者能判断经验是否适用）
> ✗ "在出版市场持续没落的情况下，怎么宣传新书作者？"（大环境短期不变，说了等于没说）
> ✗ "客户拜访注意事项"（只能写出"不能迟到"这类原则）
> ✓ "第一次拜访客户怎么留个好印象？"（逼你写出"提前15分钟到""备两份以上谈话材料"等真经验）

复杂问题用清单体定义：
> 标题：如何写好项目建议书？
> 适用边界：1. 适用于项目接洽早期——重点是论证项目是否可行，不是讨论如何执行。2. 仅适用于企业客户。

### 二、操作步骤（行动 + 操作要点 + 示范 / 避坑）

同样一句"大力宣传新书"，你指"提前一个月抖音预热"，他理解"多办几场签售会"。要让人学走经验，颗粒度必须到位。要点是**祈使句 + 动词打头**（消防员的火警清单：①突出有人被困 ②位置具体到房间 ③火势往大了估计 ④突出建筑类型——关键时刻能救命）。

- "要干什么"：行动 + 操作要点（+示范）
- "不要干什么"：避坑指南（"位置不能简略，要具体到房间"）

示例（合影环节提速，一个字不提"快"，全是动作）：
> 第一步，活动开始前备足手牌、相框和打印机，打印机2–3台（高峰期一台不够用）。
> 第二步，合影前发号码牌，最好串在手上，避免遗失。
> 第三步，合影后现场打印、装框。
> 第四步，按号码牌发照片，同时回收号码牌。

### 三、决策思路（为什么这么干）

操作步骤里任何**反常识**、对方可能理解不到位的地方，都要补理由——不理解就执行不到位（"火势往大了说"是因为火情从局部到失控可能就是一瞬间）。参考美食作家王刚的"技术总结"：加啤酒，是为了去腥增鲜；锅边淋白酒，是为了用酒精和高温带走鱼腥。
- 决策思路别写抽象逻辑，写**用户能感受到的比较优势**。
- 示例："工作沟通尽量群里说"——补上理由（信息通畅、跨岗位互相把关、过往教训案例），新同事才会真的执行。

### 四、（加分）正反案例

道理听着容易抽象似是而非，补一个真实案例就能落地（黄碧云讲超市选址，补"1500平缩小成500平、客群改成年轻人"的真实改判案例）。类比：办事窗口的示范填单。

## 事故/失误复盘的特殊处理

先问题先行，再按四要素逐条写：
1. **结构调整**：问题定义放最前；时间线只保留能说明问题的关键事件，不记流水账。
2. **不写辩解**：不解释"当时决策的无奈"——写得不好领导未必生气，找借口领导肯定生气。
3. **改善思路具体化**：不写原则（"要增强预案意识"），写符合原则的**具体行动**。

改写示例：
> ✗ "7月1日没有事先考虑到雨天方案。当天阴雨绵绵，影响客流量与现场活动效果。"（追责口吻）
> ✓ "5–8月在上海做大型活动，需要做雨天备案。这个季节有梅雨，也可能受台风影响，长三角城市可参考。雨天备案见附件1。"

> ✗ "观众合影环节，动线缺乏事先梳理，因此比计划时间超出二十分钟。"
> ✓ 定义问题（"怎么控制流程，提升**带小孩的家庭**在合影环节的体验？"——限定了人群，继任者知道经验何时适用、何时慎用）→ 操作步骤（四步清单见上）→ 决策思路（打印装框是为了让每个家庭带走全家福，促进口碑裂变）→ 案例（往年好评照片样例）。

## 分步提示词

**生成**：
```
【角色】你是<项目/岗位>负责人，擅长把经验沉淀为组织资产。
【背景】复盘对象：<项目/事故>；关键问题清单：<问题1/2/3>；每条问题对应经验：<经验>；相关素材：<时间线要点/数据/案例>。
【任务】请按"定义问题（含适用边界）+ 操作步骤（祈使句清单，含避坑）+ 决策思路 + 正反案例"的小闭环结构撰写复盘报告，每条经验独立成环；事故类复盘不写辩解，问题先行；数据用××。
```

**检查**：是否沦为表彰会/检讨书？问题定义有没有限制条件？步骤是否到"照做就能成"的颗粒度？反常识处是否补了理由？

**调整**：
- `请把第×条的追责表述改写为面向继任者的经验：定义问题+操作步骤+决策思路。`
- `请为"定义问题"补充限制条件（人群/地域/季节/阶段）。`
- `请把"××原则"式的改善思路细化成可执行的行动清单。`
- `请为第×条经验补充一个正面或反面案例。`

## 自检

- [ ] 每条经验都是"定义问题→操作步骤→决策思路"闭环
- [ ] 问题定义带适用边界（继任者能判断这条经验该不该用、何时慎用）
- [ ] 操作步骤为祈使句清单，含避坑提示，颗粒度可执行
- [ ] 无追责口吻、无辩解、无流水账
- [ ] 符合默认公开：经验脱离当时的"高语境"也能被后人读懂（`19`）
