# 公开发言（131 公式）

> 来源：《得到·职场写作训练营》第 11 讲。公文体领导讲话稿见 `14-领导讲话.md`；座谈发言、心得体会见 `08-体会与发言.md`；本文件针对**面向听众的公开发言**：经验分享、竞聘演讲、工作汇报、客户宣讲、会议发言——凡需要营造"我很专业、这事听我的准没错"信任感的场合。

## 定位

- 公开发言不是即兴讲话，是**有准备的口语逐字稿**——罗振宇四小时跨年演讲逐字码稿，罗翔刚当老师时连"谢谢，现在下课"都写进稿子。
- 但**不能照本宣科**：发言稿不能呈现复杂的书面逻辑（三大点五小点，讲到第二点听众就忘了第一点），要营造听众感受，只捋**单层逻辑**。
- 行动导向特殊：发言的目标不是讲尽所有内容，而是**建立信任**——让听众心里打上烙印"这项工作你就是专家"。

## 写作公式

**公开发言 = 一个挑战 + 三点方案 + 一次返场（131 公式）**

### 一、开场：一句挑战

开场是听众注意力最集中的黄金时刻。自我介绍、感谢主办方都是浪费。百试百灵的开头：**一句挑战**——告诉听众"我来解决你关心的一个问题"。

**挑战公式：挑战 = 主角 + 目标 + 障碍**

1. **主角永远是台下的听众**（隐形主角，"台下听众"四字不必出现）：
   > ✗ "儿童营养健康知识讲座"（主角是知识，跟家长的应用场景太远）
   > ✓ "如何培养孩子的饮食习惯，避免肥胖？"（主角是家长）
   
   同一家公司讲给不同人听，挑战完全不同：对客户讲"我们的合作理念是什么"；对求职大学生讲"为什么值得加入我们"；对政府讲"公司为当地创造了什么价值"。**先问主办方：听众是谁、诉求是什么。**

2. **目标与障碍是一根绳的两头**，两头拉扯出张力，张力越大越吸引人：
   - 目标高 = 价值高；障碍大 = 困难大（障碍无非：对手太强 / 资源不够——人、钱、时间）。
   - 示例（公路设计者李小伟）：目标"设计跨省公路" + 障碍"山多江多地形复杂 / 180天的设计周期只有20天 / 人手不足还要跨省协调多方" → "他是什么神人？我想听听。"
   - 示例（大口茶）："怎么开一家茶饮店"（平淡）→"怎么开一家**比喜茶还赚钱**的茶饮品牌？"（拉目标）→"这个新品牌**开在喜茶旁边**，怎么还能比喜茶更赚钱？"（拉障碍）

3. 练习（郑州餐饮）："2022年郑州餐饮行业经营概况" → 找用户（对老板而非研究员）→"如何在郑州做一家餐饮企业" → 找障碍（疫情）→"疫情影响下郑州餐饮企业如何突围" → 拉目标 →"疫情影响下郑州餐饮企业如何**翻倍增长**？"

### 二、正文：三点方案

**纪律：只讲三点。**（麦肯锡"凡事讲三点"；人的注意力最多驾驭三四个点；两点又没收住。）信息太多怎么办？**删**——好发言是删出来的；实在重要的做成材料发给听众："这部分今天不讲，材料放在桌上，重点已标出。"

**把排列变成递进**：别用孤立的"第一、第二、第三"，要告诉听众**第二点比第一点更重要、更难、更有价值**，层层递进建立势能。两根万能绳索：

1. **时间绳索**（覆盖80%场景）：事情先后顺序 / 解决问题步骤 / 工作流程。
   示例（物流加盟商三级筛选）："第一级，申请人有家人支持——但口说无凭 → 第二级，实地家访——全家都靠谱就保险了吗？还不够 → 第三级，价值观考核，不合拍走不长久。"标准一条比一条难，听众被一路带走。
   练习（诚品书店）："做推广、盘资源、办活动" → 按流程重排：先盘资源（定产品）→ 再做推广（壮大）→ 后办活动（升级模式）。

2. **重要性绳索**（无时间线时兜底）：最重要的放第一。体制内通例——党的领导放最前。示例（人才强校战略）：①坚持党管人才（政治保证）②服务国家战略（方向）③创新体制机制（动力）。练习（老年友好型社会）：权益保障（基础）→ 宜居环境（最可感）→ 社会敬老（细水长流）。

**每部分配感性素材**：抽象概念、严谨逻辑对权威性重要、对听众要命。逢逻辑必跟感性素材（5W1H 往细里用：人名、地名、公司名、数字、专有名词、颜色、画面、动作）——注意力是不断对焦的过程，逻辑唤不回注意力，感性素材可以。
> 反诈横幅对比："谨防电信诈骗" ✗；"你家隔壁老王前天刚被骗了400块，再不注意下一个就是你" ✓（河北承德某派出所加上人名数字后，片区连续两月零案发）。

最厉害的用法：一句道理不讲，全用故事让听众自己领悟。

### 三、结尾：一次返场

普通版"谢谢"，保守版加总结；**加分版制造意外**（峰终体验管理）：
> 成都常委介绍成都，结尾说："成都的火锅店全国第一，你们可能都知道。但你们不知道的是，成都有4500家书店，书店数量也是全国第一。"（对教育公司的听众，这个事实惊艳且可转述。）

返场素材三类：一个意外的**事实**、一个可转述的**故事**、一个号召的**行动**（"听完了今天的分享，希望大家会后配合我做××"）。

## 分步提示词

**生成**：
```
【角色】你是<身份>，擅长撰写抓住听众注意力的公开发言稿。
【背景】场合：<会/论坛/竞聘>；听众是谁、诉求是什么：<…>；要解决的问题：<…>；我有资格讲这个题目的经历与数据：<…>；时长：<分钟>。
【任务】请把以下书面材料改写成口语逐字稿，按"131公式"：①一句挑战（主角=听众，拉高目标+放大障碍）②只讲三点并做递进（时间顺序或重要程度），每点配感性素材（人名/数字/画面）③一次返场收尾（意外事实/可转述故事/号召行动）。禁用书面逻辑的三大点五小点。
```

**检查**：挑战的主角是不是听众？三点是否递进而非并列？每段抽象逻辑后是否跟了感性素材？结尾有无意外感？

**调整**：
- `请把开场改写成一句挑战，按"主角+目标+障碍"拉满张力。`
- `请把第×部分的四点压缩为三点，并入递进链，被删重点转为会后材料。`
- `请为第×点补充一个人名/数字/画面级的感性素材。`
- `请把结尾改写为一次返场：给一个听众可以带走转述的意外事实。`

## 自检

- [ ] 是口语逐字稿而非书面材料（念出来顺、听得懂）
- [ ] 开场一句挑战，主角是听众，张力拉满
- [ ] 正文只三点、有递进、有感牲素材托底
- [ ] 结尾有返场设计；整体过三原则检查（`19`）
