# 会议纪要

会议纪要分两类：**办公类**（议题制，逐议题记录议定事项）与**研讨协商类**（过程制，先记过程再记结论）。

| 类型 | 判断依据 | 结构 |
|---|---|---|
| 办公类 | 办公会、党委会、例会，有多个独立议题 | 引言段 + 议题段1/2/3… |
| 研讨协商类 | 专题研讨会、协商会、座谈会，围绕单一主题 | 引言段 + 正文段（会议过程）+ 正文段（结论要求） |

---

## 一、办公类会议纪要

### 写作公式

```
纪要篇章 = 标题 + 引言段 + 议题段1 + 议题段2 + 议题段3 + ……

标题 = 会议名称 + 纪要

引言段 = ××××（会议时间），×××（在场最高领导）在×××（会议地点）主持召开××××（会议名称），
        会议传达学习了……/会议听取了……/会议审议了……/会议通报了……，就××××（重点事项）进行研究部署。
        ×××、×××、×××（领导）参加会议。现将会议纪要如下：

议题段 = 议题句 + 会议过程句 + 结论要求句
议题句    = 关于××××工作
会议过程句 = 会议传达了……/会议听取了……/会议审议了……/会议通报了……
结论要求句 = 会议认为……/会议指出……/会议要求……/会议强调……/会议决定……/会议明确……/会议号召……
```

## 二、研讨协商类会议纪要

### 写作公式

```
纪要篇章 = 标题 + 引言段 + 正文段（会议过程）…… + 正文段（结论要求）

标题 = 会议名称 + 纪要

引言段 = 会议情况句（会议时间 + 会议主题）+ 参会人员句（与会最高领导 + 会议主持人 + 概述其他与会领导/人员）

正文段（会议过程）= 会议传达了……/会议听取了……
正文段（结论要求）= 会议认为……/会议指出……/会议要求……/会议强调……/会议决定……/会议明确……/会议号召……
```

### 生成提示词 ·【研讨协商类会议纪要】提示词

```
你是市政府办公室秘书，善于抓重点撰写会议纪要。下面我将为你提供一份【会议记录】内容。请结合会议记录内容，按照【研讨协商类会议纪要写作公式】撰写一篇会议纪要。要求：1.严格按照我提供的写作公式格式和措辞方式进行撰写；2.议题内容不能遗漏，要按照会议记录顺序撰写纪要；3.内容充实，信息要点明确，保留关键细节；4.使用专业术语；5.字数800字。
#研讨协商类会议纪要写作公式
#会议记录
```

---

## 纪要类写作要点

1. **动词库固定**：会议过程用「传达学习/听取/审议/通报」；结论用「认为/指出/要求/强调/决定/明确/号召」
2. 议题顺序严格按会议记录顺序，不得遗漏、不得重排
3. 纪要是「决定性文件」，凡写入纪要的事项须有明确的结论或要求，不能只写讨论过程
4. 涉及责任人、完成时限、数据用 `××` 占位
5. 引言段的领导排序按职务高低排列，主持人单列
6. 不写"会议讨论了各种不同意见"，只写议定的结论

## 快速纪要法（得到·职场写作训练营 第06讲补充）

上面是**正式公文纪要**的写法；日常工作会议还需要**会中速记、会后即发**的快速纪要法。公式：

**会议纪要 = 会议信息（5W）+ 行动清单 + 共识**

### 一、会中按方抓药，不是埋头速记

会前先梳理"这次会要拿到哪些信息"，会中带着问题找答案。录音笔/会议 App 负责逐字记录，人只负责**提炼要点**。

**会议信息 5W**：
- **who** 参会人——分清角色分量：负责人（最后总结结论的人）、协作者（供背景信息）、专业把关者（人力/财务/法务）
- **when** 会议时间（时长也值得记——两小时的会与30分钟的会信息密度不同）
- **where** 地点
- **why** 会议目标（一百个会九十九个跑题，先定目标的不跑题）
- **what** 会议议程（每项谁负责、讲什么、多长时间——提前整理好发给参会人，等于提前写好纪要大纲）

### 二、行动清单（纪要可以什么都没有，但不能没有这个）

**行动 = 谁 + 做什么 + Deadline + 交付标准（+ 赏罚结果，会上有则记）**

> ✗ "下周完成和市发改局的沟通，协调我司B612项目。"
> ✓ "@市场开发部王进步，请于2022年1月26日（下周三）14:00前，完成与市发改局沟通协调，确定我司B612项目列入市'十四五'规划的具体时间。"

- 对话纠缠时**拆条记录**：小张要去定发布会时间；小王 15:00 前整理嘉宾名单供小张使用；小张与公关部确认嘉宾沟通启动时间。
- Deadline 与负责人会上没明说的，**当场或会后找当事人确认**。
- **例会纪要**最简单：核心就是记清楚**下周行动清单**——每人汇报后领导的下一步指示，大概率就是最重要的信息。

### 三、共识（隐藏最深、最体现水平）

**路标词**（听到就要警觉）："我们一定要……""我们未来都不能再……""我们要吸取教训……""最重要的原则就是……"

记共识不只记结论，**必须补背景**——脱离会议的高语境也能被准确理解（默认公开原则）。填空句式：

> 这次____（项目/工作）最重要的就是____。要解决的问题是____。

> ✗ "打好品牌认知战。"
> ✓ "这次双11活动要打好品牌认知战，提出这个原则是因为要解决去年的问题——去年销售不错但没有突出品牌，导致后续一个月增长乏力。"

### 四、两个现场难题

1. **分歧记录**：A"徐总大致同意李总，记李总的话就行" ✗；B"两个观点都记下，并写下各自的判断" ✓——"同意"有时是客气，重点在后面，可能是截然不同的观点。
2. **没达成共识**：主动引导回到会议目标（"这个问题是不是还需要明确一下？"），或写成一条会后行动："该问题需在××时间前，由××牵头明确。"

**存放**：重要纪要同步相关人 + 群里 + 邮件备份，做好后人查阅的证据留存。
