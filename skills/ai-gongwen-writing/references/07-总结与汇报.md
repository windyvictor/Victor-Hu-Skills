# 总结与汇报

**工作总结**是本单位对自己工作的回顾（做法 + 问题 + 计划）；**工作汇报**是向上级报告某项工作（主要情况 + 存在问题 + 有关建议）。

| 类型 | 受文对象 | 结构 |
|---|---|---|
| 工作总结 | 本级/上级，年度或专项总结 | 帽段 + 做法段×N + 问题段 + 计划段 |
| 工作汇报 | 上级领导，专项工作汇报 | 引言段 + 主要情况 + 存在问题 + 有关建议 |

---

## 一、工作总结

### 写作公式

```
工作总结篇章 = 帽段 + 主体段1（做法）+ 主体段2（做法）+ …… + 主体段（问题）+ 主体段（计划）

帽段        = 指导思想句 + 情况背景句 + 工作思路句 + 工作成果句
主体段（做法）= 主题句why（说明为什么这么做）+ 支撑句how（说明做法）+ 支撑句what（说明成果）
主体段（问题）= 客观形势句 + 问题表现句
主体段（计划）= 形势分析句 + 工作思路句 + 结尾句
```

### 第一步 ·【信息归类】提示词（理法事果四分法）

```
你是省政府政策研究室的公文写作专家，熟悉产业政策，擅长课题研究，公文写作水平高。请对下面的【工作材料】，按照"理、法、事、果"四分法进行材料内容分类标注。"理"是"理念"，代表对问题的看法、观点。"法"是"做法"，代表具体开展工作的方法。"事"是"事例"，事例中会出现具体的单位和成效。"果"是"成果"，做法带来的成果，以数据或明确的奖项、成绩展现。
#工作材料
```

### 第二步 ·【提炼要点】提示词

```
接下来，以上面的内容为基础提炼工作要点。要求：1.提炼"理"的内涵，作为主标题；2.对做法进行归类提炼，要求提炼出共性关键词，并将事例和成果放到相应的做法之后。
```

### 第三步 ·【正文段（做法）】提示词

```
请对五个一级标题之后的正文段，按照【正文段（做法）公式】进行修改完善，保证行文逻辑性，并在内容中把数据补充进来，具体数据用××替代。要求：1.符合公文行文方式，一二级标题清晰；2.字数：2000字。
#正文段（做法）公式
正文段（做法）=主题句why（说明为什么这么做）+支撑句how（说明做法）+支撑句what（说明成果）
```

### 第四步 ·【帽段】提示词

```
请针对上述内容，写一个统领全文的帽段，要包含中央关于创新成果转化的最新精神，要求按照【帽段公式】撰写。
#帽段公式
帽段=指导思想句+情况背景句+工作思路句+工作成效句
```

### 第五步 ·【问题段】提示词（套模块）

```
请根据下面的【问题段模块】，结合B区科技城的相关工作，拓展分析相关问题。要求控制在一段，300字左右，条理清晰，符合模块的行文风格。
#问题段模块
当然，……还面临不少问题和挑战。……不够稳固，……带来的影响比较明显。……还存在不少堵点卡点，……困难增多。……任务艰巨，……不快，……不高，……偏少，……认识不够、行动不快，……程度不够，……不充分、……不丰富。……产出较低，……不多。……建设滞后，……不足、……不高。……不够平衡，……滞后，……差距较大。……任务繁重。……较少。……仍然突出，……问题仍有发生。
```

### 第六步 ·【主体段（计划）】提示词

```
请结合上述工作及存在问题，按照【主体段（计划）】写一段下一步工作计划，要求：1.有前瞻性目标和创新举措；2.工作思路句中，至少列出3点以上工作举措，并以"一是、二是、三是……"开头。
#主体段（计划）公式
主体段（计划）=形势分析句+工作思路句+结尾句
```

### 第七步 ·【修改标题】提示词（标题对仗化）

```
请按照公文对仗式标题写法，对下面的【标题】进行修改。
#标题
一、优化政务环境，提升服务效能
二、精准定位，构建创新成果转化聚集地
三、深化协同创新与产业协作，推进产业链发展
四、强化项目引进与创新载体建设，扩大创新资源集聚
五、前瞻布局，持续优化创新政策与合作模式
```

## 二、工作汇报

### 写作公式

```
工作汇报篇章 = 标题 + 引言段 + 主要情况部分 + 存在问题部分 + 有关建议部分

标题 = 关于【报告事项概括】+ 汇报提纲

主要情况部分 = 汇报事项段1 + 汇报事项段2 + 汇报事项段3……（数量根据主要工作方面确定）
存在问题部分 = 问题分析段1 + 问题分析段2 + 问题分析段3 + ……（3-4个问题段）
有关建议部分 = 建议段1 + 建议段2 + 建议段3 + ……（与问题基本对应）

引言段 = 指导思想句 + 情况背景句 + 工作思路句 + 总体成效 + 过渡句
```

### 第一步 ·【分析文件】提示词

```
你是省政府政策研究室专家，熟悉经济政策，了解经济运行规律，熟悉省外商投资情况。请综合分析我发给你的三份文件，提出对市一级"优化外商投资环境加大吸引外商投资力度"方面的具体工作指导。要求：详细列举各项措施，指导明确，符合市一级特点。
```

输入文件三件套示例：

```
#文件一：《国务院关于进一步优化外商投资环境加大吸引外商投资力度的意见》
#文件二：《AH省人民政府关于印发进一步优化外商投资环境加大吸引外商投资力度若干措施的通知》
#文件三：省商务厅《关于进一步优化外商投资环境加大吸引外商投资力度的若干措施》政策解读新闻发布会
```

### 第二步 ·【生成框架】提示词（先搭骨架）

```
你是H市政府办公室主任，熟悉经济工作，擅长公文写作。请根据下面的【工作指导措施】要求，列出H市在"优化外商投资环境加大吸引外商投资力度"方面的工作汇报提纲，提纲内容包括主要情况、存在问题和有关建议三个部分。要求：1.三个部分都列出一、二级标题，每个一级标题下至少列出三个二级标题；2.各级标题符合公文对仗形式，简洁清晰；3.主要情况的一级标题由两个分句"做法"+"成效"构成的复句，二级标题是以结果为导向的单句标题；4.存在问题与有关建议相对应。5.仅列出标题即可，不需要列出正文内容。
#工作指导措施
```

### 第三步 ·【工作汇报】提示词（4000字，逐部分生成）

```
你是市政府办公室主任，对本市经济发展情况非常熟悉，擅长公文写作。现在需要你起草一份市长对省领导的工作汇报，内容是关于本市"优化外商投资环境加大吸引外商投资力度"方面的情况。请按照【工作汇报写作公式】进行撰写，围绕【工作汇报提纲】展开。要求：1.各部分内容要有数据支撑，定性表述与定量表达相结合；2.语言表达简洁、专业，符合领导讲话表达特点；3.保持标题不变，拓展延伸标题内容；4.字数：4000字；5.根据我的指令逐个部分生成，确保字数达到要求。明确任务，回复OK。
#工作汇报写作公式
#工作汇报提纲
```

## 总结与汇报写作要点

1. **总结的骨架顺序固定**：做法 → 问题 → 计划，三段缺一不可
2. **汇报的对应关系**：建议必须与问题一一对应，几个问题就几条建议
3. 主要情况部分的一级标题用「做法 + 成效」复句，二级标题用结果导向单句
4. 数据用 `××` 占位，定性表述与定量表达结合
5. 问题段要"把握分寸、客观中立"，既要讲真问题又不能自我否定过度
6. 长文（>1500字）必须按部分生成，每部分确认后再继续
