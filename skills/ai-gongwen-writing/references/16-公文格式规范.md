# 公文格式规范（补充内容）

> **说明**：本文件**不属于**《梅俊·AI公文写作工具手册》的内容。手册只解决"内容怎么写"（结构、公式、提示词），不涉及"版式怎么排"。但正式公文必须有版头、发文字号、署名、成文日期等要素，否则不能行文。本文件依据《党政机关公文格式》（GB/T 9704-2012）与《党政机关公文处理工作条例》（中办发〔2012〕14号）整理，作为手册的补充。
>
> 各单位可能有更细化的内部规定，落地时以本单位办公室最新要求为准。

---

## 一、15 种法定公文文种

《党政机关公文处理工作条例》规定的 15 种法定公文，是本技能所有文种的上位归属：

| 序号 | 文种 | 行文方向 | 本技能对应文件 |
|---|---|---|---|
| 1 | 决议 | 下行 | 无专章，用通用骨架 |
| 2 | 决定 | 下行 | 无专章，用通用骨架 |
| 3 | 命令（令） | 下行 | 无专章 |
| 4 | 公报 | 公布 | 无专章 |
| 5 | 公告 | 公布 | 无专章 |
| 6 | 通告 | 公布 | 与通报辨析见 `17-易混文种辨析.md` |
| 7 | 意见 | 上/下/平行 | 无专章，用通用骨架 |
| 8 | 通知 | 下行 | `01-通知.md` |
| 9 | 通报 | 下行 | `02-通报.md` |
| 10 | 报告 | 上行 | 与"请示"辨析见 `17-易混文种辨析.md` |
| 11 | 请示 | 上行 | 同上 |
| 12 | 批复 | 下行 | 无专章 |
| 13 | 议案 | 上行 | 无专章 |
| 14 | 函 | 平行 | 与通知辨析见 `17-易混文种辨析.md` |
| 15 | 纪要 | 平行/下行 | `05-会议纪要.md` |

**注意**：手册涉及的"消息""信息""总结""汇报""体会""发言""述职报告""调研报告""理论文章""感谢信""慰问信""倡议书"**都不是法定公文文种**，属于事务性文书或新闻文体，格式要求相对宽松，但内容结构仍按本技能各文种公式执行。

常见错误：把"汇报""说明""情况"当作正式文种使用。

## 二、公文格式三大区域与要素

公文版式分为**版头、主体、版记**三部分。

### 2.1 版头（首页红色分隔线以上）

| 要素 | 规范 |
|---|---|
| 份号 | 涉密公文标注，6 位阿拉伯数字，顶格编排在版心左上角第一行 |
| 密级和保密期限 | 3 号黑体，顶格编排在版心左上角第二行；如"秘密★1年" |
| 紧急程度 | 3 号黑体，顶格编排在版心左上角；如"特急""加急" |
| 发文机关标志 | 发文机关全称或规范化简称 + "文件"，红色小标宋体 |
| 发文字号 | 3 号仿宋，编排在发文机关标志下空二行，居中。**编排规则见下** |
| 签发人 | 仅上行文标注。"签发人"用 3 号仿宋，姓名用 3 号楷体，居右空一字 |
| 红色分隔线 | 与版心等宽的红色实线 |

### 2.2 发文字号编排规则（高频错误点）

```
正确：国办发〔2026〕5号
错误：国办发[2026]5号     ← 方括号代替六角括号
错误：国办发【2026】5号    ← 全角方头括号
错误：国办发〔2026〕第5号   ← 多了"第"字
错误：国办发〔2026〕05号    ← 编了虚位
```

- 年份用**全称**，用**六角括号 〔 〕** 括入
- 顺序号用阿拉伯数字，**不加"第"字，不编虚位**（1 不写成 01），后加"号"字
- 上行文的发文字号居左空一字，与最后一个签发人姓名同处一行

### 2.3 主体

| 要素 | 规范 |
|---|---|
| 标题 | 2 号小标宋，红色分隔线下空二行居中。回行时词意完整，排列**梯形或菱形**，不用长方形或沙漏形 |
| 主送机关 | 3 号仿宋，标题下空一行，左侧顶格，回行顶格，最后一个机关名称后加冒号 |
| 正文 | 3 号仿宋；数字和英文用 3 号 Times New Roman |
| 附件说明 | 正文下空一行左空二字，`附件：1. ×××`；多个附件用阿拉伯数字标序，回行对齐 |
| 发文机关署名 | 成文日期之上，居中/偏右 |
| 成文日期 | 阿拉伯数字标全年月日，居右空四字 |
| 印章 | 上不压正文（与正文尾行不超过一行），下压成文日期 |
| 附注 | 如"（此件公开发布）"，成文日期下一行左空二字，加圆括号 |

### 2.4 版记（末页）

| 要素 | 规范 |
|---|---|
| 抄送机关 | 4 号仿宋，最后一个机关名称后加句号 |
| 印发机关和印发日期 | 4 号仿宋，印发机关左空一字，印发日期右空一字 |
| 分隔线 | 上下为粗线，中间为细线 |

## 三、层次序数与字体

```
一、            ← 一级标题，3 号黑体
（一）          ← 二级标题，3 号楷体
1.             ← 三级标题，3 号仿宋（可加粗）
（1）           ← 四级标题，3 号仿宋
```

- 序数层次依次为：`一、` → `（一）` → `1.` → `（1）`
- 正文中**括号、双引号、书名号之间不用顿号**：写"（一）（二）"不写"（一）、（二）"
- 标点用全角：`（）`，不用半角 `()`
- 乘号用 `×` 或 `╳`，不用字母 `X`；数字"○"不用字母 `O` 或数字 `0`

## 四、页面设置

| 项目 | 标准值（GB/T 9704-2012） |
|---|---|
| 纸张 | A4（210mm × 297mm） |
| 上白边 | 37mm ± 1mm |
| 下白边 | 35mm ± 1mm |
| 左白边（订口） | 28mm ± 1mm |
| 右白边 | 26mm ± 1mm |
| 正文行数 | 每面 22 行 |
| 每行字数 | 28 字 |
| 行距 | 固定值 28-30 磅（各单位略有差异） |
| 页码 | 4 号宋体，数字左右各一条一字线，如 `— 1 —`；单页靠右、双页靠左 |

双面印刷时须采用"对称页边距"。

## 五、AI 生成公文后的格式落地检查

本技能产出的是**内容**。用户拿到内容后排版时逐项核对：

- [ ] 发文机关标志是否用红色小标宋
- [ ] 发文字号是否用六角括号 `〔〕`、不编虚位、不加"第"
- [ ] 标题是否 2 号小标宋、回行是否梯形或菱形
- [ ] 一级标题是否 3 号黑体、二级是否 3 号楷体
- [ ] 正文是否 3 号仿宋、数字与英文是否 Times New Roman
- [ ] 层次序数是否为 `一、` `（一）` `1.` `（1）`
- [ ] 主送机关是否顶格、末尾加冒号
- [ ] 附件说明是否"附件：1. ×××"格式
- [ ] 成文日期是否阿拉伯数字标全、居右空四字
- [ ] 印章是否上不压正文、下压成文日期
- [ ] 版记抄送机关末尾是否加句号
- [ ] 页码是否 4 号宋体、单页靠右双页靠左

## 六、行文规则要点

1. **上行文**（请示、报告）：一文一事，不得多头主送；请示须标注签发人、联系人及电话
2. **平行文**（函）：不相隶属机关之间商洽工作、询问答复问题
3. **下行文**（通知、通报、批复、决定、意见）：向所属下级机关行文
4. **不得一文多事**（请示尤其禁止），主送机关必须明确
5. **请示与报告不得混用**：请示要求上级答复，报告不要求答复
6. 涉及其他部门职权的事项，须先会签再行文
