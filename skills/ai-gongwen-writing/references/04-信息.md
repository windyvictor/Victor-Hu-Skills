# 信息（政务信息）

信息分两类：**动态信息**（一段式短信息，报道一项工作进展）与**经验信息**（多段式，提炼可复制的做法经验）。

| 类型 | 形态 | 篇幅 |
|---|---|---|
| 动态信息 | 一段话，做法 + 成果 | 300字 |
| 经验信息 | 多段，主标题 + N 个小标题段 | 800字 |

---

## 一、动态信息

### 写作公式

```
动态信息 = 标题 + 做法句 + 成果句（具体数据）
标题     = 地区（单位）+ 主题
```

## 二、经验信息

### 写作公式

```
经验信息篇章 = 主标题 + 正文段1（小标题1+做法句+成果句）+ 正文段2（小标题2+做法句+成果句）+ ……

主标题 = 地区（单位）+ 主题（核心做法词）+ 效果词
```

### 第一步 ·【分析问题】提示词

```
你是省政府农业农村厅办公室主任，对农业经济发展有深刻认识，擅长提炼分析撰写农业方面的公文材料。请解释一下"农村一二三产业融合发展"的内涵。
```

### 第二步 ·【提炼经验做法】提示词1、提示词2、提示词3（三步递进）

```
我是F县政府办公室工作人员，现在需要对我县草莓产业融合驱动农业经济新增长的相关工作进行总结提炼。请你根据前面对"农村一二三产业融合发展"的分析，结合【F县草莓产业情况】，从"生产模式、品牌打造、技术合作"三个方面提炼符合"融合驱动"的做法要点，请以无序列表呈现。
#F县草莓产业情况
```

```
请对这三点概括出同样字数的三条做法，并要包含"融"字。
```

```
请用数字概括法，对下面三条做法进行概括，提炼出一个核心做法词。
###
融合生产链
融入市场化
融会新科技
```

### 第三步 ·【经验信息】提示词

```

#三个小标题

二是融入市场化，打造特色品牌。
三是融会新科技，提升种植技术。
#经验信息写作公式
经验信息篇章=主标题+正文段1（小标题1+做法句+成果句）+正文段2（小标题2+做法句+成果句）+……
主标题=地区（单位）+主题（三融策略）+效果词
#F县草莓产业情况
```

## 信息类写作要点

1. **信息不同于消息**：信息是给上级看的，重在"做法 + 数据"，不追求现场感与文学性
2. 标题公式固定：`地区（单位）+ 主题`，中间不加逗号
3. 成果句必须有**具体数据**，不确定时用 `××` 占位
4. 经验信息的小标题就是段落第一句，不要再另起主题句
5. 做法提炼优先用「数字概括法」（三融、四化、五抓），便于记忆与推广
