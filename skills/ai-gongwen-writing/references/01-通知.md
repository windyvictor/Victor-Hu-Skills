# 通知

通知分三类：**会议通知**（告知性）、**部署工作通知**（指示性）、**贯彻指示通知**（转发落实上级文件）。先判断类型，再套公式。

| 类型 | 判断依据 | 语气 |
|---|---|---|
| 会议通知 | 告知会议时间地点人员议程 | 简洁明确 |
| 部署工作通知 | 本单位自主部署某项工作 | 指示性，正规严肃 |
| 贯彻指示通知 | 上级发文，要求下级贯彻落实 | 指示性，正规严肃 |

---

## 一、会议通知

### 写作公式

```
会议通知篇章 = 标题 + 帽段 + 主体段（会议主题）+ 主体段（会议时间）+ 主体段（会议地点）
            + 主体段（参加人员）+ 主体段（议程）+ 主体段（会议要求）

标题 = 发文机关名称 + 事由 + 通知
帽段 = 会议背景句 + 召开目的句 + 召开依据句
主体段（会议要求）= 上报名单 + 报送资料 + 注意事项（着装、会场纪律）+ 联系人 + 联系方式
```

### 生成提示词 ·【会议通知】提示词

```
你是A集团办公室主任，请以集团名义面向各分公司、各部门，下发一份召开年终总结表彰会议的通知。请根据给定的【会议基本信息】，按照【会议通知写作公式】撰写一份会议通知。要求各段落有明确标题，表达清晰简洁。
#会议基本信息
#会议通知写作公式
会议通知篇章=标题+帽段+主体段（会议主题）+主体段（会议时间）+主体段（会议地点）+主体段（参加人员）+主体段（议程）+主体段（会议要求）
标题=发文机关名称+事由+通知
帽段=会议背景句+召开目的句+召开依据句
主体段（会议要求）=上报名单+报送资料+注意事项（着装、会场纪律）+联系人+联系方式
```

## 二、部署工作通知

### 写作公式

```
部署工作通知篇章 = 标题 + 通知缘由段 + 通知事项段×N + 结语段

标题 = 发文机关名称 + 事由 + 通知
通知缘由段 = 背景情况句 + 发布依据句 + 目的意义句 + 引出下文句
通知事项段 = 事项标题 + 主题句 + 支撑句（对策措施）+ 支撑句（注意事项）
结语段   = 强调要求句
```

### 第一步 · 分析工作问题提示词

```
你作为省政府林业局专家，对森林防火有深刻的认识，充分了解森林火灾的特点以及防范要求。请基于你的专业知识和经验，列出秋冬季森林防火需要注意的关键问题，并给出相应的预防措施和建议。确保这些问题和建议能够帮助相关部门和人员更好地进行森林防火工作，保护森林资源和生态环境。
```

### 第二步 ·【部署工作通知】提示词

```
你是县林业局工作人员，请根据上述内容，以××县林业局名义，面向××县各基层单位，按照【部署工作通知写作公式】撰写一份通知用于部署森林防火工作。行文运用指示性语气，正规严肃。字数：2000字。
#部署工作通知写作公式
部署工作通知篇章=标题+通知缘由段+通知事项段+结语段
标题=发文机关名称+事由+通知
通知缘由段=背景情况句+发布依据句+目的意义句+引出下文句
通知事项段=事项标题+主题句+支撑句（对策措施）+支撑句（注意事项）
结语段=强调要求句
```

## 三、贯彻指示通知

### 写作公式

```
贯彻指示通知篇章 = 标题 + 通知缘由段
                + 通知事项段（重要意义）+ 通知事项段（学习要求）+ 通知事项段（落实要求）
                + 通知事项段（监督检查）+ 通知事项段（宣贯落实）

标题 = 发文机关名称 + 关于贯彻落实《××》 + 通知
通知缘由段 = 文件发布情况句 + 文件意义句 + 目的句 + 引出下文句

通知事项段（重要意义）= 事项标题 + 主题句 + 支撑句（文件意义）+ 支撑句（要求）
通知事项段（学习要求）= 事项标题 + 支撑句（学习举措）
通知事项段（落实要求）= 事项标题 + 支撑句（落实措施）
通知事项段（监督检查）= 事项标题 + 支撑句（监督检查措施）
通知事项段（宣贯落实）= 事项标题 + 支撑句（宣传落实措施）
```

### 第一步 · 分析文件重点内容提示词（手册标注：KimiChat）

```
请整理分析《煤矿安全生产条例》文件内容。
提问1：请分析这部法规的意义价值。
提问2：煤矿安全监管部门、煤炭行业管理部门、煤炭行业企业学习这份文件可以采取哪些措施，保证学习效果。
提问3：煤炭行业企业落实这份文件可以采取哪些措施，保证落实效果。
提问4：对于督导落实好这份文件，煤矿安全监管监察部门要做好哪些监管监察措施。
提问5：煤矿安全监管部门抓好文件的宣传落实可以采取哪些措施。
```

> 五个提问与五个「通知事项段」一一对应，是贯彻指示通知的标准素材准备流程。

### 第二步 ·【贯彻指示通知】提示词

```
你是省矿山安全监察局工作人员，对煤矿安全工作非常熟悉，擅长撰写相关公文材料。现接到国务院颁布的《煤矿安全生产条例》，根据要求要起草一份面向下级煤矿安全监管部门、煤炭行业管理部门、煤炭行业企业的通知，目的是为了抓好《煤矿安全生产条例》的贯彻落实。请根据【贯彻指示通知写作公式】撰写一份通知用于《条例》指示精神的贯彻落实。行文运用指示性语气，正规严肃。字数：2000字
#贯彻指示通知写作公式
贯彻指示通知篇章=标题+通知缘由段+通知事项段（重要意义）+通知事项段（学习要求）+通知事项段（落实要求）+通知事项段（监督检查）+通知事项段（宣贯落实）
标题=发文机关名称+关于贯彻落实《××》+通知
通知缘由段=文件发布情况句+文件意义句+目的句+引出下文句
通知事项段（重要意义）=事项标题+主题句+支撑句（文件意义）+支撑句（要求）
通知事项段（学习要求）=事项标题+支撑句（学习举措）
通知事项段（落实要求）=事项标题+支撑句（落实措施）
通知事项段（监督检查）=事项标题+支撑句（监督检查措施）
通知事项段（宣贯落实）=事项标题+支撑句（宣传落实措施）
```

### 第三步 ·【完善重要意义段】提示词

```
很好，接下来让我们逐个部分修改这份通知。首先，请补充完善第一点"充分认识《条例》的重要意义"。请对我提供的【意义价值】进行概括提炼，并将提炼出的要点充实完善到第一点中，保持标题不变，行文风格简洁，并让文件内容充实饱满。
#意义价值
```

## 通知类写作要点

1. 标题必须含发文机关全称或规范化简称 + 事由 + 文种
2. 部署类和贯彻类通篇使用指示性语气（"要""必须""不得""严格落实"）
3. 事项段之间逻辑不交叉，每项事项都能独立执行
4. 涉及数据、时限、责任人时用 `××` 占位
5. 结语段单列，用一句话强调落实要求，不要重复前文
