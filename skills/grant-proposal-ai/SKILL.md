# AI 辅助课题申请书写作（Grant Proposal with AI）

## 概述

本技能源自 263 页专著《做好课题申报：AI辅助申请书写作》的系统提炼，覆盖课题申报书全部组成部分的写作要领、40 个 AI 提示词模板（如 SRGCD、TMAQ 等结构化提示法）与分步工作流。适用于国家自科/社科基金及省部级课题申报。

## 使用方式

1. **判断用户需求层次**：
   - 申报书某一部分怎么写（立项依据、研究内容、关键科学问题、技术路线、创新点、可行性、研究基础、预期成果、经费预算、摘要）→ 到 `references/proposal-writing-guide.md` 定位对应章节的写作要领。
   - 要 AI 提示词 → 同文件收集了 40 个提示词模板（原文保留【】变量占位符，代码块形式），按申报书部分对应取用。提示词为原文引用、其余为提炼改写；原始资料见本技能 README 的「参考资料 / 灵感来源」。
   - 要整体流程 → 用文件中的分步工作流章节（从选题到成稿的全流程）。

2. **执行要点**：
   - 提示词中的变量（研究主题、学科方向、资助类别等）替换为用户具体信息后再发送；信息不足时先向用户询问，不要虚构研究基础。
   - 申报书的核心论证（立项依据、创新点）必须基于用户真实的研究积累与文献，AI 仅用于结构化、扩写、语言打磨；编造研究基础或成果属于学术不端。
   - AI 产出的文献引用须逐条核实真实性。

## 工作流速查

1. 明确资助类别与申报要求 → 2. 选题凝练（SRGCD 等选题提示词）→ 3. 逐部分起草（立项依据 → 研究内容/目标/关键问题 → 技术路线 → 创新点 → 可行性 → 研究基础 → 预期成果 → 预算 → 摘要）→ 4. AI 自查与润色（逻辑一致性、术语统一）→ 5. 人工审校与查重。

## 详细资料

- `references/proposal-writing-guide.md` — 完整提炼：整体框架脉络、各部分写作要领、40 个提示词模板、分步工作流、学术诚信与查重注意事项。

## 配套技能

- **`ai-research-methodology`** — 撰写"研究内容/技术路线"时若需梳理实验方案、数据方案、创新点挖掘，用其 `references/prompt-engineering-stem.md`（理工科）或 `prompt-engineering-humanities.md`（文科）中的实验设计、创新建模、实证分析模板。
- **`academic-deai-writing`** — 申报书中涉及语言润色、去 AI 味时使用；需要直接复制粘贴的提示词原文时，见仓库 `prompt-library/paper-writing/`（资料，非技能）。
