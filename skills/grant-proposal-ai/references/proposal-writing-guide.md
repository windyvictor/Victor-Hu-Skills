# 《做好课题申报：AI辅助申请书写作》阅读提炼与参考指南

> 来源：赵鑫、宋义平、郭泽德 著，《做好课题申报：AI辅助申请书写作》，人民邮电出版社，2024（全书263页，案例贯穿"短视频对国家形象的塑造及传播研究"）。
>
> 核心理念：**AI 是学术咨询顾问/助手/伙伴，不是"写手"**。通过"提问→回答→追问→再回答"循环获得启发，最终须由研究者判断、验证、把关，绝不可复制粘贴即用。

---

## 一、文档整体框架与目录脉络

本书采用**"倒金字塔"思路**：先把课题申请书拆解为若干要素，再逐章介绍如何用 AI 辅助每个要素的编写。各章主题如下：

| 章 | 主题 | 核心内容 |
|---|---|---|
| 序 | AI 与学术研究 | 界定 AI 角色（伙伴而非写手）、警惕"机器幻想"、培养"提问—追问"能力 |
| 01 | 课题申报概述 | 借助 AI 分析各级别课题申报公告；申请书与活页结构介绍 |
| 02 | AI 辅助寻找选题 | 综合性选题（SRGCD 模型+9 类选题类型）、学科选题、自拟选题（三级细化法/gap 法/类型学） |
| 03 | AI 辅助分析课题立项选题 | 单条分析立项选题；与课题指南推荐选题比较 |
| 04 | AI 辅助研究背景写作 | 整体性；分要素（政治/政策/理论/实践背景） |
| 05 | AI 辅助学术史梳理及研究动态 | 分关键词梳理；研究述评 |
| 06 | AI 辅助研究价值写作 | 整体性；分维度；投喂式（独到价值、相对已立同类项目新进展） |
| 07 | AI 辅助阐释研究对象 | 整体性；依据"五特性"阐释 |
| 08 | AI 辅助框架思路写作 | 初步了解内容框架；按研究思路；TMAQ 模型 |
| 09 | AI 辅助重点难点写作 | 整体性；基于 TMAQ |
| 10 | AI 辅助主要目标写作 | 依据特性；基于 TMAQ；学习型；分析型 |
| 11 | AI 辅助研究计划及其可行性 | 设计研究计划；提炼可行性（七维度） |
| 12 | AI 辅助其他部分写作 | 创新之处、预期成果、参考文献、研究团队、学术简历 |

**国家社科基金申请书/活页主体结构**：选题依据→研究内容（研究对象、框架思路、重点难点、主要目标、研究计划及可行性）→创新之处→预期成果→研究基础（学术简历、前期成果、承担项目、与已承担项目/博士论文关系）→参考文献。活页另含"研究基础"，限 7000 字且不得透露个人信息。

## 二、课题申报书各组成部分写作要领

1. **选题立意**：聚焦"重大理论和现实问题"，兼具时代性、问题导向、创新性。指南分综合性选题（只给范围须自拟题）与学科选题（可直接用或微调）；9 类创新类型：新情境/新理论/新理念/新区域/新方法/新模型/新学科/新技术 + 研究对象 + 研究问题，及"新对象 + 研究问题"型。
2. **立项依据**：研究背景 200–300 字、含政治/政策/理论/实践四要素；学术史须有"史"的脉络（首次、开始、转向、深入），忌"只综不述、有述无评"；研究价值须写"独到学术价值与应用价值，特别是相对已立同类项目新进展"。
3. **研究内容/目标/关键问题**：研究对象须清晰（忌混淆研究问题）；框架思路列提纲（做到+怎么做融合）；重点难点分开、各 2–3 条；主要目标 2–3 条，须明确、可操作、科学、可评估。
4. **研究方案与技术路线**：用 TMAQ（理论-方法-思路-问题）贯穿；研究计划分阶段、有具体时间节点；可行性从学术/技术/数据/时间/实践/团队/风险七维度挑 3–4 条。
5. **创新点**：从学术思想、学术观点、研究方法（及跨学科、新对象、新数据等）提炼，忌用"填补空白"。
6. **可行性分析**：依托真实研究基础与团队构成，不可空泛。
7. **研究基础与条件**：学术简历、前期成果（限 5 项代表性、与课题紧密相关）、承担项目、团队搭配；须真实准确。
8. **预期成果**：成果形式、使用去向、预期社会效益；形式不宜多填以免抬高结题难度。
9. **经费预算**：国家社科业务费/劳务费/设备费+间接费（约 40%），单位"万元"；教育部规划基金≤10 万、青年≤8 万。
10. **题目格式**：活页课题名称必填、不加副标题；题目不出现冒号、破折号、副标题，不超 40 汉字。

## 三、AI 如何辅助各部分写作（提示词模板原文）

> 以下模板均保留原书变量占位符【】。原书大量使用"###"作为"用户材料"与"提问"的分隔符。

### 3.1 课题申报概述——分析申报公告
适用于：第1章第一节。将公告相关内容粘贴进 ### 区，让 AI 提炼申报要点。

```
以下是从《2023年度国家社会科学基金项目申报公告》中截取的部分内容。
###
【此处粘贴申报公告里相应部分，如第一、二、三、七部分】
###
请帮我分析国家社会科学基金项目的要求，申请人在进行课题选题论证时需注意哪些要点？
```
（同类模板适用于教育部人文社科项目、省级社科项目，仅替换文件名与粘贴段落。）

### 3.2 寻找选题——SRGCD 模型（综合性选题整体性提问）
适用于：第2章第一节。SRGCD = 情境(Scene)-角色(Role)-目标(Goal)-条件(Condition)-调试(Debug)。

```
我是一名高校教师，已工作【填入工作年限】，职称为【填入职称】，目前【没有承担/正在主持】【某级别】课题，【参与/主持过教育部课题，课题围绕某主题展开】，我的专业是【填入相应的专业】，我的研究方向是【填入相应的方向】，我来自【大学/科研机构/其他机构】。你将扮演课题同行评议专家角色。目前，我正在准备申报【国家社会科学基金项目/教育部人文社会科学项目/某省社会科学规划项目】的【年度重点项目/年度一般项目/年度青年项目】，需要你的指导、协助和建议。课题申报指南中有综合性选题指南，我对其中的【指南中的具体条目】很感兴趣，但是，综合性选题只明确研究主题、范围和方向，申请人须立足选题要求，从不同学科领域、不同研究视角自拟题目进行申报，不得将选题直接作为申报题目。你能告诉我，结合我的专业、研究方向、研究基础等信息，我可以申报哪些具体的题目吗？
```

调试追问句型（用于让 AI 结合个人基础细化）：

```
我的研究方向为【研究方向】，我的研究兴趣为【研究兴趣】，我的研究基础是【研究基础越详细越好，包括课题和论文等】。你能再结合我的研究方向、研究兴趣、研究基础，以及【某级别项目】所要求的【具体要求】，把上述选题再次细化吗？
```

### 3.3 寻找选题——9 类选题类型提问句型
适用于：第2章第一节各型。核心套路是把"新 X + 研究对象 + 研究问题"告知 AI，并要求题目不加副标题、不出现冒号（：）和破折号（——）。

**新情境型：**
```
我是学【专业】的，我现在正申报【某级别课题】，想做跨学科研究，发现围绕【参考选题】在【学科领域】出现了一些新的情境，请根据这些新出现的情境，围绕【参考选题】，为我提供几个"新情境+研究对象+研究问题"型课题选题，要求题目中要有新出现的情境，还要有研究对象和研究问题，题目中不加副标题，也不加冒号，请只列出推荐的题目。
```

**新理论型：**
```
我是一位高校教师，我正在申报【某级别课题】，我想围绕以下推荐选题"【选题】"来确定自己的选题，请推荐一些能够解决上述问题的【专业领域】理论，并根据所推荐的理论，按照"新理论+研究对象+研究问题"型课题选题类型推荐几个选题，要求题目不加副标题，题目中不要有冒号（：）和破折号（——）。
```

**新理念/思想型：**
```
我是一位高校教师，我现在正申请【某级别课题】，有一个推荐选题是"【选题】"，但是不能用原题目进行申报，我想采用"新理念/思想+研究对象+研究问题"型课题选题类型，请帮我列几个与这个推荐选题有关的理念或思想，并在此基础上列几个可能的选题，要求题目中不带"："和"——"。
```

**新区域型（已知区域）：**
```
我现在正申请【某级别课题】，有一个推荐选题是"【选题】"，但是不能用原题目进行申报，我想采用"新区域+研究对象+研究问题"型课题选题类型。我是【某区域】【某高校】的教师，我对【某区域】比较了解，如果我选择【某区域】作为这个选题的区域，结合【某区域】在【选题指定的研究领域】方面产生的一些具体问题，请帮我列几个课题选题。题目中不要出现"："和"——"。
```

**新对象型：**
```
我是一位高校教师，我现在正申请【某级别课题】，将【某情境】作为情境，将【某问题】作为研究问题，会出现哪些【新生事物】？结合以上【新生事物】，采用"新对象+研究问题"型课题选题类型，围绕"【推荐选题】"，提供几个课题题目，要求题目中不带"："和"——"。
```

**新模型/新方法/新学科/新技术型**（小结模板同构，仅替换"新X"）：分别让 AI"列几个能解决既定问题的较新颖的【模型/方法/学科/技术】"，再"按'新X+研究对象+研究问题'型列题目，题目不加副标题、不带冒号破折号"。注意：AI 常产生"机器幻想"（如杜撰学科名），须逐条验证。

### 3.4 寻找选题——学科选题与自拟选题
适用于：第2章第二节、第三节。

学科选题整体性分析（直接输入选题条目让 AI 析要素）：
```
有这么一个选题："共同富裕视域下的乡村工业创新发展研究"，请帮我分析一下这个选题的各个要素。
```

更换研究问题后生成题目（小结句型）：
```
有这么一个问题：【问题】。为了解决这个问题，我申报了【某级别课题】，请你为我列出这个项目的题目，题目中不要出现"："和"——"。
```

自拟选题——三级选题细化法/研究 gap 确定法/研究选题类型学（将以下说明块与要求一并投喂 AI）：
```
"三级选题细化法"：给定任何研究对象，通过"限定词+研究维度"细化。第一级确定限定词，第二级第一次问题细化，第三级第二次问题细化。
"研究gap确定法"：研究问题须有明确 gap（理论与现实差距/政策与实践差距/原研究对比不同处）。
"研究选题类型学"：What 型（描述定义）/How 型（过程方法）/Why 型（推断解释）/Should 型（价值取向政策）。
###
其他要求：综合上述三种选题逻辑，给出9个具体选题建议，选题中不出现"："和"——"。可参考结构：新情境下知识协调的底层机理及优化模型研究 / 模因论视域下红色文化的互联网群体传播研究 ……
```

### 3.5 分析课题立项选题
适用于：第3章。把往年立项选题（及对应指南推荐选题）投喂 AI。

单条分析（基于要素）：
```
2022年国家社会科学基金立项名单里，民族学学科中有这样一个立项选题"【立项选题】"。假设你是课题评审专家，请你从评审专家的角度帮我分析一下这个选题的特色，包括研究视角、研究对象、研究问题、研究方法等方面。
```

与指南推荐选题比较（表格化）：
```
【立项选题】与申报公告课题指南中的推荐选题【推荐选题】。请帮忙从研究视角、研究对象、研究问题等方面比较一下这两个选题有什么区别，用一个表格列出这些区别。
```

### 3.6 研究背景写作
适用于：第4章。

整体性（先概写再限字数）：
```
我在申报2023年国家社会科学基金项目，我的选题是"【选题】"，我在写课题申报书，请你为我写出关于这个选题的研究背景。
```

分要素（政治/政策/理论/实践背景逐一提问，再整合）：
```
我在申报国家社会科学基金项目，我的选题是"【选题】"，我在写课题申报书，请你为我写出关于这个选题的【政治背景/政策背景/理论背景/实践背景】，包括【相应要素】等因素，写一段完整的话。
```
整合提示：
```
将以上生成的政治背景、政策背景、理论背景和实践背景整合成一段300字左右关于该选题的研究背景的文字。
```

### 3.7 学术史梳理及研究动态写作
适用于：第5章。注意：AI 不是搜索引擎，直接生成文献多为"幻想"，须用"青泥学术"等平台生成初稿后投喂 AI 做梳理；国外部分可结合联网 AI。

分关键词梳理（投喂学术史资料 + 要求写综述）：
```
以下是关于【关键词】的学术史资料。
###
【粘贴青泥学术等平台生成的学术史/文献脉络】
###
请你帮我撰写一篇关于【关键词】的学术史梳理，字数在800字左右。
```

研究述评（投喂已有研究工作总结，让 AI 找不足）：
```
已有研究成果在【研究对象】方面做了如下工作。
###
【粘贴已有研究工作的总结】
###
你认为已有研究有哪些不足？
```
提炼句式：
```
将每一条提炼成一句话，用"已有研究对……研究不足或研究较少"的表达方式。在回答的开头采用"已有研究从多个方面展开研究，取得了一定的成果，但还存在以下不足"模式。
```

### 3.8 研究价值写作
适用于：第6章。

学术价值分维度（提问句型）：
```
我在申报【课题种类】，我的选题为【题目】，会综合使用【所用理论，越具体越好】，将采用【研究方法，特别是较有新意的研究方法】等研究方法，【列出其他具有特色的地方，比如新的研究对象、新的研究问题、新的研究视角等】。请你帮我写出这个课题的学术价值，包括理论贡献、实证贡献、研究方法贡献、数据贡献、跨学科贡献、对话贡献、启示贡献等方面的学术价值，当然不一定全部列出来，请根据该课题的实际情况列出。
```

应用价值分维度（提问句型）：
```
我在申报【课题种类】，我的选题为【题目】，主要研究【研究内容，特别是具有特色的研究内容】。请你为我列出该课题的应用价值，包括实践指导、政策制定、经济效益、社会价值、实践创新、教育教学等方面的应用价值，当然不一定全部列出来，请根据该课题的实际情况列出。
```

独到价值（投喂式，先把"已有研究工作总结"投喂）：
```
关于【研究对象】的相关研究，学者们主要做了以下工作。
###
【粘贴已有研究工作总结】
###
请将我拟申报的课题"【选题】"与已有研究成果进行比较，列出该课题独到的学术价值。学术价值包括【理论贡献、实证贡献、研究方法贡献、数据贡献、跨学科贡献、对话贡献、启示贡献】等方面。请综合这些方面，但不要再出现上述词汇，写出该课题独到的学术价值，控制在300字左右。
```
（应用价值的独到性同理，投喂后要求"列出独到的应用价值，不再出现实践指导等词汇，300字左右"。）

相对已立同类项目新进展（登录国家社科基金项目数据库查同年立项，投喂后比较）：
```
以下是已立项的关于【选题】的国家社科基金选题：
1. 【立项选题1】 2. 【立项选题2】 ……
请将我的课题选题"【选题】"与上述已立项课题选题进行比较，列出我这个选题相对于国家社科基金已立同类项目的新进展。
```

### 3.9 阐释研究对象
适用于：第7章。研究对象五特性：重要性、可研究性、可操作性、可靠性、有效性。

依据特性整体性（提问句型）：
```
我在申报【某级别课题】，我的课题选题为"【课题题目】"，研究对象是【研究对象】，请从重要性、可研究性、可操作性、可靠性、有效性五个方面对这个研究对象进行阐释。
```

分特性细化（各型句型）：
```
我在申报【某级别课题】，我的课题选题为"【课题题目】"，研究对象是【研究对象】，请从【对研究意义和价值的影响方面】分析这个研究对象的重要性，将上述内容改写成一段【字数要求】的话。
```
（其余四型同构，分别替换：可研究性→"研究的可行性和数据的可获取性两个方面"；可操作性→"控制变量、操作方法、实验设计等方面"；可靠性→"稳定性、内部一致性、外部一致性、可重复性等方面"；有效性→"目标明确性、解决问题、预测准确性、实际应用等方面"。最后将五段投喂 AI 整合成一段 300 字左右的阐释。）

### 3.10 框架思路写作（TMAQ 模型）
适用于：第8章。TMAQ = Theory(理论)-Method(方法)-Approach(思路)-Question(问题)。

按研究思路列框架（句型）：
```
我在申报【某级别课题】，我的课题选题为【课题选题】，我想采用【研究思路类型】的研究思路进行研究，根据这个思路，请你为我列出这个课题的内容框架。
```

TMAQ 模型（核心句型，建议全文保留）：
```
我在申报【某级别课题】，我的课题选题为【课题名称】，我采用的理论是【研究理论】，运用【研究方法】，采用【研究思路】进行研究。根据这个思路，我主要想研究【研究问题】等问题。假设你是经验丰富的课题评审专家，请你为我列出这个课题的内容框架，【提出要求，如"正文细化到三级标题""不要列引言/结论/参考文献"】。
```

若尚未想清理论方法，可让 AI 匹配（投喂 TMAQ 与 gap 定义块后）：
```
我在申报课题，我的课题选题为"【选题】"，假设你是经验丰富的课题评审专家，请为该选题匹配最合适的研究理论，在此基础上根据TMAQ模型，依据选择的研究思路，帮我写出这个课题的主要研究内容，要求采用描述的形式，不要列出框架目录，采用"该课题主要从以下几个方面展开研究。第一，第二……"的形式，包括四到六条主要研究内容。
```

### 3.11 重点难点写作
适用于：第9章。重点难点须分开、各 2–3 条；难点最好附解决策略。

基于 TMAQ 合并式（提问句型）：
```
我在申报【某级别课题】，我的课题选题为【课题题目】，我采用的理论是【研究理论】，运用【研究方法】，采用【研究思路类型】进行研究。根据这个思路，我主要想研究【研究问题】等问题。作为课题申报指导专家，你认为这个选题的研究重点和难点分别有哪些？请将研究重点和研究难点分别写出来，分别采用"第一，第二，第三"的形式表述。研究重点围绕研究内容进行提炼，写两三点；研究难点要和解决难点的策略一起写出来，写1~2点。研究重点和研究难点两部分的总字数不超过400字。
```

### 3.12 主要目标写作
适用于：第10章。目标须明确、可操作、科学、可评估，2–3 条。

基于 TMAQ（提问句型）：
```
我采用的理论是【研究理论】，运用【研究方法】，采用【研究思路】进行研究。根据这个思路，我主要想研究【研究问题】等问题。作为课题申报指导专家，请你针对主要目标应该具有明确性、可操作性、科学性和可评估性这一要求，为该课题列出切实可行的主要目标，写2~3条，总字数不超过300字。
```

学习型提问（投喂优秀范本让 AI 仿写）：
```
针对课题选题"【范本选题】"，课题负责人提出以下主要目标：（1）【目标1】；（2）【目标2】；（3）【目标3】。假如你是课题评审专家，请分析上述主要目标写得怎么样。/ 学习上述主要目标的写法，请为课题"【我的选题】"写出切实可行的主要目标……（仿照范本句式，文字不超过150字）。
```

分析型提问（投喂"研究价值+研究内容"，从学术目标/应用目标两层列）：
```
我在申报【课题】，我的选题为"【选题】"。该课题的研究价值体现在学术价值和应用价值两个方面：【投喂学术价值】【投喂应用价值】。该课题主要研究的内容如下：【投喂研究内容】。假设你是经验丰富的课题指导专家，请你结合课题的研究价值和研究的主要内容进行分析，写出该课题的学术目标（两三条，不超150字）；再写出应用目标（两三条，不超150字）。
```

### 3.13 研究计划及其可行性写作
适用于：第11章。

研究时限与步骤（先问年限，再列阶段，再给具体时间节点，可要表格）：
```
我在申报【课题】，我的选题为"【选题】"，我采用的理论是【理论】，运用【方法】，采用【思路】。我主要想研究【问题】。我计划用【N】年时间完成（从【起】至【止】）。假设你是经验丰富的课题申报指导专家，请你为我列出这个课题的研究步骤和时间安排，将每一步列出时间节点，采用"某年某月至某年某月"的形式。
```

可行性（提问句型，须如实告知团队基础）：
```
我在申报【某级别课题】，我的课题选题为"【课题题目】"，借助【研究理论】，运用【研究方法】，采用【研究思路类型】进行研究。根据这个思路，我主要想研究【研究问题】。研究的可行性包括学术可行性、技术可行性、数据可行性、时间可行性、实践可行性、研究团队可行性、风险可行性等。目前我的情况如下：具备【研究基础】，做了【前期准备】，课题组成员具有【课题组学历分布和研究专长】，请你为课题【课题题目】做一份全面且合理的研究可行性分析，上面提到的研究可行性的七个方面不必面面俱到，按照重要程度挑选3~4条即可。总字数控制在300字以内。
```

## 四、AI 辅助申报的工作流程（分步骤）

1. **研读公告**：用 3.1 模板投喂国家社科/教育部/省级申报公告，提取指导思想、选题方向、资助额度、时限、学科范围。
2. **寻找选题**：SRGCD 模型（3.2）做综合性选题提问；按 9 类选题类型（3.3）深挖"新 X+研究对象+研究问题"；学科选题析要素（3.4）；自拟选题用三级细化法/gap 法/类型学。题目须无冒号、破折号、副标题。
3. **分析立项**：把往年立项选题与指南推荐选题投喂 AI（3.5），比较异同、找评审标准与热点，避免重复申报。
4. **撰写立项依据**：研究背景（3.6，四要素）→ 学术史梳理与述评（3.7，先平台生成再投喂）→ 研究价值（3.8，整体→分维度→投喂式独到价值→相对已立同类项目新进展）。
5. **界定研究对象**：五特性法（3.9）阐释，200–300 字。
6. **搭建框架思路**：先按研究思路（3.10），再用 TMAQ 模型列框架（细化到三级标题或描述式），融合"做什么+怎么做"。
7. **提炼重点难点与目标**：TMAQ 合并式写重点难点（3.11）；特性法/TMAQ/学习型/分析型写主要目标（3.12），2–3 条。
8. **制定计划与可行性**：分阶段排时间节点（可表格），七维度可行性挑 3–4 条（3.13）。
9. **补齐其余板块**：创新之处、预期成果、参考文献、研究团队、学术简历（3.14）。
10. **人工核验与提升**：逐条验证 AI 输出（文献/理论/政策/数据真实性）；结合前期基础修改凝练；查重与诚信自查；定稿前逐字研读当年最新空表填写说明。

## 五、注意事项与常见问题

1. **学术诚信底线**：AI 是"辅助"而非"代写"，反对只提问、复制粘贴。最终申请书须体现申请人自身学术判断与积累。
2. **AI 的"机器幻想"**：AI 会"一本正经地胡说八道"——杜撰文献、虚构政策文件、编造学科名（如"普惠金融学"实为 AI 生成）。**凡 AI 提供的文献、文件、政策、数据、理论，必须逐条核实**，不可拿来即用；联网 AI 也须验证。
3. **查重与雷同风险**：直接复制 AI 文本易同质化、与他人雷同。应把 AI 输出作启发，经个人重写、融入独到见解。
4. **题目格式硬伤**：国社科题目一般**不加副标题、不出现冒号（：）和破折号（——）**、不超 40 汉字。须在提问中强制约束并反复调试（原书多次出现 AI"不听话"给出带冒号题目）。
5. **活页匿名与限字数**：活页限 7000 字、不得透露个人信息（否则取消参评）；课题名称必填；前期成果只填成果名/形式/排序/是否核心，不填姓名单位刊物。
6. **前期基础必须真实**：研究基础（学术简历、前期成果≤5 项、承担项目）须真实准确、与课题紧密关联；不可用外单位高职称者"装门面"；成员须征得本人同意。
7. **创新不可夸大**：忌用"填补空白"；述评须客观，不否定已有研究贡献以彰显自己。
8. **限项与时间规则**：国家社科同年度限项申报；基础研究 3–5 年、应用对策 2–3 年；经费单位"万元"、间接费约 40%；预期成果形式不宜多填以免抬高结题难度。
9. **工具通用性**：书中以 ChatGPT 为例，但 Bard、Claude、文心一言、讯飞星火等底层逻辑相通，相同提示方式均适用；建议多工具"优中选优"。
10. **能力前提**：AI 不能替代学术训练。对 AI 推荐的新理论/方法/模型，申请人须系统学习、真正掌握，否则评审一眼看穿、立项后也无法开展（原书警示"作茧自缚"）。
