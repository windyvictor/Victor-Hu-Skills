# 卡片模板集（card templates）

> 使用方法：按卡片性质复制对应模板填写。字段约定见 SKILL.md；更完整的规则见 `references/zettelkasten-core.md` 与 `references/community-insights.md`。
>
> **引文规则（适用于所有含引文的卡片）**：卡片正文的主体必须是**自己的话（复述）**。
> 确需保留原句时，必须同时满足三条：①**加引号**、②**注明出处与页码**、③**附自己的注解**。
> **禁止无出处的大段摘抄**——卡片盒的价值在于"加工后的知识"，而非"搬运的原文"（这也正是
> 它与剪藏工具的根本区别）。

## 1. 文献笔记卡（读书时记）

```markdown
# 文献卡｜<一句话主题>
- 来源：<书名/文章>，作者，页码/章节
- 复述：<用自己话写的完整句子，禁止照抄原文。这段作者想说什么？>
- 评论：<我同意/质疑/联想了什么？和我的哪个问题有关？>
- 原文锚点（可选）：<关键引文，≤2 行，**必须注明页码/位置**（如「p.42」「第 3 章」）；仅在"复述无法传达原味"时才用>
标签：#来源/<作者或主题>
相关卡片：[[…]]
```

## 2. 永久笔记卡（自足的知识单元）

```markdown
# <标题：以后我会在什么情况下偶然遇到它的措辞>
- 主张：<这个想法本身，完整句子，不看原文也能懂，≤300 字>
- 为什么：<理由/机制/例子，自己写>
- 来源：<依据的文献卡链接或"原创想法 YYYY-MM-DD">
标签：#性质关键词 + #场景标签
相关卡片：[[…]]（≥1 条；若与某卡矛盾，写明"与 [[…]] 矛盾"）
```

## 3. 概念卡

```markdown
# 概念卡｜<概念名>
- 定义：<这个概念是什么，一句话>
- 不是什么：<常见误解/边界>
- 例子：<1-2 个>
- 出处：<来源>
标签：#概念卡 #<主题>
相关：[[…]]
```

## 4. 观点卡

```markdown
# 观点卡｜<论断一句话>
- 主张：<谁、在什么论证下、得出什么论断>
- 论据：<支撑的理由链>
- 我的立场：□同意 □质疑 □存疑——因为
标签：#观点卡 #<主题>
相关：[[…]]
```

## 5. 方法卡 / 行动卡

```markdown
# 方法卡｜<解决什么问题>
- 适用场景：<什么时候用>
- 步骤：1. … 2. … 3. …
- 失效条件：<什么情况下不适用>
- 出处：<来源>
标签：#方法卡 #<场景>
相关：[[…]]
```

## 6. 案例卡

```markdown
# 案例卡｜<具体例子：标题必须自带情境，防止"看到标题想不起内容">
- 事件：<什么人/事，发生了什么>
- 说明什么：<印证/反驳了哪张概念卡或观点卡>
标签：#案例卡 #<主题>
相关：[[…]]
```

## 7. 金句卡

```markdown
# 金句卡｜<金句核心>
- 原句：<引文 + 出处页码>
- 为什么打动我：<我的注解——没有注解的金句=没加工的收藏>
标签：#金句卡 #<主题>
相关：[[…]]
```

## 8. 索引页 / 入口笔记（主题集群成型后建）

```markdown
# 索引｜<主题名>
> 这是入口页，不是分类目录。用一段话综述这个主题下卡片的整体图景与分歧点。
- 核心线索 1：[[卡A]] → [[卡B]] → [[卡C]]（递进关系：…）
- 核心线索 2：[[卡D]] 与 [[卡E]]（对立观点：…）
- 未决问题：<这个集群还没想清楚什么？下一步读什么能补？>
```

## 9. 读书工作流便签（把阅读接进卡片盒）

```markdown
# 《书名》阅读卡片化清单
- 检视层产出 → 结构件（目录速写、一句话概括）
- 文献笔记 × N → 逐张转永久卡或合并进既有卡
- 辩证笔记（我的质疑/共鸣）→ 延展笔记（原创卡）
- 全书处理完 → 删除/归档闪念；为本书若有 ≥5 张卡，考虑建主题索引页
```
