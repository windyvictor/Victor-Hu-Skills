# zettelkasten-notes

> **卡片盒笔记法**（Zettelkasten）—— 卡片盒不是仓库，是生产线。

## 一句话定位

解决「记了很多笔记却写不出东西」：把笔记从**仓库**改造成**生产线**。

## 核心闭环

**写**（用自己的话写独立可复用的卡片）→ **连**（新旧卡片连接，知识成网络）
→ **长**（主题卡片足够多、连接足够密时，文章自然"长"出来）。

卢曼 30 年写约 9 万张卡片，出版 58 本专著 + 数百篇论文，成本为零 ——
不靠意志力硬撑，靠系统。

## 三条铁律（违反任意一条，系统即失效）

1. **用自己的话复述**，不摘抄。摘抄 = 去语境化的信息搬运。
2. 每张卡片**只写一个想法**，独立可复用。
3. 新卡片必须**与已有卡片建立连接**，否则知识不成网络。

## 何时触发

记读书笔记、做文献笔记、建立个人知识库、整理碎片想法、「记了很多笔记却写不出东西」、
把阅读收获转成卡片、为写作 / 论文积累素材，或问笔记该记什么 / 怎么分类 / 怎么连接 /
怎么回顾。触发词：卡片盒笔记法、卡片笔记、卢曼、文献笔记、永久笔记、闪念笔记、
知识管理、双链笔记。
