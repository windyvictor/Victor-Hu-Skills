# 学术论文写作提示词库（Academic Paper Prompts Library）

## 概述

本技能整合了 40 套论文写作 AI 提示词方案与 30 条英文写作高级指令（网络流传汇编），按论文写作环节组织，提示词模板均原文保留（含【XX】等变量占位符），可直接套用。

## 来源与引用声明（重要）

本技能的每个方案均由**两部分构成**，请注意区分：

| 部分 | 性质 | 说明 |
|---|---|---|
| **方法要点 / 适用环节 / 使用要点** | **提炼改写** | 由原方案重新组织的方法骨架，非原文照搬 |
| **提示词模板**（代码块内） | **原文保留引用** | 为保持可直接套用的功能性，按原文保留，未作改写 |

关于「提示词模板原文保留」的说明：

1. **为什么保留原文**：提示词是**功能性文本**——改写成"自己的话"会使其失去可直接复制使用的价值。因此这里采取「原文引用 + 明确标注来源」的方式，而非改写。
2. **来源状况**：原始素材为网络流传的 PDF 汇编（《40 套 AI 提示词》《顶刊〈Nature〉推荐的 30 个高级 GPT 指令》等），**原始汇编未标注作者与授权信息，版权归属不明**。本仓库对其来源的标注为**据实记录、不主张任何权利**。
3. **使用边界**：本技能仅供**个人学习与研究参考**。如您是原始作者或权利人并希望调整、署名或移除相关内容，请通过仓库 Issue 联系，我们将**立即响应处理（署名 / 修改 / 删除）**。
4. **建议**：若您所在机构对第三方素材使用有严格规定，建议以各方案的「方法要点」为骨架，**自行重写**提示词模板后再使用——这也是本技能推荐的使用姿势。

## 工作原则

1. **选模板 → 替换变量 → 分步执行**：不要一次把全文扔给 AI；按环节选用模板，替换【XX】占位符后逐节推进。
2. **迭代优于一次生成**：润色/降 AIGC 类任务多轮迭代（每轮针对一个维度），效果显著好于单轮。
3. **事实核验**：文献综述、引用类产出必须逐条核实文献真实性与原文内容，AI 幻觉在此环节最常见。
4. **学术诚信**：降 AIGC/AI 味技巧仅用于改进表达质量，不得用于掩盖实质性的 AI 代写；使用须遵守所在机构与期刊的披露要求。

## 配套技能

本技能聚焦"论文文本"本身（写作、润色、降重、降 AIGC、查重、答辩）。

- **`ai-research-methodology`** — 论文之外的研究环节：工具选型、方法论、理工科/文科提示词工程实战手册（数据预处理、实验设计、AI Code 构建/改进 Baseline、实证分析、文献计量与 PRISMA）、投稿与返修回复模板。
- **`grant-proposal-ai`** — 课题/基金申请书写作（立项依据、研究内容、技术路线、创新点、经费预算）。
