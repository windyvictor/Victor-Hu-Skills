## 一、苏格拉底提问法的原理

苏格拉底式对话不是"问倒对方"，而是通过系统的追问暴露**未经检验的假设**，让理解从"听懂了"升级为"能论证"。"我唯一知道的是我一无所知"（《申辩篇》）——阅读者的起点同样是：先承认自己没读懂，再用追问逼近理解。

阅读中提问的三个层次：
1. **对文本提问**（Q1/Q2 层）：这段在说什么？关键词是什么？作者为什么这样排列章节？
2. **对论证提问**（Q3 层）：前提是什么？论据充分吗？有没有反例？
3. **对自己提问**（Q4 层）：这改变了我什么？我原本错在哪？我该做什么？

**判据**：一次合格的苏格拉底式阅读，至少应在每个阶段留下"已回答的问题清单 + 尚未回答的问题清单"。

## 二、诠释学四问（刘澜《学习之美》，读任何文本/事件的通用问法）

1. 文本究竟说了什么？（忠实理解）
2. 文本想要说什么？（意图还原）
3. 文本可以说什么？（开放诠释：还能读出什么别的可能）
4. 文本应该说什么？（批判立场：我认为它该怎么说）

与艾德勒四问的咬合：四问 1/2 ≈ 诠释学问 1/2；四问 3 ≈ 问 3/4 的混合；四问 4 ≈ 问 4。**诠释学问 3 是艾德勒框架里最容易被跳过的一环**——主动读出文本没有明说的含义。

## 三、精读一本书：建立三个联系（刘澜）

精读的成果不是复述，而是三个联系的建立：
1. **联系自己的经验**：这段内容印证/反驳了我哪段经历？
2. **联系已有的知识**：它跟我读过的其他书/已有卡片是什么关系（支持、矛盾、延伸）？
3. **联系要解决的问题**：它能用在我的哪个具体任务上？怎么用？

## 四、费曼检验（读后自测）

用自己的话、向一个外行、以最简单的方式解释这个概念，直到不用行话也能讲通。讲不通的地方 = 没读懂的地方。
常见坑（来自 BetterRead《费曼学习法三大坑》）：
- 背定义冒充理解 → 检验标准是"能举例 + 能类比 + 能说出它不适用的情况"
- 只讲结论不讲过程 → 必须能重走作者的推理路径
- 一次讲完不复盘 → 讲完回头对照原文找偏差

## 五、强力研读法（万维钢，好书写两遍）

- 态度：追求深度与效率，像小偷一样彻底挖掘书的价值
- 好书读两遍：第一遍通读陷进去；第二遍跳出来做笔记、批判性思考
- 读书笔记四要素：**每一章的逻辑脉络、书中的亮点和故事、个人看法与心得、与之前读过的书的联系**
- 强度：高度集中但不贪长；速度：不追求快

## 六、海绵阅读法：十大痛点与四层次笔记（李小墨）

**十大痛点**（用于诊断用户阅读问题）：读得慢 / 忘得快 / 输出吃力 / 笔记低效 / 不会独立思考 / 读不进去 / 无法专注 / 学不会应用 / 不成体系 / 无法坚持。

**四层次读书笔记**（由浅入深，明确产出物）：
| 层次 | 产出 | 作用 |
|---|---|---|
| 1 局部碎片化 | 万能笔记模板九要素（阅读动机/核心概念/金句/情节/疑问/联想/行动灵感/金句摘抄/任何触动） | 快速提炼重点 |
| 2 全局概览 | 一张思维导图 | 整体吸收全书的骨架 |
| 3 结构内化 | 一篇读书文章 | 深度内化，结构化整理 |
| 4 体系化 | 书或课程 | 跨书知识体系吸收 |

**检验读书笔记价值的问题**：读这本书和没读这本书，对我来说有什么区别？（知识边界/认知更新/做事方法/心结……）

## 七、阅读专业书五步骤（得到大脑笔记）

1. **明确动机**：我有一个什么问题，想知道怎么解决
2. **找到解答**：理解并整理答案，动笔写自己的理解（促进迁移）
3. **迁移追问**：这套方法还能解决什么问题？不能解决什么？
4. **弱点弥补**：方法失效的场景如何补救？
5. **提取元经验**：从论证/证明过程中能提取出什么通用经验？

## 八、记忆转化机制（支撑"为什么必须动笔/复述"）

- 瞬时记忆→短时记忆：主动筛选标注 + 分类组块化（米勒 7±2 法则）
- 短时记忆→长时记忆：**精细复述优于机械重复**——结合已有知识网络、融入个人理解的复述才有效；保持性复述（原样复现）效果有限
- 遵循遗忘曲线安排重复；对抗"读完就忘"的根本办法是输出（写作/卡片/讲解）

## 九、刻意练习四要素（把阅读本身练成能力）

1. 定义明确的目标（这次阅读要回答什么问题）
2. 练习时极度专注
3. 能获得有效的反馈（费曼检验/输出/他人追问）
4. 始终在拉伸区（略高于当前理解水平的书才是好书）

## Checklist：一次苏格拉底式阅读的自查

- [ ] 开始前写下"我带着什么问题来读"（专业书五步之第 1 步）
- [ ] 每个阶段留下已答/未答问题清单
- [ ] 至少用一次诠释学问 3（读出文本没明说的含义）
- [ ] 完成三个联系（经验/知识/问题）
- [ ] 通过费曼检验：不用行话能讲通核心概念
- [ ] 输出了四要素读书笔记（脉络/亮点/心得/联系）
