# 改后自检（诊断式）

## 为什么必须"只诊断不重写"

修改完成后，不建议让模型再"润色一次"——**越润色越像 AI**。
有效的做法是最后只让模型做诊断，输出问题清单，由人工或按条目定向修。

---

## 自检提示词

```text
请作为一名严格的学术编辑检查下面文本。

这一次不要直接重写全文。

请寻找仍然存在的模板化 AI 写作特征，包括：

过度工整的段落结构；

没有信息增量的转折句；

空泛的总结；

高频套话；

连续出现的相似句式；

过度使用"不仅……而且……"；

过度使用"不是……而是……"；

没有证据支撑的价值判断；

用形容词代替数据；

背景解释过多而关键技术解释不足；

Results 中混入过度解释；

Discussion 中重复 Results；

创新点只有评价，没有具体差异；

把相关性写成因果性；

结论强度超过证据强度。

对于发现的问题，请按照：

【原句】

【问题】

【建议修改】

的方式给出。

只标记真正影响科研表达的问题。

不要为了完成任务而强行挑错。

如果原句本身自然、准确，没有必要修改，请保留。
```

## AI 味特征速查清单

模型改写后逐项自查，命中任意一条即为未清理干净：

| # | 特征 | 典型表现 |
|---|---|---|
| 1 | 段落结构过度工整 | 每段都是"总—分—总"，长度接近，结尾都有一句总结 |
| 2 | 无信息增量的转折 | 然而 / 值得注意的是 / 需要指出的是 后接的是已知内容 |
| 3 | 高频套话 | 众所周知、不难发现、显而易见、具有重要意义、提供新视角、奠定基础、具有广阔应用前景 |
| 4 | 机械转折 | 不是……而是……、不仅……而且……、与其说……不如说…… |
| 5 | 抽象评价代替事实 | "性能显著提升" 而非 "准确率由 81.2% 提高至 86.7%" |
| 6 | 篇幅错配 | 背景常识占 70%，方法设计/参数选择只占几行 |
| 7 | 章节越界 | Results 里做解释，Discussion 里复述数据 |
| 8 | 创新点无信息 | 只有"创新的、高效的、突破性的"，说不出改变了哪一步 |
| 9 | 相关性写成因果性 | A 与 B 同时变化被写成 A 导致 B |
| 10 | 结论强度超过证据强度 | 机制未验证却用"证明""表明因果" |
| 11 | 段末自动总结 | 每段最后一句都是对前文的同义复述 |
| 12 | 术语堆砌 | 为显专业制造复合标签、生造概念 |

## 处置原则

- 命中 1–4：直接删除或改写为具体事实。
- 命中 5：替换为数据、差异、机制、条件。
- 命中 6：重新分配篇幅，压缩常识、展开关键步骤。
- 命中 7：按章节职责归位。
- 命中 8：改用"已有方法怎么做 → 改变了哪一步 → 解决了什么限制 → 实验证明了什么"四问重构。
- 命中 9–10：降回到 suggests / may / is consistent with / 可能 / 提示 等符合证据强度的表述。
- 命中 11–12：删除。
