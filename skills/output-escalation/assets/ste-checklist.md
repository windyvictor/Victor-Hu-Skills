# ASD-STE100 单页自查清单

**用法**：写完一段技术文本后，从上到下过一遍。带 ⚙ 的条目可以交给
`scripts/check_ste_compliance.py` 自动查；其余必须人工判断。

---

## 0. 写前（60 秒）

- [ ] 定档：需要**完整 STE**（安全规程 / 手册 / SOP / 要翻译）还是**80% 版**（一般说明）？分档见 `references/rung-1-controlled-writing.md`
- [ ] 定类型：这段是**程序性**（给指令）还是**描述性**（给信息）？两者的句长上限和语态规则不同
- [ ] 口径统一：全文对同一物件用同一个名词；对同一动作、同一类步骤用同一种句式（Rule 9.4）
- [ ] 有项目术语表吗？有就先读一遍，别自造词

## 1. 词（Rule 1.1–1.14）

- [ ] ⚙ 每个词要么在受控词典里（核准词），要么是技术名词/技术动词。查 `references/ste-dictionary.md`
- [ ] ⚙ 核准词只按**它被核准的那个词性**用（`CHECK (n)` 可以，`check (v)` 不行）
- [ ] 核准词只按**它被核准的那个含义**用（`see` 只表示"用眼看到"；`above` 只表物理位置，不表限值）
- [ ] 技术名词不当动词用（`Oil the surfaces.` → `Apply oil to the surfaces.`）
- [ ] 技术动词不当名词用（但**过去分词可作形容词**：`the reamed hole`）
- [ ] 技术名词 ≤ **3 词**；同一物件全文不换名
- [ ] ⚙ 用美式拼写（`colour` → `color`，`fibre` → `fiber`）；引文里的英式拼写**保留原样**

## 2. 句子结构（Rule 2、3、4）

- [ ] ⚙ multi-word noun ≤ **3 词**；超了就写全 + 缩短式或加连字符（连字符词算 1 词）
- [ ] ⚙ **没有完成时**（`has adjusted` ✗）、**没有进行时**（`is opening` ✗）——只用不定式、祈使式、一般现在、一般过去、一般将来、过去分词作形容词
- [ ] ⚙ **没有助动词被动**：`can be adjusted` / `must be removed` / `is to be installed` / `will be done` 一律改写
- [ ] ⚙ 用主动语态。被动只在**描述性写作且 agent 未知**时才可留；有 `by` 就是在告诉你 agent 已知
- [ ] ⚙ `-ing` 只作技术名词或用技术名词中的修饰语；不当作动词、形容词、动名词短语
- [ ] ⚙ 不用短语动词（`put out` → `extinguish`，`give off` → `release`）
- [ ] ⚙ **不省略**名词、动词、主语、冠词；**不用缩略式**（`don't` / `isn't`）
- [ ] 适用处补冠词或指示形容词；**但**一般性陈述/概念前不加冠词，专有名词（后接字母数字标识）前不加 the
- [ ] ⚙ 竖排列表：引言行末尾加**冒号**；每项**大写开头**；完整句加句点、非完整句不加；**末项加句点**；项末**不加逗号或分号**；不嵌子列表
- [ ] ⚙ 相关句之间用连接词/连接短语缝合；key words 用过就不再换词（Rule 6.2）

## 3. 句长与段落（Rule 5、6）

- [ ] ⚙ 程序性单句 ≤ **20 词**（**WARNING / CAUTION 也算**）
- [ ] ⚙ 描述性单句 ≤ **25 词**；NOTE 单句 ≤ **25 词**
- [ ] 程序：一句一个指令（例外：动作**同时发生**）；用数字/字母标工作步骤
- [ ] ⚙ 程序：祈使式起句；**不加 must**（除非安全指令或重要条件）
- [ ] ⚙ 有前提条件时，**条件放句首 + 逗号 + 命令**，不写成"命令 + when 条件"
- [ ] ⚙ 每段**一个主题**、≤ **6 句**；主题句放段首第一句
- [ ] 自检：**把各段主题句依次抄下来，能不能当这篇的提纲用？** 能就合格（Rule 6.5 的原法）
- [ ] ⚙ NOTE 只给信息，不给指令、要求、限值；不用祈使式
- [ ] 自检：**不看 NOTE 通读一遍，还能正确完成吗？** 能才说明 NOTE 放对了（Rule 5.5 的原法）

## 4. 安全指令（Rule 7.1–7.3）

- [ ] ⚙ 级别词选对：人身伤害/死亡 → **WARNING**；物品损坏 → **CAUTION**；两者都有 → **WARNING**
- [ ] ⚙ 以清晰的**命令**或**条件**起句，不以说明、背景、抽象断言起句
- [ ] ⚙ 必须给出**解释**，并具名具体危害（injury / death / explosion / corrosion / damage / poisonous）
- [ ] 防伤害/防损坏的内容**不能写成 NOTE**
- [ ] 若用 danger / notice 等别的词或图形符号，内容仍须满足上面三条

## 5. 标点与计词（Rule 8）

- [ ] ⚙ **没有分号** `;`（拆成两个句子，书中只给这一个替代方案）
- [ ] 连字符只用于 5 类：名词前的复合形容词、两词分数/数词、字母或数字 + 名词、名词性动词（`heat-treat`）、前缀元音相接（`de-icing`）
- [ ] 括号只用于 7 类授权用途；括号内整段在宿主句中算 **1 词**，但括号内文本要**单独**按句长复核
- [ ] 竖排列表里的冒号 = 句号：冒号**前**、每一项**各自**都受 20/25 词限制
- [ ] 计词：数字 / 数字+单位 / 缩写 / 字母数字标识 / 引用文本 / 标题标语标签 / 专有名词，各算 **1 词**；连字符词算 **1 词**
- [ ] ⚙ 不用 `e.g.` / `i.e.` / `etc.`，改用 `for example` / `that is`

## 6. 收尾

- [ ] 通读一遍，问自己：**读者会不会重读任何一句？** 会就重写那句
- [ ] 改动过的地方，检查对全文其他部分有没有负面影响（Rule 9.1 明文要求）
- [ ] ⚙ 跑一遍机器检查：

```bash
python3 scripts/check_ste_compliance.py draft.md
python3 scripts/check_plain_language.py draft.md      # 中文或有中文混排时
```

- [ ] 机器报的每一条都看过了吗？**报出来的基本确实有问题；没报不等于没问题**（未核准词表是 244 条节选）

---

**最容易犯的五条（按实战频次）**

1. 用了未核准词（`ensure` → `make sure`；`utilize` → `use`；`perform` → `do`；`prior to` → `before`）
2. 写了 `can be / must be / will be + 过去分词` 的被动构造
3. 程序句超过 20 词却没拆
4. 同一物件换了名字（`main body` / `body` / `body assembly` 混用）
5. 条件写在了命令后面（`Set the switch when the light comes on.` → `When the light comes on, set the switch.`）
