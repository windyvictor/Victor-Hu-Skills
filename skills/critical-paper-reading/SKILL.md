# 批判性文献阅读

将「读得快、读得全、读得狠」合一：以三遍法控制阅读深度，以结构化框架提取要素，以批判性思维引擎主动质疑每一篇论文，最终产出可直接用于综述写作和研究选题的报告。

## 触发条件

满足以下任一条件即触发：

1. **学术文献输入**：论文链接命中学术平台域名（arXiv、IEEE Xplore、ACL Anthology、ACM DL、SpringerLink、ScienceDirect、PubMed、Semantic Scholar、bioRxiv、SSRN、CNKI、万方、维普、顶会官网、doi.org 等）；本地 PDF/Word/Markdown/TeX/ePub 学术文档；粘贴文本含 ≥2 项学术结构标记（Abstract / Keywords / Introduction / References / DOI / arXiv ID）。
2. **结构化阅读意图**：速读/精读/深读/批判性阅读；要素提取（研究问题、方法、创新点、数据集、实验结果、局限等）；多篇对比与综述；论文质量评估、可信度分析、复现可行性判断。
3. **学术延伸**：学位论文、技术报告、专利、标准的结构化阅读。

优先级：论文链接/文件 ＞ 学术文本片段 ＞ 意图描述。仅问概念术语（无文献输入）、纯翻译、非学术网页总结、改写润色降重 → 不触发。

## 阅读模式判定

根据用户意图与文献重要性选择模式（可主动询问，也可根据上下文默认）：

| 模式 | 适用 | 对应操作 | 达标标志 |
|---|---|---|---|
| L1 速读 | 判断相关性、快速分类 | 第一遍：标题/摘要/引言/标题层级/结论/参考文献扫描 + 5C 评估 | 能说出类型、贡献、是否值得再读 |
| L2 泛读 | 领域相关但非核心 | 第二遍：通读忽略证明细节 + 结构化提取 + 图表质疑 | 能向他人转述主旨与依据 |
| L3 批判精读 | 核心文献、评估、综述种子文献 | 第三遍：虚拟复现 + 批判引擎全清单 | 能复述结构、指出隐含假设与弱点 |
| 对比模式 | 多篇文献 | 每篇至少 L2，横向/纵向/方法论三维对比 | 产出对比矩阵与空白分析 |

**精力分配原则**：不是每篇论文都值得 L3。代表性/种子文献必须 L3；一般文献 L2；重复性、低相关文献 L1 即可。逐字逐句从头读到尾是阅读第一禁忌——永远先扫结构、再按需深入。

## 工作流

### Step 0：识别论文类型

| 类型 | 标识特征 | 分析重点 |
|---|---|---|
| 理工科 | 数学公式、实验方法、算法描述、数据集、baseline 对比 | 核心方法、数学原理、实验设置、消融实验 |
| 文科 | 理论框架、案例分析、政策讨论、论证结构 | 理论框架、论证结构、比较研究、实证方法 |

无法判定时默认理工科框架，并在报告注明。同时检测导出关键词：出现 Word/docx 或 PDF 字样 → 报告末尾追加生成对应格式文档（命名 `文献批判性阅读报告_〈标题或简称〉_〈YYYYMMDD〉`）；未检测到则仅输出 Markdown。

### Step 1：确认范围与获取全文

- 用户未说明研究方向时先问一句（例如"多模态情感分析"），以便评估文献与用户研究的关联度。
- **红线：严禁仅凭摘要作答。** 必须尽力获取全文（浏览器工具读论文页、PDF 工具读文件、read_file 读上传文档）。全文不可得时在报告中明确标注"仅基于摘要"，所有摘要未提及的细节标注"需阅读全文"，绝不编造。

### Step 2：三遍式阅读与结构化提取

**第一遍（L1，全局扫描）**——回答五个 C（Keshav 三遍法）：
1. Category：什么类型的论文？
2. Context：与哪些工作相关？用了什么理论基础？
3. Correctness：假设看起来成立吗？
4. Contributions：主要贡献是什么？
5. Clarity：写得清楚吗？

任一 C 的答案存疑，记入待批判清单。

**第二遍（L2，结构化提取）**——严格基于全文，对每篇提取（无法获取的标"未提及"）：

- 通用维度：标题、作者（第一作者+等）、年份、研究问题（1 句）、研究方法（2–3 句）、创新点（1–2 个）、局限性（优先引用原文 Limitations；无则标"论文未明确讨论"）、文献综述质量（广度/深度/批判性）。
- 理工科附加：核心方法（含模型/算法名）、数学原理（LaTeX）、实验设置（baseline、消融）、数据集（来源/规模/预处理）。
- 文科附加：理论框架、论证结构（论点-论据-逻辑性）、案例分析、比较研究、政策建议、实证研究（数据来源/分析方法/结果解释）。
- **图表专项质疑（区分粗制滥造与优秀工作的试金石）**：坐标轴标注合理吗？刻度是否被操纵让效果显得显著？有误差棒吗？样本量足以支撑结论吗？每个图表是否真的对应其声称的结论？
- **论证一致性核对**：Abstract / Introduction / Conclusion 三处对照 claim，检查是否一致、是否前后矛盾。

**第三遍（L3，批判精读，仅核心文献）**——虚拟复现 + 批判引擎：
- 设想自己是作者，用同样的假设重新实现该工作；对比虚拟实现与原文，识别隐藏假设、被遗漏的引用、实验或分析技术的潜在问题。
- 逐节"猜答案"：读到问题陈述先自己想解法，再看作者方案；读到结果先自己推结论，再看作者解读。
- **必须加载 `references/critical-checklists.md`**，逐项执行其中的质疑清单（10 项挑战清单、9 问清单、分维度质疑、反面信号诊断），把每一条命中的质疑写下来——这是报告批判性分析部分的素材来源。

### Step 3：批判性分析综合（核心交付）

将 Step 2 记录的质疑整理为四个层次：

1. **问题层**：问题定义清晰吗？简化/扩展形式是什么？问题真的重要吗？
2. **方法层**：假设合理且被明确陈述吗？方法与研究问题匹配吗？有无更简单/更新的替代方法？适用范围与限制是什么？
3. **证据层**：数据足以支撑假设吗？测量有效且可信吗？有无未考虑的替代解释？结果是否被夸大（弱相关说成强相关）？
4. **贡献层**：比已有工作好在哪？文章的精华在哪？如果我来解决这个问题，会怎么做？

然后做**研究空白识别**：读综述结尾的"未来方向"、读局限性章节、对比多篇找矛盾与不足 → 提炼可操作的研究机会。对每个空白按"选题意义四标准"（相关性、时间尺度、研究贡献、与现实需求距离）和"可控性五问"（问题清晰吗、有解吗、条件具备吗、时间够吗、伦理合规吗）评估值不值得追，并定位其类型：开拓性选题（资料少、风险高、可填补空白）还是推进性选题（资料多、创新难、需另辟蹊径）。质疑要有理有据，指向"未覆盖/未解决"而非轻易否定前人；若不确定改进建议是否有效，宁可不写。

**批判性阅读的立场要求**：二次文献阅读必须"探寻多元观点"——刻意寻找与自己初始判断相悖的文献并认真对待；发现自己的观点被驳倒时如实修正，被驳不倒时那个点就是站得住的批判结论。

**识别论文的研究视角**（用于对比与综述归纳）：理论视角（从某学科/学派切入）、思维视角（关系判断、分类框架）、批判视角（对新观点/新材料/新方法的选择）。同一问题下不同论文的视角差异，往往就是矛盾与空白的来源。

### Step 4：输出报告

**必须加载 `references/report-templates.md`**，按其中模板输出完整 Markdown 报告，包含：论文概览表、逐篇深度分析（含批判性分析）、综合对比矩阵（多篇时）、研究空白与机会、可直接使用的论文表述（如"与 [A] 不同，本文聚焦…"）、GB/T 7714-2015 参考文献列表。

用户要求笔记时，同时输出文献笔记（五要素：Article 出处 / Data 简介与结论 / Comments 批判与想法 / Why 为何读 / Summary ≤5 字方向）。

**综述场景补充**（多篇对比且用户目标是写综述时）：以"综述四问"组织每篇的归纳——①前人是否说过（避免重复研究）？②说了什么（观点异同、可否分类、时间与逻辑关系）？③怎么说的（研究方法本身也要综述——某类文献只用某几种方法时，正是方法创新的机会）？④何人、何时、何地说过（观点演化脉络）？综述结构按"三写法"选型：历史发展（纵式）、现状分析（横式，国际/国内对比）、取向预测（在纵横对比中给展望）。

## 质量控制红线

- 严禁仅凭摘要作答；全文不可得必须显式标注。
- 绝不编造：指标数值、实验细节、作者/年份/标题必须来自原文；未提及一律标注。
- 局限性优先引用原文 Limitations 章节；作者没写的不要替作者"合理化"。
- 指标不可比时（不同数据集/任务）明确标注"评估条件不同，不可直接对比"。
- 批判必须基于文本证据，引用原文页码或章节；不得为批判而批判，也不得因文章知名而放弃质疑。
- 所有引用使用 GB/T 7714-2015 顺序编码制。

## 失败处理

- 单篇无法访问/读取 → 注明原因，跳过并继续处理其余论文；全部失败 → 停止并请求用户提供可访问来源。
- 单篇提取维度不足 3 个 → 对比矩阵标注"信息不足"。
- 报告生成失败 → 先返回 Markdown，末尾附注失败原因。
