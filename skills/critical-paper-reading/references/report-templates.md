# 批判性文献阅读报告模板

本文件是 critical-paper-reading 技能的报告输出规范。默认输出完整 Markdown 文档；检测到 Word/PDF 导出关键词时按文末规范追加生成对应格式。

## 一、报告结构（Markdown 模板）

```markdown
# 文献批判性阅读报告

**研究主题**：[用户研究方向]
**阅读模式**：L1 速读 / L2 泛读 / L3 批判精读 / 对比模式
**信息完整度**：[全文分析 / 仅基于摘要（标注受限原因）]

## 一、论文概览

| 序号 | 标题 | 作者（第一） | 年份 | 平台/来源 | 论文类型 | 阅读深度 |
|---|---|---|---|---|---|---|
| 1 | [完整标题] | [作者] | [年份] | [arXiv/IEEE/知网] | [理工科/文科] | [L1/L2/L3] |

## 二、逐篇深度分析

### 论文 1：[标题]

**元信息**：作者 | 年份 | 来源平台 | DOI/链接

**（一）通用分析**
- 研究问题：[1 句话概括]
- 研究方法：[2–3 句]
- 创新点：[1–2 个核心创新]
- 局限性：[优先引用原文 Limitations；无则写"论文未明确讨论"]
- 文献综述质量：[广度、深度、批判性评价]

**（二）学科特定分析**

理工科论文：
- 核心方法：[技术路线、关键模型/算法名]
- 数学原理：[LaTeX 公式]
- 实验设置：[baseline 对比、消融实验]
- 数据集：[来源、规模、预处理]

文科论文：
- 理论框架 / 论证结构 / 案例分析 / 比较研究 / 政策建议 / 实证研究

**（三）5C 快评（Keshav 第一遍）**
Category / Context / Correctness / Contributions / Clarity

**（四）批判性分析**（L3 必备；L2 至少覆盖问题层+证据层）
按四层组织，每条质疑附原文证据（章节/页码）：
1. 问题层：[问题定义、重要性]
2. 方法层：[假设、方法-问题匹配度、替代方法、适用范围]
3. 证据层：[数据支撑、测量效度、替代解释、是否夸大；含图表审读发现]
4. 贡献层：[相对已有工作的真实增量、精华所在]
5. （可选）反面信号诊断：[命中"8 大缺陷"中的哪几条]

**（五）两个终极问题**
- 这篇文章的精华在哪里？
- 如果我来解决这个问题，我会怎么做？

**（六）改进建议**
[仅在有把握时提供；基于奥卡姆剃刀与第一性原理，不确定则省略]

## 三、综合对比分析（多篇时）

**横向对比矩阵**

| 维度 | 论文1简称 | 论文2简称 | 论文3简称 |
|---|---|---|---|
| 研究问题 | | | |
| 核心方法 | | | |
| 创新点 | | | |
| 局限性 | | | |
| 与你研究关联度 | 高/中/低 | 高/中/低 | 高/中/低 |

**纵向对比（发展脉络）**
[年份区间]：[阶段概述]，代表工作 [论文名] — 解决 [核心问题]（按时间排列）

**方法论对比**
[各论文方法论特点与优劣]

## 四、研究空白与机会
- [具体问题] — [为什么是空白、为什么值得做]
（来自：原文未来方向 / 局限性章节 / 多篇矛盾与不足 / 方法空白）

每个空白附评估：**意义**（相关性/时间尺度/研究贡献/现实距离四标准）+ **可控性**（问题清晰？有解？条件具备？时间够？伦理合规？）+ **类型定位**（开拓性：资料少风险高可填空白 / 推进性：资料多创新难需另辟蹊径）。

## 四点五、综述结构建议（多篇综述场景选用）

- **综述归纳四问**核对：前人是否说过 → 说了什么（观点异同与分类）→ 怎么说的（方法也要综述）→ 何人何时何地说（演化脉络）。
- **结构三写法**：历史发展（纵式）／现状分析（横式，国际国内对比）／取向预测（纵横对比中展望）；学位论文综述多用纵横结合式。
- **述评比 7:3**：述 70%、评 30%；评必须有原创性观点，不做描述性统计式评论。
- **必守**：按"由远到近、由大到小、由宽到窄"的文献树（学术谱系）原则组织，禁止"XXX 认为……"式罗列；引文观点与自己的评述明确区分，不把观点强加给原作者。

## 五、可直接使用的论文表述
- 与 [论文A] 不同，本文聚焦于 [你的方向]
- 现有工作如 [论文B] 和 [论文C] 主要关注 [X]，而本文则 [Y]
- 受 [论文D] 启发，本文进一步解决了其指出的 [局限]

## 六、参考文献
[GB/T 7714-2015 顺序编码制，见第二节]
```

## 二、引用格式：GB/T 7714-2015 顺序编码制

正文引用用上标数字 [1][2]，文献列表按正文出现顺序编号，所有被分析的论文均须列入，标注 DOI 或 arXiv ID（如有）。

| 文献类型 | 格式 |
|---|---|
| 期刊文章 [J] | 作者. 题名[J]. 刊名, 年份, 卷(期): 起止页码. |
| 会议论文 [C] | 作者. 题名[C]//会议名称. 出版地: 出版社, 年份: 起止页码. |
| 学位论文 [D] | 作者. 题名[D]. 保存地: 保存单位, 年份. |
| 预印本/在线资源 [EB/OL] | 作者. 题名[EB/OL]. 发布日期[引用日期]. URL. |
| 多作者 | 前 3 位全写，后加 ", et al."（英文）或 ", 等"（中文） |

示例：

```text
[1] VASWANI A, SHAZEER N, PARMAR N, et al. Attention is all you need[C]//Advances in Neural Information Processing Systems. Long Beach: Curran Associates Inc., 2017: 5998-6008.
[2] 张三, 李四. 大语言模型在自然语言处理中的应用研究[J]. 计算机学报, 2024, 47(3): 512-525.
[3] WANG Y, LI M, CHEN Z. Deep learning for medical image analysis: a survey[J]. Medical Image Analysis, 2021, 71: 102045. doi:10.1016/j.media.2021.102045.
```

## 三、信息密度处理规则

- arXiv 摘要页只有标题/作者/摘要时：摘要未提及的数据集、指标、实验细节 → 标注"摘要中未提及，需阅读全文"，不得编造。
- 同时有 HTML 全文版本时 → 优先从全文提取。
- 上传的 PDF/Word → 读取完整内容后提取。
- 数学公式一律用 LaTeX（`$...$` / `$$...$$`），确保 MathJax/KaTeX 可渲染。
- 文科论文报告适当使用表格对比、案例摘要增强可读性。

## 四、文档导出规范（命中 Word/PDF 关键词时）

命名：`文献批判性阅读报告_〈论文标题或简称〉_〈YYYYMMDD〉`

**Word（.docx）**：A4，页边距 2.54cm；正文中文宋体/英文 Times New Roman 小四；标题黑体（一级三号加粗、二级四号加粗、三级小四加粗）；1.5 倍行距，段前段后 0.5 行；页眉论文标题、页脚居中页码；三线表（表题上方居中）；公式编辑器输入、居中、右侧编号；图题下方居中；参考文献悬挂缩进 2 字符。

**PDF（.pdf）**：A4，上下 2.54cm、左右 2.8cm；衬线字体；LaTeX 公式渲染为矢量；按标题生成 PDF 书签；DOI/arXiv 链接可点击；图表 ≥300dpi 且附规范图注；参考文献同 GB/T 7714。

导出失败 → 先交付 Markdown，末尾附注失败原因与建议。
