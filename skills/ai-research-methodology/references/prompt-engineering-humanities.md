## 一、科研全流程提示词模板

### 2.1 文献检索——找对文献，赢在起跑线

```text
请推荐近5年在【你的学科领域，如管理学/社会学/教育学/新闻传播学/法学/政治学】领域关于【你的研究主题】的代表性文献。要求：
聚焦权威期刊（如SSCI一区/二区、CSSCI来源期刊、领域内公认权威期刊）
每篇包含：标题、作者、期刊/年份、理论视角、研究方法、核心结论
优先引用被广泛引用或高影响力的研究
若有综述类文献也请一并列出
```

追问：`这些文献中，哪篇的理论框架最适合作为我研究的理论基础？为什么？`

### 2.2 文献翻译与内容提炼——一篇文献，5 分钟吃透

**要点**：文科提炼的五个字段是"研究问题 + 理论框架 + 研究方法 + 核心发现 + 局限"，与理工科的"贡献/方法/结果"不同，落脚在理论视角与研究方法类型（定量/定性/混合）。

```text
请根据以下英文文献摘要/全文，提供高质量的中文翻译，并提炼该研究的研究问题、理论框架、研究方法、核心发现及其局限性。
文献信息：
标题：【论文标题】
摘要/段落：【具体文本】
输出格式：
①翻译后的中文文本
②研究问题与理论视角（简短总结）
③研究方法（定量/定性/混合方法及具体设计）
④核心发现与主要结论
⑤研究局限或未来研究方向
```

### 2.3 热点趋势分析——站在学术前沿选题

**要点**：输出必须落到 **Research Gap**（理论缺口），这是文科选题论证的核心。

```text
请分析2021–2025年【你的学科领域】中"【你的研究方向】"的研究热点与理论演进趋势。
要求：
聚焦权威期刊/数据库（如CSSCI、SSCI、CNKI核心期刊）
提炼3–5个核心研究议题或主流理论视角
每个议题包含：核心概念、代表文献、常用研究方法、典型研究情境
总结整体理论演进脉络与尚未解决的研究缺口（Research Gap）
```

### 2.4 数据预处理与量表检验——数据不净，模型白跑

**要点**：文科数据预处理的独有环节是**量表信效度与共同方法偏差（CMB）**：Cronbach's α、KMO 与 Bartlett 检验、EFA/CFA、反向计分、变量中心化。

```text
我有一份用于实证研究的问卷调查数据（格式：CSV/Excel，量表类型：Likert【5/7】点量表），请按实证研究规范完成：
①数据诊断：报告样本量、缺失率、极端值、人口统计学分布、共同方法偏差（CMB）检验方案
②信效度检验：Cronbach's α信度、KMO与Bartlett球形检验、探索性因子分析（EFA）/验证性因子分析（CFA）
③数据清洗：反向计分题处理、缺失值插补策略、无效问卷剔除标准
④变量构建：量表合成变量/因子得分计算、交互项变量中心化处理
⑤输出可复现代码（R/Python/SPSS语法，注明随机种子与版本）
```

### 2.5 实证研究设计与优化——别再盲目跑回归

**要点**：先做**因果识别策略**评估（DID/IV/RDD/PSM）与内生性问题预判，再谈模型——这决定了实证部分能否站得住。

```text
针对我的实证研究项目，已准备好数据集，请协助完成：
①变量体系梳理：自变量、因变量、中介变量、调节变量、控制变量的选取依据与测量方式
②因果识别策略：评估双重差分（DID）、工具变量（IV）、断点回归（RDD）、倾向得分匹配（PSM）等方法的适用性
③内生性问题预判：可能的遗漏变量、反向因果、样本自选择来源及应对策略
④样本量与统计功效：结合效应量估算所需样本规模（Power Analysis）
```

### 2.6 数据分析建模——从描述统计到因果推断，一步到位

```text
我有一份用于【管理学/社会学/教育学/新闻传播学等】研究的数据集，请协助完成以下实证分析设计：
①描述性统计与变量相关性分析方案
②计量模型选择：OLS/Logit/Probit/多层线性模型（HLM）/结构方程模型（SEM）等，说明各自适用条件
③中介效应与调节效应检验方案（Bootstrap法、依次检验法，或PROCESS宏逻辑说明）
④稳健性检验设计：更换变量测量方式、更换子样本、安慰剂检验
⑤输出可复现分析代码（R/Stata/Python），并附结果解读要点
```

### 2.7 论文框架生成——先有骨架，再填内容

```text
请为我的研究主题"【你的研究方向】"生成一篇符合期刊标准的完整论文框架。
要求：
包含：摘要、引言、文献综述、理论框架与研究假设、研究方法、实证结果、讨论、结论
引言部分明确研究问题的重要性、现有研究的理论缺口、本文的边际贡献
理论框架部分预留研究假设（H1/H2……）撰写位置
研究方法部分包含数据来源、变量测量、模型设定、样本描述
```

### 2.8 辅助论文撰写——逐节攻破，告别空白恐惧

**要点**：文科写作的关键约束是"与已有理论对话 + 突出边际贡献"，而非仅语言正式。

```text
请基于以下研究内容，帮我撰写论文的"【指定章节，如文献综述/理论框架/讨论】"部分：
研究问题：【简要描述】
理论视角：【如"基于资源基础理论"】
关键结果：【如"X对Y的正向影响在高不确定性情境下更显著"】
要求：语言正式、使用学科术语、体现与已有理论的对话、突出边际贡献
```

### 2.9 润色优化 + 查重降重

```text
请对以下段落进行学术润色与降重处理：
【粘贴你的段落】
要求：
保持原意不变，提升流畅性、专业性与逻辑连贯性
替换高频词汇（同义改写），避免与常见表述高度重合
检查语法、时态、术语使用的一致性
输出修改后文本+修改说明
```

**降重 ≠ 降 AIGC（先分清再动手）**：查重（重复率）针对的是与他人文字的重合，降 AIGC 针对的是文本像机器写的——两套检测、两套对策。用户说"降重"时要确认他到底卡在哪一项，不要混用同一套提示词。

降重真正有用的做法只有一条：**补入本领域新近文献的具体观点，并用自己的话重述**。它既降低文字重合，也提升内容质量。倒装、被动改写、插入英文缩写等表层手法只能改变工具读数，不改变学术质量，不推荐。

### 2.10 投稿信、催稿信与返修回复

**文科特有约束**：审稿人常质疑实证与稳健性检验，回复须说明"补充的统计检验方法与结果"。

```text
请根据以下审稿意见，帮我撰写逐条回复（Response to Reviewers）：
审稿人#1, Comment 1："【意见内容，如"建议补充稳健性检验"】"
审稿人#2, Comment 3："【意见内容】"
要求：
每条回复先致谢，再具体说明修改内容及在正文中的位置
若不同意意见，需礼貌反驳并提供理论或数据证据
涉及实证部分的意见，需说明补充的统计检验方法与结果
整合为标准response letter格式
```

## 二、AI 辅助实证分析与数据分析实战（从数据到结论）

### 场景一：问卷/量表数据统计分析

**要点**：要求 AI 给出**判断标准阈值**（KMO>0.7、Cronbach's α>0.7、AVE>0.5）与可直接写入论文的结果解读话术。

```text
请帮我设计一份完整的问卷数据统计分析方案。
数据：【问卷主题及量表设计说明】
研究模型：【自变量→中介变量→因变量，含调节变量】
要求：
- 完整分析流程（描述统计→信效度检验→相关分析→回归/结构方程分析→中介调节效应检验）
- 每一步对应的统计方法与判断标准（如KMO>0.7、Cronbach's α>0.7、AVE>0.5等）
- 结果呈现方式（符合APA格式或目标期刊规范的表格）
- 代码可直接在R/SPSS/Python中运行
- 提供结果解读话术，方便直接写入论文"实证结果"部分
```

### 场景二：因果推断与实证模型构建

```text
请根据以下研究设计，帮我构建实证分析模型：
研究问题：【标题】
理论假设：【简述，如"X对Y的影响受Z的调节"】
数据类型：【面板数据/截面数据/时间序列数据】
要求：
- 说明模型设定（固定效应/随机效应/双重差分DID/工具变量IV等）及对应的Stata/R代码
- 写清楚每个变量的学科含义与理论依据
- 说明稳健标准误/聚类标准误的设置逻辑
- 输出符合期刊规范的核心回归结果表格（Table形式，含显著性标记）
```

### 场景三：质性研究编码与内容分析

```text
请帮我搭建一个质性研究文本编码分析框架：
研究材料：【访谈文本/政策文件/社交媒体文本等】
研究方法：【扎根理论/内容分析法/话语分析】
要求：
- 开放式编码→主轴编码→选择性编码的完整流程说明
- 编码表模板（一级/二级/三级编码及对应原始语句示例）
- 编码信度检验方法（如多编码员Kappa系数计算方式）
- 生成可用于论文的编码框架/概念模型可视化描述
```

## 三、AI 辅助文献计量与系统综述实战

### 策略一：文献计量分析（Bibliometric Analysis）

```text
我已从【Web of Science/CNKI/Scopus】导出【数量】篇关于【研究主题】的文献题录数据，请帮我设计文献计量分析方案：
①发文趋势分析：年度发文量、主要期刊分布、主要国家/机构分布
②关键词共现与聚类分析：说明CiteSpace/VOSviewer的参数设置逻辑，并对聚类主题进行解读
③作者/机构合作网络分析
④突现词（Burst Detection）分析，识别研究前沿的演变路径
要求：
- 说明每种分析对应的可视化图表类型
- 图表在论文中的呈现规范（图注、配色、字体、分辨率）
- 提供基于Python（bibliometrix/pybliometrics）或CiteSpace的操作步骤说明
```

### 策略二：系统综述与 PRISMA 流程

**要点**：PRISMA 2020 的四阶段（识别、筛选、资格评估、纳入）文献数量记录 + 文献质量评价工具选型 + Meta 分析异质性检验（I²）。

```text
请帮我设计一篇系统综述（Systematic Review）的完整实施方案，主题为【研究主题】：
①检索策略：数据库选择、检索式设计（布尔逻辑组合）、检索时间范围
②文献筛选：纳入/排除标准设计，PRISMA流程图各阶段（识别、筛选、资格评估、纳入）的文献数量记录方式
③文献质量评价：根据研究类型推荐适用工具（如Cochrane风险偏倚工具、CASP清单、Newcastle-Ottawa量表）
④数据提取与综合：提取表格字段设计、叙述性综合或Meta分析路径的选择依据
要求：
- 输出符合PRISMA 2020规范的流程图结构说明
- 提供文献筛选记录表模板
- 若涉及Meta分析，说明异质性检验（I²）、效应量选择、森林图的解读逻辑
```

### 策略三：实证与综述结果可视化——图表生成

```text
请帮我设计可直接用于论文的图表方案：
①回归结果表格（含标准误、显著性标记*/**/***）
②中介/调节效应路径图
③文献计量关键词共现网络图、聚类时间线图
④PRISMA文献筛选流程图
⑤描述性统计箱线图/雷达图
要求：
- 说明图表制作工具（Excel/Origin/Python matplotlib、CiteSpace/VOSviewer自带导出）及排版规范
- 每张图表配套图注撰写模板
- 提供一键生成图表的代码或操作步骤
```

### 策略四：稳健性检验与研究可信度清单

```text
请帮我设计完整的稳健性检验方案：
当前实证模型包含以下设定：
- 核心自变量：【描述】
- 控制变量：【描述】
- 模型设定：【如OLS/固定效应模型】
要求：
- 列出至少4类稳健性检验方法（更换变量测量方式、更换模型设定、剔除极端样本、内生性处理如工具变量法/安慰剂检验）
- 生成稳健性检验结果汇总表格模板（Baseline vs 检验1 vs 检验2……）
- 说明如何在论文中撰写"稳健性检验"这一段落，使其兼具严谨性与可读性
```

## 四、AI 文科科研全流程检查清单

| # | 科研阶段 | 可获得的产出能力 |
|---|---|---|
| 01 | 文献检索 | 精准定位权威文献，快速建立研究基础 |
| 02 | 文献翻译与提炼 | 英文文献快速吸收，抽取理论与方法核心 |
| 03 | 热点趋势分析 | 数据驱动选题，找到理论缺口与研究蓝海 |
| 04 | 数据预处理与量表检验 | 自动化清洗 + 信效度检验，告别手动整理数据 |
| 05 | 实证研究设计 | 科学规划因果识别策略，避免内生性陷阱 |
| 06 | 数据分析建模 | 从描述统计到因果推断，一步到位 |
| 07 | 论文框架 | 期刊标准提纲，快速开篇 |
| 08 | 论文撰写 | 学术级语言输出，告别空白恐惧 |
| 09 | 润色降重 | 专业润色 + 查重优化，一步到位 |
| 10 | 投稿与返修 | 投稿信/返修回复模板，稳健性检验回应从容应对 |
| 11 | AI 辅助实证分析 | 从问卷/面板数据到因果推断模型，一句话理清分析路径 |
| 12 | AI 辅助文献计量与系统综述 | 关键词聚类 + PRISMA 流程 + 图表生成一体化 |

> 使用提醒：计量/统计模型的设定必须由研究者依据理论与数据结构判断，AI 建议仅作候选方案；中介调节、稳健性等检验结果须在统计软件中真实跑出，严禁用 AI"生成"结果数值（属数据造假）。文献计量的题录数据须来自真实数据库导出，AI 不能替代检索。
