# human-3-skill

> **HUMAN 3.0** 中文个人发展评估 Skill —— 通过适应式面谈，看清自己卡在哪。

## 一句话定位

评估是为了**发现可操作的问题**，不是为了制造身份标签。

## 核心能力

通过适应式面谈，从**心智、身体、灵性、职业**四个象限分析用户当前的发展模式，
识别可能的层级、阶段、生活方式原型、跨象限阻碍与成长机会，并生成可执行的整合策略。

帮助用户理解：

- 哪些生命领域发展较强；
- 哪些领域正在拖累整体生活；
- 一个象限的问题是否源自另一个象限；
- 目前可能处于什么发展阶段；
- 哪个问题最值得优先解决；
- 如何把成长转化为可持续的生活方式，而不是靠意志力硬撑。

## 何时触发

自我反思、生活方式设计、个人发展复盘、长期成长规划。

## 使用边界（重要）

HUMAN 3.0 是一个**发展与自我反思框架**，而不是经过临床验证的诊断工具。
不要把 Level 1/2/3、Metatype、Lifestyle Archetype、False Transformation、
Regression、Glitch 风险写成医学、心理学或精神科诊断结论。
不用于医学诊断，不把层级或标签当作科学结论。

## 内容结构

```text
human-3-skill/
├── SKILL.md
├── README.md
└── references/
    ├── model.md        # HUMAN 3.0 模型知识
    ├── interview.md    # 适应式面谈问题与结束条件
    ├── assessment.md   # 正式评估报告结构
    └── safeguards.md   # Glitch、AI、药物、健康与精神状态的风险边界
```

主 `SKILL.md` 只负责触发条件、总工作流、面谈原则、四象限评估逻辑与输出原则；
详细内容拆分到 `references/`。

## 兼容性

该结构适合采用 `SKILL.md + references/` 形式的 Skill 系统。
如用于 Codex，可放入用户级 skills 目录后重启识别；
如用于其他平台，可按平台要求补充 frontmatter 字段。
