# 思维工具箱 · 一页式自查清单

> 任何一轮"工具箱分析"完成后逐项自查。任一项不达标，先修再交付。

## 1 · 工具选择

- [ ] 只选了 **1 个主工具**，且删掉它结论会变（不是贴标签）
- [ ] 补充/反证工具 ≤ 3 个，每个有明确工位（定题/定界/估计/找机制/造选项/找反作用/落地/查价值）
- [ ] 至少 1 个异质反证工具（如：期望值 ↔ 非遍历性；激励 ↔ 古德哈特；凯利 ↔ 黑天鹅）
- [ ] 多来源冲突已用「裁决五问」定主位，未强行调和

## 2 · 建模质量

- [ ] 已重述：目标、硬约束、时间尺度、关键未知、失败方式
- [ ] 已问零阶问题：这真正是关于什么的问题？
- [ ] 时间尺度与工具匹配（一次性决策 vs 复利 vs 制度演化）
- [ ] 有公式/数字的地方写出了公式（凯利、期望值、SIR、夏普利…）或给了方向性判断

## 3 · 证据纪律

- [ ] 事实 / 推断 / 价值判断 / 未知 已分级标注
- [ ] 用了外部视角（参考类、基准率）约束内部叙事
- [ ] 数据不足时给了范围或低/中/高，未伪精确
- [ ] 至少问过一次："如果结论错了，最可能错在哪？"
- [ ] 评估他人论证时过了 asq 十问关键三项：假设挖掘、谬误检查、替代原因
- [ ] 归因做过"个体 vs 结构"双向检查（sociology-35：个人困扰也可能是结构问题）
- [ ] 高风险领域（医疗/法律/财务/安全）已声明能力边界并建议专业校验

## 4 · 来源引用

- [ ] 引用了具体来源（万维钢 / 老喻 / 得到高研院 / 混沌 / 模型思维 / 博弈论 / 社会学 / 认知觉醒 / 批判性思维）
- [ ] 同名工具用了「跨来源对照表」确定的主条目，未混用定义
- [ ] 未把提炼卡的转述当原文引用

## 5 · 行动与更新

- [ ] 结论是可执行的一句话，放在最前
- [ ] 有下一步动作 + 触发条件 + 观察指标
- [ ] 重要且可逆 → 建议小试；重要且不可逆 → 提高证据门槛
- [ ] 明确写出更新条件：什么证据出现就加码 / 转向 / 停止

## 6 · 边界与能动性

- [ ] 未替用户规定人生目标或价值排序
- [ ] 未把他人当作可操纵变量；未建议欺骗、操控、强迫
- [ ] 用户需要倾听时，先回应人，再给工具

---

**十秒版**：一个主工具改结论？反证到位？证据分级？行动可执行？更新条件明确？——五问全过再交付。
