# 分章节专项提示词

以下提示词按原样保留（便于整段复制使用），使用时把占位符替换为对应章节文本。

> **说明**：本技能的方法框架与提示词由本项目整理撰写（详见 README「参考资料 / 灵感来源」，标注为原创方法论）。此处「按原样保留」指不改写本技能自身的提示词，以便直接套用。
分章节处理可与 `prompts-core.md` §1 通用版叠加：先跑通用版，再用本文件的专项提示词处理对应章节。

---

## §1 专门修改论文 Introduction

**症状**："一层一层说正确的废话"。典型结构——某领域很重要 → 得到了广泛关注 → 取得了显著进展 → 然而仍存在挑战 → 因此本文提出…… 形式没错，问题在于几乎每篇 AI 生成的 Introduction 都如此展开。

```text
请重写下面的论文 Introduction。

不要按照"领域很重要—近年来受到广泛关注—虽然取得进展—仍面临挑战—因此本文……"这一固定模板机械展开。

请根据文本中的真实研究内容建立论证链。

Introduction 应逐步回答：

目前这个研究问题具体是什么？

现有研究已经解决了什么？

真正没有解决的部分是什么？

这个不足为什么会限制当前研究或应用？

本文具体解决其中哪一个问题？

作者采用的方法为什么与这个问题匹配？

保持论证范围克制。

不要为了增强研究价值而扩大研究空白。

不要使用"研究很少""尚未有人研究""首次"等表述，除非原文有足够依据。

删除不能帮助读者理解研究问题的宏大背景和空泛意义描述。

尽量通过事实、已有方法的限制和具体研究问题自然引出本文工作，而不是依赖"然而""值得注意的是""因此"等连接词强行制造逻辑。

保留所有原有引用及其对应含义。

原文：

【粘贴 Introduction】
```

## §2 专门修改 Results

**症状**：把图表重新念一遍。例如"如图 3 所示，A 高于 B。值得注意的是，C 也表现出了较高水平。这说明本方法具有良好的性能。"——没有告诉审稿人真正应该看什么。

```text
请以科研论文 Results 部分的标准修改下面文本。

不要简单逐项复述图表中的所有数字。

优先写对研究问题真正有解释价值的结果：

主要效应是什么？

最重要的组间差异是什么？

是否存在异常、边界条件或相反结果？

哪些结果直接支持研究假设？

哪些结果只能作为观察，而不能支持更强结论？

数据和统计结果必须严格保持原样。

不要添加没有进行过的统计检验。

不要把相关关系写成因果关系。

避免使用"明显""显著""大幅"等主观形容词代替实际结果。如果存在统计学显著性，应根据原文中的统计检验表述；如果没有，不要自行加入"显著"。

结果段落以数据和观察为中心，不要提前加入大量 Discussion 式解释。

原文：

【粘贴 Results】
```

## §3 专门修改 Discussion

**症状**：大而空，或只是重新总结 Results。真正好的 Discussion 解释的是——为什么出现这个结果，以及它改变了我们对问题的什么认识。

```text
请按照科研论文 Discussion 的逻辑重新编辑下面文本。

不要重复 Results 中已经完整报告的数据。

对于重要结果，按照以下思路展开：

先明确需要解释的具体发现。

随后讨论能够被当前数据支持的解释。

再与已有研究进行比较，指出一致、不一致或新增的信息。

如果存在可能的机制，区分"已经被数据证明的机制"和"合理但尚未验证的解释"。

最后说明这一发现对当前研究问题意味着什么。

不要把所有结果都写成积极结论。

如果原始结果存在限制、异常或者与假设不一致，应如实保留。

避免使用空泛的拔高表达，例如：

"进一步丰富了相关理论"

"具有重要理论和实践意义"

"为未来研究提供新的视角"。

如果确实存在贡献，请明确说明究竟改变了哪个认识、解决了哪个限制或增加了什么新的证据。

不要自行创造文献观点、机制解释或研究局限。

原文：

【粘贴 Discussion】
```

## §4 专门处理"创新点写得很虚"

**症状**：创新点只有评价、没有信息。例如"本研究提出了一种创新性的高效方法，显著提高了系统性能，为该领域提供了一种新的解决方案。"——看完仍不知道新在哪里。

```text
请检查下面文本中的"创新性"和"贡献"表述。

删除仅仅依赖形容词建立价值的表达，例如：

创新的、先进的、新颖的、高效的、强大的、突破性的、有效的。

不要直接用这些词告诉读者研究"很好"。

请优先回答：

已有方法具体怎么做？

当前方法具体改变了哪一步？

这种改变解决了原方法的哪个限制？

实验结果能够证明什么优势？

哪些优势只是理论预期，目前尚未被实验验证？

如果原文没有足够信息证明"首次""突破""显著优于"等结论，请降低表述强度。

让研究贡献由方法差异、实验结果和证据体现，而不是由评价性形容词体现。

原文：

【粘贴内容】
```
