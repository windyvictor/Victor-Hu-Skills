- **macOS 是 BSD grep，不支持 `\|` 交替**！`grep "a\|b"` **静默失败返回空**，会得出错误的
  「✅ 无残留」结论。**必须用 `grep -E "a|b"` 或 Grep 工具（ripgrep）**。本轮因此重验多处。
- 隔离 Python 路径含空格**必须加引号**：
