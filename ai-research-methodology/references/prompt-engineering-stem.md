## 一、科研全流程提示词模板

### 2.1 文献检索——找对论文，赢在起跑线

**要点**：让 AI 用一条提示词锁定领域内最具影响力的论文，替代漫无目的的三天检索。追问技巧是把"推荐清单"直接转化为"基线选择"决策。

```text
请推荐近3年在人工智能领域关于[你的研究主题]的代表性论文。要求：
聚焦顶会（如NeurIPS、ICML、ICLR、CVPR、ACL等）
每篇包含：标题、作者、会议/年份、核心方法、解决的问题
优先引用被广泛讨论或高影响力的工作
若有综述论文也请列出
```

追问：`这些论文中哪篇最适合作为我研究的基线方法？为什么？`

### 2.2 文献翻译与内容提炼——一篇论文，5 分钟吃透

**要点**：把长论文压缩为"翻译 + 核心贡献 + 方法 + 结果 + 局限"五张卡片，直接形成可复用的文献笔记。

```text
请根据以下英文论文摘要/全文，提供高质量的中文翻译，并提炼该研究的核心贡献、方法论、实验结果及其局限性。
论文信息：
标题：[论文标题]
摘要/段落：[具体文本]
输出格式：
①翻译后的中文文本
②核心贡献（简短总结）
③方法概述（技术细节）
④主要实验结果
⑤研究局限或未来工作方向
```

### 2.3 热点趋势分析——站在风口上选题

**要点**：用"数据 + 顶会/顶刊"视角回答"哪个赛道还有坑位"，产出可直接写入开题的趋势论证。

```text
请分析2022–2025年在人工智能领域中'[你的研究方向]'的研究热点与技术趋势。要求：
聚焦顶会/期刊（如NeurIPS、ICML、CVPR、ACL、ICLR等）
提炼3–5个核心研究主题或主流方法
每个主题包含：关键技术、代表论文、典型应用场景
总结整体演进脉络与未来可能方向
```

### 2.4 数据预处理与特征工程——数据不净，模型白练

**要点**：一次性覆盖诊断→清洗→特征工程→划分→代码五步，关键是强制要求"无数据泄露 + 可复现代码（random_state=42）"。

```text
我有一个用于AI研究的数据集（格式：[CSV/JSON/Parquet]，
任务类型：[分类/回归/时序预测]），请按科研标准完成：
①数据诊断：报告样本量、特征类型、缺失率、异常值、类别不平衡等
②清洗策略：缺失值填充、异常值处理、标签泄露检查
③特征工程：时间特征提取、编码策略、标准化/归一化
④数据划分：分层抽样/时间切分，确保无数据泄露
⑤输出可复现Python代码（pandas/sklearn，含random_state=42）
```

### 2.5 实验设计与优化——别再盲试，让 AI 帮你规划实验路线

**要点**：调参无效的根因常在实验设计。提示词强制输出"策略 + 风险预判（过拟合/不确定性）"。

```text
针对我的AI研究项目，已准备好数据集，请协助完成：
①变量筛选：识别关键特征，去除冗余，推荐降维技术
②实验方案：推荐模型架构、超参搜索策略、交叉验证方案
③风险预判：过拟合/欠拟合评估、不确定性估计方法
```

### 2.6 数据分析建模——从 Baseline 到创新，一步到位

**要点**：把"缺创新点"转化为结构化提问：问题特性分析 → 1–2 个基线 + 1 个创新方向 → 公平对比 → 可解释性（SHAP/LIME + 消融）。

```text
我有一个AI研究项目的数据集，请协助完成以下建模设计：
①问题特性分析：数据独特挑战、现有方法局限性
②创新模型建议：1–2个基线+1个创新方向
③实验设计：公平对比、多维度评估指标
④可解释性：SHAP/LIME分析+消融实验设计
```

### 2.7 论文框架生成——先有骨架，再填内容

**要点**：先出符合顶会标准的提纲（含公式/伪代码占位），再逐节填充，效率提升最大。

```text
请为我的研究主题'[你的研究方向]'生成一篇符合顶会标准的完整论文框架。
要求：
包含：摘要、引言、相关工作、方法、实验、结论
引言部分明确问题重要性、现有方法局限、本文贡献
方法部分预留公式/算法伪代码位置
实验部分包含数据集、基线模型、主结果、消融实验设计
```

### 2.8 辅助论文撰写——逐节攻破，告别空白恐惧

**要点**：给足"研究问题 + 核心方法 + 关键结果"三要素，AI 才能写出有学术范儿的段落。

```text
请基于以下研究内容，帮我撰写论文的'[指定章节]'部分：
研究问题：[简要描述]
核心方法：[如'提出一种动态门控融合模块']
关键结果：[如'在CrackForest上mIoU提升20.4%']
要求：语言正式、用学术术语、可插入LaTeX公式、突出创新性
```

### 2.9 润色优化 + 查重降重——从 80 分到 95 分

**要点**：要求同时输出"修改后文本 + 修改说明"，便于作者核对原意是否被改变。

```text
请对以下段落进行学术润色与降重处理：
[粘贴你的段落]
要求：
保持原意不变，提升流畅性、专业性与逻辑连贯性
替换高频词汇（同义改写）
检查语法、时态、冠词等细节
输出修改后文本+修改说明
```

### 2.10 投稿信、催稿信与返修回复——最后一公里，别掉链子

**要点**：返修回复的三条硬规则：逐条致谢 → 说明修改内容与位置 → 不同意时礼貌反驳并举证。

```text
请根据以下审稿意见，帮我撰写逐条回复（Response to Reviewers）：
审稿人#1, Comment 1: '[意见内容]'
审稿人#2, Comment 3: '[意见内容]'
要求：
每条回复先致谢，再说明修改内容
若不同意意见，需礼貌反驳并提供证据
整合为标准response letter格式
```

## 二、AI Code 辅助构建 Baseline（从 0 到 1）

> 适用场景：论文 Baseline 未开源、复现成本高；或需要快速搭建对比实验框架。

### 场景一：快速搞定分类/回归 Baseline

```text
请帮我构建一个完整的[图像分类/文本分类/时序预测] Baseline项目。
数据集：[数据集名称及描述]
基线模型：[如ResNet-50/BERT/LSTM]
要求：
- 完整的项目结构（data/, models/, train.py, evaluate.py, config.yaml）
- 数据加载、预处理、增强Pipeline
- 训练循环（含lr scheduler、early stopping、checkpoint保存）
- 评估脚本（Accuracy/F1/AUC + 混淆矩阵可视化）
- requirements.txt和README.md
- 代码可直接python train.py跑通
```

### 场景二：复现论文中的模型

**关键约束**：要求代码注释与论文公式/图号一一对应，并复现论文 Table 1 主结果——这是判定"复现是否成功"的验收标准。

```text
请根据以下论文信息，帮我复现其核心模型：
论文标题：[标题]
核心方法：[简述架构，如"Encoder-Decoder + 注意力机制"]
数据集：[名称]
要求：
- 用PyTorch实现核心网络结构
- 写清楚每个模块的注释（对应论文哪个公式/图）
- 提供训练脚本+超参配置
- 复现论文Table 1的主实验结果
```

### 场景三：多模型对比实验

```text
请帮我搭建一个多模型对比实验框架：
任务：[描述任务]
数据集：[名称及规模]
对比模型：[如SVM / Random Forest / XGBoost / MLP / ResNet]
要求：
- 统一的数据加载和预处理流程
- 每个模型独立封装，通过配置文件切换
- 统一评估指标（Acc/Prec/Recall/F1/AUC）
- 自动生成对比表格+可视化图表
- 支持--model xxx命令行参数切换
```

## 三、AI Code 辅助改进 Baseline（从能跑到能发）

> 四条策略：模型结构改进 → 训练策略优化 → 结果可视化与图表生成 → 消融实验自动化。

### 策略一：模型结构改进

**关键约束**：每个改进封装为**可插拔模块**，并强制提供"每次只加一个模块"的消融代码。

```text
我的当前Baseline是[模型名称]，在[数据集]上的[指标]为[数值]。
请帮我设计并实现以下改进：
①注意力机制增强（如SE-Net/CBAM/Self-Attention）
②多尺度特征融合（如FPN/ASPP）
③损失函数改进（如Focal Loss/Label Smoothing）
要求：
- 每个改进单独封装为可插拔模块
- 提供消融实验代码（每次只加一个模块）
- 生成对比表格：Baseline vs +改进1 vs +改进2 vs All
```

### 策略二：训练策略优化

```text
我的模型在训练集上表现很好但测试集泛化差，请帮我优化训练策略：
①学习率调度：实现Cosine Annealing + Warmup
②数据增强：Mixup/CutMix/RandAugment
③正则化：Dropout/DropPath/Weight Decay调优
④知识蒸馏：用大模型指导小模型
要求：
- 每个策略的实现代码+效果对比
- 生成训练曲线对比图（loss/acc curves）
```

### 策略三：实验结果可视化与论文图表生成

**关键约束**：顶会论文图规范——300 DPI、无网格线、字号适中，每图单独导出 PDF + PNG，并给一键脚本。

```text
请帮我生成可直接用于论文的实验结果图表：
①性能对比柱状图（各模型Acc/F1/AUC对比）
②训练曲线图（loss + accuracy双轴）
③混淆矩阵热力图
④ROC曲线对比图
⑤特征重要性/SHAP可视化
要求：
- 使用matplotlib，风格符合顶会论文规范（300 DPI、无网格线、字号适中）
- 每张图单独保存为PDF和PNG
- 提供一键生成脚本：python plot_results.py
```

### 策略四：消融实验自动化

```text
请帮我设计并实现完整的消融实验（Ablation Study）：
当前模型包含以下模块：
- 模块A：[描述，如注意力机制]
- 模块B：[描述，如多尺度融合]
- 模块C：[描述，如辅助损失]
要求：
- 自动跑完所有组合（Full / -A / -B / -C / Base）
- 自动生成消融实验表格（LaTeX格式）
- 结果保存为CSV + 可视化图表
```

## 四、AI 科研全流程检查清单（理工科）

| # | 科研阶段 | 可获得的产出能力 |
|---|---|---|
| 01 | 文献检索 | 精准定位高影响力论文，快速建立研究基础 |
| 02 | 文献翻译与提炼 | 英文论文快速吸收，抽取核心价值信息 |
| 03 | 热点趋势分析 | 数据驱动选题，找到蓝海研究方向 |
| 04 | 数据预处理 | 自动化清洗 + 特征工程，告别手动清洗数据 |
| 05 | 实验设计 | 科学规划实验路线，避免无效试错 |
| 06 | 创新建模 | Baseline + 创新方向一步到位 |
| 07 | 论文框架 | 顶会标准提纲，快速开篇 |
| 08 | 论文撰写 | 学术级语言输出，告别空白恐惧 |
| 09 | 润色降重 | 专业润色 + 查重优化，一步到位 |
| 10 | 投稿与返修 | 投稿信/返修回复模板，最后一公里不掉链 |
| 11 | AI Code 构建 Baseline | 从 0 到 1 生成可跑通的完整代码 |
| 12 | AI Code 改进 Baseline | 模型改进 + 消融实验 + 论文图表生成 |

> 使用提醒：AI 生成的实验代码必须由研究者逐行审读并在独立环境复现结果；代码中的数据集划分、随机种子、评价指标口径需人工确认，避免"跑通了但结论不可信"。文献与引用须回源核实，AI 给出的论文标题/作者/年份常有幻觉。
