# 科研论文写作核心清单（综合 16 本经典指南提炼）

写完或修改论文时，按以下顺序逐项自查。每项不通过就先修再继续。

## 一、立意与聚焦

- [ ] 全文只有一个核心主张（one paper, one claim），能在一句话内说清贡献
- [ ] "天真读者"测试：外行读者能一句话复述论文贡献、几分钟能讲清大纲
- [ ] 创新点明确且经得起追问：属于视角/理论/方法/素材哪一类？与最近 3 篇最相关工作的区别是什么？
- [ ] 题目≤20 个实义词，传达贡献本身而非泛泛主题

## 二、结构（C-C-C + 沙漏）

- [ ] 摘要五要素齐备：动机→问题→方法→结果→结论，≤250 词，完全自足（不含正文也能懂）
- [ ] 引言是漏斗四步：领域语境 → However 揭示空白 → So what 说明填补意义 → 本文主张与路线图
- [ ] 每一节、每一段都遵循 C-C-C：先语境，再内容，后结论；段落以主题句开头
- [ ] 结果部分只报告事实，解读留给讨论；讨论从具体结果回到一般意义，回应引言承诺
- [ ] 结论镜像引言（环形结构），不自创新话题
- [ ] 中文论文特别注意：摘要与结论不重复；讨论部分不省略

## 三、论证

- [ ] 每个主张都有支撑：证据优先于原理推理；引用文献定位准确（不张冠李戴）
- [ ] 主动替怀疑的审稿人提问：承认主要质疑并给出回应
- [ ] 文献综述是"述评"不是"罗列"（述评约 7:3），每段有组织逻辑，批评性引用与支持性引用兼备

## 四、图表

- [ ] 图表能脱离正文被独立理解
- [ ] 图标题写结论（finding），图例写方法细节
- [ ] 图表数量与信息密度：一张图只讲一件事；数据多时用表，趋势时用图

## 五、英语表达（英文论文）

- [ ] 每个单数可数名词前有冠词（a/an/the），特指 the、泛指 a/an——中国学生第一错误
- [ ] 一句只装 1–2 个主题，主旨放句首，目的/时间/原因状语后移
- [ ] respectively 仅在顺序有意义时用且放句末；study 指研究工作，paper 指文章本身
- [ ] 时态正确：文献综述总体用现在完成时、具体实验用过去时、Methods/Results 用过去时（常配被动）、Discussion 用现在时
- [ ] 解释推论必用 hedging（may/might/suggest/indicate），不写绝对断言
- [ ] 删除寄生词（very, basically, really）；圈出所有 be 动词，1/3 换成实义动词
- [ ] 术语全篇统一，不一词多名
- [ ] 改写他人句子时句法+词汇双重重组并注明出处，避免 mosaic plagiarism

## 六、流程与投稿（中国语境）

- [ ] 写作顺序：先方法与结果 → 再讨论与引言 → 最后摘要和题目
- [ ] 投稿提前 6–12 个月规划；期刊级别与论文质量匹配；严禁一稿多投
- [ ] 回应审稿意见：逐条回复、态度专业、能改则改、不能改给出充分理由

## 七、故事线与实验（顶会顶刊标准）

- [ ] Fact–Logic–Opinion：每个观点都有事实支撑 + 严密逻辑桥 + 对比基准，不只描述实验不下结论
- [ ] 每个图表服务核心贡献；结果讨论做到三层：是什么 → 为什么 → 与全文主线的关系
- [ ] 实验覆盖审稿人期待：baseline 充分、有消融实验、默认参数做过敏感性分析
- [ ] 投稿零容错：全角/半角统一、字体统一、缩写首次出现给全称、所有引用读到原文且追到源头、文献格式在文献管理软件内统一修改

## 八、引用与学术诚信

- [ ] 全篇只用一种引用体例（notes-bibliography 或 author-date），括号注与脚注不混用
- [ ] 每条直接引用与每处改写都标了页码；直接引用 ≤4 行加引号、≥5 行作块引用
- [ ] 改写是"重构句式 + 换词"而非逐词替换（能逐词找到同序同义词即为 mosaic 抄袭）
- [ ] 引用只来自读到原文的同行评审来源，不转引二手描述
- [ ] 无自我抄袭（与本人已发表内容重复需声明并引用）
- [ ] 文献格式在 Endnote/Zotero 等工具内修改，不在 Word 里手改

## 九、文献综述专项

- [ ] 有明确的问题主线，**按问题编排**而非以作者为线索（不"竹筒倒豆子"）
- [ ] 述评比例约 7:3；有原创性评述，不是描述性统计或文献堆砌
- [ ] 先分析后结论；未读过的文献一律不引（不把他人述评当自己的观点）
- [ ] 覆盖领域内经典与权威论著；无张冠李戴、无自话自说自引
- [ ] 引言交代了结构安排及其理由，并给出初步的原创性观点
- [ ] 已对照"常见错误速查 13 项"（literature-review-workflow.md）与"常见错误详解 14 项"（structure-and-pitfalls.md）自查
- [ ] 已复查是否有最新在刊/在印文献，避免把"刚被解决的问题"当成研究空白

## 十、编辑体例（终稿格式，杜拉宾 8 版第三部分）

- [ ] 数字书写路线（拼写/阿拉伯数字/科学计数）已选定并全文贯彻；句首不用阿拉伯数字；年份与页码不加千分位逗号
- [ ] 全角/半角标点与中英文空格统一（中文用全角标点，中英文之间按刊物规范加空格）
- [ ] 标点符合体例：并列项末项前逗号（美式）、分号冒号在引号外（美式惯例）、en dash 表数字区间、em dash 分隔插入成分
- [ ] 缩写首次出现给全称；拉丁缩写（e.g./i.e./etc./cf./ibid.）使用得当且体例统一
- [ ] 引文改动全部留痕：省略用省略号、增改用方括号、存疑用 [sic]、强调标 emphasis added；省略未删去 not/always 等限定语；直接引用语法融于句子且标页码
- [ ] 表格：表题/列头/来源注释齐全，小数点位对齐、精度一致；图版编号连续；正文均按 Fig./Figure、Tab./Table 体例指涉
- [ ] 学位论文：页边距/行距符合规范；页码双轨（前置部分罗马、正文阿拉伯）；前置部分顺序完整（封面/授权页/摘要/目录/图表清单）
