## 一、文献检索策略

### 1. 关键词设计（Wilson《Academic Writing》Ch.29/32）
- **先自问后检索**：研究主题是什么？核心材料/对象是什么？关键人物是谁？需要哪些历史背景与理论概念？——对每一项答案**再列同义词**，形成关键词清单。
- 示例：研究 "Renaissance theology"，应扩展出 early-modern / sixteenth century / Elizabethan / religion / spirituality。
- **进阶检索语法**：布尔连接词（AND/OR/NOT）、短语精确匹配（加引号）、截词符（psychopath* 匹配 psychopaths/psychopathy…）、通配符（wom?n 匹配 woman/women）。
- 检索是迭代过程：边检索边发现哪个关键词组合最有效、并吸收新出现的关键词。

### 2. 数据库与资源分层（Wilson Ch.30/32/33；Handbook 第 5 章）
- **三层信息质量**：①低质量公共来源（无作者、无审校的网页，绝不可引用）；②高质量公共来源（有编辑团队的报刊媒体，可用于背景）；③学术来源（经同行评审的期刊、大学出版社书籍）——**综述只以第③层为主**。
- **参考工具书定位**：Wikipedia/教科书/百科全书/手册是"熟悉话题"的资源而非引用来源（"a resource, not a source"），但它们的参考文献表是极佳的初始书目来源。
- **检索顺序**：学科参考工具书 → 学科书目/指南 → 学科数据库与期刊 → 综合数据库（JSTOR、Academic Search Complete 等）→ 图书馆馆藏目录与书架浏览。Handbook 建议先从百科、年鉴、词典获背景，再查专业百科、书目与手册，最后查索引与数据库。
- 建立工作书目（working bibliography），配文献管理软件（EndNote/Zotero）；经验参考：**每页论文约对应 1 条参考文献**。

### 3. 引文追踪法（后向/前向）
- **后向追踪（mining references）**：精读一篇高相关文献时，细查其参考文献与注释，顺藤摸瓜找更早、更相关的来源。
- **前向追踪（Cited By）**：用 Google Scholar 的 "Cited By" 找引用该文的新文献；配合 "Related Articles" 找平行文献。反复交替点击"前向 + 后向"，即可同时构建较旧与较新的文献网。
- **识别地标文献（landmark scholarship）**：反复出现的作者与作品就是必读的 1–3 篇核心文献。

### 4. 何时停止检索（Handbook Ch.5）
- 检索前**写下研究问题**并放在手边，预设检索计划与时间上限，防止在数据库中无限漫游。
- **查到太多**（文献无穷无尽）→ 问题太宽，需收窄重新定义；**查到太少** → 检查是否找错了领域，问题太窄需放宽。
- 停止信号：新检索结果大量重复已收藏条目、关键地名文献（landmark works）已覆盖、"你对领域内已有什么有了把握感"（Wilson 称之为 Repetition and Confidence）。新领域可从综述性摘要期刊入手，或"从一本一般性著作的参考文献走向具体"。

## 二、论文精读方法

### 1. 表层阅读 vs 细读（Wilson Ch.11 "Close Reading"、Ch.43）
- 精读的对象是**不显然的东西**：表面读法（surface reading）给人一个想当然的结论，细读（close reading）揭示证据并不自动等于结论——"证据不会自我解释，证据需要分析"。同一证据（如逮捕率下降）可支撑截然不同的解读（治安变好 vs 警察消极怠工）。
- 好论点可能为真却无价值（太显然）；**原创性正来自细读**。可操作的策略：用细读反驳/复杂化常识解读；选冷门对象挑战通行假设；选热门对象给出新的读法；或从具体个案外推出可推广的理论。
- 分层阅读：先速读（标题—摘要—图表—引言—结论）判断相关性与价值，再对**少数核心文献做精读与批注**；多数文献只需读其"论证要素"。

### 2. 批判性阅读提问清单（改编自 Handbook Checklist 4 与 Wilson 论证要素框架）
- 论证结构：作者的问题/争议（problem）是什么？主张（thesis）是什么？利害（stakes/implications）是什么？
- 证据：支持主张的证据是什么类型（一手/二手/引用证据）？证据是否真的支撑结论？统计如何采集、意味着什么？
- 方法：用了什么解释方法/理论立场？方法有何局限？换一种方法结论会变吗？
- 概念：术语是否界定清楚？各文献对同一术语用法是否一致？
- 可信度：信息多旧？作者是否权威？发表刊物是否同行评审？各论点相对强弱如何？
- 综合：该文与已有共识一致还是存在争论？它留下了什么没回答的问题？

### 3. 阅读笔记方法（Wilson Ch.36 "Annotated Bibliographies"；Handbook "Taking Notes"）
- **一句话总结**：每篇文献先给出一句"某学者针对某问题，用某方法，论证了某观点"式的概括。
- **300 词结构化注释**（annotation）：引用信息 → 作者专长 → 研究对象 → 介入的争议 → 方法 → 核心论点 → 关键证据 → 意义/局限。优秀注释不逐项齐全，而是突出该文独特之处。
- 注释三型：描述型（客观概括）、评价型（指出强弱）、前瞻型（说明"我在自己论文中如何使用它"）——写综述时最有用的是**前瞻型**。
- **批判性批注**：边读边在页边标注论证要素（问题、方法、论点、证据、反驳），并记录同意/反对之处。
- **引用卡/摘录规则**：随手记页码；逐字引用必须原样抄录并附页码，防止后续误引或"马赛克式抄袭"（mosaic plagiarism：换词不改结构仍算抄袭；彻底转述但忘了标注也算抄袭）。

## 三、文献矩阵（Synthesis Matrix）

### 1. 为什么需要矩阵
- 单篇注释解决"每篇讲了什么"，矩阵解决"文献彼此说什么"——即 Wilson 所说的让文献**互相对话**（putting critics in conversation）。写作注释的总引言（headnote）时，正是靠观察文献间的呼应与矛盾来改写每条注释。

### 2. 矩阵的典型列设计
| 文献 | 研究问题 | 理论/方法 | 数据/证据 | 核心结论 | 局限 | 所属流派 | 与本文关系 |

- 行=文献，列=论证要素。填写时强制自己用可比粒度回答每个单元格，横向一列扫过去即是**该维度上的流派分布**（如"方法列"一眼看出全是横断面数据、无人做纵向追踪）。

### 3. 从矩阵发现空白
- **覆盖检查**：某列整列稀疏/同质 → 该维度被忽视（研究空白）；结论列彼此冲突 → 存在争议；时间列显示十年无人跟进 → 新现象未研究。
- 对应 Wilson 的六种合法缺口：重定向（Redirect）、进一步发展前人观点（Further Development）、新现象（New Phenomenon）、纠正错误解读（Mistaken Interpretation）、深挖奠基性论战（Giant Killer）、方法论介入（Methodological Intervention）。
- 由此，矩阵直接产出综述的**组织骨架**（按流派分段）与论文的合法性论证（question/problem2：学术对话中的不足）。

## 四、综述写作结构

### 1. 定位与目的
- Handbook：综述是对指向研究问题的文献群的审慎考察，是研究作为累积科学的体现；首要功能是**检验研究问题**——若问题已被回答，必须修改问题。
- Wilson：综述不是"谁说了什么"的清单，而应是"**对分析的再分析、对批评家的再批评**"——综述本身要有论点，论点即"为什么在已有研究之后还需要你这篇论文"。

### 2. 组织方式
- **按流派/阵营分组**（camps）：可按时段、理论取向或论点立场分组，叙述各阵营的历史与局限（Handbook 亦建议注意知识发展的时间顺序 chronology）。
- **"最新+奠基"并重**：既收录最前沿文献，也收录领域奠基之作。
- 结构嵌入引言（Wilson 模板）：第 1 段问题陈述（orientation→证据→分析→problem1）→ 第 2 段综述（文本→学术文献→分析→problem2）→ 第 3 段论点陈述（术语→thesis→stakes）。
- 两种正当化策略可组合使用："**全错法**"（已有解读皆有偏差，我来纠正）与"**全对法**"（已有解读皆有价值但留有空白/盲点，我来补足）。切勿制造假冲突——若某学者已把问题说尽且说好，你就不该再写这篇论文。

### 3. 述评比例与段落级写法
- **以评带述**：引文是学术通货，但综述中每段文献都应服务于你的问题。可操作的配比约 7:3：七成篇幅做跨文献的概括、比较、串联（用你自己的话 summarize/paraphrase），三成用于关键处的直引与评价。
- 直引他人批评性文献仅限三种情况：①提供了关键术语/概念；②无法更简洁地转述；③你正在反驳它（让他自己开口，避免歪曲对方立场）。
- **段落级模板**：每段以"流派 A 主张 X（引文串）→ 流派 B 主张 Y → 两者的分歧/共同盲点 → 由此引出本段小结或过渡到下一段的悬而未决问题"推进；段尾的问题即推进链条的钩子。
- 正确转述防抄袭阶梯：逐字引用→马赛克改词（禁止）→标注来源的完整转述（合格）→标注来源的原创性概括（最佳）。

### 4. 体例（EAP Unit A6 的启示）
- 学术文本是**体裁（genre）**：研究论文有公认的修辞步（moves）结构；综述所处的引言段承担"确立领域→确立空隙→占据空隙"（CARS，见 Handbook 引言三阶段）的体裁功能。
- 引用即**互文性（intertextuality）**：显性互文（引用、转述、综述）表明你的文本回应既有话语；写综述时意识到每个句子都在与先前文本对话，有助于从罗列转向论证。
- 学科差异：理工科倾向压制人称、以图表承载论证；人文社科常用第一人称——综述的语气与引用密度应与目标学科体裁一致。

## 五、综述中常见的英语表达错误与修正（Brittman）

| 习惯性错误 | 错误示例 → 修正 |
|---|---|
| 漏用冠词 a/an/the（最高频错误） | "on surface of main blades" → "on **the** surface of **the** main blades" |
| 超长句（≥60 词，中式一句话塞多个论点） | 拆成每句 1–2 个主题；列表信息改用项目符号或表格 |
| 先摆目的/地点/原因再说主句 | "For the application in X, this paper studies Y" → "**This paper studies Y** for application in X"（主旨置句首） |
| 时间状语一律放开头 | "When U is taken as..., the BDs are shown in Fig. 8" → "**Figure 8 shows** the BDs ... **when** U is taken as the control parameter" |
| 误用/滥用 respectively | 仅在两个列表按序一一对应且顺序对意义重要时使用，置于句尾："...are 0.600 and 0.400, **respectively**." |
| 滥用 "In this paper / in this study" | 全文超过 3 次即过多；study=研究工作，paper=承载文章，不可混用 |
| such as 与 etc. 连用（冗余） | "such as A, B and etc." → "such as A and B"（完整列举用冒号加列） |
| 句首用阿拉伯数字或缩写 | "12 parameters..." → "**Twelve** parameters..."；"Fig. 8 shows..." → "**Figure 8** shows..." |
| literature 加复数 | "literatures" → "**literature**"（指研究文献时单复数同形，综述写作尤须注意） |
| 冗余短语 | research work→research；simulation results→results（择一即可） |
| different/various/数词后名词须复数 | different node→different **nodes** |
| How to... 起句 | "How to find X is the objective" → "**Determining** how to find X is the objective" |
| 滥用 obviously / that is to say / namely | 直接陈述主张，删 obviously；一句话说清，少用"也就是说" |
| 本土化表达 | "at home and abroad / our country" → "**in China**" |
| 方程与符号入文 | "If SOC > SOClo" → "If the power battery SOC **is greater than** SOClo"（方程应被引入而非替代文字） |

对综述的特别提醒：综述句多为"某作者 + 报告动词 + 转述"结构，注意主旨句前置、单句单义、术语统一（同一概念各文献若用词不同，需先定义统一）。

## 六、可直接执行的文献综述 Checklist

**检索阶段**
- [ ] 已列出研究问题并置于检索界面旁，设定检索时限
- [ ] 关键词清单含同义词与英文变体，已用布尔/截词语法在学科数据库逐一检索
- [ ] 对核心文献同时做了后向追踪（参考文献）与前向追踪（Cited By）
- [ ] 已识别 1–3 篇必读地标文献，新旧文献兼备
- [ ] 结果重复率高、无新增相关条目（停止信号）——问题不太宽也不太窄
- [ ] 所有来源均来自同行评审渠道；低质量网页未进入书目

**阅读与笔记阶段**
- [ ] 每篇文献有一句话总结（问题—方法—论点）
- [ ] 核心文献有 200–400 词结构化注释，含批判性评价与"我将如何使用"
- [ ] 逐字引文均带页码原样抄录；转述均已彻底改写并标注来源
- [ ] 已建立文献矩阵（问题/方法/数据/结论/局限/流派/与本文关系各列齐全）

**综合与写作阶段**
- [ ] 综述按流派/主题/方法组织，而非逐篇罗列
- [ ] 综述中有明确论点：指出空白（全对法）或误读（全错法），并合法（未制造假冲突）
- [ ] 述评约 7:3；直引仅用于关键概念、不可再简或正被反驳之处
- [ ] 每段以文献间对比或悬而未决的问题收尾，段落间有推进逻辑
- [ ] 引言结构完整：领域铺垫 → problem1 → 综述 → problem2（学术对话之不足）→ 论点与利害
- [ ] 已回答：领域已知什么？知识发展时序？空白在哪？共识与争论各是什么？我的研究由综述指向何方？
- [ ] 术语已界定且各来源用法一致；数据新旧与时效已核查

**语言自查（Brittman 清单）**
- [ ] 无漏冠词；无 60 词以上长句；主旨置句首
- [ ] respectively / such as / in this paper 用法正确；无 literatures 误复数
- [ ] 句首无数字与缩写；无 obviously、How to 起句等中式习惯
