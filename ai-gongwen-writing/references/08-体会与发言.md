# 体会与发言

包含三类：**读书心得**、**培训体会**、**座谈发言**。共同点是"第一人称 + 有思想性 + 体现个人思考"。

| 类型 | 材料来源 | 主体结构 |
|---|---|---|
| 读书心得 | 一本书 + 本职岗位 | 3个子部分（观点/实践/自我） |
| 培训体会 | 一次培训 | 收获感悟部分 + 规划打算部分 |
| 座谈发言 | 一个座谈会主题 | 主体段1/2/3 + 结尾段 |

---

## 一、读书心得

### 写作公式

```
读书心得篇章 = 标题 + 帽段 + 主体子部分1 + 主体子部分2 + 主体子部分3 + 结尾段

标题 = 主标题（《书名》读书心得）+ 副标题（心得的核心观点）
帽段 = 书籍概况句 + 阅读动机句 + 书籍主旨提炼句 + 初步收获概览句

主体子部分 = 子标题（体会句）
           + 段1（核心观点句 + 对观点的理解阐述句 + 认知提升句）
           + 段2（行业背景句 + 实践对接句 + 成效预期句）
           + 段3（个人现状评估句 + 问题发现与剖析句 + 工作改善思路句 + 具体行动方向句）

结尾段 = 综述论点句 + 下一步希望愿景句
```

### 第一步 ·【内容分析】提示词

```
请分析彼得·德鲁克《卓有成效的管理者》这本书的内容与理论启示。
```

### 第二步 ·【职位分析】提示词

```
我是一家国有银行省级分行的人力资源部中层管理者，主要负责人力资源规划与管理、招聘与配置、培训开发等工作，请分析这个职位对个人能力的要求。
```

### 第三步 ·【关联分析】提示词（书 ↔ 岗位）

```
请结合上述分析，为我选择《卓有成效的管理者》中与我的本职工作联系最紧密、最有启发的三个理论点，并说明理由，以有序列表形式呈现。
```

### 第四步 ·【读书心得】提示词（逐部分确认）

```
你是国有银行省级分行人力资源部中层管理者，请结合【阅读体会】内容，按照【读书心得的写作公式】，撰写一篇《卓有成效的管理者》读书心得。要求：1.语言表达有思想性，体现个人思考；2.内容中不需要出现写作公式中的××句这样的表述，直接生成内容；3.字数2500字。先生成标题和帽段，我确认并输入"OK"后，再生成下一个部分"主体子部分1"，以此类推，逐个部分生成，每次都需要确认后再继续生成，明确要求，请回复"好的"。
#读书心得写作公式
#阅读体会
```

###【修改标题】提示词

```

```

## 二、培训体会

### 写作公式

```
培训体会篇章 = 标题 + 帽段 + 收获感悟部分 + 规划打算部分 + 结尾段

标题 = "培训项目名称" + 培训体会
帽段 = 培训概况句 + 参训原因句 + 表达感谢句 + 培训总体收获句 + 过渡句

收获感悟部分 = 段1（培训体会子标题 + 培训价值点句 + 体会收获句 + 认知提升句）
             + 段2（同上）+ 段3（同上）+ 段4（同上）

规划打算部分 = 承接过渡句
             + 段1（规划打算子标题 + 自身反思句 + 培训成果运用句）
             + 段2（同上）+ 段3（同上）

结尾段 = 整体培训收获句 + 对职业发展期待愿景句 + 对企业感恩回馈与承诺句
```

### 第一步 ·【提炼价值】提示词

```
我是一名国企办公室工作人员，请根据下列【培训内容】，分析该培训对我在办公室工作的价值点。
#培训内容
```

### 第二步 ·【内容合并】提示词

```
请对这6点内容按照逻辑层次进行合并归纳删减，整合成3个方面最有作用的价值点。
```

### 第三步 ·【联系分析】提示词（成果应用方向）

```
结合上述分析，列举我接下来在办公室工作中应用培训成果的方向。
```

### 第四步 ·【培训体会】提示词（逐部分确认）

```
你是一名国企办公室工作人员，擅长公文写作，请按照【培训体会写作公式】，结合【培训价值点】和【培训成果应用方向】撰写一篇培训体会。培训项目名称是"AI赋能职场写作"，要求：1.语言表达有思想性，体现个人思考；2.内容中不需要出现写作公式中的××句这样的表述，直接生成内容；3.字数2000字。先生成标题和帽段，我确认并输入"OK"后，再生成下一个部分"收获感悟部分"，以此类推，逐个部分生成，每次都需要确认后再继续生成。请问是否明确要求，明确请回复"好的"。

#培训价值点

```

## 三、座谈发言

### 写作公式

```
座谈发言篇章 = 标题 + 帽段 + 主体段1 + 主体段2 + 主体段3 + 结尾段

标题 = 在××座谈会上的发言
帽段 = 自我介绍句 + 表达感谢句 + 过渡句

主体段 = 子标题（阐述观点）+ 论证观点句 + 现状分析句 + 关联本职工作句 + 规划工作打算句

结尾段 = 感想总结句 + 展望未来句
```

### 第一步 ·【立意分析】提示词（找切入点）

```
你是央企总部办公室主任，擅长公文写作，了解国企公文写作特点。我是一家能源类国企青年中层干部，刚刚提拔到战略规划部门负责相关工作。根据公司安排，五四青年节公司领导要组织新提拔的青年中层干部进行座谈会，座谈会主题是——"五四精神，青春担当——共筑××公司未来新篇章"，每人座谈发言时间10分钟以内。请结合战略规划部门特点，为我分析并列举10个座谈会发言主题切入点，并进行解释。要求：切入点具体落地，以有序列表形式呈现。
```

### 第二步 ·【分解论点】提示词

```
请围绕"数字化转型与智能化战略：青年力量的驱动作用"进行座谈会发言展开论述，结合战略规划部门具体工作，列出三个分论点。
```

### 第三步 ·【座谈发言】提示词（逐部分确认）


## 体会与发言写作要点

1. **必须第一人称**，体现个人思考，不能写成工作汇报
2. 帽段都要有"感谢"，结尾都要有"展望"
3. 子标题字数一致、结构一致（对仗式）
4. 主体段遵循「观点 → 理解 → 实践 → 自我剖析 → 行动」的递进
5. 发言时长换算：10分钟 ≈ 1500字
6. 此类材料一律**逐部分生成 + 用户确认**，不要一次出全文
