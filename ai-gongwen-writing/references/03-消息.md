# 消息（新闻稿）

消息分四类：**会议消息**、**活动消息**、**动态消息**、**典型消息**。前三类是常规新闻稿，**典型消息**是深度报道，需破题角度 + 现场描写 + 直接引语。

| 类型 | 场景 | 篇幅 |
|---|---|---|
| 会议消息 | 报道一次会议 | 500字 |
| 活动消息 | 报道一次活动/培训 | 500字 |
| 动态消息 | 报道一个动态亮点（新产品、新成果） | 500字 |
| 典型消息 | 深度报道，记者视角 | 800字 |

---

## 一、会议消息

### 写作公式

```
会议消息篇章 = 标题 + 导语 + 正文段（会议背景+议程概述）+ 正文段（领导讲话要点）
            + 正文段（代表发言要点）+ 正文段（会议决议要点）+ 正文段（会议意义）

标题 = 主标题（会议主题）+ 副标题（会议名称）
导语 = 会议基本信息句 + 会议目的句 + 主要参会领导
```

精简版（要素不足时使用）：

```
会议消息篇章 = 标题 + 导语 + 正文段（会议背景+议程概述）+ 正文段（领导讲话要点）+ 正文段（会议意义）
```

### 生成提示词 ·【会议消息】提示词

```

#会议基本信息
#会议消息写作公式
```

## 二、活动消息

### 写作公式

```
活动消息篇章 = 标题 + 导语 + 正文段（活动目标）+ 正文段（活动内容）+ 正文段（活动过程概述）+ 正文段（活动意义）

标题 = 活动名称 + 顺利举办/成功举行/圆满开幕
导语 = 活动目标句 + 活动基本信息句 + 参加单位（人员）
```

活动主题：锤炼写作能力 提升行政水平

参加人员：公司各部门、各分公司行政文秘岗工作工作人员共60人

活动消息篇章=标题+导语+正文段（活动目标）+正文段（活动内容）+正文段（活动过程概述）+正文段（活动意义）

## 四、典型消息（深度报道）

### 第一步 ·【寻找新闻角度】提示词

```
你是一名新华社资深记者，有着非常强的新闻敏感性，擅长撰写工业领域新闻。你撰写典型消息稿件时，一般会从哪些角度破题？
```

### 第二步 ·【寻找新闻切入点】提示词

```
你采访了解到，××公司通过与高校科研院所合作，打通产学研链条，研发了国内首个工业设备运行状态管理大模型，该模型具备覆盖冶金、钢铁、化工、电力等行业专用和通用设备的能力，其数据处理和文本理解能力在业内居领先地位。请从技术创新解读的角度分析，可以从什么角度破题进行报道，请列出5个角度。
```

### 写作公式

```
典型消息篇章 = 标题 + 导语段 + 正文段（现状概述）+ 背景段（新闻背景信息）+ 结尾段（展望未来）

标题 = 引题（次要信息）+ 主题（新闻点）
导语段 = 延缓式导语（现场描写）
```

### 生成提示词 ·【典型消息】提示词

```
请重点围绕"产学研合作的创新模式"这个新闻破题角度，撰写一篇消息稿件。要求：1.结合【典型消息写作公式】和【示例消息】进行构思，规划典型消息的行文基调与结构。2.行文中要以"记者"的第一视角观察，要有现场感的描写语句，有采访企业用户、企业和高校科研人员、企业领导、相关政府部门官员的直接引语。语言风格准确、简洁、鲜明、生动，以白描为主。3.字数800字。
#典型消息写作公式
#示例消息
```

---

## 消息类写作要点

1. 导语必须交代 5W1H 中最关键的三项：时间/地点、主体、事件
2. 标题可采用「主标题（虚）+ 副标题（实）」或「引题 + 主题」结构
3. 典型消息必须有**现场描写**与**直接引语**，引语来源要多元（用户、科研人员、领导、官员）
4. 语言以白描为主，避免形容词堆砌
5. 数据、人名、单位名不确定时用 `××` 占位
