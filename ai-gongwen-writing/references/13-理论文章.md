# 理论文章（党报理论版风格）

理论文章是发表在《人民日报》理论版等平台的署名文章，特点是**切口小、论点明、有学理、措施实**。流程分三段：**挖掘选题 → 架构观点 → 论证成文**。

---

## 一、挖掘选题

```

```

## 二、架构观点 ·【架构观点】提示词

```
你是《人民日报》理论版资深编辑，非常熟悉《人民日报》理论版文章的写作风格。请围绕"搭建基础教育资源均衡化的数字桥梁"这个选题方向，为我列出一篇理论文章的核心观点和3-4个分论点。
```

> 核心观点 1 个 + 分论点 3-4 个，是理论文章的标准骨架。分论点之间是并列或递进关系，不能交叉。

---

## 三、写作公式

```
理论文章篇章 = 标题 + 引言段 + 对策分析段1 + 对策分析段2 + 对策分析段3 + 对策分析段4

标题     = 高度概括核心论点
引言段   = 主题句 + 指导思想句 + 工作要求句
对策分析段 = 子标题（分论点）+ 主题句 + 对策句1 + 对策句2 + ……
```

## 理论文章写作要点

1. **选题切口要小**：不要写"论教育现代化"，要写"搭建基础教育资源均衡化的数字桥梁"
2. 标题 = 高度概括的核心论点，不要写成新闻报道式标题
3. 引言段三件套：主题句（是什么）+ 指导思想句（依据什么）+ 工作要求句（要做什么）
4. 每个对策分析段 = 分论点 + 主题句 + N 条具体对策，对策要能落地、可借鉴
5. 语言风格：**客观陈述 + 专业术语**，不用第一人称，不用口号式排比
6. 2000 字左右，**逐个部分输出**确保字数达标
7. 涉及政策文件、数据时用规范表述或 `××` 占位，不得编造
