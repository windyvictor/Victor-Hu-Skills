# 易混文种辨析

用户在写作前最容易搞错的就是"该用哪个文种"。选错文种，公式再对也不合格。本文件按易混组合逐一辨析，并提供一句话判定法。

**使用时机**：SKILL.md 工作流「第 0 步 · 文种选型」时加载。

---

## 一、通知 / 通报 / 通告

| 维度 | 通知 | 通报 | 通告 |
|---|---|---|---|
| 目的 | 告知或部署事务，要求办理 | 表彰先进、批评错误、传达情况 | 向社会公布应当遵守或周知的事项 |
| 对象 | 所属下级机关 | 所属下级机关 | **社会公众**（不特定多数） |
| 是否要求办理 | 是 | 表彰批评类不要求，情况通报提要求 | 否，只需遵守 |
| 实例 | 召开会议的通知、部署森林防火的通知 | 表彰节能先进集体的通报 | 关于××路段封闭施工的通告 |

**判定法**：要别人**去做事** → 通知；要别人**知道并引以为戒/受到鼓舞** → 通报；对象是**社会大众** → 通告。

---

## 二、请示 / 报告

| 维度 | 请示 | 报告 |
|---|---|---|
| 行文方向 | 上行 | 上行 |
| 是否要求答复 | **要求答复** | **不要求答复** |
| 行文时机 | 事前行文（未办先请示） | 事中或事后行文 |
| 内容 | 一文一事 | 可综合汇报 |
| 典型结尾 | "妥否，请批示" | "特此报告" |

**判定法**：需要上级**拍板**才能推进 → 请示；只是**让上级知道** → 报告。

> 常见错误：在报告中夹带请示事项，导致上级无法批复。二者不得混用。

---

## 三、总结 / 汇报 / 述职报告

| 维度 | 工作总结 | 工作汇报 | 述职报告 |
|---|---|---|---|
| 视角 | 单位/部门 | 单位/部门 | **个人** |
| 内容重心 | 做法 + 问题 + 计划 | 主要情况 + 问题 + **建议** | 业绩 + 能力提升 + 问题 + 展望 |
| 受文对象 | 本级存档或报上级 | 上级领导 | 组织/上级（评议用） |
| 是否有"建议"段 | 无 | **有，且与问题对应** | 无（有个人展望） |
| 对应文件 | `07-总结与汇报.md` | `07-总结与汇报.md` | `09-述职报告.md` |

**判定法**：讲**单位做的事** → 总结；要向**上级提建议** → 汇报；讲**我这个人这一年** → 述职。

---

## 四、消息 / 信息 / 通讯

| 维度 | 消息 | 信息 | 通讯（典型消息） |
|---|---|---|---|
| 文体 | 新闻文体 | 政务文体 | 新闻文体 |
| 读者 | 社会公众 | **上级机关** | 社会公众 |
| 内容重心 | 事件本身（5W1H） | **做法 + 数据** | 人物、细节、现场感 |
| 篇幅 | 500 字左右 | 300 字（动态）/ 800 字（经验） | 800 字以上 |
| 是否有现场描写 | 可有 | **严禁** | **必须有** |
| 对应文件 | `03-消息.md` | `04-信息.md` | `03-消息.md` |

**判定法**：给**报纸/公众号读者**看 → 消息；给**上级简报/信息专报**看 → 信息；要深度报道、有记者视角 → 通讯（典型消息）。

> 关键差异：信息里不要写"气氛热烈""掌声不断"，那是消息的写法。

## 五、计划 / 方案 / 规划

| 维度 | 计划 | 方案 | 规划 |
|---|---|---|---|
| 时间跨度 | 年度/专项，通常 1 年以内 | 单次活动/事项 | 3-5 年及以上 |
| 核心内容 | 目标 + 任务 + 保障措施 | **具体流程 + 任务分工 + 条件保障** | 战略方向 + 分阶段目标 |
| 是否有明确执行主体 | 部分有 | **必须有，具体到单位** | 一般没有 |
| 对应文件 | `06-计划与方案.md` | `06-计划与方案.md` | `06-计划与方案.md`（参照计划公式） |

**判定法**：管一段时间的**事** → 计划；管**一次活动怎么办** → 方案；管长远**方向** → 规划。

---

## 六、会议纪要 / 会议记录

| 维度 | 会议纪要 | 会议记录 |
|---|---|---|
| 性质 | **决定性文件**，具有约束力 | 原始素材，无约束力 |
| 内容 | 只写议定结论与要求 | 原样记录所有人发言过程 |
| 表述 | 会议认为/指出/要求/决定 | ×××说："……" |
| 是否可筛选 | **必须筛选**，不写未形成结论的讨论 | 不可筛选，须完整 |

**判定法**：纪要**不是**记录的缩写。凡写入纪要的事项必须有明确结论；无结论的讨论不写入。

---

## 七、感谢信 / 慰问信 / 倡议书

| 维度 | 感谢信 | 慰问信 | 倡议书 |
|---|---|---|---|
| 对象 | 已给予帮助/支持的人 | 作出贡献或处于特殊时点的人 | 需要动员行动的人 |
| 时点 | 事后 | 节日、攻坚期、困难期 | 事前（发动） |
| 必备段落 | 感谢 + **坦诚不足** | 表扬贡献 + **承诺支持** | 意义 + **分条倡议** + 号召 |
| 情感基调 | 真诚、谦逊 | 温暖、鼓舞 | 动员、号召 |

**判定法**：别人**帮了我** → 感谢信；我要**肯定并支持别人** → 慰问信；我要**让别人行动起来** → 倡议书。

---

## 八、理论文章 / 新闻评论 / 工作研究

| 维度 | 理论文章 | 新闻评论 | 工作研究 |
|---|---|---|---|
| 载体 | 党报理论版 | 新闻媒体评论版 | 内部刊物 |
| 逻辑 | 论点 + 分论点 + 对策论证 | 由新闻事件引出观点 | 问题 + 分析 + 对策 |
| 是否引用理论 | **必须有理论依据** | 可少 | 可少 |
| 人称 | 无人称，客观陈述 | 可用第一人称 | 可用第一人称 |

**判定法**：给**党报理论版**投稿 → 理论文章（`13-理论文章.md`）；给**内部刊物**分析问题提对策 → 参照调研报告的对策部分。

## 九、文种选型决策树

```
用户要写材料
│
├─ 是"个人"视角的材料？
│   ├─ 年度履职情况 ──────────→ 述职报告（09）
│   ├─ 读书/培训后的感受 ──────→ 读书心得 / 培训体会（08）
│   └─ 会议上个人发言 ────────→ 座谈发言（08）
│
├─ 是"事件报道"？
│   ├─ 给公众读者看 ──────────→ 消息（03）
│   ├─ 给上级机关看 ──────────→ 信息（04）
│   └─ 会后就会议情况发文 ─────→ 会议纪要（05）
│
├─ 是"要求别人做事"？
│   ├─ 对象是下级机关 ────────→ 通知（01）
│   ├─ 对象是社会公众 ────────→ 通告（16 无专章）
│   └─ 要求落实上级文件 ──────→ 贯彻指示通知（01）
│
├─ 是"评价人与事"？
│   ├─ 表彰先进 / 批评错误 / 通报情况 → 通报（02）
│   └─ 向社会作出评价 ────────→ 公告 / 公报
│
├─ 是"规划下一步"？
│   ├─ 一段时间的工作安排 ────→ 计划（06）
│   └─ 一次活动的组织实施 ────→ 方案（06）
│
├─ 是"向上报告"？
│   ├─ 要求上级答复 ──────────→ 请示（上行文，一文一事）
│   └─ 不需答复 ─────────────→ 报告 / 工作汇报（07）
│
├─ 是"调查研究"？ ────────────→ 调研报告（11）
├─ 是"立规矩"？ ──────────────→ 规章制度（12）
├─ 是"讲道理"？ ──────────────→ 理论文章（13）
└─ 是"领导讲话"？ ────────────→ 领导讲话（14）
```

**选型后仍不确定时**，直接问用户两个问题：① 这份材料的受文对象是谁？② 希望对方读完后做什么（知道 / 去做 / 拍板 / 受激励）？答案即可定位文种。
