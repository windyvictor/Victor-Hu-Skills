# 周报

> 来源：《得到·职场写作训练营》第 05 讲。公文体总结汇报（向上机关正式行文）见 `07-总结与汇报.md`；本文件针对**组织内部周期性周报**。

## 定位

- 周报的本质：**提高工作透明度**，不是记流水账，也不是作文大赛。让同事、领导了解你的工作情况与思考方式，才能更好地协作。
- 三层价值：①周报的写作思路就是你推进工作的核心思路——领导看下属不光看事，还在**选人**；②每周从琐事中跳出来自我校准；③会写周报的人不容易被埋没（周报会跨部门流传，是在管理自己在组织内的品牌）。
- 管理者更要写：周报可"向下写"——向上做了思想汇报，向下指导了工作，还做了培训，一举三得。

## 写作公式

**周报 = 主线任务 + 决策思路 + 情报视野**

### 一、主线任务（上周干了什么、下周干什么）

**最怕两个毛病：接活思维、主次不分。**

#### 1. 用"目标思维"替代"接活思维"——每个任务用三个半句：

```
1.【目标】上周目标完成情况怎么样？（原定目标 → 实际达成 → 差值）
2.【分析原因】基于完成情况，原因是什么？
3.【下一步行动】下周的推进计划是什么？
```

示例（提升转化率一条）：
> 1.【目标】将广告新用户转化率提升至8%。目标为6%，超目标2%，完成任务。
> 2.【分析原因】调整投放品类，其中热门类目：美食、摄影转化提升4%，其余类目综合提升4%。
> 3.【下一步行动】下周准备探索2至3个潜力新品类，测试策略有效性。

#### 2. 可视化

可量化的亮数据；难量化的加**进度条**："完成度40%｜写A活动方案"——给领导掌控感。

#### 3. 主次判断（只写主线，不事无巨细）

属于主线的两个标准（满足其一）：
- 能直接为**组织大目标**服务（"20名用户访谈→18条有效需求→输出A方案"直接作用于"提升用户满意度"）
- 与你的**业绩考核**直接相关（"搭素材库，物料产出比上周多10%"对应效率考核）

**两类不写**：日常例行工作（例会、例行统计）；临时性小忙（打印、接待）。领导要求事事汇报时，把流水账放周报末尾附链的日程表里，周报本体保持重点突出。

### 二、决策思路（最出彩的部分，写透1–2点即可）

让工作的**思考过程**透明化。选材：团队正在攻关的重点问题 / 最近有争议的问题 / 团队共性问题 / 值得推广的好经验。

三种写法：
1. **关键变量**：这件事我关注的关键变量是什么？依据是什么？（选址周报："①租金符合预期：商场给40%补贴、大学城在预算内；②客流量大：商场日均4万人、大学城10万大学生。"）
2. **方案对比**：新方案与旧方案相比解决了什么问题、有什么进步。
3. **潜在风险**：方案优点之外预警风险（"半成品供应商：效率提升约20%；但成本提高2%，口味会变"）——体现掌控感与大局观，帮领导同事做决策。

新人与新管理者也应写：写错了正好请领导一对一纠正（"拿自己的错误答案套领导的正确答案"），比黑箱式工作强得多。**注意**：只对自己做的事、了解的业务发表意见。

### 三、情报视野（加分项，体现格局）

竞品动态、行业前沿、新鲜事。体制内可写"同一系统其他单位值得学习的新动向"。难点在坚持：持续分享 = 给组织释放信号"我是这个方向的前哨兵"，假以时日成为你在公司里的生态位。

## 分步提示词

**生成**：
```
【角色】你是<单位/岗位>的员工，擅长用周报推进工作、展示思考。
【背景】本周主线工作：<1-3项>；各项目标完成情况：<数据>；关键决策：<思考过程>；行业动态：<简述>。
【任务】请按"主线任务（目标/原因/下一步三半句）+决策思路+情报视野"的清单体结构撰写周报，每条一事，行动带绝对时间，量化处用真实数据（未提供用××）。
```

**检查**：是否存在接活思维（只列事项无目标闭环）？是否混入例行琐事？决策思路是否有事实支撑？

**调整**：
- `请把第×条改写为【目标】【分析原因】【下一步行动】三半句结构。`
- `请为第×项补充决策思路，按"关键变量/方案对比/潜在风险"之一展开，数据用××。`
- `请压缩至××字，只保留主线任务，删除例行工作与临时事务。`

## 自检

- [ ] 每条主线任务都是"目标→原因→下一步"闭环，无纯流水账
- [ ] 只写主线（组织目标/考核相关），例行与琐事已剔除
- [ ] 决策思路 1–2 点写透，观点有事实支撑
- [ ] 时间均为绝对时间；整体符合三原则（`19`）
