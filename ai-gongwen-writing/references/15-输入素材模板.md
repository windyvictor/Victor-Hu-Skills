# 输入素材模板

手册中有约 60 处以「（略）」标注的输入材料（如 `#会议基本信息（略）`、`#会议记录（略）`、`#文档1（略）`）。这些是各文种生成的前置输入。

**使用方式**：写某类公文前，先按下面对应模板向用户收集素材；素材齐全再执行生成，避免出现空泛内容。用户未提供的字段用 `××` 占位，不要编造。

---

## 一、通用素材（所有文种）

```
【发文机关】全称或规范化简称：
【受文对象】主送机关 / 受众：
【行文目的】要解决什么问题：
【文种】：
【字数要求】：
【语气要求】指示性 / 指挥性 / 客观陈述 / 恳谈性：
【上级依据】依据的会议、文件、政策名称：
【特殊要求】如需体现的政治表述、地域特色、领导关注点：
```

## 二、会议类素材

### 2.1 会议基本信息（会议通知 / 会议消息用）

```
【会议名称】：
【会议主题】：
【会议背景】召开缘由、上级会议精神：
【会议时间】×月×日（星期×）上午/下午×:××
【会议地点】：
【主办/召集单位】：
【主持人】：
【参会领导】姓名 + 职务（按职务高低排序）：
【参加人员】范围 + 人数：
【会议议程】1. … 2. … 3. …
【会议要求】上报名单截止时间 / 需报送的材料 / 着装与会场纪律 / 联系人 + 电话：
```

### 2.2 活动基本信息（活动消息用）

```
【活动名称】：
【活动主题】：
【活动时间】：
【活动地点】：
【主办/承办单位】：
【参加人员】范围 + 人数：
【活动安排】1. … 2. …
【授课/主讲人及内容】：
【活动目标】希望达成什么效果：
```

### 2.3 动态基本信息（动态消息用）

```
【动态亮点】最值得报道的一件事：
【核心信息】谁、在何时、做了什么、结果如何：
【重要细节】技术参数、规模、首创性、突破点：
【背景信息】行业背景、企业此前基础：
【采访对象与引语】用户 / 科研人员 / 领导 / 相关部门：
【示例稿件】如用户能提供，附上供模仿风格：
```

### 2.4 会议记录（会议纪要 / 会议消息用）

手册中的会议记录格式未给出，建议按下面结构收集，可直接投喂给 AI：

```
【会议时间】：
【会议地点】：
【主持人】：姓名 + 职务
【参会人员】：姓名 + 职务（按职务排序）
【缺席人员】：
【记录人】：

【议题一】关于××××工作
  传达学习：传达了《××》文件精神……
  听取汇报：听取了××部门关于××的汇报，主要内容……
  讨论发言：×××（职务）提出……；×××（职务）提出……
  议定事项：决定……，由××部门牵头，于××月××日前完成

【议题二】关于××××工作
  ……

【其他事项】：
```

> 议题数与顺序必须与用户提供的会议记录一致，纪要不得重排、不得增删议题。

## 三、文件依据类素材

### 3.1 上级文件清单（贯彻指示通知 / 计划 / 汇报 / 制度 / 领导讲话用）

```
【文件一】《全称》（发文机关 + 发文字号 + 发布日期）
  核心要点：1. … 2. …
【文件二】《全称》
  核心要点：1. … 2. …
【政策解读/新闻发布会】名称 + 关键表述：
【上级领导指示精神】原话或要点：
```

### 3.2 本级现状材料（计划 / 汇报 / 调研报告 / 领导讲话用）

```
【基本情况】体量、覆盖范围、发展阶段：
【主要做法】1. … 2. … 3. …
【成效数据】指标名称 + 数值 + 同比/占比：
【存在短板】1. … 2. … 3. …
【与其他地区/单位对比】差距在哪：
【优势资源】本地/本单位独有条件：
```

### 3.3 先进地区/标杆材料（调研报告用）

```
【标杆一】名称 + 做法 + 成效 + 可复制要素：
【标杆二】名称 + 做法 + 成效 + 可复制要素：
【共同特征】…
```

## 六、素材齐全度自检

在开始生成前逐项确认：

- [ ] 发文机关、受文对象、行文目的三项齐全
- [ ] 上级依据的具体文件/会议名称已确认（不得编造）
- [ ] 涉及的数据均有来源；无来源的已用 `××` 占位
- [ ] 人员姓名与职务已确认，或统一用 `××`
- [ ] 字数与语气要求已明确
- [ ] 长篇材料已确认分部分输出的节奏

**任一项缺失时，先向用户提问补齐，不要直接生成。** 这是手册 7 步法中第 2、3 步（分析处理信息、判断信息质量）的落地动作。
