# 职场写作三原则与清单体（心法层）

> 来源：《得到·职场写作训练营》（罗砚），导论 + 第 01–04 讲。本文件是**所有文种通用的质量通则**：体制内公文、职场文体（周报、申请、复盘、方案、发言等）写完都应过一遍三原则自检。与前四讲配套使用：三原则是尺子（评价、避坑），清单体是工具（快速成文）。

---

## 一、总纲：职场写作的本质

- **职场写作 ≠ 文学创作**。文学写作是自我表达，唤起情绪；职场写作要**导向行动**——小到请假条，大到战略报告，都要让读者照着做。
- **终极目标是推进工作**。三个字诀：**快、简洁、准确**。写得短比写得长厉害，写得准比写得漂亮厉害。追求文采反而增加理解成本。
- **把每一步工作都成果化**：职场写作像拍立得，把说完就过的工作瞬间，变成可追溯、可查找、可复用的产品，是撬动个人影响力的大杠杆。
- **写作 = 用户产品**：你不是作家，是产品经理；面向的不是"读者"而是"用户"，你的文字是用户的行动说明书。

## 二、第一原则：导向行动

**公式：导向行动 = 起止时间 + 执行动作 + 赏罚结果**

口诀链：**凡是行动，必有起止；凡是起止，必有执行；凡是执行，必有结果；凡是结果，必有赏罚。**

### 1. 起止时间
- 任何书面沟通都要有意识地安排起始与截止时间，哪怕"长期有效"的事也要先设截止时间再滚动更新（Deadline 是第一生产力）。
- 正式文件时间写法规范：**绝对时间 + 24 小时制**，精确到分。`下周三下午` ✗；`24日下午20:00` ✗（24 小时制不配"下午"）；`2021年2月24日20:00` ✓。截止时间越精确，越能管理预期、促成行动。

### 2. 执行动作
- 少用形容词，多用**祈使句**（动词打头："批复邮件""执行方案""消除故障"）。对设计师说"PPT 要简洁大方" ✗；说"一张 PPT 配色不超过三种、文字不超过三行" ✓。
- 向政府文件学祈使动词的分级：崇尚创新 / 注重协调 / 倡导绿色 / 厚植开放 / 推进共享——动词在交付动作的同时交付了动作的**程度与目标**。
- 所有文体都能导向行动：指令类（通知、纪要）写清指令；要资源类（简历、方案、申请）导向面试/支持/审批；要信任类（年终总结、复盘）导向信任；只传递信息的写明"**请周知**"。

### 3. 赏罚结果
- 赏罚**不是人的赏罚，而是事的赏罚**：把做/不做这件事未来的结果提前展示给对方。
- 正向示例："您要是能在朋友圈推荐一下，这本书当天销量至少能多卖二百本。"
- 负向示例："请于6月22日24:00前确认设计修改。如延迟确认，现场会面临挖掘机空等、人员空闲等问题。"（戳痛点换行动力）
- **硬赏罚有风险**：必须在自己权限内且事先规定；写"晚提交就扣分"易引发对立，应转为"展示不行动的负面影响"——"温馨提示：做好复盘是为公司沉淀经验，根据《××管理办法》，延迟提交复盘，年终考核扣五分。"

### 自检问句
读完这篇文章，读者知道**什么时候做完、具体做什么、做与不做的后果**吗？

## 三、第二原则：用户意识

**公式：用户意识 = 踩油门 + 清路障**

动笔前先答三问：①我的用户是谁？他的需求是什么？②他理解我的意图吗？难点在哪？③他按我的要求行动会遇到什么障碍？

### 踩油门（帮用户理解）
1. **要事优先**：重要的事放开头，别憋在后面。职场里的"要事"一般只有两类：**结论**或**行动**。自问："如果对方只看一段话，我必须让他知道什么？"——述职开头不要写籍贯性别，要写"我竞聘××岗，我的差异化优势是……"。
2. **划出重点**：小标题（路标）、方括号提取关键词（"截止时间【2022年2月8日14:00】"）、加粗/下划线/高亮。**适可而止**——重点划多了等于没重点。
3. **给模板或示范**：用户不是不理解，是不会干。发统一模板 + 填写示范（如政务大厅的示范表），把复杂协作变填空题。

### 清路障（帮用户行动）
1. **消除歧义**：歧义两大高发区——**相对信息**（"下周三""3楼会议室""小王"）与**形容词**（"大力支持""快速融入""要得很急"）。改为绝对信息与可执行标准："新员工入职第一天，上司要请新人吃午饭；入职第一周做一次不少于半小时的正式沟通。"
2. **消除顾虑**：用户明白怎么干但有后顾之忧。例：培训要求"关电脑手机"，补一句"我在上课，有事请留言，课后及时回复"并让大家拍照转发，顾虑即消。通知开会补上"学校停课半天，各班自行安排自习"，有课老师的顾虑即消。
3. **减少协作**：把拆解麻烦留给自己。"给王总发压缩包" ✗；改成"①简单产品介绍 ②对接方式与联系人 ③以上两段您直接转发客户即可" ✓。**把简单留给用户，把复杂留给自己**（复杂指行动复杂度，不是字数）。

## 四、第三原则：默认公开

**公式：默认公开 = 禁得起扩散（对外人）+ 禁得起时间（对后人）**

任何你觉得不能发到网上的文字，就绝不要出现在职场写作里。写东西时心里要装着**三个人**：目标用户 + 外人 + 后人。

### 对外人：禁得起扩散
大众传播天然是漏斗——传播出去的往往只有一句话、一张截图。默认传播会被断章取义。
1. **检查**：发前多问一句"这篇文章被别人看到，会不会有人不高兴、有误解？"（私发领导的复盘邮件被转给全组，因没提帮了大忙的同事而结怨——就是没做这一步。）
2. **永远保持正面情绪**：写职场文章不带负面情绪，负面问题用中性表达。不指责乙方、不在周报里吐槽同事（显得不职业且有理变没理）；不用负面词汇（收割、画饼、洗脑、摸鱼、内卷……）。
3. **缩小对象**（高阶，用于敏感公告）：主动把用户锁定到一类可达成共识的人。看似写给退票用户的《退票公告》，实则分层照顾了现场观众、线上用户、媒体、赞助商、政府——一层一层喊话。

### 对后人：禁得起时间
1. **绝对信息**四条标准：
   - 时间：年月日 + 24 小时制（`2022年3月3日19:00`）
   - 地址：相对完整（"北京市朝阳区东三环"，不只写"东三环"）
   - 人名：写真实全名，不写"小王""陈总"
   - 事名：用全称不用缩写（"小鱼会议系统"不缩成"小鱼"）
2. **标签意识**：文件名/邮件主题可检索。`《上新采购清单》` ✗；`《2022年A渠道秋季上新采购清单》` ✓；周报固定命名 `《2021年第23周竞品调研-H产品》`；多人协作稿件用"文件名+版本+时间+修改人"。

## 五、通用工具：清单体

**公式：清单体 = 列条目 + 涟漪结构**

清单体诞生于手术室（一张手术清单把感染率从 11% 降到 0%），天生导向行动；每条指向一个精准动作。国务院意见、公开信、倡议书等最正式的公文，正文都是清单体——**越是大型的组织文章，越要靠清单体调动大范围共识**。响应"短、实、新"文风要求，清单体是最快捷的落实方式。

### 1. 列条目（一条一事）
- 每条最多三四句话、不超过一百字；一条只写一件事（一个动作 / 一个观点 / 一个角度）；维度变了就另起一条；一条里有两个行动就拆成两条。**宁多写几条，不一条多层**。
- 行动写一条，原因单独写一条；原因有多个，一条一个原因。
- 升级格式：每条 = **小标题 + 核心意思**。小标题三种起法：
  1. 一组同维度关键词（"成立时间/学校地点/授课方式/讲师团队"——这就是分析框架）
  2. 同结构短语，动词打头（"扩大科研经费管理自主权""减轻科研人员事务性负担"——公文标准式）
  3. 格式一致（八字中四字相同，只看不同的字，降低理解负担）

### 2. 涟漪结构（排序）
像石子入水的涟漪，由内向外一圈圈扩散——**用户最关心的放最前**：

| 层 | 内容 | 说明 |
|---|---|---|
| 1 | **行动** | 你需要我干什么（最重要） |
| 2 | **观点** | 我的主张、为什么 |
| 3 | **事实** | 支撑观点的数据与事实 |
| 4 | **视野** | 相关背景延伸（可省略） |

口诀类比：楼下喊人——"下来玩吧"（行动）→"别闷坏了"（观点）→"篮球场刚装修好"（事实）→"昨晚球赛谁表现最好"（视野）。**反面典型**：宏大开头 → 摆历史事实 → 谈观点 → 最后才"来买我的桃子"——头重脚轻，以自我为中心。
- 涟漪结构是金字塔原则（要事优先/归类/MECE）的实操版，写汇报、方案、总结直接套用。
- **事实 vs 观点**口诀（刘润）：**观点无对错，事实有真假**。"公司欠供应商1000万"是事实；"公司周转不灵"是观点。论证目标时（"保底50万冲刺60万，因为组员能拿出超水平销售额"）必须给观点补事实：超水平的定义、对标数据、前三个月的具体数字。

### 3. 适用与变通
- 体制内、创意写作都适用（读库主编老六每篇公众号固定六条）。不放心直接用 1234，可"开头结尾用惯常写法 + 正文清单体"或"自然段 + 小标题"过渡。

## 六、写作前通用三问（结合三原则）

1. 我这篇文章**写给谁**看？他关心什么？（用户）
2. 用户能**准确理解**我的意思吗？（踩油门：要事优先/划重点/给示范）
3. 他**行动时**会遇到什么障碍？我还能帮他做什么？（清路障：消歧义/消顾虑/减协作）

## 七、成稿三原则快检（接入 18-成稿自检清单）

- [ ] 每个行动要素齐全：绝对时间（年月日时分）+ 祈使句动作 + 赏罚/结果展示
- [ ] 要事在开头（结论或行动先行），关键信息有视觉突出且不过度
- [ ] 通篇无相对时间/相对称呼/歧义形容词；敏感内容已按"外人视角"检查
- [ ] 后人可查：绝对信息、可检索命名、共识带背景
- [ ] 长段落已清单化：一条一事，按"行动→观点→事实→视野"排序
- [ ] 观点均有事实支撑（观点无对错，事实有真假）
