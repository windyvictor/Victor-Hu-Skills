# 申请（请示资源类）

> 来源：《得到·职场写作训练营》第 07 讲。法定公文"请示"的格式与行文规则见 `16-公文格式规范.md` 与 `17-易混文种辨析.md`；本文件针对**向上要经费、要资源、要岗位**的申请/请示怎么写出说服力。报销类常规申请按单位规章照写即可，不在本文件范围。

## 定位

- 适用场景：追加预算、增加编制、升职/转岗/竞聘申请、采购申请、培训预算等**超出常规**、需要领导权衡取舍甚至跨部门调资源的申请。
- 难点：①要通过文字给领导建立**结实的决策依据**（不能来回对话说服）；②写不好不仅不通过，还会让领导觉得不靠谱。
- 三原则卡位：导向行动=争取批准；用户=领导（且文件会在多部门流转，可能成为领导说服别人的"武器"）；默认公开=写得明白，让所有经手人都愿支持。

## 核心转变：从"许愿式"到"资源投放式"

**公式：申请 = 资源回报 + 风险提示**

写理由之前先摆正**姿态**：
- **许愿式（✗）**：写自己的诉求——"我生活重心在东京，调岗方便""我年龄最大，再不升职机会越来越少"。领导凭什么拿稀缺资源满足你的诉求？
- **资源回报式（✓）**：证明"批准我，对领导/组织有什么好处"——能创造更大价值、更快胜任岗位。

### 一、资源回报（怎么写理由）

反例→正例（转岗申请）：
> ✗ 我的生活重心在东京，工作也调整到东京比较方便。
> ✓ ①入社第一年在本社技术部学习了设计和构造计算的基本知识，参与六个工地技术方案优化项目。②这一年熟知工地运作模式，能快速理解工地负责人的痛点，拿出更好的技术优化方案。③报考了半年后的"技术士"资格证考试。

三层潜台词：**选我，我能胜任 → 我的独特经验能让方案更落地 → 学习意愿和能力有佐证**。

**"解决麻烦式"申请是第一大忌**：
> ✗ "部门业绩不佳，是因为去年大量员工新入职。今年希望通过培训解决这个问题。申请200万培训预算……"——领导心里只会想：业绩不好你怪新人？培训不到位你怎么不早提？
> ✓ "申请200万培训预算，请行业专家开展业务培训。1.培训能拓展思路，几位专家有我部门今年攻关重点问题的行业最佳实践；2.培训能加速团队建设，带来落地方案，缩短自行摸索时间。"

**邀约同理**（沈祖芸邀请函的启示）：不说"我们来学习"，而说"也诚挚期望贵公司对此次访学提出要求——需要我们做哪些案头准备、有哪些教育方面的需求需要我们支持"——把单方面索取变成双向价值交换。

### 二、找不出回报怎么办：目标5要素

发散口诀 **"多快好省爽"**（以200万培训预算为例）：

| 要素 | 追问 | 示例 |
|---|---|---|
| 多 | 业绩/盈利/产品更多？ | 团队能力提升，今年带来更多业务收入 |
| 快 | 速度/效率更高？ | 学习适应更快，解决问题更快 |
| 好 | 品质/口碑更好？ | 给用户提供的服务质量更高 |
| 省 | 少花钱办大事？ | 算上试错成本，培训反而更省 |
| 爽 | 体验更好？ | 团队留存率、忠诚度提高 |

### 三、风险提示 + 预案

- **不要隐瞒风险**：短期你信息多，长期领导信息优势大；瞒报风险，出事时没人挺你（王进步瞒报工具更新风险 → 推广受阻 → 领导未力挺 → 计划流产 → 信誉受损）。
- 写法 = **风险提示 + 预案**：
> 1. 风险提示：此次技术升级可能存在团队磨合风险，需调整工作流程，涉及造价、技术、安全、资料四个部门。
> 2. 预案：已与厂商协商两案——①提供5个同类公司落地方案；②派专业团队为相关部门做业务培训。

- 升职申请的风险 = 坦承不足 + 补齐动作（选**经验型**风险，别选天赋型）：
> ✗ "项目管理跟团队管理有相通之处，相信我能迁移方法……不辜负期望"（表决心无说服力）
> ✓ "我没有管理团队经验，但牵头过双十一等大项目，有工作协调经验。为此我正在上管理训练营，提前补齐管理知识，希望能就管理问题多向领导请教。"

- 风险预案不追求100%解决——展现的是**风险意识 + 已做准备**。

## 分步提示词

**生成**：
```
【角色】你是<单位/岗位>员工，擅长撰写有说服力的资源申请。
【背景】申请事项：<事>；申请资源：<量>；决策者的关注点：<领导近期目标/考核导向>；我方已有的准备：<能力/经验/佐证>；潜在风险与预案：<风险+应对>。
【任务】请按"资源回报（用目标5要素多快好省爽组织收益点）+ 风险提示+预案"的结构撰写申请，全文禁止出现"解决××麻烦"式的诉求表达，用祈使句和事实说话，数据用××。
```

**检查**：是否还有许愿式表述（生活诉求、年龄资历、表决心）？收益点是否都有事实佐证？风险是否隐瞒？

**调整**：
- `请将申请理由从"解决××问题"改写为"资源投放带来的收益"，按多/快/好/省/爽展开。`
- `请补充风险提示与预案部分，风险选经验型，预案体现已做的准备。`
- `请删除表决心式语句，改为用具体行动与数据证明胜任。`

## 自检

- [ ] 全文视角是"资源投放给组织带来什么"，而非"我需要什么"
- [ ] 收益点覆盖目标5要素中至少2–3个，且有事实验证
- [ ] 风险已如实提示并附预案
- [ ] 符合三原则：行动（批什么、何时批）清楚；对外人视角检查过敏感表述（`19`）
