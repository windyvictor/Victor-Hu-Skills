# 述职报告

分两类：**员工述职报告**（个人年度述职）与**领导述职报告**（如党组织书记抓党建述职）。后者要先依据上级通知拟制提纲。

| 类型 | 主体 | 结构差异 |
|---|---|---|
| 员工述职 | 一般工作人员 | 工作业绩与亮点 + 能力素质提升 + 问题与改进 + 展望 |
| 领导述职 | 党组织书记/主要负责人 | 严格按上级通知的述职提纲撰写，不得遗漏 |

---

## 一、员工述职报告

### 写作公式

```
员工述职报告篇章 = 标题 + 帽段 + 工作业绩与亮点部分 + 个人能力与素质提升部分
                + 存在问题与改进措施部分 + 下一步工作展望段

标题 = 202×年度述职报告
帽段 = 岗位职责句 + 年度工作背景句 + 工作定位与理念句 + 工作自我评价句 + 过渡句

工作业绩与亮点部分 = 工作业绩段1 + 工作业绩段2 + 工作业绩段3……（数量根据工作职责及主要业绩确定）
个人能力与素质提升部分 = 理论学习段 + 专业技能段 + 党风廉政段
存在问题与改进措施部分 = 问题分析段1 + 问题分析段2 + 问题分析段3 + ……（3-4个问题段）
下一步工作展望段 = 工作规划段 + 个人职业发展意愿段
```

### 第一步 ·【文件分析】提示词（个人工作 ↔ 上级精神对齐）

```
我是市政府办公室工作人员，请结合这两份文件进行分析，对我的个人年度基本工作情况进行价值提炼，要求：1.我的工作价值点要与Y省文件精神关联；2.将价值点以有序列表进行排列。
```

输入文件：

```
#文档1 个人年度基本工作情况
#文档2 Y省推进作风革命加强机关效能建设的若干规定
```

### 第二步 ·【提炼亮点】提示词

```
你是市政府办公室主任，非常熟悉办公室工作特点，擅长公文写作。请结合【个人工作情况（价值提炼后）】，梳理个人工作情况，提炼出工作业绩与亮点。要求：1.梳理出一、二级标题，标题采用结果导向式标题，体现做法与成果；2.二级标题下列出内容要点，突出与上级精神的关联性。
#个人工作情况（价值提炼后）
```

### 第三步 ·【员工述职报告】提示词（逐部分输出）

```
你是市政府办公室主任，熟悉办公室工作业务，擅长公文写作。我是刚到办公室工作刚满一年的工作人员，请为我撰写一份年终述职报告。按照【员工述职报告写作公式】，参照【工作业绩与亮点】进行撰写，其余内容自行拓展。要求：1.严格按照员工述职报告写作公式各部分要求进行撰写，不能遗漏；2.符合公文语言表达习惯，各部分采用对仗式标题，标题序号层次清晰，行文简洁清晰；3.表达内容要谦虚低调，符合工作一年的新人身份；4.字数2500字。请逐个部分输出，等我确认并回复OK后，你再继续生成。明确任务，请告诉我"好的"。
#员工述职报告写作公式
#个人工作业绩与亮点
```

###【修改标题】提示词

```
请对下面的标题进行修改，要求符合公文对仗式标题要求。
###
一、公文处理：迅速响应，精准执行，提升效能
二、会议组织：精简高效，强化实效，服务决策
三、信息报送与信息公开：敏锐捕捉，高效传播，提升透明度
四、沟通协调与接待工作：积极服务，强化协作，展现良好形象
```

## 二、领导述职报告（以抓党建述职为例）

### 第一步 ·【文件分析】提示词1、提示词2（分析上级通知）

```
你是国企党建工作专家，熟悉国企党建工作相关要求，请为我分析这份文件的内容要点，告诉我哪些是需要重点关注的内容。
```

```
在这份文件中，对抓党建述职报告的写作内容和标准，有什么具体要求？
```

输入文件：

```
#文档3 关于做好202×年度市直公司基层党组织书记抓党建述职评议工作的通知
```

### 第二步 ·【生成框架】提示词（生成述职提纲）

```
请根据上述分析内容，为我拟制一份抓党建述职报告提纲。
```

### 第三步 ·【领导述职报告】提示词（逐部分输出）

```
你是国企党建工作专家，擅长撰写党建工作材料，我是B市电力公司党委书记，根据上级通知要求，要对202×年度抓党建工作进行述职，请根据【抓党建述职报告提纲】，结合【B公司党建工作情况】，为我撰写一份述职报告。要求：1.严格按照抓党建述职报告提纲进行撰写，不能遗漏；2.符合公文语言表达习惯，各部分采用对仗式标题，标题序号层次清晰，行文简洁清晰；3.字数2500字。请逐个部分输出，等我确认并回复OK后，你再继续生成。明确任务，请告诉我"好的"。
#抓党建述职报告提纲
#B市电力公司党建工作情况
```

###【补充内容】提示词

```
在【四、抓牢主责主业，全面压实党建工作责任情况】部分，内容遗漏了第三点【"一岗双责"与"争先赛马"机制运行】，请补充这部分内容，并补充相关工作案例和数据，仅重新输出这部分内容。
```

###【概括提炼】提示词（加理论性主题句）

```
你是国企党建工作专家，擅长撰写党建工作材料，请为下面的内容在段首增加一句主题句。要求：主题句具有理论性，能概括段落内容。
###
党员发展与教育管理。一是队伍壮大，结构优化 全年新发展党员7名，全部符合"双优"标准，党员队伍规模适度增长，结构更加合理。二是教育培训，常抓不懈 扎实开展党员教育培训，依托"智慧党建"平台，实现在线学习常态化，不断提升党员综合素质。三是模范引领，作用凸显 设立"党员示范岗"，党员在技术研发、安全生产、客户服务等领域发挥关键作用，有效提升服务质量和工作效率。
```

## 述职报告写作要点

1. **四个部分缺一不可**：业绩亮点、能力提升、问题改进、下一步展望
2. 能力提升部分固定三件套：理论学习段 + 专业技能段 + 党风廉政段
3. 员工述职语气**谦虚低调**；领导述职语气**担当有力**
4. 个人价值点要与上级文件精神关联，体现政治站位
5. 问题段 3-4 个，改进措施与问题一一对应
6. 一律**逐个部分输出**，每部分确认后再继续
