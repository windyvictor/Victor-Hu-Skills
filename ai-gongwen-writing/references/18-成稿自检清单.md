# 成稿自检清单

手册 7 步法的第 6 步是「判断内容质量」。但手册只给了这一步的名字，没有给可执行的检查项。本文件把它补成可逐项打勾的清单。

**使用时机**：SKILL.md 工作流「第 6 步 · 判断内容质量」时加载。分两部分：先用**通用自检**过一遍，再用**分文种专项自检**核对。

---

## 一、通用自检（所有文种必过）

### 1.1 结构完整性

- [ ] 写作公式中列出的**每一个段落模块**都能在成稿中找到对应段落
- [ ] 段落顺序与公式一致（不得跳段、并段）
- [ ] 帽段具备公式要求的全部句子（如"指导思想句 + 情况背景句 + 工作思路句 + 工作成果句"）
- [ ] 结尾段/结语段未与正文混同

### 1.2 真实性红线

- [ ] **无编造**的政策名称、文件号、领导姓名、单位名称、数据
- [ ] 不掌握的数据一律用 `××` 占位（不用 `xx`、`XX` 混用）
- [ ] 引用的上级文件名称为全称或规范简称，且确实存在
- [ ] 事例来源可追溯（用户提供或明确标注为待补充）

### 1.3 标题规范

- [ ] 文种标题 = 发文机关 + 事由 + 文种（法定公文）
- [ ] 同级子标题**字数一致、结构一致**（对仗式）
- [ ] 做法/成绩段子标题 = 复句（做法 + 结果）
- [ ] 对策/要求段子标题 = 行动导向
- [ ] 成果/收获段子标题 = 结果导向
- [ ] 标题中**无逗号**（信息、动态类标题尤其注意）

### 1.4 层次与序号

- [ ] 序号层次为 `一、` → `（一）` → `1.` → `（1）`，不跳级
- [ ] 括号、引号、书名号之间不加顿号
- [ ] 标点全角，与 `16-公文格式规范.md` 一致

### 1.5 语气与政治表述

- [ ] 指示性语气（部署/贯彻类）用了"要""必须""不得"
- [ ] 指挥性语气（批评通报）严肃明确
- [ ] 客观陈述（理论文章、调研报告）无第一人称
- [ ] 第一人称（心得、体会、发言、述职）体现个人思考
- [ ] 政治表述规范，与最新政策口径一致

### 1.6 公式痕迹清零

- [ ] 成稿中**无**"主题句（why）""支撑句（how）""××句""【帽段公式】"等公式内部表述
- [ ] 无"某某""xxx"等非规范占位（应统一为 `××`）

### 1.7 字数

- [ ] 达到用户要求的字数，或已明确说明偏差与原因
- [ ] 长文（>1500 字）已按部分输出并经用户逐段确认

## 二、分文种专项自检

### 通知（01）

- [ ] 通知缘由段四句齐全：背景 + 依据 + 目的意义 + 引出下文
- [ ] 每个通知事项段有明确事项标题（不写成大段话）
- [ ] 事项之间有执行主体与时限，无交叉重复
- [ ] 结语段单列，未重复前文

### 通报（02）

- [ ] 表彰通报：正文只点领头单位/人员，其余以附件呈现
- [ ] 批评通报：区分"具体要求句"（对当事人）与"面上要求句"（对全体）
- [ ] 情况通报：正面与负面典型单位各点名，数据用 `××`
- [ ] 三类通报均有明确的表彰/处理**决定**，不是只描述不决策

### 消息（03）

- [ ] 导语交代了时间/地点、主体、事件三要素
- [ ] 典型消息有现场描写与**多元来源**的直接引语
- [ ] 语言白描，无形容词堆砌

### 信息（04）

- [ ] 标题 = 地区（单位）+ 主题，中间无逗号
- [ ] 成果句含具体数据
- [ ] 经验信息小标题即段落第一句，未另起主题句
- [ ] **无现场描写**（区别于消息）

### 会议纪要（05）

- [ ] 议题数量与顺序与会议记录**完全一致**
- [ ] 每个议题段三句齐全：议题句 + 会议过程句 + 结论要求句
- [ ] 会议过程动词限于「传达学习/听取/审议/通报」
- [ ] 结论动词限于「认为/指出/要求/强调/决定/明确/号召」
- [ ] 领导排序按职务，主持人单列

### 计划与方案（06）

- [ ] 计划有可量化的工作目标段（总体目标 + 分目标）
- [ ] 分目标标题为**结果导向**，重点任务标题为**行动导向**
- [ ] 保障措施五件套齐全：组织领导、资金投入、政策制度、监督管理、宣传引导
- [ ] 方案有任务分工段（单位名称 + 具体任务）与条件保障段（场地 + 经费）

### 总结与汇报（07）

- [ ] 总结三段齐全：做法 + 问题 + 计划
- [ ] 做法段三句齐全：why + how + what
- [ ] 问题段"把握分寸、客观中立"，未过度自我否定
- [ ] 汇报的建议与问题**一一对应**
- [ ] 主要情况一级标题为"做法 + 成效"复句，二级为结果导向单句

### 体会与发言（08）

- [ ] 第一人称，体现个人思考，非工作汇报口吻
- [ ] 帽段有"感谢"，结尾有"展望"
- [ ] 发言时长换算合理（10 分钟 ≈ 1500 字）

### 述职报告（09）

- [ ] 四部分齐全：业绩亮点 + 能力提升 + 问题改进 + 下一步展望
- [ ] 能力提升三件套齐全：理论学习 + 专业技能 + 党风廉政
- [ ] 问题段 3-4 个，改进措施与问题一一对应
- [ ] 员工述职语气谦虚低调；领导述职贴合上级述职提纲且无遗漏

### 公开信类（10）

- [ ] 帽段与结尾用诗句/金句，首尾呼应
- [ ] 感谢信有"坦诚不足"段；慰问信有"承诺支持"段
- [ ] 倡议段子标题为行动导向对仗式，每条下有多句要求
- [ ] 地方特色介绍按"历史文化 → 自然风光 → 人文景观 → 地区特产"顺序
- [ ] 扩大邀请段用了排比

### 调研报告（11）

- [ ] 三段论齐全：基本情况 + 问题及原因 + 对策建议
- [ ] 每部分都有统领性的"概括段"
- [ ] 帽段写清了调研过程概况（何时、谁、去哪、怎么调研）
- [ ] 对策与问题对应，且从与先进地区的差距中推导而来

### 规章制度（12）

- [ ] 章条式结构：第一章总则 → 各章 → 末章附则
- [ ] 每条可执行（谁、在什么条件下、做什么、怎么做），无宣示性空话
- [ ] 用词规范：多用"应当""不得""由××负责"
- [ ] 已做上位法合规比对，无冲突抵触条款

### 理论文章（13）

- [ ] 选题切口小而具体
- [ ] 核心观点 1 个 + 分论点 3-4 个
- [ ] 引言段三句齐全：主题句 + 指导思想句 + 工作要求句
- [ ] 客观陈述，无第一人称，无口号式排比

### 领导讲话（14）

- [ ] 正文严格按已确认提纲填充，标题无自行增删
- [ ] 一级标题为复句（现状：做法+结果；工作/要求：措施+目标）
- [ ] 三部分小帽段功能未混：现状=总体成就、核心工作=上级要求+思路+目标、工作要求=形势+总体要求
- [ ] 存在问题段只写"问题概述 + 解决决心"，未展开剖析
- [ ] 结尾段 = 归纳点题句 + 号召倡议句

## 三、交付前格式核对

内容通过后，提醒用户按 `16-公文格式规范.md` 完成版式落地：发文机关标志、发文字号（六角括号、不编虚位）、标题字体与回行、层次序数字体、主送机关、附件说明、成文日期、印章、版记、页码。

---

## 四、自检结果的处理

| 发现的问题 | 处理动作 |
|---|---|
| 段落模块缺失 | 补写该段，不并入其他段 |
| 编造了数据/名称 | 立即改为 `××`，并告知用户需补实 |
| 子标题长度参差 | 用 `00-通用方法与模块库.md` 五「标题改写规则」重写 |
| 公式内部表述残留 | 直接改写为正文语言 |
| 字数不足 | 优先在"支撑句（what）"补充事例与数据，不注水 |
| 语气不符 | 按文种重新锁定语气词表后通篇校订 |

**自检未通过的部分不得交付**，先修正再输出。

## 职场写作三原则快检（得到·职场写作训练营，适用于所有文种）

详细通则见 `19-职场写作三原则与清单体.md`，成稿后快速过一遍：

### 导向行动
- [ ] 每个行动要素齐全：**绝对时间**（年月日+24小时制）+ **祈使句动作** + **赏罚/结果展示**（做与不做的后果提前给出）
- [ ] 行动指令无歧义：无相对时间（"下周三"）、无抽象形容词（"大力支持""尽快"）

### 用户意识
- [ ] 要事在开头（结论或行动先行），关键信息有视觉突出且不过度
- [ ] 已给模板/示范（复杂协作变填空题）；已消除顾虑（行动的连带影响有交代）；对方协作动作已降到最少

### 默认公开
- [ ] 外人视角：此文被截图/转发出去，有没有会被误解、冒犯的表述？负面词汇（收割/画饼/摸鱼/内卷…）已清除，负面问题用中性表达
- [ ] 后人视角：全部为绝对信息（时间/地址/真实人名/全称）；文件名与主题可检索；共识与经验带适用背景

### 清单体
- [ ] 长段落已清单化：一条一事（≤100字），按"行动→观点→事实→视野"涟漪排序
- [ ] 观点均有事实支撑（观点无对错，事实有真假）
