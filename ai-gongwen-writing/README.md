# ai-gongwen-writing

> **公文与职场写作**技能库 —— 20+ 公文文种 + 职场文体，每个文种都有写作公式。

## 一句话定位

把一份模糊的公文 / 职场写作需求，变成一份结构对、口径准、可直接交稿的材料。

双来源融合：

- **《梅俊·AI 公文写作工具手册》**：通知、通报、消息、信息、会议纪要、计划方案、
  总结汇报、体会发言、述职报告、公开信、调研报告、规章制度、理论文章、领导讲话等 20+ 文种
- **《得到·职场写作训练营》**：职场写作三原则（导向行动 / 用户意识 / 默认公开）、
  清单体、周报、申请、复盘报告、方案、公开发言、年终总结

每个文种提供：**写作公式 + 分步提示词 + 调整修改提示词**。

## 何时触发

撰写、改写、扩写、压缩、润色公文或职场材料，或询问某类材料怎么写、结构怎么搭、
该用哪个文种。触发词：写通知、写通报、写会议纪要、写总结、写汇报、写请示、写申请、
写报告、写调研报告、写领导讲话、写发言稿、写述职报告、写倡议书、写周报、写复盘、
写方案、写年终总结、写制度、写信息稿、整理会议记录、公文格式、公文改写、公文润色。
