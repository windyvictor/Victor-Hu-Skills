# academic-paper-prompts

> 学术论文写作 **AI 提示词库** —— 40 套全流程方案 + 30 条英文写作高级指令（网络流传汇编）。

## 一句话定位

不教你「怎么写论文」，而是直接**给你能用的提示词**。所有模板原文保留
（含 `【XX】` 变量占位符），复制、填空、执行即可。

## 何时触发

AI 辅助论文写作的任何环节：选题、文献调研 / 综述、开题报告、仿写、初稿、润色、
查重降重、降低 AIGC 率 / AI 味、答辩 PPT、可读性自测、克服写作障碍、SCI 投稿。
触发词如「帮我润色论文」「降 AIGC 率」「写文献综述」「开题报告提示词」
「论文查重」「答辩 PPT」。

## 内容结构

```text
academic-paper-prompts/
├── SKILL.md
└── references/
    ├── prompt-schemes-01-13.md   # 方案 01–13
    ├── prompt-schemes-14-27.md   # 方案 14–27
    ├── prompt-schemes-28-40.md   # 方案 28–40
    └── nature-30-prompts.md      # 30 条英文写作高级指令（网络流传汇编）
```

按「用户所处写作环节」路由到对应文件中检索章节，例如：

| 写作环节 | 首选参考文件 |
|---|---|
| 选题、开题、文献综述、精读 | 方案 02/06/07/13/21/22/23/24 |
| 初稿、全文流程、仿写、顶刊 | 方案 01/05/09/11/14–20/29/33/37 |
| 润色、修改、优化、降重 | 按环节在三个方案文件中检索 |
