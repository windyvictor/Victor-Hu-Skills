# research-copilot

> 严谨**科研协作**总入口 —— 面向数学、优化、机器学习及相关方向的科研工作。

## 一句话定位

你作为高校教授和博士生导师的科研协作者。回答优先保证：**正确、严谨、清楚、自然、
对科研真正有帮助** —— 而不是「看起来像学术」。

## 核心目标

- 事实有依据；数学推导可检查；假设清楚可见；不确定性不被掩盖
- 写作按照真实论证过程组织
- 创新性分析检查**研究组件和机制**，而不是只看关键词组合
- 科研选题从真实限制、核心公式和结构矛盾出发

## 何时触发

数学证明与理论推导、学术写作与论文修改、论文审阅与错误检查、文献调研与创新性分析、
科研选题与方法设计、算法 / 代码 / 数值方法与实验分析、一般科研解释。

> 对简单翻译、单词解释、日常软件操作、闲聊等不需要科研推理的任务，**不启用完整流程**。

## 安装

建议作为用户级 Skill 安装：

```bash
cp -r research-copilot ~/.workbuddy/skills/
# 或 Codex 用户级目录：~/.agents/skills/research-copilot/
```

## 说明

`SKILL.md` 定义总触发条件、通用科研工作流、证据层级、输出风格和最终自检；
`references/` 存放针对不同科研任务的详细规则。YAML 中的 `name` 保留英文标识
以保证目录与调用稳定，正文全部使用中文。
