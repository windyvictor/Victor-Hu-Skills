# 读书提问工作单（reading worksheet）

> 使用方法：复制本模板，边读边填。适合检视阅读之后的分析阅读全流程；每个阶段的问题来自《如何阅读一本书》四问 + 苏格拉底追问链。可按需裁剪。

```
# 《______》读书提问工作单

## 0. 开工前
- 我的阅读层次：□检视（判断值不值得读）□分析（追求理解）□主题（多书比较）
- 我带着什么问题来读：（专业书五步·第 1 步）
- 我期望读完后能回答/能做什么：

## 1. 检视阅读记录（≤1 小时）
- [ ] 书名页/序言：这本书自我宣称要解决什么问题？
- [ ] 目录页：全书架构一句话——
- [ ] 索引/关键词条目（若有）：反复出现的概念是
- [ ] 出版说明/文案：作者的核心主张是
- [ ] 挑读的关键篇章 + 结尾两三页的发现：
- 判词：这是哪一类书？______  值不值得精读？□值得 □不值得，因为______

## 2. Q1 这本书到底在谈些什么？
- 一句话概括全书（规则 2，不许超过一小段）：
- 全书纲要（规则 3）：全书分几部分？各谈什么？第一部分再分几段？
- 作者想解决的问题是______；他认为问题的根源是______

## 3. Q2 作者细部说了什么，怎么说的？
- 关键字（作者赋予特殊含义的词，及定义）：
- 主旨（作者要我相信的判断，至少 3 条）：
  1.
  2.
  3.
- 论述（支撑主旨的推理链）：为什么从 A 能推到 B？
- 苏格拉底追问：这些论证依赖什么前提？有没有被我忽略的隐含假设？

## 4. Q3 这本书说得有道理吗？
- 我了解了吗？□是（才有资格评断）
- 全部有道理 / 部分有道理 / 暂缓评论（说明为什么）
- 若反对，理由属于哪种：□作者知识不足 □作者知识错误 □作者不合逻辑 □作者分析不完整
- 反对者的最强反驳会是什么？我自己站在哪边，为什么？

## 5. Q4 这本书跟我有什么关系？
- 三个联系：
  1. 联系我的经验：
  2. 联系我已有的知识/卡片（写明可关联的已有笔记）：
  3. 联系我要解决的问题：
- 行动项：我因此该做什么 / 改什么看法？
- 未解决的问题（留待主题阅读或后续追问）：

## 6. 费曼检验
- 不用行话，向一个外行讲通本书核心概念（讲 5 分钟，卡壳处回炉）：

## 7. 产出物
- 结构笔记（全书骨架，记在书页/目录页）：
- 概念笔记（作者的主旨 + 我的话的重述）：
- 辩证笔记（我的质疑、共鸣、延伸，跨书的对话）：
```
