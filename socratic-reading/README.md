# socratic-reading

> 用**苏格拉底提问法**读一本书 —— 带着问题读，用追问检验理解。

## 一句话定位

以艾德勒「四层次阅读」为流程骨架，以四个基本问题（苏格拉底式追问链）为思考引擎，
融合《越读者》选书体系与《高效能阅读》速读产出法。

## 四个基本问题（全流程骨架）

1. **这本书到底在谈些什么？**（主题与架构）
2. **作者细部说了什么，怎么说的？**（关键字、主旨、论述）
3. **这本书说得有道理吗？**（评断前必须先说「我了解了」）
4. **这本书跟我有什么关系？**（意义、行动、与既有知识 / 卡片盒的连接）

第四问直接通向笔记系统（卡片盒笔记法）。

## 何时触发

要求读一本书、精读某本书、带读 / 共读、制定阅读计划、写读书笔记的前置阅读理解、
评估一本书值不值得读，或问「这本书讲了什么 / 我该怎么读」。
触发词：苏格拉底阅读法、读书方法、如何阅读一本书、精读、带读、检视阅读、
分析阅读、主题阅读、阅读笔记。
