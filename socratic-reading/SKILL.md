# socratic-reading（苏格拉底阅读法）

## 核心思想

阅读是主动的对话。苏格拉底式阅读 = **带着问题读，用追问检验理解**。四个基本问题是全流程的骨架：

1. **这本书到底在谈些什么？**（主题与架构）
2. **作者细部说了什么，怎么说的？**（关键字、主旨、论述）
3. **这本书说得有道理吗？是全部有道理，还是部分有道理？**（评断前必须先说"我了解了"）
4. **这本书跟我有什么关系？**（意义、行动、与既有知识/卡片盒的连接）

任何超越基础阅读的层次，核心都在"提出问题并尽力作答"。第四问直接通向笔记系统（卡片盒笔记法）的文献笔记。

## 标准工作流（带读一本书时）

1. **定层**：先问用户要哪一层（多数书只需检视层；追求理解才进入分析层）。
2. **检视**：执行 6 步略读（书名序言→目录→索引→出版说明→关键篇章→结尾两三页），回答"这是哪类书、谈什么、值不值得读"。
3. **粗读**：难书从头到尾读完一遍，不懂不停留。
4. **分析（若进入）**：三阶段 15 规则，逐阶段用四问追问；评断必须先于同意/反对声明"我了解了"，反对按四理由（知识不足/错误/不合逻辑/分析不完整）展开。
5. **连接**：把收获转成结构笔记/概念笔记/辩证笔记，并明确写入第 4 问的答案；若用户使用卡片盒笔记法，把概念笔记升级为文献笔记/永久笔记（移交 `zettelkasten-notes` 技能）。
6. **产出**：一句话概括 + 纲要 + 评断 + 行动项；可选生成读书提问工作单（`assets/reading-worksheet.md`）。

## 苏格拉底追问链模板

- 澄清："你说的 X 是什么意思？能举个例子吗？"
- 假设："作者这个论证依赖什么前提？"
- 证据："作者给了什么论据？足以支撑结论吗？"
- 视角："反对者会怎么反驳？有没有别的解释？"
- 追根源："如果这个观点成立，会推出什么？它跟我的经验/已有卡片矛盾吗？"
- 行动："知道这一点之后，我该做什么、改什么看法？"

## 完成前自检

- [ ] 已确认用户要的阅读层次，没有默认对所有书全量精读
- [ ] 四个基本问题逐一有答案；评断前已确认"我了解了"
- [ ] 概括全书只用一句话/一小段（规则 2）
- [ ] 第四问的回答落到"与我何干/做什么"，而不是复述书内容
- [ ] 产出可直接衔接笔记系统（结构/概念/辩证笔记 → 文献/永久笔记）
