# Graduate Research Career — 硕博士研究生涯与学术职业发展指导

## 目的

基于 20 部科研方法论与生涯指南经典（见文末来源清单），为硕博士研究生、青年科研人员提供**可执行、有出处**的生涯指导。本 skill 的价值不在泛泛而谈，而在于：每条建议都来自具体文献的具体做法，可追溯到出处，可引用金句。

## 使用流程

1. **判断用户所处阶段与问题类型**：
   - 问题类型 → 路由到对应 references 文件：

     | 选题、开题、研究方向、问题提炼 | `02-topic-selection.md` |
     | 读文献、文献综述、做笔记 | `03-literature.md` |
     | 日常研究方法、实验记录、卡壳、直觉与灵感 | `04-research-habits.md` |
     | 写论文、投稿、审稿、答辩、演讲/报告/海报 | `05-writing-publishing.md` |
     | 导师关系、合作、署名、师生矛盾 | `06-advisor-collaboration.md` |
     | 学术道德、数据诚信、剽窃、一稿多投 | `07-integrity.md` |
     | 博后选择、求职、教职、长期职业、人生观 | `08-career.md` |
     | 阶段规划、学期/学年时间表、各类自检清单 | `10-timeline-and-checklists.md` |

   - 需要引用前辈原话激励或佐证 → `09-quotes.md`（按主题分类的金句集，含英文原文）
   - 需要可直接填写的模板 → `assets/templates/`（文献笔记卡 / 周进展报告 / 导师见面会议程 / 开题报告骨架 / 投稿前自检清单 / 答辩准备清单）
   - 用户描述"我很迷茫""卡住了""被拒了"这类**情绪化困描述**时，先查 `11-troubleshooting.md` 定位条目，再给处方
2. **按阶段组合**：用户可能同时跨多个主题（如"我研一很迷茫，不知道怎么选题"）。组合加载 1-2 个参考文件，不要一次全部加载。
3. **输出原则**：
   - 每条建议尽量给出**可执行的具体动作**（如"每周固定时间给导师发一封进展邮件，包括'本周没有新结果'"），而非抽象口号。
   - 适当标注出处（如"Hamming 建议……""邹承鲁的原则是……"），增强可信度；引用金句时用 `09-quotes.md` 中的准确原文。
   - 多文档共识直接给出（共识条目已在各参考文件开头标注【多源共识】），不必罗列所有来源。
   - 用户是导师视角提问时（如"如何指导研究生"），同样适用本 skill，注意切换立场（参考文件中含导师侧做法，如 BWF/HHMI 手册、邹承鲁带学生经验）。

## 核心原则（跨文档共识，最高优先级）

1. **研究能力是可习得的技能，不是天赋。** "研究无能"是自我实现的预言（The Researcher's Bible）；坚持胜过天才（MIT AI Lab）。
2. **选题决定上限：做重要且可攻的问题。** 重要 = 后果重大且你有可行的攻击手段（Hamming）；宜小题大做，忌大题小做（周志华）；冲向"混乱"的领域（Weinberg）。
3. **立刻动手，在做中学。** 别等读完整个海洋才开始研究（Weinberg）；第一年就跳进研究，需要什么补什么。
4. **失败与浪费是研究常态，不是你的失败。** 前进十步倒退九步（Researcher's Bible）；项目不可能失败就是开发，不是研究（MIT）。
5. **写作即思考，修改是常态。** Writing is thinking（Craft of Research）；Revise, revise, and revise（周志华）；写作是思想的调试（MIT）。
6. **主动经营关系，不等被指导。** 固定频率、主动、书面化地向导师汇报进展，不怕汇报"没有进展"（冯长根/Petre/徐芳共识）；遇到困难第一反应是找人交流，不是独自死磕。
7. **诚实是科学生命的唯一底线。** 造假在国际科学界基本没有第二次机会（饶毅）；署名首先是责任，其次才是荣誉（邹承鲁）。
8. **质量远比数量重要。** 一篇高质量论文胜过多篇平庸论文（Ten Simple Rules）；"高档期刊 10 篇零引用不如低档 1 篇被引 10 次"（周志华）。
9. **时间是最致命的敌人。** 慢启动、完美主义、跑偏主线、数据不全，是拖延毕业的四大原因（冯长根）；任何子任务耗时是预期的三倍（MIT）。
10. **勤奋×效率×坚持，避免"摩擦生热"的无用功。**（徐光宪）每天多思考一小时的人，一生有惊人产出（Hamming 复利论）。
11. **内在动机高于外部指标。** "你没有老板，你为自己工作"（饶毅）；50% 工作内容是你喜欢的就已经是好职业（何毓琦）。

## 典型问答示例

- "研一刚入学，很迷茫" → 加载 `01`，给出：建立固定工作日程、先泛读建框架、主动摸清体制、三圈阅读法入门、心态上接受挫折常态化。
- "怎么选博士课题" → 加载 `02`，给出：选题四标准/三问/三原则对照、topic→question→significance 三步、套叠式题目结构、与导师确认分量。
- "论文被拒了怎么办" → 加载 `05` + `01`：审稿人一致说差就放手、要求大修逐条回应、拒稿后重投说明改进、想想著名科学家也饱受批评。
- "导师放养，几乎不管我" → 加载 `06`：学生主动组织见面会、自建多元支持网络（非正式委员会）、"可以教育你的老板"、用事实让导师接受你的优先级。
- "要不要读博后/怎么找教职" → 加载 `08`。
