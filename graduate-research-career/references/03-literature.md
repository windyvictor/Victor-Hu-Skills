# 03 文献阅读与笔记

【多源共识】文献要带着问题、批判地读，并区分"事实"与"作者的解释"（贝弗里奇：初学者最普遍的错误是把实验结果与作者解释混为一谈）；先泛读建框架，再精选精读建主干；建立可检索的文献管理体系；引用必读原文。

## 入门路径

- 先读教材/最早专著搞清概念，再读论文——否则"看 20 篇文章认识还没形成"（《研究生学习生活手册》/《50 件事》第 8 条同源："进入一个领域最简单也是最有效的办法是找这个领域最早的论述专著或教材，**不可以在网上乱搜论文**"）；先综述后论著。
- 很多研究人员花一半时间阅读文献——阅读文献要始于今日，可以很快从别人的工作中学到东西（《50 件事》第 1 条）。
- 学会使用 Google Scholar 和各类数据库，以及各类检索方法（《50 件事》第 3 条）。
- 建立合理的知识结构：尽量广地涉猎学科基本知识，尽量深地了解研究领域的方方面面、过去和现在（《50 件事》第 9 条）。
- 数量参考（徐芳）：本科毕业论文前读 20–30 篇、硕士开题前约 50 篇、博士开题前约 100 篇。
- 顺藤摸瓜法（周志华）：请导师/资深学者推荐 → 沿参考文献找齐重要文献；自力更生三步——搞清本领域最重要的刊物/会议 → 找最近几年文章 → 读摘要了解有哪些 topic；一个方向读 20–30 篇就知道哪些问题没解决；重点盯 leading expert 文章指出的待解问题。
- 三圈阅读法（Bible）：每周 1 小时图书馆 skim 新文献和摘要（外圈）→ 中圈读全文做卡片索引 → 内圈核心论文反复读、做习题、联系作者、开讲习班教别人。
- 找 5 篇最相关的外文文献，花一个月反复读懂（《研究生学习生活手册》）；同一本经典反复读多遍，每遍收获不同（《我的研究生五年》）。

## 批判性阅读

- 带着问题读："这有什么错？我怎么用它？"（Bible）——别等灵感，读文献本身就是研究。
- 保持独立思考，警惕"构成学习最大障碍的是已知的东西"（贝弗里奇）；定期翻阅 20–40 种期刊标题，像看报一样大部分略读、少数精读。
- 阅读不应局限于本领域——"独创的精神往往在于把原先未曾想到会有关联的观点联系起来"（贝弗里奇）。
- 分清 primary/secondary/tertiary 来源（Craft）；主动寻找反驳你观点的来源——"你无法真正理解自己的想法，直到你理解理性的人为何会不同意"。
- 两种系统化找问题套路（Craft）：创造性同意（补强证据、推广到新场景）与创造性分歧六型（种类/部分-整体/历史发展/外部因果/视角矛盾）。
- 尽信书不如无书（邹承鲁）；但换材料做模仿性研究"决不能说是高水平的研究"。

## 笔记与管理

- 笔记三分法（Craft）：原文引用 / 自己的转述 / 自己的想法，并记录主张在原文中的角色（主论点还是让步）与置信范围。
- 文件管理（《研究生学习生活手册》）：文献文件名用标题命名、按主题分文件夹、重要文献加 001/002 编号；集中时间看、做好标记批注"否则等于没看"；3–4 个月温习一遍。
- 带说明的文献目录（Petre & Rugg）：建立 100–150 部核心文献清单，记书目信息、阅读时间、你的评价——这是能给自己最好的研究工具。
- 每周记录读过的论文与短评（Bible）；做索引卡片/摘要帮助记忆（贝弗里奇）。
- 知识框架法（徐光宪）：把学到的知识存入脑中"中药铺抽屉"（知识文档树），便于检索、比较、归纳；知识结构如金字塔，一条竹竿是站不直的。
- 引用文章必须亲自看过、核实原文（邹承鲁/手册/Petre）。

## 补充：笔记卡片的解剖（Craft of Research）

- **左上**：作者 / 短题 / 页码；**右上**：keywords（供日后重排检索）；**中部**：summary + 引文 + 自己的评注（**须与引文明确区分**）；**左下**：索书号。
- **纸质笔记四原则**：①录全书目 ②按主题分卡 ③务求准确 ④**务必区分（1）引文（2）转述概括（3）自己想法**。
- **Quote / Paraphrase / Summarize 判据**：Summarize 用于只要要点；Paraphrase 用于词语不重要而意思重要；Quote 用于——词句本身即证据 / 权威之言 / 极其原创能框住讨论 / 需精确指出你要反驳的主张。
- **引用时的完整书目必录项**：书（作者/题名/编者译者/版次/卷/出版地/出版社/年份/页/索书号/ISBN）；期刊文另加刊名/卷期/日期/页；电子资源另加 URL/数据库/访问日期。

## 补充：读来源时的"上下文五条"（Craft，6.6.4）

1. 连作者的论证线索一起记，别只摘结论；2. 记该主张在原文中的角色（主旨 / 次要点 / 限定 / 让步）；3. 记 scope 与 confidence（适用范围与置信度）；4. 别把作者转述的他人观点当成作者自己的观点；5. 记来源为何同意/不同意，以及你为何同意/不同意。

## 补充：来源可靠性的 10 项判据（Craft，5.4.2）

出版社是否可靠 / 是否同行评审 / 作者是否可信学者 / 仅在线者看主办方 / 是否 current / 有无注释与参考文献 / 网站有无书目信息 / 讨论是否 judicious / 是否被好评 / 是否被高频引用。

## 补充：快速略读入口（判断相关性，Craft 5.4.1）

- **书**：索引 → 首末段 → 前言 → 末章 → 编者导言 → 参考文献。
- **文章**：摘要 → 引论与结论 → 小标题段落 → 参考文献。
- **网页**：About → Site Map → 站内搜索。

## 补充：两种阅读姿态（Craft 6.1）

先 **read generously**（不急着找分歧），对确有争议的来源再 **slowly & critically** 读——过早批判会让你读不到作者真正在说什么。

## 补充：MIT 的三阶段论文读法

① 判断有无兴趣（跳读 intro / 目录 / 结论）→ ② 直奔"有干货的那一页"（15 页论文大多可压成 1 页）→ ③ 值得才通读。读时持续自问："How can I use this? 真的做到了它声称的吗？What if...?"

## 补充：追踪前沿的渠道（MIT §3）

- 读实验室近两年的 Working Papers / Memos / Technical Reports（**政治上也很重要**——知道本所在做什么）。
- 顺 **reference graph** 向回追踪；被高频引用的必读；注意两个互不知晓的学派之间的"图断裂"。
- 记录有趣引文，定期去图书馆批量查；订阅子领域邮件列表。
- 读到激动人心的论文，复印 5 份送人；别人说"你读过 X 吗"，立即记下全引文并借去复印。
- 经允许"读别人的桌子"（他们的待读论文堆）和文件柜——常常比图书馆快。
- 接入 **Secret Paper Passing Network**（秘密传论文网络）：潮流工作从"酷人皆知"到见刊至少晚一年。

## 补充：中文文献管理实务

- **文献三分类**（冯长根）：拿到一批论文先分堆——"基本的" / "有时间可以读一读的" / "天知道我为什么要打印这一篇论文"。
- **文献管理五条**（手册）：①文件名＝文章题目 ②不同主题分文件夹 ③看过的归入子文件夹 ④重要文献加 001/002/003 编号 ⑤打孔装硬质文件夹。
- **读文献须知**（手册"搞研究须知"）：先看综述后看论著 / 早动手 / 多数文章看摘要少数看全文 / 集中时间看 / 做好记录和标记 / 准备引用的文章必须亲自看过 / 注意文章参考价值 / 交流是最好的老师 / 最高层次的能力是表达能力。
- **外文文献精读法**（手册）：先找 5 篇最相关的，花一个月反复读懂；读引言时积累好句子；3–4 个月温习一遍。
- **数量标准**（徐芳）：本科毕业论文前 20–30 篇、硕士开题前约 50 篇、博士开题前约 100 篇。
- **定期扫描**（贝弗里奇）：定期翻阅 20–40 种期刊标题，像看报一样大部分略读、少数精读。
- **反例警告**："读太多别人的东西就会像别人一样想""读书是为了知道问题所在，不是为了找答案"（Hamming）——先用自己头脑想透问题，再看文献；倪明选也说"论文读得太多会被洗脑"，折中方案是先泛读建框架、再精选精读建主干。
