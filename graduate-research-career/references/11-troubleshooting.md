# 11 困境速查（诊断 → 处方）

用户描述困扰时，先定位到条目，再按处方给具体动作；每条都注明出处，可引用原话佐证。

| 困境 | 诊断 | 处方（含出处） |
|---|---|---|
| **迷茫、不知从何下手** | 常态化阶段，非个人缺陷 | ①建立固定工作日程并坚持，每晚留一件 easy 任务作次日冷启动（Bible）②先泛读建框架再精读（Bible 三同心圆）③尽量多与每位老师、高年级学生交谈（MIT）④焦虑解决不了问题，脚踏实地默默耕耘才是王道（徐芳）⑤读王汎森《如果让我重做一次研究生》 |
| **拖延** | 任务太大 + 环境干扰 | ①任务切小、列清单、创造无干扰环境（徐芳）②用"简单小事"重建自信再攻难关（徐芳）③时间四象限：把时间花在"重要但不紧急"（BWF）④彻底卡死一周以上 → 承诺"每天只干 1 小时"，几天后多半恢复（MIT）⑤读 Lakien《How to Get Control of Your Time and Your Life》（MIT 推荐） |
| **卡壳、死机** | 可能方向或方法需换，而非能力问题 | ①搁置几天、与外行讨论、用新方法从头开始（贝弗里奇三招）②回到具体例子：彻底探索具体实例，再上抽象理论（MIT）③做子问题恢复心流（MIT）④写 DRAFT 工作论文向小组报告（Bible）⑤让潜意识工作——散步、沐浴、睡前醒后最有利（贝弗里奇/Hamming） |
| **"论文回避症"** | 半意识地逃离论文 | ①察觉即治疗——"你会突然发现修一个废弃操作系统的冷僻 bug 无比迷人且头等重要"（MIT）②把论文当"与领域对话中的一句话"，不必完美（MIT）③写烂稿再改，写作是 debugging（MIT） |
| **完美主义瘫痪** | 高标准误用于起步阶段 | ①高标准只用于成品，不用于初稿（Bible 陷阱 9 Ambitious Paralysis）②写烂稿、极端时把屏幕对比度调到看不见（MIT）③接受一天一页（MIT）④"十步前进九步后退"是常态（Bible） |
| **论文被拒** | 研究常态，非个人失败 | ①审稿人一致说差 → 放手转投；要求大修 → 逐条回应写进 cover letter（Ten Simple Rules）②被拒必须修改再投，绝不原样转投（BWF）③收到意见先冷静几天（BWF）④想想著名科学家也饱受批评（Bible）⑤拒稿后重投时清楚说明"上次错在哪、这次怎么改"（Ten Simple Rules）⑥对审稿人永远礼貌——此后还要共事一生（MIT） |
| **与导师意见冲突** | 需要"有效争论"技巧 | ①带证据争辩；区分"批评你的观点≠攻击你"；用提问代替断言（Petre）②用"自我陈述"：描述影响而非指责（Petre）③若确信自己是对的，用证据说服导师，他也会高兴（Herman 法则 5）④记住"重要的是什么是正确的，而不是谁是正确的"（Herman 法则 2） |
| **导师放养、几乎不管** | 需自建支持网络 | ①自建多元网络：跨组朋友、外所同行、非正式委员会 2–3 人（MIT/Petre）②"可以教育你的老板"——用事实让老板接受你的优先级（Hamming）③自己组织见面会并会后邮件确认（Petre）④每周主动汇报一次，包括"没有进展"（冯长根）⑤无实质导师制只适合彻底自驱者，且至少完成过一个受监督的工作之后再走（MIT） |
| **自我怀疑、冒充者感** | AI 领域无公认进步标准 | ①自我评价在"史上最伟大"与"语无伦次"间震荡是正常的，用他人反馈校准（MIT）②诺奖得主调查：一致回答"始终怀疑自己工作的价值"——持续批判评估正是科学进步的一部分（MIT）③向大量陌生人解释你的工作以重识其难度（MIT）④从"全校最聪明"跌入"被高一个量级碾压"是必经的一年级自尊危机（MIT） |
| **第二年忧郁** | 博士中段的正常低谷 | ①用"图表测试"判断是否属正常阶段并习惯它（Petre）②设可实现的小目标、找明智的人聊、吃巧克力、读自助书（Petre 反制习得性无助）③别孤立自己——固定频率与人交谈的学生更容易成功（Petre） |
| **数据与预期不符 / "难看"的结果** | 可能藏着重要发现 | ①先想"有些重要发现就在这里面"，而不是"影响发论文怎么办"（饶毅）②四种实验结果皆有收获，第四种（完全意外）可能有巨大收获（徐光宪）③诚实给导师看原始结果，不怕难看（饶毅）④"留意意外之事"是研究者的座右铭（贝弗里奇） |
| **时间不够用** | 规划问题，非勤奋问题 | ①自设截止期 + 按里程碑分阶段（冯长根）②砍掉边边角角的任务，做完一件再做下一件（冯长根）③任何子任务耗时是预期的 3 倍——按此放大计划（MIT）④用 KISS 法则；学会说"不"（BWF）⑤不在排版宏、工具、语言设计上耗时间（MIT 时间黑洞黑名单） |
| **想换题 / 换方向** | 需区分"逃避"与"真转向" | ①"一个不断改变任务去追逐新设想的人往往一事无成"（贝弗里奇）②每 6–7 年主动换方向是好的，但要有节奏（何毓琦/Hamming）③方向被判定穷尽时果断独立转向（《我的研究生五年》）④换前与导师谈，别擅自岔开（Ten Simple Rules） |
| **被人抢先（scoop）** | 机会来了必须扑上去 | ①Berkeley 核裂变数据之败：数据在手未及分析，被欧洲抢先（Hamming）②有 idea 就放下一切扑上去（Hamming）③结果尚单薄时先 announce、按住不发，攒厚再投（《我的研究生五年》）④读到"貌似解决了你课题"的论文先别慌——通常只是表面相似，拿给懂你的智者看（MIT） |
| **怕做报告 / 演讲紧张** | 可用演练根治 | ①重要报告绝不首次讲给同行，先在组会试讲，并给六个朋友试讲请批评（Ten Simple Rules/MIT）②在将作报告的空教室排练（情境记忆效应）（MIT）③设计"一周后听众记住的 3 个点"（Ten Simple Rules）④录像回看改坏习惯（Ten Simple Rules）⑤把讲台当舞台，但别超出本性与极限（Ten Simple Rules） |
| **送审等待期焦虑** | 已被指出是可管理的 | ①转移注意力、远离传播焦虑的人、准备求职、短期旅行（徐芳）②等待期做替代活动：散步、整理归档、读与课题无关的书（Petre）③区分"实耗时间"与"任务时间"——等待不是你的时间浪费（Petre） |
| **娱乐成瘾（游戏/刷帖/灌水）** | 曾导致整学期停摆 | ①《我的研究生五年》作者自述游戏（heros/星际/三国群英传）、BBS 灌水、网恋直接导致进度落后②规律作息 + 适度娱乐硬扛寂寞期③不把压力带回家；累了果断离开实验室（冯长根）④身体健康是 1，其他都是 0（徐芳） |
| **不喜欢当前课题** | 别为"容易发表"做自己不爱做的研究 | ①选题第一标准是热情——"nothing less will keep you going"（MIT）②"发表周期病"：你以为完了它还要缠你数年（MIT）③让 passion 驱动，不兴奋就别做（Ten Simple Rules） |
| **毕业快 vs 多发现** | 诚实优先 | ①"毕业快重要还是更多发现重要？"把不方便的结果诚实发表（饶毅）②"捡了一篇文章丢了诺贝尔"是最大的愚蠢（饶毅）③学位论文质量标准=每部分结果都达到能发表的要求（Herman 法则 14） |
| **署名争议** | 需在数据成型时立即谈 | ①开工前谈好第一作者（Ten Simple Rules）②署名讨论在数据成型时立即进行，不要等初稿出来（BWF）③署名首先是责任其次才是荣誉（邹承鲁）④合作前书面写清目标、分工、经费责任、署名期望（BWF） |
| **合作变质** | 有明确止损机制 | ①给对方三次回正轨的机会，之后止损（Ten Simple Rules）②想清楚还需要的最基本帮助并趁早拿到（Ten Simple Rules）③绝不因争一篇文章失去合作、失去长远（饶毅）④合作前用"是否需要合作十一问"自检（BWF） |
| **体力/情绪透支** | 生活平衡是科研的组成部分 | ①不带压力回家、"船到桥门自会直"（冯长根）②把边边角角砍掉，做完一件再做下一件（冯长根）③压力按来源分类求助：师生/学术/家庭/个人分别找不同渠道（徐芳）④运动、冥想、兴趣是科研的组成部分（徐芳）⑤本实验室约一半学生在读期间看过心理治疗师——求助是常态（MIT）⑥治愈书单：Bateson《Advice to a Young Scientist》、Dyson《Disturbing the Universe》、Feynman《Surely You Are Joking》、Hardy《A Mathematician's Apology》、Watson《The Double Helix》（MIT） |
| **"backlash effect"（论文完成后觉得它一文不值）** | 厌倦 + 后见之明，别当真 | ①论文完成后一两个月会觉得它一文不值——别当真；一两年后回看："嘿，挺聪明的嘛！"（MIT）②给论文一个 cooling-off period 再判断（Bible） |
| **攀比焦虑（别人升职/月薪翻番，后悔读研）** | 心态管理问题 | ①"不要因为别人而左右自己的内心——这些都跟你无关"；安心读书做学术，收获内心的宁静（50 件事 21）②不要随便拿两个人比：只看到他得到的，看不到他失去的（50 件事 22）③好工作给能力强的人而非学历高的人（50 件事 32）④内在动机高于外部指标（饶毅/何毓琦，见 08） |
| **觉得基础差、起步太晚、不敢开始** | 自我设限，非事实 | ①"从来就没有太晚的时候"——担心是自然的，但不要因此否定自己的能力（50 件事 35）②研究能力是可习得的技能，"研究无能"是自我实现的预言（Bible）③每天多思考一小时，长期复利惊人（Hamming） |
| **想放弃 / 考虑退学** | 先分清是"真问题"还是阶段低谷 | ①读博只有取得/未取得两种结果，要为坚持找到有力理由（Petre）②对困难要有高容忍度："high tolerance for low results"（MIT）③项目失败≠你失败——它证明你有勇气做难事（MIT）④与导师、同伴、心理咨询谈，别独自决定 |
